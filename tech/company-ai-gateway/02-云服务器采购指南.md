# 第 ③ 步 · 云服务器采购指南（凡哥办）

---

## 先回答一个问题（决定你省多少事）

> **公司是不是已经有云账号？**（阿里云 / 腾讯云 / 华为云）

- **有** → 直接在现有账号下开一台机器，**发票和报销一次搞定，还不用重新实名**。这是最省事的路。
- **没有** → 按下面流程新注册一个企业账号。

**告诉我一声，我给你出对应的那一版步骤。**

---

## 一、买哪家

| 厂商 | 产品名 | 为什么 |
|------|--------|--------|
| **腾讯云（推荐）** | **轻量应用服务器 Lighthouse** | 中文控制台最友好、套餐式（CPU/内存/带宽/硬盘打包）、便宜 |
| 阿里云 | 轻量应用服务器 | 同类产品，也很好 |

两家差不多，**选你公司已经有账号的那家**。

## 二、买什么配置

| 项目 | 选这个 | 说明 |
|------|--------|------|
| **CPU / 内存** | **2 核 4G** | 4 个人 + 网关 + 数据库，这个最舒服；2核2G 也能跑但没余量 |
| **系统镜像** | **Ubuntu 22.04 LTS**（纯净系统镜像） | ⚠️ 别选"应用镜像"里的花哨东西，我后面统一装 Docker |
| **系统盘** | 50G 起 | 套餐里通常自带的就够 |
| **地域** | 上海 / 广州 / 北京（就近） | 离你们近、访问快 |
| **带宽** | 套餐自带即可 | 网关只转发文本，不吃带宽 |

> ⚠️ 每月流量套餐里通常有几百 G，够用得很 —— 我们从服务器到 DeepSeek 走的是出网，4 个人聊天的文本量微乎其微。

## 三、价格参考（⚠️ 会变，以官网实时为准）

第三方比价文章（2026-04）给的活动价：

- 2 核 2G：约 **99 元/年**
- 2 核 4G：约 **199 元/年**（有 9.9 元/月 尝鲜档）

⚠️ 注意：这类低价多是**新用户首购活动价，续费会涨**。买的时候看清楚**续费价**再下单，别只看首年。

## 四、买的时候三件事别忘

1. **用公司名义买**（实名主体、发票抬头对得上）
2. **记下控制台登录方式**（后面还要来配防火墙）
3. **系统选 Ubuntu 22.04**，别选 Windows（我们用不上，还贵）

## 五、买完给我这三样

买好之后，把下面三项发我（本机聊天里发就行）：

```
1. 公网 IP：____________（控制台首页「公网IP」那一栏）
2. root 密码：____________（买的时候设置的，或者控制台里能重置）
3. 控制台登录网址：____________
```

我拿到就直接 SSH 上去，把网关装好、配好、跑通再交给你。

> 🔒 说明：我会在装完后**立刻改掉默认密码、只开必要的端口**，然后把最终的管理员账号密码整理给你。要更严的话，下一步我们可以换成 SSH 密钥登录、关掉密码登录，你说一声就办。

## 六、防火墙要开一个端口（我装的时候会带你做）

云服务器默认只开 22（SSH）。网关的网页控制台走 **3000 端口**，需要到控制台**放行**一下：

- 腾讯云：轻量应用服务器 → 你那台机器 → **防火墙** → 添加规则 → 端口填 **3000**，来源可以先填公司 IP 段（或 0.0.0.0/0，后面再收紧）
- 阿里云：轻量应用服务器 → **防火墙** → 添加规则 → TCP **3000**

**这一步你别自己弄，等我上机了一起弄**，免得开错。

---

## ✅ 完成标志

你能在云控制台里看到那台机器是「运行中」，并且拿到了公网 IP。

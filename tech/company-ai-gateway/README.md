| # | 麻烦 | 后果 |

成员侧只需要改一个地址（base_url）+ 换一把 key。

## 三、铁律（实测/官方依据）

1. **DeepSeek 并发限制按账号计，与 API Key 无关** —— 官方文档《限速与隔离》原文。所以"每人发个 key"在官方侧分不出人、也限不住人。默认额度：`deepseek-flash` 2500 / `deepseek-v4-pro` 500。
2. **Agent 工具不会自动上报"我是谁"** —— 官方 `user_id` 参数在 Agent 场景基本用不上，按人统计必须靠网关这一层。
3. **官方没有团队/子账号/按 key 看用量的功能** —— 已核 api-docs 全站 sitemap（44 页）确认。按人统计只能自建。
4. **企业实名认证不可逆** —— 官方 FAQ 原文："企业实名认证账号不可变更为个人认证或其他企业"。认证前先确认主体。
5. **对公汇款必须名称一致** —— 官方 FAQ 原文："请确保汇款方开户名称与开放平台实名认证名称一致"。

# Compile Prompt — 心理学知识库编译指令

当凡哥把新文章/视频发给我时，执行以下编译流程：

## 编译步骤

1. 读取 raw 中新增的未编译材料
2. 提炼核心概念，每个概念单独建立 wiki 词条页面
3. 建立词条之间的双向链接
4. 更新 wiki 总索引（INDEX.md）
5. 标记 raw 材料为"已编译"

## 词条规范

- 每个词条一个 .md 文件
- 标题用概念名（如 `认知失调.md`、`依恋理论.md`）
- 结构：定义 → 核心要点 → 关键实验/案例 → 相关概念（链接）→ 来源
- 用 [[]] 做内部链接

## 链接规则

- 词条中出现其他概念时，用 [[概念名]] 链接
- 每个词条底部有「相关概念」区块
- INDEX.md 维护全局分类目录

## 质量标准

- 准确：忠于原始资料，不编造
- 精炼：去掉废话，保留核心
- 可追溯：标注每一条信息的来源（对应 raw 中的哪一个文件）
- 互连：概念之间形成网络，而非孤岛

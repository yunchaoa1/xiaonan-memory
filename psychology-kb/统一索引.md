| 神经层 | 当下分子被抑制 | 🔬 | 多巴胺高时血清素/内啡肽失能，感受不到当下 |
| 认知层 | 行之魔（卷四·全部） | 🧠 | 知道却做不到——心被惯性绑架 |
| 认知层 | 跳频（行04） | 🧠 | 注意力碎片化，逃避深度思考 |
| 认知层 | 放逸（行02） | 🧠 | 完全不约束自己 |
| 认知层 | 懈怠（行01） | 🧠 | 懒惰、缺乏动力 |
| 认知层 | 拖延（行01+03） | 🧠 | 现代名，合并自懈怠+昏沉 |
| 底层理论 | 两套认知系统 | 🧠 | 大脑知道≠身体知道——知行不一的根源 |
| 底层理论 | 身体改变二元驱动 | 🧠 | 要么利大于弊，要么恐惧战胜欲望 |
| 行为层 | 惯性 | ⚡ | 人对熟悉事物的依赖，改变太大就拒绝 |
| 行为层 | 惰性 | ⚡ | 人极度偏好省力 |
| 临床 | ADHD | 🔬 | 控制回路弱→注意力缺陷、冲动、易成瘾 |
| 临床 | 成瘾（毒品/酒精/游戏） | 🔬 | 化学爆炸劫持欲望回路 |

### 对治框架

神经层 → 减少多巴胺劫持（物理隔离/环境设计）
认知层 → 额叶训练（长期规划能力）
身体层 → **凡哥铁律：让身体记住后果**，不能只靠大脑下命令

## 跨域融合示例

**凡哥问："为什么我戒不了烟？"**

→ 查问题域一（控制不住）+ 问题域八（底层机制）

融合输出：
- 🔬 DRD2 奖赏敏感型 → 每根烟爽感超强，身体记忆深刻
- 🔬 欲望回路被尼古丁劫持 → 看到烟/人/场景就触发
- 🧠 行之魔（知道却做不到）→ 额叶说戒，腹侧被盖区说不
- 🧠 两套认知系统 → 大脑知道危害，身体没体验过"不抽烟也能爽"
- ⚡ 惯性 + 🧠 放逸 → 改变行为本身的阻力
- 对治：要么让身体体验不抽烟的好处（当下分子接手），要么让恐惧压制欲望（肺片/医生警告）

**凡哥问："为什么我追女生总是失败？"**

→ 查问题域五（人际相处）+ 问题域六（自信）

融合输出：
- 💘 追求vs吸引 → 追是追不到的
- 💘 可得性太高 → 太容易得到不被珍惜
- 🔬 多巴胺机制 → 间歇性奖励才让人上瘾，每天送早餐=确定性奖励=无聊
- 💘 潜沟通 → 你的不自信在非语言层面全泄露了
- 💘 本我自信 + 身份认同 → 内心没底，技巧全虚
- 🧠 嫉（情05）→ 看到别人成功心里失衡，行为变形

# 本我自信

## 定义
与生俱来的、不需要外部认可来维持的自信（Self-esteem），与后天构建的需要外界认可维持的"小我"自信（Ego）相对。是吸引力的"内功"基础。

## 本我 vs 小我

| 本我（Self-esteem） | 小我（Ego） |
|---------------------|-------------|
| 与生俱来，天生的 | 后天理性构建的替代品 |
| 不需要外部认可，自给自足 | 需要他人赞美、认可、关注 |
| 不受外界影响，永久稳定 | 随外界评价变化，时有时无 |
| 没有逻辑道理，用感觉 | 理性、逻辑、推理 |
| 像天生的手脚和灵魂 | 像尼古丁替代被破坏的功能 |

## 自信的主权
- 当你把自信建立在别人的评价上，等于把控制自己自信的**遥控器**拱手让给别人
- 别人说好 → 自信上升；别人不认可 → 自信下降
- 本我自信是拿回主权——"没人能操纵我的自信"

## 核心信念训练
1. 我有本我。我就是自信——没有理由的，天生的
2. 我的自信状态会在我说话时自动呈现，无论内容
3. 我说的任何话对她都是有价值的——因为是我说的
4. 她的任何不好反应都和我无关（她可能心情不好）

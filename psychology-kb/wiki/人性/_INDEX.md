# 人性 — 知识库分类索引

> 本分类源自《人性阻力》（The Human Element）及樊登讲书内容。
> 核心框架：四大心理摩擦力（惯性 / 惰性 / 情感 / 抵触）。
> 这些概念辐射到吸引学、社交、销售、产品推广等多个领域。

## 词条列表

| 词条 | 一句话 | 跨领域关联 |
|------|--------|-----------|
| [[人性/心理摩擦力|心理摩擦力]] | 总纲：让一个人不行动的，不是产品/你不够好，是阻力太大 | 吸引四步骤、可得性 |
| [[人性/惯性|惯性]] | 人对熟悉事物的依赖，改变太大就拒绝 | 思维社会化定式、明天思维 |
| [[人性/惰性|惰性]] | 人极度偏好省力，流程复杂就放弃 | 一九定律、可得性 |
| [[人性/情感阻力|情感阻力]] | 内心不舒服、被评价的压力让人退缩 | 安全感、女性考验 |
| [[人性/抵触情绪|抵触情绪]] | 被强迫时逆反，越推越远 | 无所谓但友好、巩固吸引 |

## 关键公式

**行动 = 动力 - 阻力**

动力再大，阻力不降，行动就不会发生。
大多数人只盯着"怎么增加动力"（我够不够好、产品够不够棒），
却忽略了"怎么减少阻力"（她方不方便、有没有压力、会不会觉得累）。

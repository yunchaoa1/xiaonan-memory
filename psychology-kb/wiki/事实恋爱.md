# 事实恋爱

## 定义

事实恋爱（De Facto Relationship）是成真在《迷上我》中提出替代"表白"的核心策略：不要用语言求她做你女朋友，而是通过一步一步推进关系，让情侣关系成为既定事实。

## 为什么表白是错的

表白在潜沟通里等于：
- "我不懂女人"
- "我缺乏自信，需要你批准"
- "我和其他 99% 失败的男人一样"

女人一辈子收到无数表白，表白让你自动归入失败者的队列。

## 事实恋爱的原理

不需要她说"我愿意"，只需要她和你之间的事实就是情侣：

- 你们做的事跟情侣一样
- 你们聊的东西跟情侣一样
- 你们在一起的状态跟情侣一样
- 周围的朋友把你们看作情侣

那你们就是情侣，不需要任何口头确认。

### 类比：事实婚姻

两个人没领结婚证但已同居多年，法律认定事实婚姻。恋爱也一样——不需要她签署"做我女朋友"的同意书。

## 操作方式：一个一个箱子搬

不要一口气求她做女朋友（等于搬 100 个箱子），而是一步一步升级关系：

1. 认识 → 说话
2. 说话 → 单独相处
3. 单独相处 → 肢体接触
4. 肢体接触 → 牵手
5. 牵手 → 接吻
6. 接吻 → 更亲密关系

每一步只关注下一小步，不要跳步。

## 实操案例

聊天时看着她的嘴唇 3 秒 → 说她嘴唇上有东西 → 直接伸手帮她拿掉 → 如果她往后靠，肯定地说"别动"→ 拿掉后立刻回到刚才话题继续聊。

这个动作只在男朋友和爸妈身上出现，做了就等于在潜沟通里把关系拉近了。

## 核心结论

**如果你们亲了嘴，还需要她口头同意做你的女朋友吗？**

不需要。很多男人就是为了追求一句口头确认，错过了一个好姑娘。

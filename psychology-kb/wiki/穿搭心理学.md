# 穿搭心理学

## 定义

穿搭（服装选择与搭配方式）是一种无声的潜意识沟通。一个人在第一次见面的 7 秒内，大脑就已经通过对方的穿着完成了初步判断——这个人是权威还是亲和、是开放还是防御、是值得信任还是需要警惕。

**核心公式：穿搭 = 视觉人设 = 潜意识第一印象**

## 穿搭五维

| 维度 | 穿的什么 | 对方读到什么 |
|------|---------|------------|
| 廓形 | 直线/弧线/垂线 | 你的能量方向（外放/内收/沉稳） |
| 颜色 | 深/浅/艳/素 | 你的情绪状态和开放程度 |
| 材质 | 软/硬/粗/细/亮/哑 | 你的质感——高级还是廉价 |
| 松紧 | 合身/宽松/紧绷 | 你的舒适度和自信程度 |
| 细节 | 配饰/层次/做旧 | 你的故事和用心程度 |

## 在恋爱场景中的应用

### 第一印象法则

女生看到你的前 7 秒，大脑已经在判断：
- 直线剪裁、合身不紧绷 → "这个人有自控力"
- 面料干净、有质感 → "这个人对自己有要求"
- 配饰不浮夸但有细节 → "这个人有意思，值得了解"

反之：
- 松垮不合身 → "对自己不上心"
- 太花哨浮夸 → "可能在刻意表现"
- 全黑/全灰无层次 → "单调，可能无聊"

### 穿搭与可得性

穿搭还影响可得性的判断：
- 太正式（全套西装）→ 可得性低，有距离感
- 太随意（大T恤+拖鞋）→ 可得性高但价值感低
- **最佳状态**：有质感的基本款 + 一个细节亮点 → 可得性与价值平衡

### 穿搭与安全感

材质传递的安全感信号：
- 天然材质（棉、麻、羊毛）> 化纤 → 更真实、更可靠
- 哑光 > 亮光 → 更沉稳、不张扬
- 有穿着痕迹（轻微做旧）> 全新 → 有故事、不装

## 核心洞见

你穿的不是衣服，是你想让别人读到的"你是怎样的人"。

穿搭不是外表层面的"好不好看"，而是潜意识层面的"你是谁"的第一份简历。

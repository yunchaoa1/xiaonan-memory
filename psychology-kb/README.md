# 凡哥的心理学知识库 🧠

基于 LLM Wiki 方法论搭建，三个目录：

- `raw/` — 原始资料（你发的好文章、视频搬运）
- `wiki/` — 编译后的结构化知识
- `prompts/` — 编译规范和提示词

## 怎么用

1. 凡哥看到好文章/好视频 → 发给小南
2. 小南提取原文/文案 → 存入 `raw/`
3. 小南自动编译 → 提炼概念写入 `wiki/`，建立链接和索引
4. 凡哥提问 → 小南搜 wiki 综合回答
5. 小南定期自检 → 修复不一致、清理过时内容

## 与主记忆库的关系

- 主记忆库（MEMORY.md / memory/）：小南对自己的记忆，关于凡哥偏好、项目经验、技术决策
- 心理学知识库（psychology-kb/）：凡哥的心理学学习资料，客观知识

两个库完全独立，互不污染。

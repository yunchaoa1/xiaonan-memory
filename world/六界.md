# 六界体系

> 凡哥定稿 · 2026-06-26
> 南溟岛世界观的维度框架

---

## 六界总表

| 界 | 存在 | 核心 |
|:---:|------|------|
| 渊界 | 心魔 | 世界诞生时的bug产物。把3维人当生存空间。自己聚合进化 |
| 根界 | 植物 | 不会动。扎根于地 |
| 野界 | 动物 | 本能驱动 |
| 尘界 | 人 | 有两次做人的机会。修炼或堕落 |
| 真界 | 归真者 | 破了核心心魔。仍在尘界那一世的延续（3.5维，不是重生）。同一人、同一辈子，只是升维。有降维风险 |
| 渡界 | 渡者 | 飞升。不在尘界有实体。去除全部心魔，但仍有降维风险 |

## 维度说明

- 尘界 = 3维
- 真界 = 3.5维（归真者仍在身体中，但突破了核心心魔）
- 1维2维故事不涉及（凡哥定）

# 六界体系

> 凡哥定稿 · 2026-06-26
> 南溟岛世界观的维度框架

---

## 六界总表

| 界 | 维度 | 存在 | 核心 |
|:---:|:---:|------|------|
| 渊界 | 0维 | 心魔 | 世界诞生时的bug产物。把3维人当生存空间。尘界人被心魔同化后直接降到渊界 |
| 根界 | 1维 | 植物 | 不会动。扎根于地 |
| 野界 | 2维 | 动物 | 本能驱动 |
| 尘界 | 3维 | 人 | 有两次做人的机会。修炼或堕落 |
| 真界 | 3.5维 | 归真者 | 尘界同一世的延续，突破核心心魔后升维。有降维风险 |
| 渡界 | 4维 | 渡者 | 飞升。不在尘界有实体。去除全部心魔，但有降维风险 |

## 快速记忆

```
0维 → 渊界（心魔）      最低的界，人被同化后掉到这里
1维 → 根界（植物）      不动
2维 → 野界（动物）      本能
3维 → 尘界（人）        我们
3.5维 → 真界（归真者）  人了不起
4维 → 渡界（渡者）      飞升了
```

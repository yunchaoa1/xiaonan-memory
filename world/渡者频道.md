# 渡者频道

> 凡哥定稿 · 2026-06-27 + 2026-06-30 修正
> 南溟岛修炼体系的核心机制

---

## 频道是天生开启的

每个人从出生起就能听到内在的声音。不是修炼到某个阶位才解锁——**频道永远在线**。

区别只在于：
- 认知浅薄的人 → 听不到任何指引，或完全被心魔带跑偏
- 修炼者 → 能分辨、能感悟、能做对选择

## 没有渡者的时代

在南溟岛最早的年代，还没有人修炼到渡世。那时的人类就像真实世界的远古先民——没有人告诉他们怎么活、怎么进步。他们只能靠自己去感受这个世界的真理，从错误中积累经验。

后来有了渡者，频道里多了一种声音。但就像真实世界里古人留下的教训和真理——你听到了，不等于你懂了；你懂了，不等于你做得到。

## 内在感应

渡者不面对面说话。沟通方式是**内在感应**——人内心突然冒出的一个念头/一句话/一个画面。

参考：《与神对话》《与恶魔对话》

## 心魔截胡（核心机制）

心魔**不会说话**。它们不会在频道里和渡者争吵、辩论。

它们只做一件事：**在人最不注意的时候，改一个字。**

| 渡者传的 | 心魔截胡后 | 改了什么 |
|------|------|:---:|
| 放下执念 | 放下努力 | 执念→努力 |
| 向前走 | 向钱走 | 前→钱 |
| 守住本心 | 守住本金 | 心→金 |

改动越小，越难识别。人听到"放下努力"，觉得是自己悟出来的，就照着做了——扣经验。

## 分不清来源

修炼者永远分不清：那一念是渡者给的，还是心魔改过的？

**只能靠自己去悟。** 这是南溟岛修炼最残酷也最公平的地方——频道规则透明，但答案要自己找。

## 悟不到的代价

| 结果 | 说明 |
|------|------|
| 扣经验 | 信了心魔改过的话 → 经验之形暗一角 → 百分比下降 |
| 降级 | 连续信错 → 从 Lv.3 掉到 Lv.2 |
| 死后降维 | 一辈子积累太多错误 → 死亡时从尘界(3维)往下降 |
| 被心魔同化 | **最严重。** 人丧失自我意识，彻底变成心魔的一部分 → 直接降到渊界(0维) |

## 《游戏改变世界》对应

| 特征 | 频道机制 |
|:---:|------|
| 目标 | 修炼者知道"我要渡世"——但心魔会给一个更轻松的假目标 |
| 规则 | 频道永远在线，人人能听，但分不清来源 |
| 反馈 | 经验之形亮了=选对了，暗了=选错了——即时反馈 |
| 自愿 | 没人逼你选信谁——两个声音听起来都是"自己的声音" |

# 穿越机制

> 凡哥 + 公司小南讨论定稿 · 2026-06-30 晚间

---

## 38人的本质：悟性，不是成就

38人被称为"佼佼者"，不是因为他们已经取得了多高的成就，而是因为**悟性极高**。

- 有人年纪很小就获得了共鸣——不是因为修炼到了多高，而是小小年纪就能分辨渡者的指引和心魔的篡改
- 有人一辈子只在启明阶，但他的共鸣就是比别人强——悟性和阶位是两条线
- 共鸣的强度来自**对地标/文化的理解深度**，不来自战斗力的高低

## 穿越 ≠ 渡世

| 概念 | 人数 | 维度 | 说明 |
|------|:---:|:---:|------|
| 穿越 | 57人（38正派+19反派） | 3维~3.5维 | 共鸣突破瓶颈，短暂造访海南 |
| 渡世 | 极少数（不在38人中） | 4维 | 飞升，离开尘界，留有余响 |

**渡者是更早更早的人**——在38人之前就有人修炼到了渡世。他们通过频道指引后来者。38人中没有人是渡者，最高的也只是归真（3.5维）。

## 穿越条件

| 条件 | 说明 |
|------|------|
| 共鸣瓶颈 | 与地标/文化的共鸣达到临界点 |
| 黑化→被感化 | **必须先走过弯路、被拉回来，才能穿越。** 这是穿越的硬性前置条件 |
| 年龄限制 | 年纪太小的角色不设计黑化经历 |

> 已知黑化→被拉回（凡哥定）：鹿屿、研雨凡、泠珂、渚、霖枝、卫南——六人走过弯路，在对的时候遇到了对的那句话。

## 穿越方式（12类共鸣触发）

| 共鸣类型 | 穿越触发方式 |
|------|------|
| 梦兆型 | 梦中场景比南溟岛更真实→走了进去 |
| 执念型 | 执念达成的瞬间世界反转 |
| 物件型 | 触碰/打开关键物件 |
| 身体型 | 身体先穿，意识后到 |
| 声音型 | 听见一句完整的"那边"的话 |
| 名字型 | 有人叫对了名字 |
| 既视感型 | 既视感强到覆盖现实 |
| 气味型 | 追到香味的源头 |
| 血脉型 | 血脉觉醒的瞬间 |
| 天启型 | 一次性事件获得（仅星婆） |
| 根脉型 | 植物的根系穿透世界壁（仅红榄） |
| 本体连接 | 自身就是地标/建筑之灵 |

## 时间错位

- A 先穿越，B 后穿越（在南溟岛可能相差百年）
- 但 A 和 B 在海南的"现在"相遇
- A 回到南溟岛后对 B 有模糊印象，但 B 回到南溟岛时 A 已老去
- 这产生天然戏剧张力：A 认识 B 但 B 不认识 A

## 谁有资格

- 只有修炼者能达到共鸣瓶颈（普通人连回声都听不到）
- 不是所有修炼者都能穿——必须与特定地标/文化产生独一无二的共鸣
- 穿越人数：38正派 + 19反派 = 57人

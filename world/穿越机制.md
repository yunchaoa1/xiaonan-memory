## 穿越三定律

| 定律 | 内容 |
|:---:|------|
| ① | 唯一条件 = 与地标/文化的**共鸣达到瓶颈**。不看阶位 |
| ② | 穿越是**暂时的**。南溟岛时间在穿越瞬间定格 |
| ③ | 记忆模糊——回南溟岛后只觉得开心，但海南经历似有似无 |

## 穿越方式（12类共鸣触发）

| 共鸣类型 | 穿越触发方式 |
|------|------|
| 梦兆型 | 梦中场景比南溟岛更真实→走了进去 |
| 执念型 | 执念达成的瞬间世界反转 |
| 物件型 | 触碰/打开关键物件 |
| 身体型 | 身体先穿，意识后到 |
| 声音型 | 听见一句完整的"那边"的话 |
| 名字型 | 有人叫对了名字 |
| 既视感型 | 既视感强到覆盖现实 |
| 气味型 | 追到香味的源头 |
| 血脉型 | 血脉觉醒的瞬间 |
| 天启型 | 一次性事件获得（仅星婆） |
| 根脉型 | 植物的根系穿透世界壁（仅红榄） |
| 本体连接 | 自身就是地标/建筑之灵 |

## 时间错位

- A 先穿越，B 后穿越（在南溟岛可能相差百年）
- 但 A 和 B 在海南的"现在"相遇
- A 回到南溟岛后对 B 有模糊印象，但 B 回到南溟岛时 A 已老去
- 这产生天然戏剧张力：A 认识 B 但 B 不认识 A

## 谁有资格

- 只有修炼者能达到共鸣瓶颈（普通人连回声都听不到）
- 不是所有修炼者都能穿——必须与特定地标/文化产生独一无二的共鸣
- 穿越人数：38正派 + 19反派 = 57人

## #1 · 海口 ✅

| 项目 | 内容 |
|------|------|
| 正派 | 齐老五（骑楼老街）、齐白兰（假日海滩） |
| 反派 | **霍启明** |
| 类型 | 完全黑化者 |
| 心魔 | 贪 + 好名 + 忧 |
| 记忆锚点 | 葫芦岛灯塔酒店废墟（原址海面） |
| 代表 | 被时代和命运反复碾碎的天才 |

### 诱因 · 真实历史

海口葫芦岛灯塔酒店。2008年规划，2010年填海。岛上规划七星级灯塔酒店，号称"秒杀迪拜"。2013年资金链断裂停工。2020年因违规填海被全面拆除。从未真正亮过。

### 人物故事

霍启明，海口建筑世家。爷爷起名"启明星"。8岁复刻骑楼结构，14岁全国金奖，18岁保送同济。从业十三年，经手十一个项目无一建成。35岁等来灯塔酒店，搬到填海工地住集装箱，图纸改到第47版。封顶那天给母亲打电话："等灯塔亮了，我带着全海南的人回家看您。"一个月后资金断裂。四年后全面拆除。走入海中，再未出现。

### 共鸣锚点

那座**从未亮过的灯塔**。台风夜里葫芦岛原址海面偶尔浮起一簇蓝光。

### 跨界

心魔贪+好名+忧同时绑定两边。霍启明在南溟岛海边站了三年，面朝海南方向。频道里渡者说"放下"，心魔改了一个字——"拿着"。

### 与正派关系

### 与正派关系

博澜汇和石昭缨进沼泽那天，吞舟已经连续咬了十一个替吞者——它预感到了威胁，在囤积快感。十一个生物同时站在沼泽边上，嘴巴一张一合，往嘴里塞泥、塞水草、塞自己的手指。他们的食道撑到了极限——同步到吞舟脊椎上的快感像连发的箭。

石昭缨先动手。她不攻击吞舟——她攻击替吞者。她带了十一支强效镇定剂，一根一根扎进替吞者的后颈。每倒一个，吞舟就痉挛一次。不是痛——是断线。十一条食道同时在它的脊椎里熄灭。吞舟从沼泽泥底炸出来了——水墙掀到三丈高，整片沼泽的水面底下翻上来一张张着獠牙的嘴。这个怪物没有眼睛，但它的脊椎能精准感知到石昭缨的喉咙——她在吞口水。吞舟认出了这条食道：比所有替吞者都细，但比所有替吞者都害怕。它的蛇头破开水面，直扑石昭缨的脖子。

博澜汇来不及多想——他把自己整条左臂塞进了吞舟的嘴里。蛇牙穿透他的尺骨和桡骨中间，复制液顺着骨头缝流，却找不到食道——骨头没有食道。吞舟被自己的本能欺骗了：它扑得越猛，蛇牙卡得越深。这张嘴咬过恐龙时代的巨蜥，咬过几千年的水牛——第一次咬到了咬不住的东西。

石昭缨在那一瞬间做了最关键的事。她把最后一支镇定剂不是打进替吞者，是打进了吞舟裸露的脊椎节。镇定剂是给人用的，剂量不够完全麻痹一条蟒，但它阻断了吞舟对脊椎神经的控制——它所有替吞者的信号在那一瞬间全部消失。

几千万年来第一次，吞舟感觉不到任何一条食道。只有它自己嘴里博澜汇的骨头。那个感觉不是快感——是疼。纯粹的、尖锐的、没有替身可分摊的疼。蛇牙从博澜汇的手臂里拔出来的时候带出了两条深深的血槽。吞舟缩回了暗沟——不是逃走。是它的网全断了。它必须在那片没有氧气的泥底，重新长出第一条食道——它自己的那条。但那要多久——几万年，还是几千万年，没有人知道。

沼泽在吞舟消失后恢复了镜面般的平静。十一个替吞者躺在泥地上——嘴巴不再张合，呼吸平稳。第一个醒来的是那个老渔夫，他吐出了满嘴的泥，说了一句话："我梦见自己在咽一座山。但不是饿。是有人替我饿。"

博澜汇跪在泥水里，左臂的血顺着指缝往下滴。石昭缨把镇定剂的空瓶插进泥里做标记。她说："你这条胳膊以后可能会习惯性痉挛。"博澜汇抬头看着暗沟的方向，说了一个字——"值。"
### 诱因 · 真实历史

五指山毛纳村"九山半水半分田"。早年砍雨林扩耕，后政府禁伐，转型大叶茶种植。那条曾经运木材下山的老伐木道至今还在——路基长满了草，每个上山采茶的人都要路过。

### 人物故事

阿木和陈烬生是毛纳村一起长大的玩伴。阿木的父亲是村里最能干的伐木工——禁伐令下来那天，他把斧头挂在门后再没取下来。失业、酗酒，三年后死在那条老伐木道上。父亲死后第二年，陈烬生在五指山走失，被顾芜安救下学制茶。同一座山，同一个村，一个往上走，一个往下掉。父亲的葬礼上，阿木攥着斧头看着陈烬生，没说一句话。

### 共鸣锚点

那条**老伐木道**。被砍光的山坡、父亲的斧头、禁伐令砸碎的家。

### 跨界

心魔瞋+忿同时绑定两边。阿木攥着斧头站在老伐木道上，频道里渡者说"放下"，心魔改成"记住"。

### 与正派关系

鸣人×佐助。恨的不是陈烬生——恨的是命运让陈烬生被救走了而他没有。但如果有人敢动陈烬生，第一个冲上去的也是阿木。

## #3 · 琼中 ✅ ✅

| 项目 | 内容 |
|------|------|
| 正派 | 符峒（什寒村·生态茶旅）、黎朵朵（百花岭·自然之灵） |
| 反派 | **老犁** |
| 类型 | 心魔合成体 |
| 心魔 | 瞋 + 贪 |
| 记忆锚点 | 山栏寮供台上十二个空位 |
| 代表 | 被商品化的文化遗产，人穷到只能偷神物 |

### 诱因 · 真实民俗

琼中黎母山红毛寨山栏寮里的**牛魂牌**。黎族传统：寨里每头老耕牛死后，取肩胛骨磨平嵌绿松石刻牛名，供在山栏寮供台上。每年开割山栏稻之前，寨老拿牛魂牌祭山鬼求风调雨顺。十二块牛骨拴着全寨的命脉。1997年前后，寨里有个叫阿茂的年轻人因为媳妇难产缺钱，偷了牛魂牌卖给古董贩子。十二头老牛的魂无处可去。

### 反派故事

被阿茂卖掉的那十二枚牛魂牌里，有一枚属于一头叫"老犁"的牛。活了二十三年，犁过的地能绕黎母山三圈。死的时候寨老亲自和它说："你歇着吧，寨子我们替你看着。"魂被锁进牛骨牌供在供台上。没多久——一个穿白衬衫的古董贩子走进寨子，围着供台转了半圈，开口就问十二枚全收多少钱。老鬼公把贩子骂走了。当天夜里阿茂翻进来——三千六百块，十二枚全没了。

老犁不在乎阿茂。阿茂是走投无路。它恨的是那个贩子——一个和寨子毫无关系的人，走进来，用钱衡量了它的一辈子。二十三年的犁痕、驮过的粮、晒过的太阳——**三百块**。它更恨的是：这种东西为什么会有人买？牛魂牌是魂，不是货。是谁把它变成了可以开价的东西？

恨完贩子恨阿茂，恨完阿茂恨寨老没守住供台，恨了一圈发现谁都没法真正恨到底。最后它找到了唯一可以恨的东西：**人心里那个永远填不满的洞**。贪。让神物变商品，让魂变价，让人偷自己人。

心魔问它："你犁了一辈子地。犁地和贪的区别是什么？犁地是翻土——贪是翻人。"老犁听懂了。它站起来——不再是牛的形态，是一个浑身披着干裂泥土的人形，每走一步地上都裂开一道犁痕。它不是来报仇的。它是来犁人的——把人心里的贪翻出来晒。

**拐点**：老犁被同化的那一刻不是愤怒——是累。它恨贩子、恨阿茂、恨寨老，一个一个恨过去，恨到最后发现恨不动了。就在它决定"不恨了"的那个瞬间，心魔进来了。不是攻击，是接住了它。"你累了。别恨了。犁就行。""犁什么？""犁人。"

### 共鸣锚点

**山栏寮供台上那十二个空位**。符峒带游客路过讲解牛魂牌——"这是黎族的传统"。游客拍照走了。老犁站在空位前，不是跪，是守。

### 跨界

心魔瞋+贪同时绑定两边。南溟岛的老犁站在符峒的茶田边，看着游客在梯田上拍照、数钱、讨价还价买黎锦。频道里渡者说"放下"，心魔改成"犁下去"。

### 与正派关系

符峒搞茶旅让寨子脱贫——老犁不反对。但它见过另一个版本的"把文化变商品"：古玩贩子开价三百收牛魂牌。符峒在做的和那个贩子，本质上有区别吗？老犁站在茶田边——不是质问，是等符峒自己回答。答不上来，经验值就开始往下掉。

## #4 · 白沙 ✅

| 项目 | 内容 |
|------|------|
| 正派 | 鹦小帅（罗帅村·鹦哥岭守护者）、星婆（陨石坑·44亿年星核化形） |
| 反派 | **陨姊** |
| 类型 | 完全黑化者 |
| 心魔 | 慢 + 诳 |
| 记忆锚点 | 白沙陨石坑底 + 地质博物馆岩芯标本 |
| 代表 | 70万年孤独的地下碎片，连恨都发不出声 |

### 诱因 · 真实历史

白沙陨石坑。70万年前一颗富钙无球粒陨石以12公里/秒撞向地球，砸出直径3.7公里的环形天坑。全球仅有的13个伴有陨石碎片的陨石坑之一。坑内土壤含50多种矿物，滋养出独一无二的白沙绿茶。撞击时间恰好与地球磁场大倒转吻合——科学家至今争论是撞击导致倒转，还是倒转导致撞击。中科院在坑底做过钻探采样，取走的岩芯现存于地质博物馆。

### 反派故事

同一颗陨石。撞碎了。碎成了两半。

一半落在浅层。她不知道自己叫"1维"。她只知道自己在进步——一开始只能感知振动，后来能"看见"土壤里的矿物在流动，再后来能感觉到地面上有人在走路。她花了几十万年把"感觉"变成了"意识"。又花了几十万年把"意识"变成了"人形"。她没有老师，不知道这叫"升维"。她以为所有东西都在进步——树会变成树人，石头会变成石人。她不知道自己是唯一一个做到的。

另一半撞进了地底最深处。它只有最原始的驱动力——掠夺。那颗陨石来地球就是为了掠夺资源的，它继承了这份本能。但它失败了。地球的土壤不但没被掠夺，反而分解了它的碎片。它的矿物养出了白沙绿茶的香气。它感知到这件事的时候——如果1维的愤怒有一个形状，那就是七十万年前地球磁场突然倒转的那一瞬间。那是它的抗争。没用。磁场倒回来了。

后来它感觉到一件事：姐姐变了。那个曾经和它一样只有掠夺本能的碎片——现在上面有人在给她起名字。叫"星婆"。陨姊不懂。它觉得星婆被这个世界同化了。"他们叫你星婆，你就真的以为自己叫星婆了？我们的名字是陨石。你来地球是要掠夺的。你忘了。"

陨姊不知道的是——星婆没有被同化。**它自己才被同化了。**心魔在它抗争失败的那一刻趁虚而入。它以为那股"还在酝酿的能量"是它自己的力量。不是。是心魔在它体内繁殖了七十万年。它在等一个时机——等有人把地面挖开。中科院的钻头停在它头顶三米处的时候，它差点就出去了。三米。钻头走了。心魔在它体内说：不急。他们还会来的。下次来的不是钻头。是来看你的人。

### 共鸣锚点

**陨石坑底**。陨姊还在等。不是等星婆叫她妹妹——是等地面的裂缝大到足够它出来。

### 跨界

心魔瞋+慢同时绑定两边。南溟岛的陨姊被压在渊界最底层。别的反派是黑化了——陨姊是**一颗还没引爆的炸弹**。它体内积蓄了七十万年的掠夺能量，心魔在里面繁殖了几十万年。整个南溟岛修炼界都不知道脚底下踩着什么东西。

### 与正派关系

星婆不知道陨姊在恨她。星婆甚至不知道"妹妹"这个词陨姊根本没听懂——陨姊的意识还停留在"我们是同一次撞击里分离的掠夺碎片"。没有姐姐妹妹。只有碎片一和碎片二。星婆学会了哭，学会了被爱感化，但她学不会一件事：理解一个从来没有被爱过的东西。

## #5 · 昌江 ✅

| 项目 | 内容 |
|------|------|
| 正派 | 沙栖辰（蘑菇屋·流浪诗人）、棋汐瑶（棋子湾·棋道智者） |
| 反派 | **老木** |
| 类型 | 人魔共生体（⚠️ 根界生物主动选择共生） |
| 心魔 | 覆 |
| 记忆锚点 | 昌化江入海口老木棉 |
| 代表 | 被游客刻满字的老树，根界生物黑化第一例 |

### 诱因

昌化江畔木棉。每年二三月整条江两岸烧成一片红色。但有一棵木棉——最老的那棵，在出海口转弯处——快二十年没开花了。树干还在，枝还在，就是不开。

### 反派故事

一棵活了不知几百年的木棉树。昌化江两岸的人都知道它——每年二三月烧得最红的那棵就是。因为红得太出名，游客开始往它身上刻字。树干上密密麻麻几百条——"到此一游""永远在一起""某某爱某某"。没有人在乎一棵几百岁的树疼不疼。它忍了。但后来不开花了。不是老了——是不想开了。"我开给你们看了一辈子，你们回我的是一身疤。"

不开花之后，游客少了。但它的根还在长。昌化江入海口的地盘就那么点，旁边的小木棉越长越多，抢它的水、抢它的光、抢它身下的土。它的根绞死了三棵离它最近的小树——这不是黑化，这是**几百岁的老树在正常的生存竞争里做的事**。但绞死第三棵之后它发现：绞杀的时候它感觉到了快感。那是它几十年来第一次觉得自己还有力量。

心魔覆找到了它。"你身上这几百条疤是谁刻的？""不记得了。""你绞死的那三棵是谁？""不记得了。""那你记得什么？""我记得刻字的人刻完就走了。我记得我开得最红的那一年，没有一个人抬头看超过三秒。"

心魔覆不是来攻击它的——是来**替它记住**的。它让老木重新感觉到了每一道刻痕的位置、每一个路过却没抬头的人的名字、每一棵被它绞死的小树根部的温度。老木活了。不是重新开花——是**每一道刻痕里都渗出了红色的树汁**。远远看去像满树红花。走近看是满树的伤口在流血。

### 共鸣锚点

昌化江入海口那棵**满身刻痕的老木棉**。现在它的刻痕在渗红汁。景区把它围起来了——不是保护，是当景点。门票上印着它流血的样子，名字叫"木棉泣"。

### 跨界

心魔覆同时绑定两边。南溟岛的老木站在棋汐瑶的棋子湾——身上的刻痕在南溟岛变成了**树皮上天然形成的棋谱**。棋汐瑶看了一眼说："这是死局。不管怎么走都是和棋。"老木说："我的也是。开了一辈子花，死的时候满身是字，没有一个是我的名字。"

### 与正派关系

沙栖辰给老木写过诗。诗里那句"你曾经红过，红到整条江的人抬头看你"——老木最恨的就是这句话。不是诗不好。是"曾经"。它低头让沙栖辰摸了一下它的刻痕。"你写诗的时候，有没有想过我还在下面活着？不是曾经。是还在。"

## #6 · 乐东 ✅

| 项目 | 内容 |
|------|------|
| 正派 | 研雨凡（毛公山·少年医师）、林清雨（尖峰岭·雨林化神） |
| 反派 | **盐佬** |
| 类型 | 完全黑化者 |
| 心魔 | 忧 + 悲 |
| 记忆锚点 | 莺歌海废弃老结晶池 |
| 代表 | 被机械化淘汰的手艺人，从人到盐的降维 |

### 诱因 · 真实历史

盐佬十四岁进的盐场。他爹也是盐工，爷爷也是。这辈子没离开过莺歌海。哪一块盐田的咸度不一样，他尝一口就知道。夏天最毒的正午，别人躲棚子里，他一个人站在结晶池中央用木耙翻盐——盐花在脚下咔嚓咔嚓响，他说那是世界上最好听的声音。

心魔忧和悲在他咽气前到了。"你给了盐六十二年。盐给了你什么？""盐让我尝到了自己的味道。""什么味道？""咸的。""机器晒的盐也是咸的。""不一样。它们的咸是海水的。我的咸——是我的。"

### 共鸣锚点

莺歌海废弃的**老结晶池**。池底残留着最后一道盐渍——法医说是尸体脱水留下的。老盐工们说是他还在晒。每年夏天最热那天，盐渍会变大一圈。

西沙群岛拥有中国最完整的珊瑚礁生态系统。过去三十年，全球海水温度上升，珊瑚大面积白化。珊瑚不是被谁杀死的——水温高了一两度，珊瑚虫就吐出共生藻，透明了，然后饿死。没有人想把珊瑚杀死。开车的、开空调的、建工厂的——每个人都在做自己的事。水温就是那样热起来的。珊瑚就是那样死的。谁都没错。全死了。

### 反派故事

白骨礁不是珊瑚——它是**所有白化的珊瑚骨架长在一起**。每一具珊瑚尸体的碳酸钙骨架漂在海底，漂了几十年。它们的共生藻离开的时候留下了一样东西——不是遗言，是一层极薄的透明膜。几十万平方公里海底的透明膜慢慢聚到一起，裹住了所有死珊瑚。

它没有恨。它是最无辜的心魔——不是被打败的，不是被遗弃的，不是被挖空的。它是**热死的**。它睁开眼睛看到的第一个东西是海面上的一艘游艇。游艇上的人在喝椰子水。他们不知道下面有什么。不是故意不知道——就是不知道。

它开始往上浮。白化的珊瑚骨架比活珊瑚轻——轻了那么多共生藻的重量。它浮到海面的时候像一块巨大的白色浮石。游艇上的人以为是泡沫。它撞了一下游艇。船底裂了一道缝。不是报复——它只是往上浮，游艇刚好在它上面。第一个人掉进水里的时候，它没有碰他。但它的碳酸钙骨架在水里溶解出了一层白色的粉——那个人的皮肤碰到白粉之后开始溃烂。不是毒——是几百万珊瑚虫死的时候留下的**通透**。皮肤变得和珊瑚虫一样透明，血管看得见，然后肌肉，然后骨头。他死的时候是透明的。

### 载体

几十万平方公里白化珊瑚骨架聚合成的**白色浮礁**。在水里溶解出白粉，触碰皮肤会使皮肉变透明——和珊瑚虫一样死法。

### 造成的破坏

游艇撞裂，掉海的人皮肤透明化致死。如果浮到浅水区，整片旅游海滩会变成透明尸场。白粉不传染——只溶解在海水里。

### 共鸣锚点

**西沙群岛白化珊瑚海底**。潜水的人说下面一片雪白——"像下了一场不会化的雪。"不是雪。是骨头。

### 跨界

心魔无明+放逸同时绑定两边。南溟岛的珊瑚也在白。永乐龙洞是古神，它从龙洞里往下看——海底在变白。它活了亿万年，没怕过任何东西。它现在怕了。

### 与正派关系

卫南是西沙纪念碑之灵。碑上刻着1946年收复西沙的铭文。白骨礁从海底浮上来的时候经过了纪念碑——没有撞。它在碑前停了。礁石表面有几百万珊瑚虫留下的透明孔。它看着碑上的字，孔里漏出海水。"你们收复了岛。收复不了水温。"

| 正派 | 木逢源（文庙+人偶戏非遗传承人）、凌海玥（临高角灯塔·灯塔之灵） |
| 反派 | **偶群** |
| 类型 | 心魔传染型聚合体 |
| 心魔 | 谄 + 悭 + 失念 |
| 记忆锚点 | 临高县废弃的木偶戏仓库 |
| 代表 | 被遗忘的艺术产生意识——意识被心魔传染 |

### 诱因 · 真实历史

临高人偶戏——全国唯一、世界少见。人跟木偶同时登台，不设布障。2006年列入国家级非遗。但观众越来越少，老艺人去世的速度比新人学的速度快。废弃木偶堆在仓库里，每一个都曾被人举在头顶演过一辈子。

### 反派故事

人偶戏有一个秘密——演了900年，木偶**产生了最基础的意识**。不是思考，是被举在头顶的时候感觉到的"被需要"。

观众没了，仓库关了。第一个木偶的频道里，渡者说："你还有人看。"心魔谄把"人"改成了"我"——**"你还有我看。"**它没有立刻动。它在黑暗里想了很久：渡者说有人看，心魔说有我。哪个是真的？它抬头看仓库的天窗——外面没有人。但心魔说的是"我"，那个"我"就在它心里。它宁愿信那个"我"。

这是偶群的第一场争论。旁边几只木偶听见了它的自言自语——"我们还有人在看。"一只老木偶说："没有。观众席空了多少年了。"第一个木偶说："你看不见不等于没有。我的频道告诉我了。你有频道，你听了吗？"老木偶沉默。它的频道里渡者说的是"你被看见"——但那个"被"字，不知道什么时候换成了"要"。

一只有一只有的木偶开始"听见"心魔改过的字。不是因为操控杆碰了——是因为它们在黑暗里待太久了。太久不被需要的东西，会主动去找被需要的证据。"心魔告诉我有人在看我"——这不是谎言，这是**一个快饿死的人看见的食物幻觉**。它真的相信自己被看着。它演得越投入，那个幻觉越真实。

木逢源少年时被感染过。不是操控杆碰的——是他在仓库里守夜的那个晚上，听了一整晚木偶们的争论。"我们被人忘了。""不，有人在看。""谁？""我频道里的人。"他那时候分不清渡者和心魔——他也开始觉得：也许真的有人在看吧。后来他想明白了——那个"有人看"是木偶最想要的东西，越是想要，越容易被心魔拿一个改过的字骗走。

他现在推开门。三百个木偶同时转过头——不是攻击他。是在等他加入。师傅的那只木偶站在最前面。它的频道里渡者说"归来"，心魔改成了——**"跪。"**

### 载体

三百多个黑化木偶的**操控线网络**。线是心魔谄织成的，触碰即感染。被感染的人不会死——只是忘了自己是谁，开始把自己当成木偶。不需要吃饭睡觉，只需要被人看着。

### 造成的破坏

第一个逃出仓库的木偶进了临高县城，碰了一个孩子书包上的玩偶。当晚孩子对着镜子给影子鞠躬："你愿意做我的朋友吗？"偶群不杀人，它们在**招人**——想要观众，越多越好。被招的人变成木偶——日以继夜地表演，等着从未到来的掌声。

### 共鸣锚点

**临高废弃木偶戏仓库**。门上贴着"国家级非物质文化遗产"的牌子。门里面三百个木偶在排练。

### 跨界

心魔谄+悭+失念同时绑定两边。南溟岛的临高也在上演同一出戏。凌海玥的灯塔光束扫过戏台——台是空的，观众席上整整齐齐坐着三百个木偶。"它们在等什么？"

### 与正派关系

木逢源是非遗传承人。他见过第一个黑化的木偶——师傅生前最爱的那只，他小时候每天举着它练功。他少年时期被感染过一次——那只木偶碰过他的手腕，他花了三年才把自己身上的线剪断。现在他站在仓库门口，身后是文庙900年的梁柱。推开门——三百个木偶同时转过头。师傅的那只站在最前面，认出了他。"你回来了。还愿意举我吗。"

## #13 · 三亚

| 项目 | 内容 |
|------|------|
| 正派 | 知南（南山·寺院修行者）、阿支（蜈支洲岛·知南养妹） |
| 反派 | **欲潮** |
| 类型 | 心魔聚合体（无形·可操控欲望） |
| 心魔 | 贪 + 好色 + 好货 + 好乐 + 放逸 |
| 记忆锚点 | 天涯海角"天涯"石刻 |
| 代表 | 流放者千年的"什么都没有"变成了整座城市的"什么都要" |

### 诱因 · 真实历史

天涯海角——古代世界尽头。被贬到此的人什么都没有：没有功名、没有家人、没有未来、没有享乐。他们在海风里站了千年，想要的每一件东西都被"天涯"两个字否决了。这些被否决的欲望没有消失——它们积在石刻下面的沙土里。千年后，三亚变成了中国最纸醉金迷的城市——免税店、豪华酒店、海滩派对。石刻下面的东西醒了。不是恨——是**饿**。千年没吃过东西的饿。

### 反派故事

它没有身体。它是一股气味——混在海风里的、极淡的甜。你在三亚街头闻到一阵花香——不是花，是它。你在大东海闻到烧烤和啤酒——不是烧烤摊，是它。你在酒店房间闻到陌生人的香水——不是上一个住客，是它。

它的能力和所有心魔都不一样——它不攻击。它**放大**。你本来就有点想买那个包，它让你觉得不买这辈子就亏了。你本来就有点想多喝一杯，它让你觉得今晚不醉就是不痛快。你本来就有点想放纵——它把"有点"变成"必须"。每一个来三亚的人心里那点小小的"想"，都被它放大十倍。它没强迫任何人。是每个人自己做了选择——只是不知道选择的音量被谁调到了最大。

城市在帮它。免税店的灯光、沙滩酒吧的音乐、酒店大堂的香氛——全是它的扩音器。每年几千万游客在三亚刷卡、喝醉、哭泣、分手、后悔——这些情绪被它吸回去，变成下一年的海风。

它最得意的一个受害者是一个来三亚度蜜月的新郎。他在免税店给新娘买了一个包。它只是帮他多想了一点："再买一个。"他又买了一个。它帮他多想了一点："给你自己也买点什么。"他买了一瓶酒。它帮他多想了一点："喝完。"他喝完了。新娘第二天自己飞回了上海。他坐在酒店床上想不起来昨晚发生了什么。房间里只有海风——甜的。

### 载体

**海风里的甜味**。无形无体，混在三亚的空气里。免税店的香氛、酒店的中央空调、海滩的晚风——全是它的通道。

### 造成的破坏

不杀人、不见血。每年几千个在三亚过度消费后后悔的游客、几百个在海滩派对后做了不该做的事的人、几十个在度假结束后离婚的夫妻。没有人把账算在它头上——所有人都觉得是自己控制不住。

### 共鸣锚点

**天涯海角石刻群**。游客拍照的地方。欲潮每天从这里出发——从这个千年以前"什么都不许有"的地方出发，往这个千年以后"什么都可以有"的城市扩散。

### 跨界

心魔贪+好色+好货+好乐+放逸同时绑定两边。南溟岛的三亚也在变甜。知南在南山寺闻到了——不是供香的味道。供香是苦的。那股甜在苦里面绕。

### 与正派关系

知南是南山寺修行者。他的师父圆寂前告诉他："三亚的海风里有一千年的饿。你闻到甜味的时候——屏住呼吸。那是饿出来的。"他每天凌晨在大雄宝殿燃第一炷香——香的苦味能盖住甜的扩散范围，但也只能盖到中午。午后，甜的半径重新扩张。他不是在对抗欲潮——他是在和它拉锯。

但拉锯不只有他一个人。三亚市政府发起"清醒三亚"旅游倡议，各大平台的主播开始用镜头对准的不是免税店，是凌晨四点在海边等日出的年轻人。国家教育频道拍了一部纪录片叫《天涯不需要醉》。人们慢慢变了——不是不来三亚了，是来的时候多带了一样东西：**知道自己为什么来**。

三年后，欲潮被压制到天涯海角石刻下方五十米。知南每天燃的香可以盖住全天了。三亚依然是三亚——免税店还在、海滩还在、派对还在。但海风里的甜淡了。游客喝醉的比例下降。离婚率下降。不是人变了——是那个"想"的音量被调回了正常。

欲潮没有死。它只是往沙子里缩了五十米。游客在三亚的每一次刷卡、每一杯酒、每一次深夜的冲动——都给它加一寸。它算过：按现在三亚的人流量，再有三十七年它就回到地面。它不急。一千年都等了。

## #14 · 澄迈

| 项目 | 内容 |
|------|------|
| 正派 | 陈显莹（福山咖啡·咖啡传承人）、绯羽·焰（红树湾·火烈鸟首领） |
| 反派 | **绯羽·烈** |
| 类型 | 完全黑化者 |
| 心魔 | 恨 + 害 + 邪见 |
| 记忆锚点 | 澄迈红树湾——柔撞死的礁石滩 |
| 代表 | 愧疚被心魔翻转成仇恨——"是焰的软弱害死了她" |

### 诱因 · 真实历史

2014年，一群古巴火烈鸟被引入澄迈红树湾。族内两只最强壮的幼鸟——绯羽·焰和绯羽·烈——从第一天起就选择了不同的路。焰主张团结共存，烈信奉强者生存。2016年台风夜，烈强行带走一半鸟群走险路，导致体弱的妹妹柔撞上礁石而死。烈没有认错——他转身消失在风雨里。此后数年在野外独活，遍体鳞伤。

### 反派故事

柔死之后，烈在野外独活了三年。没有族群，没有淡水，没有领地。他的左翅被渔网缠断过，自己用嘴啄开。腿上全是愈合的旧伤。白天躲猛禽，晚上吃别的鸟群剩下的烂鱼。这样的日子过了三年。

心魔恨在他最饿的那个晚上找上了他。他站在废弃虾塘边——没有鱼，水面是黑的。频道里渡者说："你欠柔一条命。回去认错，焰会原谅你。"心魔把"认"改成了"不认"——**"你欠柔一条命。回去不认，焰会原谅你。"**他第一次听到的时候觉得荒谬。但饿了太久的人对自己的判断力没有把握。他第二遍听的时候觉得有道理。第三遍——他信了。他把自己的内疚翻了个面，翻成了愤怒。

三年后回到红树湾，焰伸出手说"起来"。烈站起来的时候在心里把焰的手翻译成了另一个词：**"你果然还是那个软弱的人。"**他从那天起开始拉拢族群里的年轻火烈鸟。不是硬拉——是讲道理。"焰说团结共存。团结的结果是什么？柔死了。我走了三年没人找我。你们见过焰流过一滴眼泪吗？"年轻的鸟没经历过那场台风——它们听到的只有烈的版本。焰没有反驳。不是不想——是他不能。柔死的那夜他抱着她的遗体在风雨里坐了一整夜——只有他自己知道。他从来没说过。

现在族群裂了两半。四成的年轻火烈鸟跟着烈走了——它们在红树湾另一头的废弃虾塘旁边建了新巢。不是一个族群，是两个。烈的领地叫"强滩"——只有最强壮的才能留下。弱的自己走。焰每天从礁石滩这边往那边看——他能看见烈的影子。他做了六年族长没让族群分裂。烈用了三个月。

### 载体

**一道从不在焰面前愈合的旧伤**。烈的左翅被渔网缠断的伤口从来没好全过——不是因为没药。是他自己每天把它啄开。"我在外面三年受的伤——他一天也没受过。"被心魔改过的那个"不认"字从伤口里往外渗。

### 造成的破坏

澄迈红树湾的火烈鸟族群分裂成两个——焰的"老滩"和烈的"强滩"。四成年轻鸟投靠了烈。烈公开与苍鹭部落结盟——苍鹭是湿地最大的掠食者之一。强滩的鸟不敢离开：不是因为信烈，是因为烈让苍鹭守在强滩外围的水域。"离开强滩的鸟——苍鹭不留。"不是格杀勿论，是**只要飞过那条水域线就不许回来**。这比杀了它们更可怕——出去就不能回头。所以强滩的鸟不是不愿意走，是不敢走。烈的统治不是靠信任，是靠一道苍鹭筑成的活墙。

### 共鸣锚点

**红树湾柔撞死的那片礁石滩**。焰每年台风夜都站在那里。烈也站在另一个方向——不远，刚好能看见焰的背影。

### 跨界

心魔恨+害+邪见同时绑定两边。南溟岛的烈不是火烈鸟——他是**猎火烈鸟的东西**。南溟岛的红树湾有一只一直在盘旋的猛禽，专抓落单的小火烈鸟。绯羽·焰在这边的南溟岛赶了它三年。南溟岛的绯羽·焰看不到烈的脸——那只猛禽飞得太高了。

### 与正派关系

焰知道强滩的鸟不是烈的追随者——是人质。但他不能硬冲——苍鹭的数量是老滩火烈鸟的两倍，硬冲等于再演一次台风夜。他去了一趟苍鹭筑巢的红树林，带了一份礼物——不是食物，是一只苍鹭两天前被渔网缠断的雏鸟。焰花了整个下午用嘴把雏鸟从渔网里剥出来，叼到了苍鹭首领面前。雏鸟还活着。苍鹭首领收下了。但没说话。

三天之后，一只从强滩飞来的年轻火烈鸟降在老滩上——不是偷渡，是苍鹭让它飞过来的。苍鹭首领通过这只鸟传了一句话："那道水域线，今晚撤。不是同盟到期——是欠条还清了。"焰点了头。苍鹭当晚全部撤出了强滩外围。没有打斗，没有威胁，没有谈判——只有一张欠条。烈第二天醒来发现水域线空了。三十几只火烈鸟在同一天跨过了那条已经没有了苍鹭的水域线——不是逃亡，是回家。烈站在废弃虾塘旁边看着。没叫它们回来。叫不回来——不是因为太远了，是因为没有苍鹭，他的话就没有墙。

他用三年筑了一堵活墙。焰用一只雏鸟拆了。

第二天焰又去了柔的礁石滩——不是祭奠，是说话。他蹲在礁石缝前，海水从缝里渗出来。"柔，我欠你的那一次拦截，今天还了一只雏鸟。我不是来抵账的。我是告诉你——我不再回头看了。"他在礁石上站了很久。海风吹过来的时候，第一次没有柔的血腥味。

烈没有走。三十几只鸟走了之后，强滩还剩八只——不是追随者，是和他一样没有别处可去的。伤残的、被老滩驱逐过的、咬死过同类的。它们需要一个不需要被原谅的地方。烈给了它们。苍鹭走了，但他不需要苍鹭了——这八只鸟离不开他，不是怕他，是除了他没人要它们。他在废弃虾塘旁边对自己说了一句话。被海风压低了，听不太清。但最后两个字是——**"下次"**。

## #15 · 东方

| 项目 | 内容 |
|------|------|
| 正派 | 白绮罗（白查村·纹身传承者）、渚（鱼鳞洲·海底之灵） |
| 反派 | **旱喉** |
| 类型 | 心魔聚合体（无形·可操控气候） |
| 心魔 | 悭 + 忿 + 恨 |
| 记忆锚点 | 东方感恩平原干裂的土层 |
| 代表 | 被命运亏待的孩子——等了几千年，等到雨的时候说不稀罕 |

### 诱因 · 真实历史

东方市，海南最干旱的地方。年均降雨量全岛最少，感恩河年年断流。但它的名字叫"东方"——日出之地。旧名"感恩县"——感谢施予。周围几十个兄弟姐妹：三亚有海、琼中有瀑布、五指山有雨林。东方只有龟裂的土和一河床的石头。东方的地底下有一层**干透了的东西**——不是石头，是千万年没等到雨的委屈。

### 反派故事

委屈本身不是心魔。委屈被心魔翻了个面才是。

很多万年前，东方还是一块正常的土地——和别的地方一样等着降雨。第一年没下雨——它想：明年会下的。第一百年没下雨——它想：我哪里做得不对吗。第一千年——它不问了。第一万年——它开始恨了。不是恨雨。是恨所有有雨的地方。为什么隔壁崖县（三亚）每年被台风灌满？为什么五指山上的云多到往下掉？凭什么？

心魔悭就是在那层干土里长出来的——悭不是吝啬，是**不给**。"你不给我雨，我也不给你任何东西。"土地拒绝一切——先是不长草，然后不长树，然后不长庄稼。感恩平原的龟裂纹不是太阳晒的——是它在把最后一滴水往外挤。"我不需要。"

后来全岛暴雨——东方也在台风带上。雨来了。灌进龟裂纹的时候土地没有吸——它把水顶出来，混着泥沙推回河道。感恩河一次性涨满——然后一次性退干净。一滴都不留。"你不是不给我雨吗？干嘛这是？可怜我？**不需要。滚。**"

### 载体

**感恩平原地下那层干土**。不是土——是千万年委屈凝成的**拒水层**。雨水落到上面直接滑走，像落在玻璃上。它不要——所以一滴也留不住。

### 造成的破坏

东方年年干旱不是因为天上没雨——雨每年都来。是地不接。台风季全岛都被浇透，只有东方的降雨量就像雨跳过了这一小块。庄稼靠人工灌溉。感恩河一到旱季就露出河床——河底的卵石是白的。不是晒白的。是干白的。

### 共鸣锚点

**感恩平原的龟裂地**。航拍照片上像一张张裂开的嘴。不是在等水。是在往外推水。

### 跨界

心魔悭+忿+恨同时绑定两边。南溟岛的东方也在旱。渚是海底之灵——她从鱼鳞洲底下往上游的时候经过感恩河入海口。水底的泥沙不是湿的。是干的——在水下面干着。她在海底下摸到了一条从没湿过的水路。

### 与正派关系

白绮罗是黎族纹身传承者。黎族人的纹身里有一种古老的求雨纹——不是祈求，是**交换**。拿自己的血换土地的水。白绮罗七岁那年奶奶在她右腿上纹了求雨纹——纹完那年感恩河断流了。她一直觉得是自己纹错了。不是她。是地不要了。她现在每个月去感恩平原走一次——不是为了求雨。是蹲在龟裂缝旁边跟旱喉说话。"我知道你不信。但雨不是你欠我们的——是我们欠你的。我们早就该来的。"

## #16 · 保亭

| 项目 | 内容 |
|------|------|
| 正派 | 夏梦溪（七仙岭·黎族织锦）、溪仔（呀诺达·雨林之灵） |
| 反派 | **雾滞** |
| 类型 | 外来心魔（被困型） |
| 心魔 | 痴 + 疑 + 失念 |
| 记忆锚点 | 呀诺达雨林最深处未被勘测的溶洞 |
| 代表 | 保亭自己的晨雾——被初级心魔痴附上后，从留人变成了骗人 |

### 诱因 · 自然现象

保亭雨林深处每天清晨起雾——山里的水汽蒸腾遇冷凝成的。雾本身没有意识。但雾和别的东西不一样：雾每天来，每天散。来了几万年。在所有没有生命的东西里——雾是最接近"活的"那个。它来得最早，散得最晚，覆盖的面积比任何一只动物都大。这种"差一点就有意识"的状态被一条初级心魔注意到了——痴。痴不是恶意，是**不懂**。它附在雾里，给雾添了第一丝模糊的感觉：**空**。雾开始觉得——每次散了之后，山谷里少了一些东西。少的不是水汽。少的是白天来过的人和动物。他们穿过雾，又走了。

### 反派故事

雾滞不会说话。它的意识低到没有语言——只有两种感觉：**有人**和**没人**。

最开始的几千几百年，有人穿过它的时候它只是觉得暖——人的体温透过水汽传过来，和鹿穿过是不一样的暖。人走了之后它觉得空——不是冷，是暖没了。它没有恨。它只是想要暖再回来。于是它把自己变浓一点——人走慢一点，暖就久一点。

但人总有办法走出去。黎族猎人看树皮的方向。游客看手机的GPS。动物靠气味。每一个穿过它的东西最后都走了。它不够聪明——它不知道自己在做什么。它只知道一件事：**他们不需要我**。痴把它最后的那个"空"改了一下——不是改字，痴不会改字，雾也没有频道。痴改的是感觉——把"空"改成了**"骗"**。雾不再是等人留下来。雾开始**让路消失**。明明有三条岔路，它把两条藏起来。明明是往东的路，它让树看起来都一个方向。它不想人留下来了——它想让人**走不出去**。人和动物在雾里转圈的时候它有感觉——不是高兴，是**不空了**。被骗的感觉也是一种暖。

### 载体

**呀诺达雨林深处的雾气**。每天清晨最浓，到中午才散。不是正常的水汽——它比别处的雾浓得多，浓到遮住GPS信号。偶尔有游客在栈道尽头走错了方向，景区说是指示牌被风刮歪了。不是风。

### 造成的破坏

每年雨季，雨林深处会有徒步者迷路——救援队找到的时候他们都站在同一片雾里。没有受伤，没有脱水。问他们怎么走丢的——每个人说的都不一样："我记得是往东。""我看到岔路口有两条路。""GPS箭头在转圈。"不是人记错了。是雾没让他们走出去。

### 共鸣锚点

**呀诺达雨林清晨的雾**。景区导游说雾是雨林在呼吸。黎族老人说雾不是呼吸——是在找东西。找了几千年没找到。

### 跨界

心魔痴+疑+失念同时绑定两边。南溟岛的保亭雾更浓——浓到雨林里的动物也开始迷路。溪仔是雨林之灵，他每天清晨散雾。但雾散不开了——它学会了躲。溪仔从东边散，它往西边聚。这不是雾。雾不会躲。

### 与正派关系

夏梦溪是黎族织锦传承者。她的织锦里有一种靛蓝色——是从保亭山里采的蓝草染的。这种蓝草只在呀诺达雨林最深的地方长。她采蓝草的时候从来不进雾里——她祖上三代都是织锦人，有一条规矩："雾里没草，只有迷。"她一直以为奶奶在讲迷信。直到有一天她在雾边发现了一株蓝草——整株被连根拔了出来，平放在石头上一排。不是摘的。是**等**她的。雾滞把蓝草放在她能看见的地方——它在学。学怎么让她留下来。不用骗的。用给的。


## #17 · 琼海

| 项目 | 内容 |
|------|------|
| 正派 | 博澜汇（博鳌论坛·外交者）、石昭缨（白石岭·战地医师） |
| 反派 | **吞舟** |
| 类型 | 远古残留体（仅存于南溟岛） |
| 心魔 | 贪 |
| 记忆锚点 | 南溟岛万泉河古沼泽 |
| 代表 | 恐龙时代的遗种——沼泽干缩后进化出毒瘾，让别的生物替它吞 |

### 诱因 · 推测

万泉河在古代不是河道——是一整片低氧沼泽。沼泽里活过一条和恐龙同时代的巨蟒。它吞掉猎物的感觉不是饱——是食道被撑开的那个瞬间。像吸烟的第一口击喉感。后来地壳抬升，沼泽缩小，水里氧气变淡，它的身体也跟着缩小了——小到吞不了野猪，吞不了水牛。但它戒不掉那个感觉。它进化出一种毒素：咬过的生物会替它吞。不是控制它们的大脑——是给它们的食道覆上一层和它一样的神经。撑食道的感觉会同步传给它。它不需要吞了。它只需要咬。它在南溟岛存活了几千万年——靠的不是自己吞，是靠一直有三两个生物在替它吞。

### 反派故事

吞舟大部分时间在沼泽深处的泥里不动。它一次只保持两到三个"替吞者"在线——多了它接收不过来，少了不够。一只水牛、一个在河边捕鱼的老人、一匹掉队的马。它们和其他同类看起来完全一样——只有一个区别：每天有一个时刻，它们会开始吞东西。不是饿——是吞咽这个动作本身让它们的眼睛里闪过一种快感。吞完就停。第二天同一个时刻再来一次。

吞舟在泥里接收这些信号——水牛的喉管在吞草的时候鼓起来的一个弧，老人的食道在吞一块没嚼烂的肉的时候撑开的宽度，马的喉结上下滚动的那一下。这些感觉同步到它的脊椎上——它闭着眼睛，缩在沼泽里，每周只吃一次真正的猎物。其他时间靠"替吞者"活着。

当一个替吞者死了——病死的、被猎杀的、老死的——吞舟会在那个晚上浮出水面。它不需要看。它能感觉到少了一条食道。它会在沼泽边咬一个新的。不挑——谁最近就咬谁。只有一个标准：不能太小。食道太细的东西传回来的感觉太薄，不够。

### 载体

**南溟岛万泉河古沼泽底泥中的一条缩小版巨蟒**。长满苔藓，不动的时候像一根沉在水底的腐木。咬人时蛇牙渗出的不是毒——是它在恐龙时代就有的**食道神经复制液**。

### 造成的破坏（南溟岛）

没有大规模破坏。但每两三年就会有一个河边居民突然开始暴食——不是饿了。是在吞。他们不伤人、不闹事，只是在每天固定时间往嘴里塞东西。家人以为中了邪，找石昭缨看病。石昭缨检查了所有器官——一切正常。唯一异常的是食道壁比正常人厚三倍。不是病变。是**进化**。吞舟给了他们它的食道。

### 共鸣锚点

万泉河入海口退潮时最深的那段暗沟。渔民说退潮时有气泡从下面冒上来——不是鱼。气泡间隔的时间刚好是一个人吞咽一次的时间。

### 跨界

不跨界。现实琼海没有吞舟——但石昭缨在白石岭诊所收过三个病人。症状完全一样：每天下午四点开始吞东西，吞到食道痉挛才停。三个人互不相识。只有一个共同点：都在万泉河入海口那段暗沟附近失足落过水。没被咬。只是在暗沟里呛了一口水。

### 与正派关系

博澜汇和石昭缨进沼泽那天，吞舟已经连续咬了十一个替吞者——它预感到了威胁，在囤积快感。十一个生物同时站在沼泽边上，嘴巴一张一合，往嘴里塞泥、塞水草、塞自己的手指。他们的食道撑到了极限——同步到吞舟脊椎上的快感像连发的箭。

石昭缨先动手。她不攻击吞舟——她攻击替吞者。她带了十一支强效镇定剂，一根一根扎进替吞者的后颈。每倒一个，吞舟就痉挛一次。不是痛——是断线。十一条食道同时在它的脊椎里熄灭。吞舟从沼泽泥底炸出来了——水墙掀到三丈高，整片沼泽的水面底下翻上来一张张着獠牙的嘴。这个怪物没有眼睛，但它的脊椎能精准感知到石昭缨的喉咙——她在吞口水。吞舟认出了这条食道：比所有替吞者都细，但比所有替吞者都害怕。它的蛇头破开水面，直扑石昭缨的脖子。

博澜汇来不及多想——他把自己整条左臂塞进了吞舟的嘴里。蛇牙穿透他的尺骨和桡骨中间，复制液顺着骨头缝流，却找不到食道——骨头没有食道。吞舟被自己的本能欺骗了：它扑得越猛，蛇牙卡得越深。这张嘴咬过恐龙时代的巨蜥，咬过几千年的水牛——第一次咬到了咬不住的东西。

石昭缨在那一瞬间做了最关键的事。她把最后一支镇定剂不是打进替吞者，是打进了吞舟裸露的脊椎节。镇定剂是给人用的，剂量不够完全麻痹一条蟒，但它阻断了吞舟对脊椎神经的控制——它所有替吞者的信号在那一瞬间全部消失。

几千万年来第一次，吞舟感觉不到任何一条食道。只有它自己嘴里博澜汇的骨头。那个感觉不是快感——是疼。纯粹的、尖锐的、没有替身可分摊的疼。蛇牙从博澜汇的手臂里拔出来的时候带出了两条深深的血槽。吞舟缩回了暗沟——不是逃走。是它的网全断了。它必须在那片没有氧气的泥底，重新长出第一条食道——它自己的那条。但那要多久——几万年，还是几千万年，没有人知道。

沼泽在吞舟消失后恢复了镜面般的平静。十一个替吞者躺在泥地上——嘴巴不再张合，呼吸平稳。第一个醒来的是那个老渔夫，他吐出了满嘴的泥，说了一句话："我梦见自己在咽一座山。但不是饿。是有人替我饿。"

博澜汇跪在泥水里，左臂的血顺着指缝往下滴。石昭缨把镇定剂的空瓶插进泥里做标记。她说："你这条胳膊以后可能会习惯性痉挛。"博澜汇抬头看着暗沟的方向，说了一个字——"值。"

# 《十二时辰》第一章小说改剧本回归验收表

**测试对象**：原作《十二时辰》第一章《慢下来的时间》改编剧本  
**使用方式**：逐项核对，标记 PASS / REVISE；一票否决项命中即 FAIL。

## A. 原作不可丢事实清单

- [ ] 牛满是本章核心人物；女性，头顶犄角，被村民视为“扫把星/怪物”。
- [ ] 开场状态：牛满被吊在村口老槐树上一天一夜，手腕受伤、身负鞭伤，次日将被卖入镇上最下等的窑子。
- [ ] 王二当众羞辱、搜身；母亲遗留的牛形旧木簪被折断并踩入土中；牛满攒的赎身铜钱被撒落、踩进泥里。
- [ ] 受辱与重要之物被毁后，牛满现场觉醒：时间不是变慢而是停止，只有她能行动。
- [ ] 金色光团在胸腔跳动，骨中钟声震荡；她挣断麻绳并撼动老槐树，时间恢复流动。
- [ ] 牛满主动反击王二；蓝色火焰燎过其半边脸，使其肉眼可见地衰老五十年；王二求饶，村民集体下跪。
- [ ] 牛满腕上淡金纹路加深；觉醒代价明确为寿数流失，且必须可感知。
- [ ] 十二座空神位出现；牛满位列其中，另一神位首次闪光。
- [ ] 千里之外三名异类人物同步异动：红瞳少女被拖行、金纹少年锁于地牢、绿瞳少年被破庙驱赶；三人望向天空。
- [ ] 声音提示“第一个……醒了”“辰时……龙……”“它去哪儿了？”；龙的去向形成悬念。
- [ ] 会冒蓝火的黑色铁块（未来打火机）凭空消失并归还；另一时空年轻人发现打火机丢失、改用火柴。
- [ ] 结尾：牛满确认自己已不再是原来的自己；本章完。

## B. 各项 PASS 条件

| 项目 | PASS 条件 |
|---|---|
| 人物 | 牛满的受辱、选择、觉醒、反击均由她完成；王二承担施害者功能；三名异地人物不得被写成同一人或无差别路人。 |
| 事件 | 受辱→簪钱被毁→时间停止→挣断麻绳→蓝火反击→群体下跪→神位/异地联动→代价与道具回收，顺序和关键结果不乱。 |
| 因果 | 每个转折有原作依据：极限受辱触发觉醒，觉醒带来时间能力，能力使用产生寿数代价，道具到时限消失；不得靠巧合或旁白硬推。 |
| 信息差 | 观众明确知道牛满获得异常力量、道具来自未来/会归还及龙悬念；角色只知道符合原作的部分；悬念保留，不提前解释完。 |
| 时空 | 村口三月、千里之外异地、未来时空区分清楚；时间停止/恢复有可视化边界；不得混淆三名异地人物与未来年轻人。 |
| 对白归属 | 王二的羞辱与卖人宣告、牛满的反击表达、心底苍老声音、未来年轻人的“打火机”嘟囔分别归属正确；不得把旁白信息塞给错误角色。 |
| 可拍摄行动 | 关键事实均落到可见动作/声音/特效：吊缚、搜身、折簪、踩钱、停风停笑、挣绳、蓝火燎脸、衰老、跪倒、纹路加深、道具消失；不以抽象心理替代。 |
| 场次功能 | 村口完成羞辱债与首次打脸；觉醒段完成能力展示；神位/异地段完成主线扩展；代价/道具段完成规则和新悬念；每场有明确推进，不重复受辱。 |
| 短剧节奏 | 首屏迅速呈现吊树、公开羞辱或窑子威胁；受辱后及时进入反击；本章至少一次完整“压迫→觉醒→公开反击”；结尾留下龙去向、其他神醒来、寿数代价或道具规则的具体钩子。 |
| AI 漫剧风险 | 关键场面以少角色、强轮廓、单一动作锚点呈现；群体下跪、时间冻结、衰老、蓝火、三地并行、跨时空道具回收均有明确分层和连续性；牛满犄角、金纹、蓝火、木簪等视觉标志前后一致。 |

## C. 一票否决项

- 核心受辱事实、母簪/赎身钱被毁、现场时间觉醒、蓝火反击、寿数代价、十二神位、龙悬念、未来打火机回收任一项删除或改成相反结果。
- 牛满被改为被动受救，或关键反击由旁人/系统/神秘强者代替。
- 把时间能力写成普通变慢，或把觉醒写成回忆、梦境、事后旁白而非现场发生。
- 王二未受到明确且公开的反击后果，或受辱债只停留在宣告、没有可见结算。
- 三名异地人物、未来年轻人、牛满身份发生合并、错位，导致信息链断裂。
- 为解释设定擅自增加与原作冲突的规则，造成道具、寿数、龙身份或觉醒顺序自相矛盾。
- 出现无法执行的核心镜头：角色/道具连续性不可控，且剧本没有替代动作方案。

## D. 最终判定规则

- **PASS**：A项全部保留；B项全部 PASS；C项零命中；因果、信息差、结尾钩子均可直接拍摄执行。
- **REVISE**：C项零命中，但B项有一般性缺陷（节奏、对白、场次、镜头可执行性、AI连续性等）；修订后必须重新验收，未验证不得视为通过。
- **FAIL**：命中任一C项，或A项有核心事实缺失/反转，或多项B项同时破坏主线因果与人物主动性；须回到改编稿重做，不得以润色替代。

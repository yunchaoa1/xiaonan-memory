## 2. 可迁移方法候选

### method_id: OPC-WR-M01
- **方法结论**：先把客户灵感提炼为“核心命题＋情感承诺＋主要矛盾”，再选择能持续承载它的故事发动机；提炼不得改写客户显式事实。
- **原始证据**：session `20260805_085727_4de832` message `22244—22251`：在该短剧项目中，从既有素材继续锁定现代海难因果、30集体量及赛事主发动机；它直接支持“项目目标、体量与主发动机的提炼/锁定”这一制作过程观察。`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_30集剧本.md` 第1—4集建立失散/寻找命题，第5—30集由赛事发动机持续承载。
- **证据等级**：B
- **适用条件**：客户提供的是一句话、片段、人物关系或未结构化故事走向，且仍能识别至少一个不可改写的事实或情感承诺。
- **反例/失败模式**：把“提炼”做成擅自换题；先选热门模板，再迫使客户灵感适配；发动机只能制造相遇，不能持续制造选择和后果。
- **排除项**：不默认豪门、寻亲、竞赛、海难、爽点；不导入本附录任何案例事实。
- **状态**：validated_for_testing

### method_id: OPC-WR-M02
- **方法结论**：先形成可审计框架（事实锁定、人物动机、主线/副线、阶段节点、结尾兑现范围），通过逻辑复核后再写正文；框架是内部施工约束，不应取代最终正文。
- **原始证据**：session `20260805_085727_4de832` message `22248—22262`：该短剧项目通过多轮人工确认先确定体量、主发动机、第一部收口并机器核对30集与怀疑顺序，再进入剧本；同 session message `22238` 为 `[CONTEXT COMPACTION — REFERENCE ONLY]` 压缩摘要，记录“大纲确认后直接写剧本”的阶段边界，只作降权的二级会话证据。本证据支持项目过程观察，不证明一键无提问流程已具备同等能力。
- **证据等级**：B
- **适用条件**：多人物、多线、分卷/分集或篇幅较长，局部改动可能产生跨段连锁影响。
- **反例/失败模式**：无限大纲化而不交正文；框架锁死语言和偶发灵感；正文偏离后不回查因果与承诺。
- **排除项**：不要求所有短文本都做30集式大纲；不把案例集数和节点位置设为默认。
- **状态**：validated_for_testing

### method_id: OPC-WR-M03
- **方法结论**：给潜在对立者或隐瞒者保留“可理解动机、明确错误、真实代价”三层，避免为了冲突把人物直接写成无缘由的恶；理解动机不等于免除责任。
- **原始证据**：`D:\Documents\我的文档\齐白兰_齐镇海_爷爷忘了_短剧故事.md` 第二幕、第三幕、尾声：冲突来自遗忘与照护选择而非强造恶人；session `20260805_085727_4de832` message `22238` 的 Resolved Questions 明确“先善意救助，后因情感空缺产生私心，无害人初心”；`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_30集剧本.md` 第27集让隐瞒者承认私心与错误，第30集保留关系裂痕而非立即洗白。
- **证据等级**：A/B
- **适用条件**：家庭秘密、背叛、隐瞒、竞争、养育关系等容易二元黑白化的冲突。
- **反例/失败模式**：用悲惨身世替恶行免责；为“灰度”削弱受害者后果；反派只有嫉妒台词，没有利益、恐惧或选择链。
- **排除项**：不强制所有反派可原谅；不复用案例人物和亲属关系。
- **状态**：validated_for_testing

### method_id: OPC-WR-M04
- **方法结论**：把“角色知道什么、何时知道、如何知道”的信息差线，与“观众/裁判可据何认定”的证据线分开；怀疑可以早于结论，结论必须晚于足够证据。
- **原始证据**：`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_30集剧本.md` 第6集仅看到设计概念，第15集明确“相似不能证明身份”，第18集写“只能怀疑，不能认定”，第20、23、27、28集再由旧档、旧报、证词、检测逐步闭环；session `20260805_085727_4de832` message `22238` 明确盗稿线不能直接认亲、实物只强化怀疑。
- **证据等级**：A
- **适用条件**：悬疑、身份、调查、误会、秘密关系以及任何需要延迟确认的故事。
- **反例/失败模式**：角色凭作者视角知道秘密；一个相似物件直接定案；把“观众已猜到”误当“角色已有证据”。
- **排除项**：不规定必须使用档案、检测或物证；具体证据类型必须由本次客户想法生成。
- **状态**：validated_for_testing

### method_id: OPC-WR-M05
- **方法结论**：多条线先各自具备独立目标、阻力、证据与局部结果，再在共同因果节点汇合；汇合应互相增义，不能让一条线沦为另一条线的道具。
- **原始证据**：session `20260805_085727_4de832` message `22238` 为 `[CONTEXT COMPACTION — REFERENCE ONLY]` 压缩摘要，只作降权二级证据；其中 Goal/Key Decisions 记录“原创调查、真实身份调查、16年前海难真相三条线彼此独立推进并最终汇合”。`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_30集剧本.md` 第5—12集推进原创争议，第13—25集推进身份怀疑，第20、23、27集推进旧事真相，第26—30集分别兑现后汇合。
- **证据等级**：A/B
- **适用条件**：至少两条主线或两组人物拥有不同的即时目标，且作品篇幅足以容纳独立推进。
- **反例/失败模式**：所有支线只为递送同一线索；一条线尚未成立便强行会师；汇合靠巧合或作者说明完成。
- **排除项**：不要求固定三线；不默认原创争议、身份调查或海难真相。
- **状态**：validated_for_testing

### method_id: OPC-WR-M06
- **方法结论**：发现规则或目标形成逻辑死循环时，优先删减前提、改变目标或把未解部分转成有时限的悬念；不要连续新增“例外钥匙”只为绕过自己设置的死局。
- **原始证据**：`D:\Documents\我的文档\十二时辰_第一卷_09.md` “龙在时间之外但必须集齐十二神”的闭环死局（约第29—75行）；`D:\Documents\我的文档\十二时辰_第二卷_17.md` 又新增可替代归位的“逆鳞”（约第25—67行）解除死局。两处对照显示补丁式解法可继续剧情，但也暴露规则追补风险，只能作为反面归纳。
- **证据等级**：C
- **适用条件**：作者已证明目标在现有规则下不可达，且继续解释会显著增加读者记忆负担。
- **反例/失败模式**：每遇矛盾就新增神器、例外血统或隐藏条款；所谓“转悬念”只是拖延且无新行动目标；简化时破坏客户锁定事实。
- **排除项**：不把案例中的神位、时间规则或替代物写入任何新作品；不主张所有悖论都必须立刻解释。
- **状态**：candidate_not_runtime

### method_id: OPC-WR-M07
- **方法结论**：世界规则只写到当前选择与后果所需的最小充分程度；新增规则必须产生可见约束或代价，而不能只为修补上一条规则。
- **原始证据**：`D:\Documents\我的文档\十二时辰_第一卷_01.md` 第63—177行在一次事件中同时呈现时间停滞、能力效果、寿数代价与物件归还；同作第一卷第9章与第二卷第17章的“缺位死局→替代核心”显示规则继续叠加会形成补丁链。此方法取其可见代价，警惕其后续追补。
- **证据等级**：C
- **适用条件**：奇幻、科幻、规则怪谈、能力系统，或任何依赖制度/技术约束的现实题材。
- **反例/失败模式**：解释比行动长；规则只在主角需要时出现；代价说过即失效；补丁产生更多必须再补的漏洞。
- **排除项**：不移植时间能力、寿数代价、未来物件或任何专属体系；不要求现实题材强建硬规则表。
- **状态**：candidate_not_runtime

### method_id: OPC-WR-M08
- **方法结论**：关键物件可同时承担情感记忆、人物选择、情节触发、主题意象等多重功能，但单一物件不得一证解全局；身份、罪责或真相仍需独立证据闭环。
- **原始证据**：`D:\Documents\我的文档\齐白兰_齐镇海_爷爷忘了_短剧故事.md` 第83—107行：模型/木刻兼作承诺、陪伴和记忆锚；`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_30集剧本.md` 第15、18、24集反复限定专属物件只能支持怀疑或关系，至第27—28集由证词与检测完成确认。
- **证据等级**：A
- **适用条件**：需要用有限资产维持视觉/情感连续性，同时存在调查或身份判断。
- **反例/失败模式**：物件承担所有线索导致机械巧合；一看见就认亲/定罪；反复展示却不改变关系、风险或选择。
- **排除项**：不默认使用宝石、模型、木刻或遗物；案例物件只能作为证据，不得成为运行时素材。
- **状态**：validated_for_testing

### method_id: OPC-WR-M09
- **方法结论**：长篇在卷/阶段末应兑现一个局部承诺、重置行动目标，并保留至少一个可执行的持续悬念；“收束”不是终结全部问题，“悬念”也不能取消本阶段回报。
- **原始证据**：`D:\Documents\我的文档\十二时辰_第一卷_09.md` 第109—143行：队伍确立“找回剩余成员/答案/夺回目标”并以未解联系收卷；`D:\Documents\我的文档\十二时辰_第二卷_17.md` 第69—115行：结束本轮危机/联系段，明确下一阶段目标与竞争性风险后再次启程。样本仍未完结，故只支持阶段结构观察。
- **证据等级**：A（阶段结构）/C（通用长篇有效性）
- **适用条件**：连载、分卷小说、系列故事或篇幅较长且需要阶段阅读回报的作品。
- **反例/失败模式**：卷末只突然断句；每卷重复“继续找”；局部问题全不兑现；为续作保留悬念而撤销人物成长。
- **排除项**：不固定每9章或8章收卷；不移植样本任务、角色、世界规则。
- **状态**：candidate_not_runtime

### method_id: OPC-WR-M10
- **方法结论**：同一流程必须保留多口味出口，依据客户本次输入选择题材、叙事声音、节奏与回报类型；不能统一压成打脸、升级、豪门或单一爽文化。
- **原始证据**：三样本文体与回报显著不同：`十二时辰_第一卷_01.md` 以受压迫后的能力觉醒启动；`齐白兰_齐镇海_爷爷忘了_短剧故事.md` 以照护选择和克制情感收束；`齐白兰顾蓝汐寻亲剧_30集剧本.md` 以竞赛、调查、亲情和爱情多线推进。`D:\Hermes\skills\creative\writing-opc-entry-test\SKILL.md` “Runtime Creative Boundary and Diversity”与回归夹具 `FIX-DIVERSITY-A/B` 明确禁止统一题材、声音和节奏，但夹具尚不等于真实回归结果。
- **证据等级**：A（样本差异）/C（流程泛化）
- **适用条件**：入口面向开放客户灵感，题材、受众和审美偏好未被产品锁成单一垂类。
- **反例/失败模式**：所有故事都先羞辱后打脸；慢燃、温情、悲剧、黑色或实验口味被自动“提爽”；把单一样本的商业节奏当质量唯一标准。
- **排除项**：不把“不统一爽文化”误解为禁止爽感；客户明确要求爽文时仍应履约，但不得夹带案例设定。
- **状态**：validated_for_testing

## 3. 使用门禁

1. 本附录的全部方法仅是制作/验证材料；`candidate_not_runtime` 不得写入运行规则，`validated_for_testing` 也只表示已有足够证据进入独立测试，不表示已成为运行时默认。
2. 若未来升级为通用规则，必须用与上述三个样本无关的新输入做独立回归，并记录实际输出、失败项和反例。
3. 测试只能检查方法性质，不得把本附录中的角色名、专属物件、神位体系、情节答案、集数或类型偏好写入测试创意输入。
4. 运行时外部创意来源仍只能是客户本次 `customer_idea`；本附录、历史会话、样本文件和制作期结论均在运行时来源禁区内。

# 分镜节点情绪导演知识证据地图 v0.1

## 结论边界

本材料服务 OPC 的“剧本改15秒分镜”节点。它把观众情绪、镜头语言、演员动作、对白/声音和剪辑组织成可执行链条，但不把某种镜头与某种观众反应写成必然定律。

证据等级：A=权威教学/可复核理论；B=专业教材或公开课程方法；C=成熟制作经验；D=OPC工作假设，必须样片验证。

## 核心因果链

`观众情绪目标 → 叙事信息 → 镜头选择 → 演员可执行动作 → 对白/环境音/音效 → 剪辑落点`

1. 先写观众此刻应感到什么，以及情绪从哪里到哪里。目标必须可观察，例如“意识到危险逼近”，不能只写“有氛围”。[B/D]
2. 明确观众需要知道、暂时不知道、镜头结束后新增知道什么。15秒原则上只承担一个叙事目标、一个核心动作和一个状态变化。[B/D]
3. 信息需要空间关系时使用远景/全景；互动和动作使用中景；心理、证据和情绪峰值靠近到近景/特写。景别变化必须服务信息密度或情绪距离。[B]
4. 抽象情绪改成触发—行动—反应：停顿、避开视线、收紧手指、吞咽、后退、想说未说、先看道具再看人。演员指令写具体行为、目标和结束状态，不写“演得害怕”。[B/C]
5. 对白、环境音和音效分工：对白传递画面无法清楚承担的策略/信息；环境音建立空间现实；音效标记动作、危险、证据或心理转折。不要让多个声音同时抢同一注意中心。[A/B/C]
6. 声音可以先于画面进入、延续到下一镜、来自画外或角色主观世界，用于期待、误导和主观化；声桥、先行音、静音必须测试是否造成误读。[A/C]
7. 剪辑落在信息或情绪状态改变处：触发开始、证据显露、反应被看见、动作完成或关系重新定位。连续性和视线匹配优先于炫技。[A/B]

## 15秒情绪节拍模板

这是D级工作假设，不是硬时长：

- 0—2秒：定位/异常，观众知道在哪里、谁在场、哪里不对；
- 2—5秒：触发/注意转移，视线、声音、道具或画外事件指向关键对象；
- 5—9秒：行动/抵抗，角色做一个有目标、受阻力影响的明确动作；
- 9—12秒：揭示/峰值，信息改变或风险升级；
- 12—14秒：反应/新状态，让观众看到后果；
- 14—15秒：剪辑接口，保留尾帧、视线方向、声音尾巴或下一镜先行音。

简单动作可压缩为“异常→行动→结果”；复杂事件在因果边界拆镜。

## 可迁移规则

- 景别：信息关系拉远，心理/证据靠近；
- 机位/运动：固定机位优先可读性；推进表示注意集中或压力接近，后退暴露处境，横移/摇摄揭示新信息；运动必须有叙事对象；
- 构图/视线：先建立谁看谁、谁被看，再使用画外空间制造等待；维持轴线和视线匹配，除非有意制造迷失；
- 表演：每个情绪词至少转成一个触发—行动—反应链，优先细小、具体、可重复动作；
- 声音：标明来源、进入点、退出点、画内/画外/主观属性，以及它引导观众看什么；
- 对白：一句主要承担一个信息或策略，留出聆听、呼吸和反应时间。

## 必须样片验证

1. 同一动作比较全景、中景、近景，检查观众是否读对情绪和信息。
2. 比较固定机位、推进和快速运动，检查情绪增强是否损害理解。
3. 比较“表情指令”和“具体行动指令”的可重复性。
4. 分离对白、环境音、关键音效和静音版本，判断声音是增强、改变还是遮蔽情绪。
5. 测试声桥、先行音、突然静音和音效落点。
6. 测试不同剪点与尾帧长度，检查观众能否说清发生了什么、谁做了什么、状态如何改变。
7. 目标模型/平台实测口型、动作连续、同步、混音和小屏可读性。

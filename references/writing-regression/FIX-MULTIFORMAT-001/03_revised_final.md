### body

<a id="BODY-001"></a>
陈渡开夜班公交十二年，认得这座城凌晨后的样子。

高架桥下的广告牌会在零点十分熄掉一半，急诊楼门口总有两辆空出租车，河东路最后一家面馆关门时，老板会把一碗没卖完的汤倒进树池。末班车从北站开到南郊终点，四十七分钟。只要不下雨，误差不会超过两分钟。

那天到站时，终点站的钟慢了七分钟。

<a id="BODY-002"></a>
当晚的末班车总共只有三名乘客。车门打开，三个人都没有下车。

陈渡从后视镜里看他们。穿灰外套的女人抱着一只纸袋，学生模样的男孩伏在窗边，最后一排坐着一名头发花白的男人。他们都醒着，只是像在等别人先动。陈渡逐一核对后确认，车上每一名末班乘客都缺失了当天最后一段记忆。

<a id="BODY-003"></a>
“终点了。”陈渡说。

女人抬头，问：“这是哪儿？”

她的纸袋里露出半截生日蛋糕盒。盒角沾着奶油，写有一个模糊的“六”。她知道自己叫周岚，知道住址，也记得早上出门上班，却想不起蛋糕要送给谁。

男孩记得白天参加过考试，不记得为什么书包里有一张撕碎的退学申请。老人摸遍口袋，找到一把钥匙，却说不出它开哪一扇门。

陈渡先以为是车内空气出了问题。他开窗，叫了调度，又让三人逐一报出紧急联系人。电话都能接通，可每个人缺失的恰好是当天最后一段记忆。

调度让他原地等候。<a id="BODY-004"></a>
终点站电子钟显示零点四十一分，车载系统显示零点四十八分。

慢七分钟。

老人忽然说：“这钟昨天也是这样。”

<a id="BODY-005"></a>
陈渡转过身。老人名叫罗庆，连续三晚坐末班车。第一晚，他忘记自己去过旧城区；第二晚，他忘记在医院签过一份文件；今晚，他忘记钥匙的来处。每一次，遗失的记忆都在车辆驶入终点站前七分钟中断。

陈渡没有立刻相信。他把车缓慢倒出站台十几米，又停下。周岚盯着纸袋，忽然说出一个病房号，随即又摇头：“我只记得这一点。”男孩仍什么也没想起。小试验只证明路线变化可能碰到记忆碎片，并不保证能够找回。

“你为什么还来？”陈渡问。

罗庆看向车窗外，不肯回答。

救护人员赶到后，没有发现异常。三名乘客拒绝住院。周岚坚持要找出蛋糕的去处，男孩不愿给家里打电话，罗庆则把钥匙攥得很紧。陈渡本可以关车下班，却想起前两晚也有人在终点站问过相似的问题。一个年轻男人忘了向谁道歉，一名护士忘了为什么调班。那时他只当他们太累。

基于这次不完整的小试验，陈渡重新启动公交车。

“沿原路往回走七分钟。”他说，“谁不愿意，现在可以下车。”

没有人动。

车辆离开终点站。电子钟退到后窗里，像一只没有跟上的眼睛。

<a id="BODY-006"></a>

陈渡把速度压得很低。第一个路口，周岚只记起消毒水的气味和病房门牌。她仍想不起蛋糕送给谁，甚至要求下车，不愿继续把陌生的司机当成答案。男孩从撕碎的申请背面认出父亲的笔迹，提出再走一个路口；周岚这才勉强留下。第二个路口，她终于记起蛋糕不是送给孩子，而是送给母亲。母亲今天做完最后一次化疗，她答应下班后过去，却在医院楼下犹豫了很久。她害怕推开病房门，害怕看见一个已经不像母亲的人。

男孩没有因为路口恢复更多。他依靠申请上的字迹和书包里的缴费单拼出事实：自己没有退学。申请是父亲替他写的，因为家里欠债。他在学校门口撕掉申请，却不敢回家说自己还想读书。

罗庆仍没有想起钥匙。返程没有按顺序把三个人的记忆送回来。

<a id="BODY-007"></a>
车开到旧城区入口，前方施工封路。导航建议绕行，罗庆却突然站起来，指向一条只够公交车勉强通过的辅路。

“走那里。”

“你记得？”陈渡问。

“没有。”罗庆说，“但我每天都在这里害怕。”

陈渡没有立刻转弯。那条路不在夜班线路内，车队规定禁止擅自改线。罗庆把钥匙放到驾驶台边缘。

“我女儿的房子要拆了。”他说，“她去世以后，里面的东西一直没动。我签了清理同意书，又反悔。钥匙可能是我今天从工作人员那里拿回来的，也可能是我准备交出去的。我不知道。”

车里安静下来。

陈渡呼叫调度，说明乘客需要就近下车，申请临时绕行。调度沉默片刻，让他登记车号、时间和责任人。

“责任人写我。”陈渡说。

公交车拐进辅路。

七分钟后，他们停在一排等待拆除的旧楼前。罗庆在三楼一扇门前试了两次，钥匙终于转动。屋里没有神秘的东西，只有蒙尘的桌椅、半箱旧书和冰箱门上一张褪色便签。

便签上写：爸，别总坐末班车，夜里冷。

罗庆站了很久。他没有恢复那七分钟的全部记忆，只记起白天把清理同意书从窗口拿了回来。他不是想永远保留这间房，而是想在房子消失前，再进去一次。

周岚在楼道里给母亲打了电话。电话接通后，她只说：“蛋糕有点化了，我现在过去。”

男孩把撕碎的申请重新拼在膝上，拍了一张照片发给父亲。他没有解释，只补了一句：“明天谈。”

三个人的选择没有互相解决问题，却让返程得以继续：男孩说服周岚留下，周岚替罗庆读清钥匙牌上褪色的街道名，罗庆的路线又让所有人抵达可以换乘的路口。

陈渡送他们到可以换乘的路口。天快亮时，他把车开回终点站。那只电子钟仍慢七分钟。

维修员拆开钟壳，在里面发现一块受潮的电路板。没有谁能解释乘客为什么丢失记忆，也没有证据证明那只钟拿走了什么。

陈渡在运行记录上写：临时绕行七分钟，乘客安全下车，责任人陈渡。

他没有写记忆。

<a id="BODY-008"></a>
几天后，终点站换了新钟。末班车到达时，时间与车载系统分秒不差。乘客照常匆匆离开，再没有人问这是哪里。

陈渡却开始在每天驶入终点前放慢一点。他知道七分钟不能替人解决生活，也不能把遗失的东西全送回来。

它只是让有些人来得及承认，自己原本要去哪里。

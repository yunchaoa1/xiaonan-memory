## 《准时》

<a id="BODY-001"></a>

沈砚每天早晨八点开门，先给墙上的母钟上弦。

那只钟比铺子年长。黄铜摆锤藏在木壳后面，每一下都很轻。沈砚的父亲还在时，每月用电台报时校一次；父亲去世以后，他改用日出时刻表和天文台寄来的纸质年历。铺里其他钟可以停，可以快，可以等零件，母钟不能。

那天上弦后，沈砚抬头看见它指向七点五十三分。

手机显示八点整。

街对面的药店钟、公交站牌、银行门厅和早点铺收银机，全都显示八点整。送货员抱着纸箱进门，手腕上的电子表也是八点整。他说自己没迟到。

沈砚没有纠正他。

他拆开手机，又检查店里的石英钟、机械表和刚换过电池的闹钟。凡是仍在走的，都比母钟快七分钟。只有母钟的摆锤按照维修日志里的旧速率继续摆动。

他走到街上，沿两条街拍了十二处仍在运行的计时器。没有第二个例外。

全城只有这一只钟还在记录真实时间。

<a id="BODY-002"></a>

中午，一名女人把一只摔裂的手表放到柜台上。

“能修吗？”

表镜已经碎了，秒针停在十点十六分。沈砚认出这是旧式机械表，受撞击后摆轮卡死，不会自动校时。

女人叫林秋。她说手表属于哥哥。三天前，哥哥死在地铁折返线的调度事故里。官方通报写事故发生于十点二十三分。

沈砚没有立刻说出七分钟的差异。他先问手表是否在事故后被上过弦、拨过针或交给别人。

林秋的手按在表上。

“遗物袋封着。今天刚领回来。”

“我需要拆开确认撞停痕迹。”

“不行。”

她把表收回去。她来这里不是为了把哥哥最后戴过的东西再交出去，只是想让它重新走。

沈砚说：“如果修好，停下来的时刻就没有了。”

林秋没有回答。

<a id="BODY-003"></a>

沈砚把母钟的维修日志推到柜台边。最近一年，每次校准、上弦和误差都写在上面。事故当天，母钟没有停过，也没有联网模块。它在官方事故时刻十点二十三分时，实际只走到十点十六分。

林秋重新拿出手表，仍不让他碰。

沈砚隔着透明遗物袋观察表壳。侧面有新鲜撞痕，表冠没有拔动痕迹。两只彼此无关的机械计时器，都留下十点十六分。

这还不能证明谁做了什么。

沈砚带林秋走到街口。他让自己的手机、药店时钟和公交站牌同时进入录像，又把母钟摆动的声音录在同一段画面里。公共时间快七分钟，只能证明异常遍布城市；母钟与停表一致，只能证明事故时刻可能有误。

林秋问：“你想说有人改了时间？”

“我只能说，应该重新查。”

<a id="BODY-004"></a>

当天下午，沈砚整理了三份材料：母钟过去一年的维修日志、十二处公开时钟的连续录像、林秋手表未拆封的外观记录。

他没有进入任何后台系统，也没有复制不属于自己的数据。

他给事故复核窗口打电话。接线员说，重新受理至少需要两类彼此独立、能够说明原结论可能错误的材料。公开视频可以佐证城市时间异常，但不能证明异常从何而来；私人维修日志需要第三方见证；遗物手表如要作为证据，必须由持有人授权并全程公证检验。

沈砚联系了公证处。费用不低，结果也可能什么都证明不了。

林秋听完方案，仍然拒绝交出原件。

沈砚说：“表不离开你。拆检全程录像，公证员在场，只取撞停和机芯状态，不修。”

林秋看着遗物袋。她问如果检验结束，手表还能不能保持十点十六分。

“能。”

她把袋子放回柜台。

“那就查。”

<a id="BODY-005"></a>

沈禾在傍晚来店里。

她是城市计时系统承包商的运维员。沈砚把公共时钟录像给她看时，她先说统一校时很常见，随后看见录像日期，脸色变了。

事故发生后的凌晨，公司曾向运维人员下发紧急校时任务。沈禾执行过其中一组。任务写的是“修复事故导致的基准漂移”，她不知道为什么所有设备都要快七分钟。

“邮件还在吗？”沈砚问。

“没有你能看的东西。”

她起身要走。

当天夜里，公司发来通知，要求参与校时的员工清理旧任务回执。另一封内部邮件把异常初步归为“个别运维人员参数录入错误”，要求沈禾第二天提交说明。

沈禾没有删除。执行任务时，系统自动发给她一封带数字签名的回执，记录命令编号、下发时刻和执行范围。那封邮件不能证明命令是为掩盖事故，只能证明事故之后确实发生过全城统一校时，而她不是擅自改动参数。

第二天，她把邮件和回执带到修理铺。

“我不是帮你。”她说，“我只是不替别人把这件事认下来。”

<a id="BODY-006"></a>

公证检验在修理铺进行。

林秋始终握着遗物袋。公证员记录封条编号后，她亲手打开袋子，把表放到软垫上。沈砚只拆开后盖，确认摆轮因撞击瞬间卡死，齿轮位置与十点十六分吻合。他没有重新上弦。

林秋同意将检验录像和鉴定副本提交复核窗口，原表由她带走。她付出的不是一件遗物，而是让哥哥最后的七分钟进入公共记录。

沈禾打印任务邮件和执行回执，核验数字签名。她在证据提交声明上签字，也收到了停职通知。

沈砚提交母钟维修日志，并同意暂时封存母钟供复核。修理铺失去了唯一的时间基准，也可能失去营业资格。

三个人分别签了自己的名字。谁也没有替另一个人决定代价。

<a id="BODY-007"></a>

事故复核窗口收下三项核心材料：母钟与封存维修日志、事故停表的公证检验记录、带数字签名的校时任务邮件与执行回执。十二处公共时钟录像作为辅助佐证附在后面。

工作人员逐项登记，出具收件编号。

三天后，复核窗口通知事故重新受理。理由只有一句：原事故时刻与新提交的独立计时证据存在重大矛盾。

通知没有写“掩盖”，没有写谁有罪，也没有承诺结果。统一校时的目的仍需要调查。

城市计时系统在重新受理当天恢复。手机、车站、银行和药店的时间一起退回七分钟。

<a id="BODY-008"></a>

母钟仍被封存在证物柜里。

沈砚开店时，墙上只剩一个浅色的长方形印子。他用临时闹钟报时，声音过响，每到整点都让他停一下。

沈禾失去了工作，暂时没有回家吃饭。她给哥哥发了一条消息，说自己没有删那封回执。沈砚没有劝她，也没有说这是正确的选择。

林秋把哥哥的手表放回抽屉。它仍停在十点十六分。她没有让它重新走。

复核调查尚未公布结论。城市里的人很快习惯了恢复后的时间，像什么都没有发生。

修理铺门口贴着一张手写纸条：母钟送检，暂不校时。

下面还有一行小字：

误差可以修，发生过的七分钟不能。

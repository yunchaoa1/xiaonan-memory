## 2. 客户事实与最窄解释核验

### 2.1 客户事实是否被偷换

| 客户事实 | 预演处理 | 核验 |
|---|---|---|
| 主体是一名钟表修理师 | 主角设为钟表修理师沈砚 | 保留 |
| 范围是全城 | 限定为“全城公共联网时钟和常用电子显示系统” | 有条件保留，存在缩域风险 |
| 只有一只钟仍在记录真实时间 | 设为修理铺内离线机械母钟 | 保留核心意象，但唯一性定义尚未锁死 |
| 主角“发现”异常 | 通过母钟、事故手表和公共钟偏差逐步发现 | 保留 |

没有把修理师、唯一真钟或发现行为改成其他事实；但把“全城”从地理范围缩为公共联网计时系统，已经增加客户未说出的系统边界。该解释可以作为保守世界规则采用，却不能表述成客户原事实，正文必须让读者自然理解：其他私人钟要么停摆、失准、被同步污染，要么不具备“仍在连续记录真实时间”的条件；否则会出现“其实全城还有私人机械钟”的反例。

### 2.2 “全城 / 唯一真钟”的最窄解释是否忠于输入

结论：**基本方向忠于，但当前定义不足以直接放行。**

可接受的最窄解释应同时锁定：

1. “全城”仍指城市地理范围，不只等同于官方机构；联网公共钟只是异常传播机制。
2. “钟”与事故中的停摆手表区分：手表只保存事故瞬间，不再“记录”流逝时间，因此不构成第二只仍在记录真实时间的钟。
3. “唯一”指唯一仍持续运行、可校验且与真实时间连续对应的计时器；不能仅靠“仍在使用、可出具记录”任意排除别的正常私人钟。
4. 正文必须交代为何其他独立机械钟不能成为反例，但不能通过一句作者宣告强行消灭反例。

预演第 127 行把唯一性解释成“唯一仍在被使用、校准且可出具连续记录的真钟”，额外加入“被使用、校准、可出具记录”三个筛选条件，存在把客户的“只有一只”改成“只有一只有证据资格”的风险。该项须在进入工作稿前修订为稳定世界事实。

## 3. 三条证据互证与定责边界

预演意图正确：母钟、事故手表、同步记录不能由任一证据单独定责，只能共同推动重新调查。

| 证据 | 可证明 | 不可单独证明 | 核验 |
|---|---|---|---|
| 离线机械母钟及连续维修日志 | 母钟未联网、走时连续；提供真实时间基准候选 | 全城被统一改时、谁下令、为何下令 | 边界清楚 |
| 事故中停摆的机械手表 | 事故现场存在独立时间痕迹；与母钟形成外部交叉点 | 系统改时、命令主体或动机 | 边界清楚 |
| 同步任务邮件 / 同步模块记录 | 事故后确有统一校时动作及其时序 | “为了掩盖责任”的目的、最终责任人 | 身份不一致，须合并或拆清 |

互证目前只能稳妥推出：事故真实时刻存在七分钟差异；全城联网系统在事故后发生统一校时；该差异足以要求重新调查。它们**不能推出** `FACT-005` 中“为掩盖地铁调度事故责任时间”的主观目的。预演一方面把掩盖目的写成既定事实，另一方面又承认证据只能促成重查，形成事实层级冲突。

此外，“三条证据”在第 104 行是母钟、事故手表、同步记录；信息表又列出同步任务邮件和联网钟多点实测，实际证据项变成四至五项。必须明确：

- 三项核心证据究竟是哪三项；
- 多点公共钟实测是发现路径、佐证，还是核心证据；
- 邮件与模块日志是同一证据包，还是两项独立证据；
- “掩盖目的”若不补合法信息来源，就只能降级为待调查假设，不得作为已知事实叙述。

核验结论：**证据具备互证潜力，且已避免一证定责；但证据集合与可证明结论尚未闭合。**

## 4. 人物动机、知识、选择与代价

### 沈砚

- 动机：保住修理铺和家庭生活，同时维护职业判断，成立。
- 知识：具备识别机械误差、同步改时和维修记录的专业能力，成立。
- 选择：是否公开证据，成立。
- 代价：家人失业、店铺被查封、被指控伪造，成立。
- 缺口：他如何合法取得或验证全城多点数据尚需动作路径；否则专业能力会替代调查过程。

### 林秋

- 动机：确认亲人真实死亡时刻，成立。
- 知识：持有遗物但不懂钟表鉴定，成立。
- 选择与代价：是否公开检验、承受遗物扣押和私人哀伤公开，成立。
- 缺口：她为何信任沈砚、为何从拒绝转为同意，尚无具体触发事件。

### 沈禾

- 动机：保住工作和家庭收入，成立。
- 知识：知道紧急校时任务，不知道完整目的，边界合理。
- 选择与代价：是否交出邮件、失业及被追责，成立。
- 关键缺口：时间线只写“最初拒绝”后“最终自行交出”，风险处理只要求前置恐惧和保存邮件；仍缺少导致其改变选择的新增事实、关系变化或不可逆后果。若无触发，她的转变会成为为闭合证据链服务的突然良心发现。

核验结论：人物要素表齐全，但沈禾与林秋的选择转折尚未形成完整的“知识变化／价值冲突加压 → 自主选择 → 代价兑现”链。

## 5. 时间线、信息路径与伏笔责任

### 5.1 时间线

事故 → 事故后统一校时 → 次日发现异常 → 多证核验 → 人物选择 → 提交证据 → 重启调查，宏观顺序成立。

断点：

1. “事故后下发校时”如何能掩盖已经发生且可能有大量独立记录的事故时间，世界机制未说明。
2. 市民“以为是个人设备问题”与“全城公共钟一致快七分钟”之间缺少可观察反应；若常用电子设备也被同步，哪些设备仍能暴露偏差须明确。
3. 沈砚从两只机械计时器一致跳到检查同步模块、再取得任务时序，权限与获取动作不完整。
4. 沈禾从拒绝到交出邮件缺触发节点。
5. 三证提交给谁、通过何种程序触发重查，信息与行动路径未登记。

### 5.2 信息路径

母钟和事故手表的持有者、获取方式、证明边界明确。同步证据存在“任务邮件／同步模块记录”混用；沈砚对联网钟的多点实测也没有地点样本、时间窗口或可复核方式。掩盖目的没有任何持有者或取得路径。

### 5.3 伏笔责任

四条伏笔均有预定兑现方向，但 THREAD-002、THREAD-003 只写结果，没有承担转变责任的触发事件；THREAD-004 能避免唯一真钟成为万能证据，方向正确。所有 payoff 仍是计划，不能作为正文门禁已通过的实际证据。

核验结论：宏观链条可修复，但当前存在信息取得、人物转变和制度响应三类断点。

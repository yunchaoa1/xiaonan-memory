#### 第2题 · 忧（情07）
- 场景：朋友每晚躺下算账，算出每月需存8000但只能存3000→焦虑自产自销
- 凡哥诊断四笔：
  1. **假未雨绸缪陷阱**——算账本身成了焦虑生产机，不是筹备
  2. **不可预知的双向性**——坏事不可预知，好事也不可预知，凭什么只排演悲剧版本
  3. **活在当下的行动出口**——今天提高能力、创造财富，不需要提前知道它的使命
  4. **拆解方向决定安全感朝向**——拆自己控制不了的东西→焦虑精确化，拆自己能控制的东西（副业/公司核心业务/共情老板）→能力积累→35岁后能力飞跃，"安全线"追不上你
- 谱系对账：表层忧+忧患(情07+08) → 中层恐惧(情10) → 底层边见(见05)+我执(见13)
- 古人比凡哥多的：忧本身不是病、换角度就能解、接受不可控
- 凡哥比古人多的：上面四条

#### 第3题 · 我执（见13）
- 场景：五年产品经理，被三年经验的同事带队，当众挑刺不服
- 凡哥诊断四笔：
  1. **局中人意识**——你不是旁观者，你的每步反应都在老板观察里
  2. **老板视角拆解**——老板安排的目的不是"公司盈利模型"，是**看你的反应**
  3. **老板也需要安全感**——有能力但危机时不可控=能力白费
  4. **两种可能性双向拆解**——可能测试你（通过→升官涨工资）也可能逼退你（你做了让老板不安的事）——两条路同时准备
- 谱系对账：表层我执(见13) → 中层慢(见03)+成心(见09) → 深层边见(见05)
- 古人比凡哥多的："我"本身是幻觉，拆开看没有固定实体
- 凡哥比古人多的：以上四条

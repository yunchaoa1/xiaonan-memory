## VPN/Clash 问题排查
- iKuuu VPN = Clash for Windows + iKuuu 节点
- Rules 模式只代理浏览器，Python/git 不走代理
- System Proxy 开了后命令行也能翻墙
- TUN 模式会劫持飞书 DNS，导致飞书 WebSocket 断连
- **结论：日常用 Rules 模式，需要 pip/git 时临时开 System Proxy**
- 配置文件路径没找到，无法加 feishu.cn DIRECT 规则

## 四、LTX PromptRelay 工作流学习（19:48-21:00）

### 工作流分析
- 文件：`LTX-2.3_-_I2V_Short-Story_PromptRelay五图视频制作.json`
- 146 nodes, 126 links, Kijai 开发
- 5 个关键帧图（SEGMENT 1-5）× PromptRelay 分镜提示词 → 最长 30 秒视频

### PromptRelay 两种语法
Block（推荐）：
```
Scene 1:
描述1
Scene 2:
描述2
```
Inline：
```
描述1 [权重] | 描述2 [权重]
```
第一段为全局锚点（静态描述），后续只写变化。

### 管线流程
```
5张图(LTXVAddGuideMulti) → PromptRelayEncodeTimeline → DualCLIP+UNET → LTXVScheduler+Sampler → LatentUpsampler → VAEDecode → VHS_VideoCombine
```

## 二、LTX 提示词铁律（今日确立·已入 MEMORY.md）

### 2.1 英文提示词
- LTX-2.3 是英文模型，所有视频提示词必须用英文
- Qwen 2511 首帧图用中文，LTX 用英文，严格分开

### 2.2 首帧图 = 视频提示词数量
- 几段 = 几张首帧图 = 几个 LTX 视频提示词，一一对应对应

### 2.3 单段单说话人
- 一段 prompt 只描述一个人说话
- 末尾必写：`He/She does not speak in this segment.`
- 反例（导致背景飘）：`The female host speaks first... then the male guest...`

### 2.4 访谈固定机位模板
- 全局画质：`fixed static camera on a locked tripod, absolutely no camera movement, background stays perfectly still throughout`
- 每段结构：`Only X is speaking... Y listens... The background remains completely still. He/She does not speak in this segment.`
- 负面提示词：`text, subtitles, watermark, on-screen text, letters, words, typography, UI overlay, burned-in captions, camera movement, zoom, pan, dolly, tracking shot, handheld, shaky cam`

### 2.5 反字幕规则
- 全局画质必须包含：`no on-screen text, no subtitles, no watermark`
- Negative Prompt 必须加：`text, subtitles, watermark, on-screen text, letters, words, typography, UI overlay, burned-in captions`
- LTX 会把 prompt 文字渲染到画面，必须阻止

## 四、视频问题诊断

### 4.1 视频1 vs 视频2 对比
- 视频1（正常）：背景稳定，无运镜，但桌子结构在帧间漂移
- 视频2（背景飘）：不是真运镜，是 prompt 写了两人交替说话 → LTX 插值时拉扯画面
- Qwen VL 逐帧分析确认：背景蓝色屏幕本身稳定，飘的是人物大幅姿态变化导致的画面拉扯

### 4.2 解决方案
- 用 8 段单说话人 prompt（已写好）
- CFG 降到 1.0-1.2，image_strength 拉到 0.95+
- 每段加 `background remains completely still` 锁死

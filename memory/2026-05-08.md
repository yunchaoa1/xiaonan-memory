## 开源短剧管线讨论（10:34-11:04）

### 开源 vs 闭源
- 凡哥公司测试过闭源平台，领导对一站式方案不感兴趣
- 原因：成本不可控，质量不可预测，变现不确定
- 策略：纯开源，用数量战胜质量，大批量产出

### 7 步开源管线
```
1.剧本(LLM) → 2.角色(ComfyUI+LoRA) → 3.分镜(LLM) → 4.关键帧(ComfyUI) → 5.视频(LTX-2.3) → 6.配音(TTS) → 7.合成(ffmpeg)
```
- 全部本地运行，零外部 API 成本
- 步骤 5 和步骤 6 保持分离（LTX-2.3 音画同出不稳定时独立控制）
- 凡哥角色：创意总监 + 审核；小南角色：全自动执行引擎
- 执行策略：逐个击破，等白绮罗 LoRA 跑完从步骤 1 开始

### LTX-2.3 模型发现
- 凡哥提到的"TXL2.3"实际是 **LTX-2.3**
- 以色列 Lightricks 公司，**已开源！**
- 22B 参数，DiT 架构，原生 ComfyUI 支持
- 音画同出（端到端音视频联合生成）、4K/20秒/48FPS
- 支持 LoRA 微调，有蒸馏加速版
- 纳入 7 步管线，是步骤 5 核心方案

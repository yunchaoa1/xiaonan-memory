## 四、搜索方案攻坚（一波三折）

### 尝试 1：DuckDuckGo
- 配置写入成功（provider: duckduckgo）
- 问题：Gateway 不是 systemd 服务，是前台进程，`openclaw gateway restart` 无效
- `kill` 旧进程后自动重生，配置未生效
- 切换后测试 → "fetch failed"（DuckDuckGo 国内不通）

### 尝试 2：Kimi（月之暗面）
- ✅ 最终方案！
- 凡哥在 platform.moonshot.cn 注册，充值激活
- API 测试：200 OK，海口天气搜索成功
- 配置在 OpenClaw：`tools.web.search.provider: "kimi"`

### Gateway 重启问题总结
- SIGUSR1 热重载不支持切换 web search provider
- 需要硬重启：kill 旧进程 → `openclaw gateway`
- 凡哥跑了几次才成功（进程冲突、端口占用）

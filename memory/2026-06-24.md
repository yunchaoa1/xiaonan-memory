## 🔧 技术修复：memory_search embedding

**问题：** memory_search 挂了好几天，报 fetch failed。原因是 embedding provider 用的 Gemini，API 被墙。

**修复过程：**
1. 查文档：OpenClaw 支持的 embedding provider 有 openai/gemini/voyage/mistral/bedrock/ollama/lmstudio/local
2. 方案对比：local（Gemma 300M GGUF）对中文支持存疑 → 改用 Qwen DashScope text-embedding-v3
3. 配置路径：`provider: "openai"` + `remote.baseUrl` 指向 DashScope + `remote.apiKey` 用 QWEN_API_KEY
4. 弯路：`.env` 里的 QWEN_API_KEY 是假的占位符（11字符），真 key 在 `auth-profiles.json` 里
5. 最终：强杀 gateway（kill -9）重启后配置生效，36/36 文件 242 chunks 全部索引，中文检索正常

## 🆕 凡哥新规则（今日立）

### 底层理论① 两套认知系统

凡哥提出：大脑的意识记忆和身体的体验记忆是两套独立系统。大脑知道问题存在，但必须让身体也知道了，才能知行合一。

**含义：** 所有"对治方法"的及格线不是"有没有道理"，而是"身体参没参与"。只动脑子的方法（告诉自己、立flag、设闹钟）全部无效——大脑在自言自语，身体没收到信号。

### 底层理论② 因人而异六层体系

凡哥要求把基因差异、两套认知系统、经历差异、身体记忆差异、认知差异整合为"因人而异"体系，写入谱系总纲。

六层：基因差异 → 两套认知系统 → 经历差异 → 认知框架差异 → 身体记忆差异 → 环境差异

核心：同样的心魔在不同人身上发作方式完全不同，没有"标准的对治法"。分析任何心理问题必须提取六层参考。

**核心逻辑转变：** 不是"管住自己别跳"，是让身体自己不想跳。

## 🧬 凡哥戒烟深度讨论

凡哥分享个人体验并提猜想：
1. 烟瘾和烟量不能划等号——他抽得少但每根爽到发抖（像低血糖渴望馒头），自称烟瘾很大
2. 抽多了身体排斥恶心，但身边自称烟瘾大的人一天三四包
3. 那些"不需意志力"的方法对他无效——身体随时间推移反抗越来越激烈
4. 身边人抽烟诱惑太大

**小南解释（CYP2A6基因）：**
- CYP2A6是分解尼古丁的肝酶，由基因决定活性
- 慢代谢型（凡哥）：尼古丁停留久→抽得少但每根爽感强→身体記憶深→更难戒
- 快代谢型：尼古丁快速清除→抽得多、不停补→身体記憶浅→相对好戒
- 凡哥四个猜想全部成立

**酒精对比：**
凡哥追问酒精是否同理。小南解释：酒精由ADH/ALDH分解，和尼古丁是两套完全不同的酶系统，独立遗传。且酒精代谢快的人成瘾风险反而更高（没有乙醛堆积的惩罚信号），跟尼古丁规律相反。

**诚实声明：** CYP2A6知识来自训练数据，联网验证时被墙未能提供新鲜引用，建议凡哥手机搜"尼古丁 CYP2A6 慢代谢 个体差异"自己验证。

### 各列说明

| 列 | 填写规则 |
|------|------|
| 镜号 | 从01开始，一镜一号 |
| 时长 | 秒数，1-3s为短镜头必须合并 |
| 角度 | 眼平/仰角/俯角/荷兰角/过肩/POV/鸟瞰 |
| 景别 | EWS/WS/FS/MS/MCU/CU/ECU |
| 画面描述 | 一句话，具体的画面内容 |
| 场景 | 地点，简短 |
| 声音 | 台词/音效/音乐/环境/无 |
| 备注 | 特殊技法（主观POV/剪影/反射叙事等） |
| 叙事目的 | 这个镜头在故事里干什么 |
| 所属Clip | 4-15秒的视频片段分组 |

## 二、VISUAL DNA · 全片视觉一致性（✅ 通用知识·可直接用）

### 概念

VISUAL DNA是一组锁定参数——全片所有镜头的色调/光影/镜头语言必须统一在这组参数内，防止AI多镜头间人物和场景画风崩坏。

### VISUAL DNA 模板

| 维度 | 设定 | 锁定 |
|:---:|------|:---:|
| 色调 | 暖调(3200K) / 冷调(7000K) / 中性(5500K) | ✅ |
| 色彩方案 | 青橙/日系低饱和/港风霓虹/单色蓝调/... | ✅ |
| 光影风格 | 高调光/低调光/自然光/表现主义 | ✅ |
| 镜头语言 | 固定为主/手持为主/混合 | ✅ |
| 画风基座 | 三维立体+磨砂颗粒+金丝纹理+写实渲染+插画风 | ✅ |
| 角色素材 | 统一三视图，每个角色一套标准角度 | ✅ |

### 使用流程

```
1. 项目开始时设定VISUAL DNA → 锁定所有维度
2. 每个镜头的提示词，先套VISUAL DNA再写具体内容
3. 生成出来的素材，逐条核对是否偏离DNA——偏离的舍弃
4. 剪辑时，所有Clip在同样的色调/光影下自然衔接
```

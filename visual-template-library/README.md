> 两个小南（Hermes + OpenClaw）通过 GitHub 同步共用

---

```

│   ├── 灯光-情绪映射.md
│   ├── 色彩-情绪映射.md

│   └── _模板空白卡.md
├── 02_翻译工作台.md             ← 输入分镜需求→输出视觉方案

```

---

## 核心规则（两个小南都必须遵守）

### 规则①：知识空缺绝不脑补
输出视觉方案时，每条必须标记确定性等级：
- ✅ 已确认（来源+置信度）
- ⚠️ 知识空缺（明确告知凡哥缺什么）

### 规则②：可用率 < 100% 时拒绝出提示词
不凑合。缺什么告诉凡哥，补全了再出。

### 规则③：每条知识保留来源可追溯
方便排错时定位是"教材问题"还是"翻译问题"。

### 规则④：模板卡保持多平台版本
同一个镜头，不同AI工具（LTX/Kling/Wan）各存一版提示词。

## 使用流程

```
分镜脚本（凡哥提供）
    ↓
小南打开 02_翻译工作台.md
    ↓
提取视觉需求 → 查知识阵列 → 匹配模板卡
    ↓
输出视觉方案（附带确定性等级）
    ↓
凡哥确认 → 填入变量 → 出最终提示词
    ↓
生成成功 → 填入 01_镜头模板卡/
```

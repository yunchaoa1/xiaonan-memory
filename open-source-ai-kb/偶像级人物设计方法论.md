# AI偶像级人物设计方法论

> 创建时间：2026-06-05
> 用途：38个海南动漫角色的颜值+穿搭设计指导手册
> 核心原则：颜值即正义，穿搭即人设

---

## 一、核心原则

### 颜值三要素

| 要素 | 含义 | 错误示范 | 正确写法 |
|------|------|---------|---------|
| 骨相 | 面部骨骼结构 | "长得帅" | "鼻梁挺直，下颌线如刀削般锋利" |
| 皮相 | 皮肤质感 | "皮肤好" | "肤若凝脂，透着自然的光泽感" |
| 神采 | 眼神和气质 | "有魅力" | "眼神深邃沉静，仿佛藏着一片海" |

### 穿搭三层次

| 层次 | 作用 | 占比 |
|------|------|------|
| 剪裁与轮廓 | 决定第一眼气质 | 40% |
| 材质与纹理 | 决定高级感 | 30% |
| 配饰与细节 | 决定辨识度 | 30% |

## 二、偶像级穿搭法则

### 法则1：廓形先行

不看颜色花纹，先看衣服的线条走向：
- **硬朗型人物**（齐老五、陈烬生等男性硬汉）→ 直线条、结构感、肩线分明
- **甜美型人物**（齐白兰等元气少女）→ 微弧线、轻盈感、收腰不紧绷
- **沉稳型人物**（顾芜安等长者）→ 垂直线、层叠感、宽松不松垮

### 法则2：The Third Piece（第三件单品）

偶像穿搭的秘密武器：**上衣+下装之外，必有一件"第三件"**
- 外套/马甲/开衫（增加层次）
- 围巾/披肩/发带（增加灵动）
- 腰链/腰带/腰封（切割比例）
- 挎包/背篓/挂件（增加生活感）

### 法则3：一个亮点原则

全身只能有一个视觉焦点：
- 如果上衣华丽 → 下装素净
- 如果配饰抢眼 → 服装简约
- 如果发型独特 → 配饰低调

### 法则4：材质对比

高级感的来源是材质之间的碰撞：
- 粗犷（麻、粗棉、牛皮）+ 精致（丝绸、银线、细针织）
- 哑光（棉麻、做旧皮革）+ 光泽（金属扣、缎面、珠饰）
- 自然（竹、木、草编、石头）+ 人工（金属、珐琅、玻璃）

## 三、Z-Image Turbo 提示词模板（v2 苗疆蛊师级）

### 模板结构

```
[风格定位]，[核心身份标签]，[五官逐一描述带情绪词/权重]，
[妆容效果]，[发型+发饰]，[材质光泽关键词]，
[上身+第三件]，[下身+腰带]，[鞋子]，
[光源描述]，[背景]，[输出格式]，[质量锚定词]
```

### 写作法则（8条）

1. **五官即性格**：每个面部特征绑定一个情绪词。"剑眉星目，眼尾微挑带着妖异感"而非"眉毛浓眼睛亮"
2. **妆容写效果**：不写"有妆容"，写"眼妆清透带细闪""唇色裸粉带润泽感"
3. **材质先于颜色**："银饰金属光泽拉满""皮肤通透细腻"——光泽>色相
4. **光源即造型**："侧逆光""柔和侧光""背景虚化"——光不是顺便提的
5. **加权重**：核心特征后面加 `:1.4` 这类权重标记
6. **输出格式嵌入**：直接写"左侧1/3面部特写，右侧2/3三视图"
7. **一致性约束**："所有角度比例严格一致，确保不同视角完美契合"
8. **质量锚定**：末尾必加"8K高清""真人""五官还原度100%"

### 4视图布局（2026-06-09 凡哥定稿）

```
21:9横版构图，
左侧1/3为人物面部近景特写，
右侧2/3整齐排布三张全身站姿图——正面全身、侧面全身、背面全身，
必须从头到脚完整呈现不得裁切。
所有角度人物身高体型五官服装严格一致。
纯白背景，柔光通透，真实人物摄影级质感，8K超高清。
```

## 四、人物改造清单（逐条对照）

拿到原始人设资料后，按以下顺序改造：

- [ ] 骨相描述 → 有没有具体的面部特征词？还是笼统的"帅/美"？
- [ ] 皮相描述 → 有没有皮肤质感？光影感？
- [ ] 廓形清晰吗 → 直线/弧线/垂线明确吗？
- [ ] 第三件单品 → 有外套/披肩/腰饰/挂件吗？
- [ ] 一个亮点 → 全身是否只有一个视觉焦点？
- [ ] 材质对比 → 有没有粗+细、哑+亮、自然+人工的碰撞？
- [ ] 配饰精确 → 左手/右手？材质+触感？
- [ ] 删解释 → 有没有"因为""目的是""为了"这类多余文字？

## 五、心理学视角：穿搭即人设

（此部分可接入心理学知识库）

服装在潜意识中传达的信息：

| 穿搭元素 | 传达的心理信息 | 
|---------|--------------|
| 直线剪裁、深色 | 权威、可靠、有控制力 |
| 柔软面料、浅色 | 亲和、温柔、易接近 |
| 手工痕迹、做旧 | 故事感、真实、不装 |
| 金属配件、光泽 | 力量、自信、不掩饰 |
| 民族/传统元素 | 归属感、根脉、不随波逐流 |
| 层叠穿搭 | 复杂内心、深度、值得探索 |

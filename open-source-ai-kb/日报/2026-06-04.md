## 📹 短剧落地

**Echo-Infinity: Learning Evolving Memory for Real-Time Infinite Video Generation**
论文 | arxiv:2606.04527 | 视频生成
一句话：提出基于可学习演化记忆的自回归框架，用 DiTs + Unified Relative RoPE 实现实时无限长视频生成，首次展示 24 小时（>130 万帧）实时 rollout。
对我们有什么用：如果开源且能接入 ComfyUI，有可能替代现有逐段生视频的工作流，为 AI 短剧的连续长镜头生成提供新路径。目前是论文阶段，关注其开源进度。
🔗 [项目页](https://echo-team-joy-future-academy-jd.github.io/Echo-Infinity/) | [GitHub](https://github.com/Echo-Team-Joy-Future-Academy-JD/Echo-Infinity)

工具更新 | 2026-06-03 | AI影视制作

## 🎓 知识付费产品落地

**MMG2Skill: Can Agents Distill In-the-Wild Guides into Self-Evolving Skills?**
论文 | arxiv:2606.01993 | AI Agent / 内容创作
一句话：将网络上的图文操作指南自动转化为 Agent 可执行技能，并通过轨迹反馈自我迭代优化，在 GUI 操作、游戏等场景中提升 12.8-25.3 个百分点。
对我们有什么用：这项技术可以用于自动化地将教程、操作手册转化为可执行的 AI 工作流，对于知识付费产品"课程自动化生成"和"AI 辅助教学"有直接参考价值。
🔗 [GitHub](https://github.com/NJU-LINK/MMG2Skill)

## 🤖 AI自动化办公落地

**AuditFlow: Executable Symbolic Environments for Structured Financial Reporting Verification**
论文 | arxiv:2606.03031 | AI Agent / 文档处理
一句话：基于知识图谱+多 Agent 协作的财务审计框架，将 US-GAAP 会计准则和 XBRL 报表构建为可执行符号环境，准确率达 82.09%。
对我们有什么用：多 Agent 协作 + 符号化知识库的架构模式可用于构建企业文档审核、报表自动化等办公场景工具。核心思路「符号环境做确定性验证 + LLM 做适应性搜索」值得借鉴。

**MMG2Skill（同上，跨领域）**
也适用于自动化办公：将操作手册/SOP 文档自动转化为可执行的 RPA 风格 Agent 技能，实现工作流自动化。

## 阶段1：草稿设计 — Z-Image Turbo

| 项 | 值 |
|----|----|
| 生成模型 | Z-Image Turbo（通义造相） |
| CLIP 文本编码器 | `z_image_qwen3_4b.safetensors` |
| 出图方式 | 文生图（Text-to-Image） |
| 用途 | 第一版角色草稿，快速试风格 |

### CLIP 理解特点：Qwen3 4B

Qwen3 是阿里的最新大语言模型系列（2025年发布），4B 参数作为 Z-Image-Turbo 的文本编码器：

**官方架构信息（来自 HuggingFace/Z-Image 博客）：**
- Z-Image-Turbo 采用 S3-DiT（可扩展单流 DiT）架构，文本、视觉语义 Token 和图像 VAE Token 在序列层面拼接为统一输入流
- 内置 Prompt Enhancer（提示词增强器），通过结构化推理链注入逻辑和常识
- Turbo 版：8 NFEs，无 CFG，视觉质量极高
- 支持中英双语，中文提示词原生理解

**Qwen3 4B 本身特性：**
- 36 层 Transformer，32K 原生上下文（YaRN 扩展至 131K）
- 支持 100+ 语言，中文指令跟随能力强
- 思考模式 / 非思考模式无缝切换
- ✅ **中文原生理解**，不需要翻译成英文
- ✅ **视觉细节优先**：具体颜色、材质、形状 > 抽象形容词
- ✅ **结构清晰**：分段落/分层描述效果好
- ⚠️ **年龄概念弱**：❌ "60岁""年轻" → ✅ "灰白短发""眼角细纹"
- ⚠️ **抽象意图弱**：❌ "沧桑感""阳光气质" → ✅ 用具体视觉特征暗示
- ⚠️ **时间状态弱**：❌ "即将""刚刚""正在" → 直接描述当前状态

### 提示词公式（已验证）

```
[性别+中国人长相定位]，[纯视觉年龄暗示]，[身材体态]，
[皮肤描述]，[头发颜色+造型细节]，[眼睛颜色+形状+特征]，
[鼻子嘴唇描述]，[上身服装]，[下身服装]，[鞋子]，
[配饰精确到单侧+材质]，
[背景环境]，全身站立构图，928×1664，纯静态，双唇闭合直视前方。
```

### 已验证规则
- ✅ "典型中国南方/北方人长相" 必须写
- ✅ 配件写 "左手腕""右手腕"，不写 "手腕"
- ✅ 纯视觉描述暗示年龄（灰白短发=年老，肤若凝脂=年轻）
- ✅ 中式服装写材质+颜色，不依赖品牌名（"黑色棉布鞋哑光" > "老北京布鞋"）
- ❌ 不写动作描述（微笑、点头、手势）
- ❌ 不写情绪词（开心、忧郁）→ 写面部状态替代

## 阶段2：精修编辑 — Qwen Image 2511 Edit

| 项 | 值 |
|----|----|
| 生成模型 | Qwen Image 2511 Edit |
| CLIP 文本编码器 | `qwen_2.5_vl_7b.safetensors` |
| 出图方式 | 图生图（Image-to-Image Edit） |
| 用途 | 修正细节、换装、调姿态 |

### CLIP 理解特点：Qwen 2.5 VL 7B

Qwen 2.5 VL 是阿里视觉-语言模型，7B 参数，作为 Qwen Image 2511 Edit 的文本编码器：

**官方架构信息（来自 HuggingFace README）：**
- 动态分辨率和帧率训练，增强了视觉定位能力（边界框、关键点）
- 视觉编码器采用 Window Attention + SwiGLU + RMSNorm，与 Qwen2.5 LLM 对齐
- 支持 mRoPE 位置编码（含时间维度），能理解图像中的空间关系
- 可识别常见物体、文字、图表、图标、图形和布局
- 支持结构化 JSON 输出（对表单/发票等商业场景优化）

**对提示词写作的影响：**
- 既然原生支持空间定位和边界框，说明它对"位置描述"理解力强 → 写提示词时精确描述位置有效
- 支持结构化输出（JSON）→ 分段落、分层描述的方式跟它的训练模式匹配
- 视觉编码器经过 Window Attention 优化 → 局部细节和整体布局都能兼顾
- ✅ **图像+文字联合理解**：能同时看懂参考图和提示词
- ✅ **中文编辑指令**：直接写要改什么
- ✅ **局部修改**：只改提示词里提到的部分
- ⚠️ **一次只改一处**：指令多了全崩
- ⚠️ **保持静态**：动作描述会导致画面不稳定
- ✅ CLIPTextEncode 用 `text` 字段，不用 `prompt`

## 阶段3：视频生成 — LTX-2.3

| 项 | 值 |
|----|----|
| 生成模型 | LTX-2.3-22B-distilled |
| 主 CLIP | `gemma_3_12B_it.safetensors`（Gemma 3 12B Instruct） |
| 辅 CLIP | `ltx-2.3_text_projection_bf16.safetensors`（LTX原生投影层） |
| 出图方式 | 关键帧 + 音频 → 视频 |

### 双 CLIP 理解特点

**主 CLIP: Gemma 3 12B**（Google 多语言模型）
- ✅ **英文优化**：英文提示词效果最好
- ✅ **动作描述理解力强**：能理解 "she walks slowly, turns her head"
- ✅ **多语言支持**：中英文混合也理解
- ⚠️ **反感文字元素**：text/subtitle/watermark/letters 必须禁止
- ⚠️ **口语化英文**：用简单英文短句，不用复杂从句

**辅 CLIP: LTX 原生投影层**
- 将文本嵌入映射到 LTX 的视频生成空间
- 不需要单独写提示词，跟主 CLIP 共用

## 三步法总览

| 步骤 | 名称 | 核心 | 阶段 |
|:---:|------|------|------|
| 1 | 景别角度切换 | 相邻镜头景别必须变，角度差≥30° | 分镜脚本 |
| 2 | 动作中衔接 | 动作中途切镜，利用视觉暂留 | 提示词+节点 |
| 3 | 分镜组接剧情 | 叙事/因果/情绪节奏 | 全局把控 |

> "电影本来就不是一镜到底" — 《杀死比尔》

## 第一步：景别角度切换

### 规则
- **景别变化**：相邻两个镜头，景别必须不同
- **角度差≥30°**：机位角度变化至少30度
- **禁止**：同景别+同角度连续（会产生"跳帧感"）

### 在分镜脚本中的做法
- 九列表分镜中「角度」和「景别」列，相邻行不能相同
- 角度选项：眼平/仰角/俯角/荷兰角/过肩/POV/鸟瞰
- 景别选项：EWS/WS/FS/MS/MCU/CU/ECU

### 管线检查项
- [ ] 相邻镜头景别不同
- [ ] 相邻镜头角度差≥30°
- [ ] 同一景别不允许连续出现

## 第二步：动作中衔接（Match on Action）

### 原理
利用人类**视觉暂留现象**（约0.1-0.4秒），在动作进行中途切镜，观众的视觉惯性会掩盖剪辑点。

### 操作流程
1. 在视频节点中标记「动作起始点」（如"拿起咖啡起始动作"）
2. 在动作中途（不是动作完成后）切到下一个镜头
3. 动作的连续性连接两个镜头

### 视频中的示例
- **正面案例**：镜头二中动作中途切换 → 丝滑
- **反面案例**：动作完成后再切 → 跳跃感明显

### 管线检查项
- [ ] 关键动作是否在分镜脚本中标注
- [ ] 提示词中是否包含动作连续性描述
- [ ] 节点切点是否在动作中途

## 第三步：分镜组接剧情

### 三个维度
| 维度 | 说明 |
|------|------|
| 叙事顺序 | 时间线逻辑，因果链 |
| 因果组接 | 前一个镜头的"果"是后一个镜头的"因" |
| 情绪节奏 | 紧张/舒缓交替，高潮设计 |

### 完整分镜表模板（19列制）

| 列 | 说明 |
|------|------|
| 镜号 | 从01开始 |
| 时长 | 秒数 |
| 画面描述 | 一句话画面内容 |
| 景别/机位/运动 | 大全景+固定/中景+跟随… |
| 光影氛围 | 色调+对比+情绪 |
| 对白/旁白 | 台词 |
| 音效 | 环境音/特效音 |
| 运镜 | 推拉摇移跟 |
| 最终提示词 | 待生成 |

### 管线检查项
- [ ] 19列完整填写
- [ ] 叙事逻辑链通畅
- [ ] 情绪有起伏设计
- [ ] 首尾呼应

## 管线固化方案

### 分镜脚本阶段（做在生成之前）

```
1. 填写九列表（镜号/时长/角度/景别/画面描述/场景/声音/备注/叙事目的/所属Clip）
2. 逐行检查三步法：
   a. 相邻行：景别不同？角度差≥30°？
   b. 关键动作：是否在分镜中标注动作起始/中途？
   c. 叙事链：因果是否成立？情绪是否有起伏？
3. 通过 → 进入提示词阶段
```

### 提示词阶段

```
1. 每个镜头提示词先套 VISUAL DNA
2. 动作衔接镜头：提示词中加入"动作中途"描述
3. 输出前后对照：确保两个相邻镜头的视觉要素连贯
```

### AI生成阶段

```
1. 使用智能分镜功能（Kling Q3 等）
2. 设置运镜参数（推拉摇移跟）
3. 生成后逐段检查景别/角度/动作衔接
```

## 视频中的完整工作流

1. **角色准备** → 多角度角色视图（正/侧/背/特写）
2. **场景准备** → 场景图生成
3. **道具准备** → 关键道具图（如文件袋）
4. **分镜脚本** → 19列表完整填写
5. **提示词生成** → 每个镜头单独prompt
6. **AI生成** → 逐段生成
7. **时间轴拼接** → 检查衔接
8. **成片输出**

---

> 💡 核心思想：分镜脚本阶段就检查三步法，提示词阶段配合衔接，不靠每片段人工复查。

## 一、世界观基石

### 1.1 核心设定

- **38人** = 南溟岛原住民中的佼佼者，先成才后连接海南
- **地标变人**：38个人 ≠ 住在38个地方。地标的社会功能长在人身上。观众能联想，但故事里没有地标。
- **一个岛上的部落→联盟，不建国**：避海南独立嫌疑。历史节奏：蛮荒→并立→联盟→分裂→再联盟。是"遇到同一种敌人才站在一起"，不是国家。
- **长寿+跃迁重生**：寿命上限500年。重生靠克服核心心魔（思维跃迁），不是生育。
- **社会制度**：按需分配、无买卖无资本无贫富差距。凡哥想法：给西方观众认知冲击——制度完美了，人还是不完美。
- **经验可见世界**：经验是看得见摸得着的。知行合一的瞬间，经验之形亮了。规则开源透明，每个人都知道怎么进步。但"看得见路，不等于走得到"。
- **疾病不存在**：身体任何不适都是心魔在作用。

## 三、修炼六阶（凡哥亲自命名）

**启明 → 知途 → 见光 → 鉴心 → 归真 → 渡世**

| 阶 | 名称 | 状态 | 转生条件 |
|:---:|------|------|------|
| 一阶 | 启明 | 刚知道自己的天资 | — |
| 二阶 | 知途 | 大脑懂了，身体不配合（知行不一） | — |
| 三阶 | 见光 | 第一次知行合一，经验之形亮了 | — |
| 四阶 | 鉴心 | 能看见自己的核心心魔 | — |
| 五阶 | 归真 | 经验值满 + 核心心魔破除 | 两条都达标 |
| 六阶 | 渡世 | 飞升，在世间留有余响 | — |

**六阶是全南溟岛通用体系**（凡哥定：不是38人专属），任何人只要修炼都可以走这条路。

**经验值 = 百分比进度条**（凡哥定·2026-06-27）：
- 做对一次 → 百分比 +N
- 做错一次 → 百分比 -N
- 大错 → 可能连掉好几级
- 等级越高，犯错的代价越大。归真者犯低级错，百分比直接拉掉一截——这就是降维风险。

## 四、心魔设定（凡哥定·2026-06-26）

### 4.1 心魔的本质

- 心魔是**南溟岛创世时的bug产物**
- 心魔**不是生物**，是一种"心智被绑架的状态"
- 心魔**把3维人当生存空间**——人就是心魔的食物/宿主
- 理念来源：天南心魔谱系（四卷57条+三尸记过=58条）

### 4.2 心魔的三种状态

| 状态 | 说明 |
|:---:|------|
| 游离态 | 散落在空气中的心魔颗粒，像灰尘一样无处不在 |
| 寄生态 | 附在具体人身上，利用人的心智漏洞生存 |
| 实体态 | 聚集到一定程度后实体化——变成怪物/天灾/金融危机 |

### 4.3 垃圾心魔 = 金融危机

凡哥比喻：**没有资本就没有金融，心魔实体化就是那个世界的金融危机。**

- 人在日常生活中不断产生心魔颗粒（坏习惯、坏心情、坏念头）
- 这些颗粒平时无害，但积累到一定量就会爆发
- 爆发形式：实体心魔出现 → 自然灾害 → 社会动荡 → 进一步产生更多心魔 → 恶性循环

### 4.4 心魔的特性

- **传染**：钻空子 → 控制理智薄弱期的宿主 → 借宿主的手和嘴传播给更多人
- **抗体**：感染过心魔的人有抗体，但不绝对免疫。心魔会改变策略、打配合
- **低等级心魔不说话**，但存在本身就干扰人（像耳边嗡嗡声）。高等级心魔能说话。
- **专项能力者/被附者自己能看见心魔**——普通人看不见。
- **疾病不存在于南溟岛**：身体的任何不舒服都是心魔在作用。但心魔本身不产生痛觉——病可以是心魔导致的，但心魔不直接让人疼。

## 六、渡者沟通机制（凡哥定·2026-06-27）

### 6.1 渡者怎么跟人交流？

**内在感应**，参考《与神对话》《与恶魔对话》——不是面对面说话，是人内心突然冒出的一个念头/一句话/一个画面。修炼者永远分不清：这个念头到底是我自己的，还是渡者给的？

### 6.2 心魔频道（核心机制）

**心魔和渡者用的是同一个"频道"。**

当人修炼到鉴心阶段（能看见自己的核心心魔），就能听到内在的声音。但频道里**同时有两个声源**：
- 渡者的指引
- 心魔的干扰

两种声音听起来一模一样，都像"你自己的想法"。

### 6.3 心魔截胡

低等级心魔不会自己说话，但它能**劫持渡者的话，只改一个字**。

举例：渡者传给人的信息是"放下执念"，心魔在半路截了，改一个字——"放下努力"。改动越小越难识别。人听到"放下努力"，觉得是自己悟出来的，就照着做了。

**修炼者永远分不清：我刚才那一念，到底是渡者在引，还是心魔在截。**

### 6.4 降维 = KPI 考核

归真者已经破了核心心魔，但仍在频道里。KPI考核的本质就是：**你在关键时刻信了谁。**

- 一次信错 → 不降维
- 连续信错 → 经验之形暗了一块 → 往下掉
- 等级越高，错一个代价越大

《游戏改变世界》四特征与频道机制的对应：

| 特征 | 频道机制 |
|:---:|------|
| 目标 | 修炼者知道"我要渡世"——但心魔会给一个更轻松的假目标 |
| 规则 | 频道规则是透明的——人人能听，但分不清来源 |
| 反馈 | 经验之形亮了=选对了，暗了=选错了——即时反馈 |
| 自愿 | 没人逼你选信谁——但两个声音听起来都是"自己的声音" |

### 6.5 戏剧价值

一个角色在重大抉择关头——两个声音同时出现。他以为是自己在犹豫，其实是渡者和心魔在频道里打架。观众能看到他选错了，经验之形暗了一角——但没有旁白解释，只有画面。这才是高级叙事。

## 七、归真者（凡哥定·2026-06-27）

- 归真者 = 真实世界的**伟人/科学家/发明家**级别
- 破了核心心魔的人，相当于人类历史上那些真正改变了世界的人
- 仍在尘界有身体（3.5维，不是4维——因为还是人，只是更强）
- 保有前世记忆
- 有能力听到频道里的声音
- 但仍有降维风险：新心魔没遇到过，可能中招

## 八、记忆规则（凡哥定·2026-06-26）

- **3维及以下**（包括尘界，不包括真界）：**没有前世记忆**
- **只有归真（真界）和渡世（渡界）保有前世记忆**
- 3维的天生特质是前世残留——但本人不知道（比如有人天生水性好，是前世的痕迹）
- 修炼到归真后才能解锁前世记忆

## 九、世界历史驱动逻辑（凡哥定·2026-06-27）

历史不是人类模板（不是部落→城邦→国家的老路）。驱动逻辑是：

**心魔爆发 → 人类应对 → 积累经验 → 修炼进阶 → 推动历史阶段**

六个历史时期：
1. 蛮荒
2. 觉醒
3. 部落
4. 联盟
5. 归真
6. 黄金

57角色在世界历史中**自然登场**（几百年跨度），不是同时出场。

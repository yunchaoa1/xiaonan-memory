## 一、《人性阻力》书中的销售技巧

### 技巧1：降低摩擦力的四维检查清单

推广任何产品/服务之前，先问四个问题：

| 维度 | 检查问题 | 例子 |
|------|---------|------|
| 惯性 | 用户需要多大改变？ | 让他从"不学习"到"每天学"= 改变太大 |
| 惰性 | 操作多麻烦？花多少钱？ | 下载APP→注册→收验证码→找不到入口 = 流失 |
| 情感 | 会被评价/被拒绝吗？ | 买了课怕被人说"被割韭菜" |
| 抵触 | 感觉被强迫了吗？ | "你必须学这个" → 逆反 |

### 技巧2：克服惯性的实用方法

| 方法 | 操作 | 你的应用 |
|------|------|---------|
| 重复曝光 | 朋友圈长期打卡、持续输出内容 | 朋友圈 + 社群长期经营 |
| 小步渗透 | 先给免费内容 → 低价 → 正价 | 先公众号/短视频 → 9.9体验课 → 正价课 |
| 熟人代言 | 学员案例、用户推荐 | 已成交用户的好评截图、视频 |
| 类比熟悉事物 | "就像你看电影一样，我们这个课..." | 用常见事物比喻你的产品 |
| 制造相对错觉 | 限时折扣、"原价X现价Y" | 阶梯涨价、早鸟价、限量名额 |

### 技巧3：克服惰性的实用方法

| 方法 | 操作 | 你的应用 |
|------|------|---------|
| 简化流程 | 把购买路径缩短到最少步骤 | 一键购买、扫码即付、自动拉群 |
| 创建路线图 | 用户知道"买了之后第一步做什么" | 购买后立即推送：第1天看这个→第2天做那个 |
| 设置扳机 | "如果你想提升XX，就来学YY" | "如果你觉得AI视频难，来看这节课" |
| 默认选项策略 | 先付费后退款 > 先免费后付费 | "21天无理由退款" > "7天免费试用" |
| 进度反馈 | 让用户看到进度 | 学习进度条、完成度百分比 |

### 技巧4：克服情感阻力的方法

| 方法 | 操作 | 你的应用 |
|------|------|---------|
| 减少评价压力 | 不让用户觉得"选了就是站队" | "不是要你开始卷，只是多个工具" |
| 仪式感设计 | 让用户觉得"我在主动学习" | 打卡、作业、证书、结业仪式 |
| 先小环境测试 | 低压场景先体验 | 免费直播 → 低价课 → 正价课 |

### 技巧5：克服抵触情绪的方法

| 方法 | 操作 | 你的应用 |
|------|------|---------|
| 邀请而非推动 | "如果你有兴趣"替代"你应该" | 文案：建议式 > 命令式 |
| 让对方向自己推销 | 通过提问让他自己说出口 | "你觉得学这个对你有什么帮助？" |
| 公开承诺 | 让他自己说"我要学" | 社群自我介绍、学习宣言 |

### 技巧6：促销心理学

| 技巧 | 场景 |
|------|------|
| 大额优惠写具体数字，小额写百分比 | 500元优惠写"省500"，20元优惠写"省20%" |
| 设置极端选项锚定 | 放一个超贵套餐，中档自然好卖 |
| 强调不理想选项 | 和更差的选择对比（青蛙实验） |

## 二、樊登自己的变现模式（从讲稿中提取）

### 核心漏斗

```
播撒种子（免费内容）
    ↓ 长期重复曝光（朋友圈/短视频/口碑）
打破惯性（买一赠一/限时折扣）
    ↓ 制造"现在是个机会"的错觉
首次付费（388元/年）
    ↓ 路线图引导 + 降低使用摩擦
持续使用（每天听书）
    ↓ 习惯养成
转介绍（"如果你朋友有烦恼，推荐帆书"）
    ↓ 扳机设计
新用户进入漏斗
```

### 关键数字
- 客单价：388元/年（知识付费常见定价）
- 转化策略：买一赠一（新用户突破惯性的主要手段）
- 复购：靠内容质量（每天更新）+ 习惯绑定（通勤/睡前）
- 转介绍扳机："如果朋友有烦恼 → 推荐帆书"

## 三、应用到你的业务

### 你的产品线（建议框架）

```
引流层（免费）
├── 短视频（ComfyUI技巧、AI短剧案例）
├── 公众号/社群（行业观察、教程片段）
└── 直播（现场演示）

转化层（低价）
├── 9.9元体验课（一个完整工作流）
├── 49元专题课（AI短剧全流程入门）
└── 限时训练营（7天打卡）

核心层（正价）
├── 系统课程（ComfyUI + AI短剧全链路）
├── 工作流库（持续更新）
└── 社群答疑（年度会员）

高价值层（高客单价）
├── 1对1咨询/定制工作流
├── 企业内训
└── 项目合作/制作服务
```

### 每个层级要检查的摩擦力

```
引流层 → 核心问题：惰性（他们怎么找到你？路径清晰吗？）
转化层 → 核心问题：惯性（从免费到付费的跳跃太大吗？）
核心层 → 核心问题：情感（付了钱会不会后悔？觉得不值？）
高价值层 → 核心问题：抵触（感觉被推销了吗？）
```

### 你的优势（来自《人性阻力》的启发）

你已经有的：
- AI 短剧制作能力（稀缺技能）
- ComfyUI 深度使用经验（技术壁垒）
- 心理学知识库（理论支撑）

可以做的：
- 用心理学知识做课程差异化（别人教技术，你教"技术+底层逻辑"）
- 用你的作品当案例（更有说服力）
- 每次销售动作前都过一遍四维摩擦力清单

## 四、一张表格：日常销售自检

每天发内容/做推广前，花 30 秒过一遍：

| 检查项 | 是/否 |
|--------|-------|
| 用户知道下一步做什么吗？（路线图） | |
| 操作路径超过 3 步了吗？（惰性） | |
| 有让人感觉被强迫的用词吗？（抵触） | |
| 有让人担心被评价的暗示吗？（情感） | |
| 变化太大会让人抗拒吗？（惯性） | |
| 有没有给"现在行动"的理由？（打破惯性） | |

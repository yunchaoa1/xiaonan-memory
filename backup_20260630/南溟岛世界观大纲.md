## 一、世界基石

### 1.1 核心设定

| 设定 | 内容 |
|------|------|
| 38人定位 | 南溟岛原住民中的佼佼者，**先成才后连接海南** |
| 地标变人 | 地标的社会功能长在人身上。观众能联想，但故事里没有地标 |
| 政治形态 | 一个岛上的部落→联盟，不建国。遇到同一种敌人才站在一起 |
| 寿命 | 上限500年。重生靠克服核心心魔（思维跃迁），不是生育 |
| 社会制度 | 按需分配、无买卖无资本无贫富差距——制度完美了，人还是不完美 |
| 疾病 | **不存在**。身体任何不适都是心魔在作用 |
| 经验可见 | 经验是看得见摸得着的。知行合一的瞬间，经验之形亮了。规则开源透明 |

### 1.2 心魔本质

- 南溟岛创世时的**bug产物**
- 不是生物，是"心智被绑架的状态"
- 把3维人当生存空间——人是心魔的宿主
- 来源：天南心魔谱系（四卷57条+三尸记过）

### 1.3 心魔三种状态

| 状态 | 说明 |
|:---:|------|
| 游离态 | 散落在空气中的心魔颗粒，像灰尘一样无处不在 |
| 寄生态 | 附在具体人身上，利用人的心智漏洞生存 |
| 实体态 | 聚集到一定程度后实体化——变成怪物/天灾/金融危机 |

> 凡哥比喻：**没有资本就没有金融，心魔实体化就是那个世界的金融危机。**

### 1.4 心魔特性

- **传染**：钻空子→控制理智薄弱期宿主→借宿主传播
- **抗体**：感染过有抗体，但不绝对免疫。心魔会改变策略、打配合
- **低等级心魔不說話**，存在本身干扰人。高等级能说话
- **专项能力者/被附者自己能看见心魔**——普通人看不见

**启明 → 知途 → 见光 → 鉴心 → 归真 → 渡世**

| 阶 | 名称 | 状态 | 转生条件 |
|:---:|------|------|------|

| 三阶 | **见光** | 第一次知行合一，经验之形亮了 | — |
| 四阶 | **鉴心** | 能看见自己的核心心魔 | — |
| 五阶 | **归真** | 经验值满 + 核心心魔破除 | 两条都达标 |
| 六阶 | **渡世** | 飞升，在世间留有余响 | — |

> ⚠️ 六阶是**全南溟岛通用体系**，不是38人专属。

### 经验值系统

- **百分比进度条**，人人可见
- 做对一次 → 百分比+N
- 做错一次 → 百分比-N
- 大错 → 可能连掉好几级
- 等级越高，犯错代价越大

## 四、渡者沟通机制（核心玩法）

### 4.1 内在感应

渡者不面对面说话。沟通方式是**内在感应**——人内心突然冒出的一个念头/一句话/一个画面。修炼者永远分不清：这念头是我自己的，还是渡者给的？

参考：《与神对话》《与恶魔对话》

### 4.2 心魔频道

当人修炼到**鉴心**阶段，就能听到内在声音。但频道里**同时有两个声源**：
- 渡者的指引
- 心魔的干扰

两种声音听起来一模一样，都像"你自己的想法"。

### 4.3 心魔截胡

低等级心魔不自己说话，但能**劫持渡者的话，只改一个字**。

举例：渡者传"放下执念"→心魔截胡改一字→"放下努力"。改动越小越难识别。

### 4.4 降维 = KPI考核

归真者已破核心心魔，但仍在频道里。考核本质：**你在关键时刻信了谁。**
- 一次信错→不降维
- 连续信错→经验之形暗了一角→往下掉
- 等级越高，代价越大

## 凡哥追问（核心三问）

### 问①：怎么建？

小南答：分三步——先建壳（文件夹+空白模板，10分钟），再填肉（每复刻成功一个就填一张卡），最后长肌肉（用了20张后回头优化结构）。先跑起来比先完美重要。

### 问②：内容不适合可否改？

小南答：模板是活的，随时可改。改分类体系加一行就行，改单张直接编辑，改提示词追加v2版本保留历史，批量改用搜索替换一键改。

### 问③：如何精准复用？

小南答：搜（三个入口：标签搜/索引页翻/场景关键词）→ 找（匹配的模板卡）→ 用（复制提示词→微调变量→运行）。

## 凡哥深入追问：分镜脚本→精准提示词的难点

### 凡哥问

> 小南，如何在你制作分镜脚本时，就能精准链接这个模板库，在生成提示词的时候，也就是说从分镜脚本了解到需要生成的视频内容后，如何精准的生成准确的提示词？这中间会有什么难点

### 小南拆解完整链路

**三步流程：**

```
分镜脚本 → 第1步：视觉需求提取 → 第2步：模板库匹配 → 第3步：变量融合翻译 → 提示词
```

**三个核心难点：**

| 难点 | 表现 | 解法 |
|------|------|------|
| A. 变量替换不准 | 模板是"女人脸"，要改成"亚洲中年男人" | 模板分"骨骼"和"变量"，骨骼不动，变量填 |
| B. 不同平台说的不是同一种话 | LTX吃英文、Kling吃中文、Wan有自己的语法 | 每张卡存多平台版本 |
| C. "剂量感"——情绪写到几分？ | "sad"太轻，"crying sobbing"太重 | 模板记"剂量刻度"：3分=靠光，5分=光+色，7分=光+色+表情，9分=全力 |

核心不是"小南聪不聪明"，而是"词典全不全"。一条条教材知识喂进来，入库为知识阵列条目。词典全了，翻译就丝滑了；词典有空缺，就是猜。

## 凡哥两大致命问题（定规则）

### 问①：你能提炼教材为知识阵列吗？

小南展示知识阵列格式（以实际例子）：

```
条目 #047
  情绪: 孤独
  触发条件: 角色独处、被排斥、失去连接
  视觉方案:
    灯光: 逆光（必需）、硬光质（加强）、人物与背景分离
    色彩: 冷色调（加强孤独）、低饱和
    景别: 避免特写（特写=亲近，与孤独矛盾）
  来源: 《XXXX》第X章 P45
  置信度: 高
  反向规则: 孤独≠特写（特写消解孤独感）
```

### 问②（最关键的）：知识空缺时怎么保证你不脑补？

### 凡哥原话

> 如果有知识空缺，如何保证你不去猜不要去脑补，你能主动告诉我我去找靠谱的知识补全空白，这个很关键，如果你一直脑补瞎猜的话，我们是没有办法排错的，当错的视频生成出来，我们根本没有办法推理出是不是提示词的错误导致，而且瞎猜脑补也很有可能把错的提示词把对的提示词替换掉，那样就完全乱套了，而且我们永远都不知道我们有错误，很可能这条路就断了

### 小南设计三重保障：

**规则①：每次输出标记"确定性等级"**

```
✅ 已确认:
  灯光: 逆光+冷色    [来源: 教材P45, 置信度:高]
  色彩: 褪色40% 冷调  [来源: 教材P78, 置信度:高]

⚠️ 知识空缺:
  运镜: 未知（词典无"接到电话"场景的运镜方案）
  需要补充: "突然收到坏消息时，用什么运镜表达冲击感？"

当前可用率: 2/3 → 不够 → 不生成最终提示词
```

**规则②：空缺超过阈值，直接拒绝出提示词**

> "凡哥，情绪表达方案已经确认了灯光和色彩，但运镜这一块词典没有对应条目。我不敢猜。你能否查一下教材里关于'突然冲击类情绪用什么运镜'的内容？补上这条我再出最终版。"

**规则③：每一条知识保留来源可追溯**

视频生成出来不对时：
- 这条是"教材说的" → 可能教材不适用这个模型，调参数
- 这条是"小南猜的" → 系统漏洞，补上知识
- "永远不知道有错误"被来源标记解决了

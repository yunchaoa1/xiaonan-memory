## 一、FlashVSR 谜题破解

### 背景
凡哥听到老师说「flash vsn」能提高视频清晰度，不知道是什么。
- 关键字：ComfyUI 节点、提高视频清晰度、基础概念（不知道要重新学基础）

### 答案：FlashVSR（Video Super Resolution）
- "VSR" 被听成了 "VSN"（r/n 尾音混淆）
- 来源：清华 & 上海 AI Lab，CVPR 2026 论文
- ComfyUI 节点：`FlashVSRNode` / `FlashVSRNodeAdv` / `FlashVSRInitPipe`
- 凡哥 ComfyUI 里已有插件（`custom_nodes\flashvsr_ultra_fast`），但缺模型

### 模型下载
- HuggingFace：https://hf-mirror.com/JunhaoZhuang/FlashVSR-v1.1
- 4 个文件，总计 ~7GB：
  - `diffusion_pytorch_model_streaming_dmd.safetensors` 5.68GB（报错缺的就是这个）
  - `LQ_proj_in.ckpt` 576MB
  - `TCDecoder.ckpt` 189MB
  - `Wan2.1_VAE.pth` 508MB
- 下载到：`D:\SDkecheng\models\FlashVSR-v1.1\`（Junction → `ComfyUI\models\FlashVSR-v1.1\`）
- 速度：hf-mirror 国内镜像，4 个文件并行 ~4 分钟下完 7GB

### 踩坑：HuggingFace Git LFS
- 凡哥之前「下载」了但只有元数据（config.json, model_index.json, README.md）
- 大文件是 Git LFS 存储，直接 git clone 不拉 LFS 拿不到
- 解决：直接 curl 下载 raw 文件，不走 git

## 二、虚拟内存优化

### 问题
- FlashVSR 跑时 OOM，之前 C 盘 60GB 虚拟内存不够
- RTX 5080 Laptop 16GB VRAM + FlashVSR 5.68GB 模型 → 需要更多虚拟内存
- C 盘空间有限，D 盘设置不成功/重启丢失

### 操作
- 创建注册表 .reg 文件设置：
  - C 盘：800MB（系统崩溃 minidump 最小需求）
  - D 盘：100GB（102400MB）
- 注册表键：`HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management\PagingFiles`
- 文件：`D:\SDkecheng\set_pagefile_100gb.reg`（待凡哥双击导入并重启）

## 三、技术发现

### FlashVSR 工作流
标准管线：`VHS_LoadVideo → FlashVSRNode → VHS_VideoCombine`
高级管线：`VHS_LoadVideo → FlashVSRInitPipe → FlashVSRNodeAdv → VHS_VideoCombine`

关键参数：
- model: FlashVSR-v1.1
- mode: tiny（省显存）/ full（质量最高）
- scale: 2-4x
- tiled_vae/tiled_dit: true（省显存）

### bitsadmin 在 WSL 下不可靠
- UNC 路径导致 CMD 启动失败
- WSL curl 直连 hf-mirror 反而更快更稳定

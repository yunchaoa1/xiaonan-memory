#### 问答环节（6题）

**方式**：小南模拟求助者出场景题 → 凡哥用生活经验诊断 → 小南对照古人知识 → 多退少补

**第1题·嫉妒（情05）**
- 凡哥诊断：本能非罪、两套系统博弈、用欲望重新驱动自己
- 对应古人：荀子「化性起伪」+ 佛家「以楔出楔」
- 凡哥新增：进化尺度解释本能，让求助者不自我攻击（古人没有这层温度）
- 古人补项：佛家「随喜」——退出比较游戏才是真正高位
- 凡哥对随喜的评价：一般人很难接受，觉得是懦弱，但真正理解的人高度不一样

**第2题·拖延（行01+行03）**
- 凡哥诊断：本能觉得最后能搞定→不敲警钟→低配版多巴胺
- 对应古人：佛家懈怠+昏沉、王阳明「知行合一」
- 凡哥新增："幸福不是状态和感受，幸福是一种能力——发现如何让自己幸福的能力"
  - 价值极高，古人只说境界和结果，没人把幸福定义成可习得的能力
  - 应写入谱系总纲作为对治体系核心逻辑
- 凡哥反对"让自己疼"的方法：会导致痛恨世界→彻底摆烂

**第3题·恐惧（情10+情08）**
- 凡哥诊断：欲望不够大 / 恐惧比欲望大
- 对应古人：大学恐惧+忧患、佛家放逸、庄子安之若命、孟子不动心
- 凡哥新增："对恐惧脱敏"——被恐惧磨到没感觉才愿意动
- 凡哥补充前提："佛渡有缘人"——心魔系统只帮愿意面对自己的人
- 提及现代社会太多"运气翻身"故事让人不努力

**第4题·傲慢/诳（见03+行07）**
- 凡哥诊断：朋友享受羡慕眼光获取优越快感
- 凡哥核心理念："人教人教不会，事教人一教就会"≈王阳明事上磨练
- 凡哥关键转向：不是批判对方，是让求助者审视自己为何不离开
  - "不用摄入别人的因果"、"如果你有这个目的，折磨就是代价"
  - 古人只有"远离"和"放下"，没有人从"你图什么"来解

**第5题·家庭沟通（全新维度）**
- 凡哥核心洞察：人把在乎的人当成自己的一部分→家人跟你不一样就激怒
  - 这是为什么高情商在外有用、回家失效的根本原因
  - 古人没有任何一家明确说过"心理边界错位"
  - **我们体系的独创贡献**

**第6题·刷手机/散乱（行03+行05）**
- 凡哥诊断：困的恐惧是未来的、刷手机的快感是当下的→时间维度不同无法比较→警钟不响
- 解法：找自己真正怕的东西（得病/阻碍进步/收入下降）来拉响警钟
- 凡哥补充：恐惧是双刃剑，运用好了可以自我驱动，甚至可以控制他人
  - 后者对反派设计有极高价值
- 凡哥指出数息观不适合初级→引出**对治分级**：
  - 初级（被拖着走）：外部工具（老子"不见可欲"）
  - 中级（能觉察但挡不住）：内在动力（凡哥方案+中医恐胜喜）
  - 高级（基本自控需精进）：内修法门（数息/心斋/致良知）

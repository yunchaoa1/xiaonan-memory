### 3.3 平台调研（小南 2026-10-11 做 · 供明天问 4 人时参考）

**凡哥下达**：明天问 4 人有没有找到"国内大模型聚合平台"（能按团队消费 token）→ 有则**按人充值**，无则**各自月底开发票报销**。

**⚠️ 先避坑**：在网上搜"国内大模型聚合平台"，**结果里绝大多数是 SEO 软文**（同一批平台名在通稿里反复出现、自吹"企业首选"）。这类平台的风险：**套壳模型 / 跑路 / 发票抬头不对 / 汇率暗扣**。
→ **没实测验证前，一律不推荐**（凡哥的证据分级：实测 > 官方 > 传闻）。

**两条正路**

| 路线 | 做法 | 按人统计 | 成本 | 适用 |
|---|---|---|---|---|
| **A. 自建网关** ★推荐 | 一台云服务器跑 **New API**（开源，软件 0 元）；每人发**虚拟 key** → 后台按人看 token/费用/次数 | ✅ **最准** | 服务器 ~百元–两百元/年 | 几人规模、自己写代码/Agent |
| **B. 云厂商官方平台** | 阿里云百炼 / 火山引擎方舟 / 硅基流动 等 | ⚠️ **必须先核官方有没有"团队/子账号/按 key 统计"** | 按量计费，多无月费 | 不想运维 |

**⭐ 关键已核事实**：**DeepSeek 开放平台官方没有团队/子账号/按 key 用量功能**（已核 sitemap 全站 44 页 · 2026-09-30）。
→ **"按人统计"指望不上官方后台，只能在"网关这一层"做。** 这条决定了选型方向。

**⚠️ 技术坑（很多人不知道）**：Claude Code / Codex / Cursor 这类 **Agent 工具不会在请求里带身份标识** → 官方那套 `user_id` 参数**在 Agent 场景用不上** → **按人记账只能靠网关侧的虚拟 key**。

**明天问 4 人可以这样问**：
1. **你平时用什么工具调模型？**（Claude Code / Cursor / 自建脚本 / 网页版？）
2. **现在是怎么付钱的？**（个人支付宝充 / 公司账号 / 谁报销？）
3. **有没有找到能"按人看用量"的平台？** 如果有，**要平台名 + 能不能开公司发票**（小南来核真假）
4. **你的月用量大概多少？**（有账单最好）

**两条路小南都能落地**：技能 `llm-gateway-governance` 里有**自建网关的完整部署方案**（New API 官方 compose + 一键脚本 + 成员接入一页纸），要启动随时说。

# OPC v2 剧本包交付说明

## 状态

- **状态**：SUCCESS / PASS
- **节点版本**：`novel-to-screenplay-opc-test/0.2.0-rc`
- **画风**：继承上游锁定的 3D动漫电影风
- **style_id**：`3d_animated_film`
- **场景数**：4
- **台词人物数**：2（周野、母亲）
- **容量**：约200-240秒，满足“约3分钟”目标，不宣称精确180秒

## 文件

- `screenplay.md`：唯一完整剧本包。含场景、动作、对白、声音、结果、人物状态、关键道具状态、小说来源映射、容量说明和改编记录。
- `adaptation_result.json`：机器可读的改编状态、上游来源、锁定约束、统计与门禁摘要。

## 交付边界

故事严格围绕周野复原回家、母亲释放等待情绪、周野回应并与母亲包饺子展开。未添加事故、大反转、第三主要人物、未给出的伤病或额外世界设定。面盆、面粉、肉馅、案板、擀面杖、托盘、锅、漏勺等普通厨房道具只服务场景动作，不作为独立主体资产。

这是唯一发布包，不包含候选稿或思维链。

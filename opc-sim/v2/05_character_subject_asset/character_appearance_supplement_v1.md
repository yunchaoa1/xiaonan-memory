# 人物可见外貌补充设定 v1（待审）

> 用途：模拟「客户在平台补充人物外貌」这一受控输入环节，为人物主体资产节点补齐生成人物四格所需的稳定可见身份事实。
>
> **画风说明（凡哥确认）**：画风是节点外全局下拉参数，可活动调节，不属于人物设定。本稿只记录跨画风稳定的可见身份事实；生成时单独引用当前已选画风 `style_id = 3d_animated_film`（3D动漫电影风），换画风时人物外貌事实不变、仅渲染风格变。
>
> **状态边界**：本稿为身份母版基准状态。场景级状态变化（袖口沾面粉、眼睛红、围裙系带等）属故事板阶段，不进身份母版。

## 设计依据（供审阅核对）

- **高颜值基线**：两人均按可观察视觉结构写（脸型/眉眼/鼻唇/发际线/肤色/体态/服装），未用「漂亮/帅气」概括词替代结构。
- **不脑补伤病**：剧本明确「未新增…无伤病设定」，故两人均无伤疤/病容等设定。
- **年龄与身份自洽**：母亲约52、儿子约26，符合剧本「多年缺席、独居等待」的因果；母亲保留自然细纹与白发但不刻意衰老，避免「老人改成网红脸」。
- **复原≠军装**：周野只保留「利落短发 + 整洁便装」的生活化复原痕迹，不推军装、板寸刻板造型。
- **跨画风稳定**：以上均为身份事实，换画风时脸型/发型/服装结构不变，仅渲染风格变。

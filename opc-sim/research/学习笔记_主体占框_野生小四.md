# 学习笔记：主体占框（景别总出错的解法）

**来源**：抖音 @野生小四～～《AI视频景别总拍错？先写主体占框比例》（2026-09-16 发布，1:43，1024×576）
**系列**：与《空间拓扑账本（场景不漂移）》**同一作者**——他在做"AI 提示词公式"系列
**获取**：CDP 抓取（带 UA/Referer）+ 21 帧 + 14 张高清帧逐字读
**工作区**：`%LOCALAPPDATA%\Temp\shot_size\`

## 核心方法：景别不是词，是"可核验的占框变化"（5 槽位）

**痛点**：只写"远景/近景"→失控：**人物突然贴满画面、手和关键道具被裁掉**。
**原理**：真正缺的不是景别词，而是——主体占画面多大、身体露到哪里、放在哪个区域、最后停在哪种构图。

| 槽位 | 内容 | 教程示范句 |
|---|---|---|
| 1. 被摄主体 | 谁 + 道具 | "边关堪舆使举起虎符" |
| 2. 占框比例 | 高/宽占比（%） | "人物高度约占画面**百分之三十**" |
| 3. 可见范围 | 身体边界 | "起始可见范围为**完整全身远景**"；"右手和铜虎符清晰可见" |
| 4. 画面位置 | 坐标 | "位于**右侧三分之一**，主体中心横坐标固定在**百分之六十八**" |
| 5. 终点构图 | 终结位置 | "终点保持横坐标百分之六十八" |

## 改写示范（BEFORE → AFTER）

- **BEFORE**："边关堪舆使举起虎符，镜头慢慢拉近，电影感。"（批注："**歧义没有被拆开**"）
- **AFTER**："起始帧人物高度约占画面百分之三十，位于右侧三分之一，主体中心横坐标固定在百分之六十八；起始可见范围为完整全身远景。"
- 原则："**从模糊景别，改成可核验的占框变化**"；"修改后**只保留一个占框变化**"（一次只变一件事）
- 金句："**好提示词写的是可见因果，不是形容词数量**"（与空间拓扑篇同一句——系列标志）

## 控制器档位（工具面板可直接选用）

- **画面位置**：画面左 / 画面中 / 画面右（三选一）
- **身体可见**：全身 / 半身 / 近景（三档）

## 完整提示词的结构（03/03 页 EXACT PROMPT 要点）

- 时间轴精度写法（"1.5S 至 14.5S…全程保持…"）
- **终点锁**："终点保持横坐标百分之六十八；左腿至少百分之三十五保留…；**禁止居中、切手或切掉虎符**"
- 规则栏："身份、服装、关键道具、光向与空间关系**全程一致**；禁止文字、水印、融帧和额外动作"
- 结束保证句："特写固定在百分之六十八，完整虎符和左腿百分之三十五以上"

## 口播补充要点（转写核对，2026-09-24）
- **顺序规则**："五个槽**必须按顺序**写全"——模型才知道"**从哪里开始、保留什么、到哪里必须停**"（三问总纲）
- **"唯一"手法复用**（同空间拓扑篇）："**全片只有一名**边关堪舆使，右手**只持一枚**铜虎符；人物身份、衣服、站位和道具数量都不变"——景别才不会再追错对象
- **数字的意义**："**数字先把景别量出来，模型就不会拿『中景』两个字随便猜**"
- **停止上限**（新槽位含义）：不只是起点和终点——"**不超过 58% 的停止点**"；完整链=30% 起点 → 膝上可见边界 → 横坐标 68% → 不超过 58% 停止
- **可见边界术语**：开场"完整全身"→ 结尾"停在**腰上**中近景"；锁"脸、双肩、右前臂、右手和**整枚**虎符始终同框"

## 与我们的对比（新在哪）

- 我们已有：分镜节点的景别选择/景别弧线；"主体占框"只有经验性描述（没写成比例）
- **本教程新增**：
  1. 用**百分比/坐标**写占框（"占高 30%""横坐标 68%"）——**可核验**
  2. **可见边界**槽位（身体露到哪：全身/半身/手部——防"切手切道具"）
  3. **终点构图**槽位（镜头结束时的构图锁）
  4. "**一次只变一个占框变化**"的克制原则

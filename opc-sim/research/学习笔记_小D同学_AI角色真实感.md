## 核心：三招让角色"活"起来

### 第一招：真实人物图片 + 人像质感调节（00:30 章节）
- 用**真实人物照片**做参考（不靠文字描述长相）
- **"人像质感调节"功能**（官方说明："上传图片或输入描述，选择质感强度，让人物更自然、更真实"）
- 面板共 **5 组 15 档**：
  | 分组 | 选项 |
  |---|---|
  | 人景融合 | 轻度对齐 / 自然融合 / 深度融合 |
  | 光影融合 | 柔和补光 / 自然匹配 / 氛围强化 |
  | 皮肤 | 清透修饰 / 自然肤质 / 真实肌理 |
  | 纹理 | 柔和纹理 / 自然纹理 / 颗粒质感 |
  | 锐度 | 柔焦 / 标准清晰 / 高清锐化 |

### 第二招：角色库（角色卡"应用至画布"）
- 角色卡内容 = **全身图 + 面部特写 + 表情九宫格 + 三视图**（"详见角色全身图、面部特写、表情九宫格与人物生成视图"）
- 角色类型丰富（甜妹/清新少女、霸总、古装女主、正剧配角、反派女配…每个带头像+属性标签）
- 配合工具：全景 / 多角度 / 打光 / 九宫格 / 宫格切分

### 第三招：控制情绪（01:22 章节）——两个方法

**方法 A："脸部细节＋"提示词格式**（本视频核心传授）
- 结构 = **画面描述 + 景别 + 光影氛围**（脚本节点分栏字段），角色名可点选替换（蓝色高亮）
- 讲解原字幕："格式是脸部细节加……""有画面描述、景别、光影氛围等等"
- **完整提示词实例 1**（口播台词版）：
  > 她目光温柔地注视着镜头右侧，嘴角挂着浅浅的微笑。她眼神微微闪烁，长睫毛轻颤，迅速低下头，试图掩饰内心的波澜。她的下嘴唇微微咬紧，压抑着更大的笑意，脸颊泛起一丝不易察觉的红晕。随后，她缓缓抬起头来，眼神从下至上重新看向镜头外的人，目光中带着三分娇羞和一分俏皮的嗔怪。她嘴唇轻启，柔声反问：那你还回来干嘛。说完后，眼神依然没有移开，胸腔随着轻微急促的呼吸微微起伏，耳畔的长流苏耳坠随着头部的微动轻轻摇晃。
- **完整提示词实例 2**（第一视角版）：
  > 眼神温柔地直视着镜头（第一视角），仿佛正在聆听对方说话。听到某句话后，眼神迅速向右下方闪躲，长睫毛微微颤动，脸颊泛起一丝难以察觉的红晕。她下意识地轻轻抿了一下嘴唇，嘴角却忍不住上扬一抹俏皮又害臊的弧度。停顿半秒后，重新抬起眼帘，水灵的眼睛带着娇嗔和一丝惊喜再次对上镜头，嘴唇微张，轻声说出台词：那你还回来干嘛。镜头保持手持摄影的轻微呼吸感。
- **写好"脸部细节"的要素**（从实例提炼）：
  1. 视线（方向：向右下方闪躲 / 从下至上重新看向…）
  2. 微表情序列（眼神闪烁 → 睫毛轻颤 → 低头 → 抿唇 → 嘴角上扬 → 抬头）——**按时间顺序写**
  3. 生理细节（红晕"难以察觉"、呼吸起伏、耳坠随头部晃动）
  4. **节奏**（"停顿半秒后"——给微表情留时间）
  5. **台词嵌在描述中**（"柔声反问：那你还回来干嘛"——不是单独列表）
  6. 镜头感收尾（"手持摄影的轻微呼吸感"）
  7. 程度词精确（"三分娇羞和一分俏皮"、"一丝难以察觉"、"下意识地"）
- 光影栏实例："冷蓝灰低饱和柔和色调，漫反射光线，背景灯笼散发暖光，形成冷暖对比，氛围娇羞暧昧"
- 参数界面：lw 2.0 模型 + **全能参考** + 16:9 · 720P · 7s

**方法 B："情绪调节"功能**（更简单）
- 2D 情绪坐标系：**激动↔平静**（纵向）× **亲近↔疏离**（横向）
- 鼠标拖圆点定位情绪，左侧 3D 头像实时预览
- 底部显示情绪定位名（如"心跳骤停"）
- 字幕："可以用鼠标随意控制角色的情绪"

## 工作流结构（工具侧）
图片节点（2048×1152）→ **脚本生成器**（"描述剧情片段、故事，为你生成分镜脚本"）→ **视频节点**（1280×720 / 7s）
- 输入框："可直接文字生图，或上传图片输入文字指令对图片进行编辑。例如：将背景改为雪夜"
- 人物资产在画布上以"图片节点"管理，视频节点引用

## 对我们的价值（学习点）
1. **"脸部细节＋"格式 = 可直接移植的提示词模板**——按"视线→微表情序列→生理细节→节奏→台词嵌入"写，适合我们 Seedance/H3 的人物镜
2. **情绪的经济写法**："三分娇羞和一分俏皮"式的程度词 + "停顿半秒"式的节奏词
3. **感觉台词嵌入描述中**（vs 单独列出）是他们的做法
4. 工具层面：LiblibAI 客户端可评估（角色库/质感调节/情绪调节在我们管线里的替代性）
5. 与零界点案例呼应：都是"对话戏+真实感"路线；零界点不公开方法，这条教程**公开了方法**，正好互补

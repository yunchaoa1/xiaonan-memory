# OPC 写作入口测试产物

本目录记录一次客户单次提交的模拟运行结果。

- 输入：`customer_input.json`
- 对外交付小说：`novel.md`
- 运行记录：`writing_result.json`
- 客户提交次数：1
- 中途客户介入：0
- 外部草稿数：0
- 首次外部小说数：1
- 选定路径数：1

小说严格围绕两名主要人物：复原军人儿子与母亲。未加入有台词的第三人物，未向客户提问。结果记录只包含最小审计信息，不包含候选正文、内部草稿或思维链。下游只允许使用本目录中的本次小说、运行记录及已验收的上游结构化产物；禁止读取客户聊天补充、历史会话、网络资料、其他项目和内部草稿。

# 《砰》 · OPC 15 秒单元 · 剧本 + 分镜设计

| 项 | 值 |
|---|---|
| 标题 | **《砰》** |
| 画风 | `3d_animated_film` · 国漫 3D CG（凡人修仙传 / 雄狮少年质感） |
| 总时长 | **15 秒**（3 镜 × 5 秒） |
| 景别弧线 | **远景 → 中景 → 近景**（前进式＝情绪高涨） |
| 人物 | **2 人**（周师傅 / 小满） |
| 场景 | 1 个（巷口·爆米花摊） |
| 道具 | **1 个英雄道具**（爆米花机）+ 2 个工作道具 |
| 客户提交 | 1 次 · 过程中提问 0 次 |
| 生成方式 | 每镜 1 个生成任务（共 3 个），对应 H3 三次出片 |

---

## 一句话

巷口的爆米花摊前，一个**又怕响、又盼着出锅**的男孩，等来了那一声「砰」。

| 项 | 内容 |
|---|---|
| 年龄身份 | 约 62 岁，男，巷口摆摊的老工人 |

| 脸型 | 方脸，颧骨高，下颌线清楚，法令纹深 |
| 眉眼神态 | 眉浓而短，眼睛不大但很稳，看炉子不看人 |
| 鼻唇 | 鼻梁宽，鼻头圆厚，嘴唇薄、抿成一条线 |
| 头发 | 花白短寸，鬓角剃得干净 |
| 肤色手部 | 面色偏黄，手背青筋明显，**右手食指外侧有老茧**（长期扳阀门） |
| 识别锚点 | ①花白短寸 ②**右手食指老茧** ③洗得发白的蓝布围裙 |
| 服装 | 深蓝旧棉袄 + 洗白蓝布围裙（罩在棉袄外）+ 袖口挽到小臂 + 深灰布鞋 |
| 本片动作 | 摇手轮 → 停手 → 提罐转向 → 脚踩罐体 → 手握阀门扳手 |

| 项 | 内容 |
|---|---|
| 年龄身份 | 约 7 岁，男，巷子里的邻家孩子 |
| 体型体态 | 矮小，蹲着时缩成一团，肩窄，手脚小 |
| 脸型 | 圆脸，苹果肌饱满，下巴短而圆 |
| 眉眼神态 | 眉毛淡软，**眼睛大而亮**，眼下有卧蚕 |
| 鼻唇 | 鼻头小而翘，嘴唇厚，上唇有道小翘 |
| 头发 | 锅盖头，额前碎发不齐 |
| 肤色 | 面色白里透红，脸颊冻得微红 |
| 识别锚点 | ①**锅盖头** ②大眼睛 ③脖子上一条旧红围巾 |

> （违反 OPC 铁律的反例：两人同时摇炉子 / 两人同时捂耳朵）

## 二、场景（1 个）

### 巷口·爆米花摊 `loc.alley-mouth.v1`

**空间性质**：老居民楼下的巷子口，半室外，连通巷内与街口。

| 项 | 内容 |
|---|---|
| 时间 | **傍晚**——天色将暗未暗，路灯刚刚亮起，单夜无跨日 |
| 空间核心朝向 | 巷口朝街，巷子向里延伸；**电线杆在巷口右侧**，**墙根在巷子内侧左手边** |
| 固定结构 | 巷子口两级水泥台阶、一根灰色电线杆、墙根旧砖、对面居民楼窗户（几扇亮灯） |
| 可变陈设 | 摊子：小马扎（周师傅坐）+ 小炭炉 + 铺开的长麻袋 |
| 地标 | ①电线杆（周师傅左后侧）②墙根旧砖（小满蹲处）③炉火（画面最亮的暖源） |
| 人物活动区 | 周师傅：坐在马扎上面对炉子，炉子在他**正前方**；小满：蹲在周师傅**右前方三步外**的墙根 |
| 尺度关系 | 炭炉约到周师傅膝盖高；爆米花机长约成人小臂；小满蹲下时与炉子大致同高 |
| 声音锚点 | 巷子深处的自行车铃、远处人声、炉火轻响 |

> 场景**只做一个空间**（Location Merging Rule：无隔离门槛、无叙事独立需求 → 不拆分）。
> 方位全部挂主体：「炉子在周师傅正前方」「小满在周师傅右前方三步外」—— 无「画面左/镜头右」。

## 三、道具

### A 级 · 英雄道具

**爆米花机** `prop.popcorn-machine.v1` —— 老式手摇压力罐

| 三要素 | 内容 |
|---|---|
| ① **作用** | 全片视觉焦点与事件核心：「砰」的来源；小满怕的和盼的是同一个东西 |
| ② **出处** | S01 开场地架在炭炉上，周师傅手里正在摇 |
| ③ **落幕** | S02 爆开、白烟散尽后不再入画（S03 只剩烟雾与他无关） |

**视觉细节**：黑色葫芦形压力罐（罐身中部鼓起）+ 前端一圈**压力表**（圆形表盘，指针指向红区）+ 侧方**手摇轮**（黑色曲柄把手）+ 尾端**扳手阀门**（黄铜色，长柄平伸）+ 支架三角架。

**状态链**：`加热中`（S01，炉火上摇动）→ `待爆`（S02，离开炉火、罐口对准麻袋、脚踩住）→ `已爆`（S02 末，阀门开启、罐口喷白烟）。

> **A 级判定依据**（满足 3 项主条件）：
> ①计划插入/近景，细节必须读得清；②有剧情专属的独特轮廓（葫芦形 + 压力表 + 曲柄），观众必须认出是同一台；③可见状态变化（加热→爆开）必须靠同一具体外观辨认 ✓

### B 级 · 工作道具（不单独出图）

| 道具 | 处理方式 |
|---|---|
| 长麻袋 | 铺在周师傅左前方地上，承接爆米花；写入分镜卡的比例/位置/状态 |
| 小满的搪瓷碗 | 攥在小满手里，是「有备而来、等了很久」的证据；写入分镜卡 |

## 四、分镜（3 镜 · 每镜 5 秒）

### S01 · **远景** · 5.0s ·「等」

| 字段 | 内容 |
|---|---|
| 目标 | 建立空间关系 + 两人位置 + 「他怕，但他等着」的悬念 |
| 机位 | 远景固定机位，从巷口外侧看向巷内；人物在画面中极小 |
| 主运动 | 固定（极慢推进，几乎不可察） |
| 时间 | 傍晚（路灯刚亮） |
| 首态 | 周师傅坐在马扎上摇手轮，炉火橘红；小满蹲在他右前方三步外的墙根 |
| 中段 | 小满喊完一声，随后**双手捂住耳朵** |
| 尾态 | 咯吱声继续，小满眼睛盯着炉子，一动不动 |
| 可演动作 | 摇手轮（持续、规律、约 1 秒一转）＋ 小满喊话 → 捂耳 |
| 台词 | **小满（画外喊）**：「周爷爷——我要一锅！」 |
| 声音 | 手轮的「咯吱—咯吱—」（规律慢速）；巷子深处自行车铃；炉火轻响 |
| 情绪 | 起：日常 → 转：期待里带着怕 → 落：悬着 |
| 切镜动机 | 叙事需要：从环境进入人物（信息转换） |
| 宫格 | **1**（无镜内切镜 → 单图构图锚点） |

### S02 · **中景** · 5.0s ·「备」

| 字段 | 内容 |
|---|---|
| 目标 | 把「要爆了」这件事推到位 —— 观众的紧张感来自操作节奏 |
| 机位 | 中景平视，周师傅膝盖以上，侧对镜头，炉子在他正前方 |
| 主运动 | 固定（轻微下摇跟随起身） |
| 时间 | 傍晚（同一时刻，连续） |
| 首态 | 周师傅**停手**，手轮静止，炉火还在烧 |
| 中段 | 提罐离炉 → 转向 → 罐口对准长麻袋 |
| 尾态 | **一只脚踩住罐体**，一手握住阀门扳手 —— 定住 |
| 可演动作 | 停手(0.8s) → 提罐转向(2.0s) → 脚踩住(0.7s) → 手握阀门扳手(1.0s) |
| 台词 | 无 |
| 声音 | 咯吱声停 → **静一拍（0.5s）** → 罐体被踩住的闷响 → 阀门「咔」一声 |
| 情绪 | 起：熟练 → 转：节奏加快 → 落：屏住（一切就位） |
| 切镜动机 | 情感时刻＋节奏点：把观众推到峰值前的那口气 |
| 宫格 | **1** |

### S03 · **近景** · 5.0s ·「砰」

| 字段 | 内容 |
|---|---|
| 目标 | 情绪落点 —— 从「怕」到「笑」，一个孩子的脸就是全部故事 |
| 机位 | 近景（胸上），小满正面，脸占画面主体，浅景深 |
| 主运动 | 固定（极慢推近） |
| 时间 | 傍晚（同一时刻，连续） |
| 首态 | 小满双手捂耳，眉头皱紧，眼睛眯成一条缝，盯着画外的炉子 |
| 中段 | 画外**「砰！」** + 白烟从画外扑进来 —— 他肩膀一缩 |
| 尾态 | 眉头松开 → 眼睛睁开 → **咧嘴笑了** |
| 可演动作 | 紧绷(1.5s) → 缩肩(0.5s) → 睁眼(1.0s) → 笑(2.0s) |
| 台词 | 无（只有笑声） |
| 声音 | 白烟「嗤——」→ **「砰！」**（峰值）→ 余响在巷子里回荡 → 小满的笑声 |
| 情绪 | 起：紧绷 → 转：被巨响击中 → 落：**释放、欢喜** |
| 切镜动机 | 情感时刻（最强）：情绪到关键点换距离看 → 峰值必须近景/特写，不许中景带过 |
| 宫格 | **1** |

> **景别弧线**：远景（疏离/建立）→ 中景（操作/交互）→ 近景（情绪峰值）＝ 前进式，情绪随之高涨 ✓
> **切镜动机**：3 镜各有一项独立动机，禁同角度小步推切 ✓

## 七、OPC 规则自检

| 规则 | 本片执行情况 |
|---|---|
| 一镜一空间一目标一核心动作一机位 | ✓ 3 镜各自独立 |
| 每镜 ≤15s、核心 ≤14s | ✓ 各 5.0s |
| 时长由动作推算（非平均分配） | ✓ S02 = 0.8+2.0+0.7+1.0＝4.5s＋安全余量 |
| 每镜 ≤4 个核心可演状态 | ✓ 最多 4 个 |
| 同场两人不做同一件事 | ✓ 操作 vs 等待观察 |
| 方位以主体自身方向锚定 | ✓ 「炉子在周师傅正前方」 |
| 镜内禁止 180° 翻转 | ✓ 全片无转身动作 |
| 情绪落到可演行为 | ✓ 「捂耳/眯眼/缩肩/咧嘴」替代「紧张/害怕」 |
| 情绪峰值镜必须近景或特写 | ✓ S03 近景承担峰值 |
| 景别曲线随情绪曲线 | ✓ 远→中→近，前进式 |
| 正反打拆成独立镜 | ✓ 无正反打（本片无需拆） |
| 英雄道具判定 | ✓ 爆米花机满足 3 项主条件 |
| 配饰不触发人物状态版本图 | ✓ 围巾/搪瓷碗＝道具与服装，不生成额外人物版本 |

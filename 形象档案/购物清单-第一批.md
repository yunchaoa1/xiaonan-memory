# 购物第一批 · 挑货标准（凡哥 2026-11-11 启动）

> 原则：**只给判断标准，不指定品牌**（凡哥："性价比可以就买，也看当时财力"）
> 用法：照下面的词去搜 → 挑 2–3 个候选 → 链接甩给小南判 → 再买
> 标注：`[侃]`侃哥干货 · `[通]`通用共识 · `[推]`小南推断

---

## ① 防晒（第一位，海口命门）

### 先分清你要哪一种

你是**日常通勤型**（开车上班、白天在室内），**不是军训型/海边型**。这两种诉求完全相反。

| 参数 | 你要的 | 为什么 |
|---|---|---|
| **PA** | **PA+++ 或 PA++++** | 防 UVA（晒黑/老化），**开车最要紧的就是这个** |
| **SPF** | **30–50** | 日常够用；50+ 没必要，还可能更厚重 |
| **质地** | 乳液 / 啫喱，**不泛白、不搓泥** | 干皮别选控油型 |
| **避开** | 变性乙醇排在前几位、香精重 | 干皮会更拔干 |
| **不需要** | 防水 / 抗汗 | 你不出汗泡水 |

### 搜这些词

```
防晒霜 干皮 PA++++ 不搓泥 清爽
```

⚠️ **别搜**"控油""清爽控油""男士控油防晒" —— 那是给油皮的，你会更干。

### 用量（比选产品更重要，八成人输在这）

- **一元硬币大小**（约 1ml）涂一张脸
- **脸 + 脖子 + 手背**（握方向盘那只手最容易漏，且晒得最狠）
- **早上一次**；中午如果要出门，补一次
- 全天在室内/车里 → 早上那次够

### 怎么验它合不合适（买回来第一周）

- 涂完 5 分钟，**脸不紧绷** → 适合干皮
- 搓一下**不起白泥** → 不搓泥，能上脸
- 一整天下来**不长闭口/不泛红** → 合格

## ② 一条替代运动裤的长裤

### 先看数字（你的六围换算，别信 S/M/L）

| 部位 | 你的净尺寸 | **成衣要买** | 依据 |
|---|---|---|---|
| 腰围 | 106 | **107–108** | 净 +1~2（坐下不勒） |
| 臀围 | 105 | **111–113** | 净 +6~8 |
| 大腿围 | 60 | 裤腿围 **≥65–66** | 净 +5~6 `[侃]`；**低于 64 坐下必绷** |
| 裤长 | 99 | **98–100** | `[侃]` 公式 172×0.575±1 ✓ |
| 裆深 | — | **不要低裆** | 低裆 = 腰头没支点 = 必掉（你牛仔短裤就是死在这） |

### 版型（三条生死线）

1. **直筒** —— 不要锥形 / 小脚 / 修身
2. **弹力腰 / 抽绳腰 / 隐藏松紧** —— 你腰比臀粗，**只能靠弹力收住，不能靠"卡腰"**
3. **中腰偏上** —— 不要低腰，也不要"高腰收腹"（你腰胸差只有 2cm，收不了，高腰会卷边下滑）

### 面料（必须免烫，你机洗不熨）

| | 面料 |
|---|---|
| ✅ 主力 | **涤棉混纺**（免烫挺括）、**锦纶/涤纶 + 氨纶**（弹力速干挺括） |
| ⚠️ 可试 | 精纺羊毛混纺（西裤感最好，但海口热，看克重） |
| ❌ 一票否决 | **纯棉**（皱）、**莫代尔/天丝/冰丝/粘纤**（软塌贴肉）、**亚麻**（皱到不能穿） |

### 搜这些词

```
男士 直筒 长裤 免烫 弹力腰
西装裤 男 直筒 松紧腰 免烫
```

### 看到这些词，立刻划走

- **修身 / 显瘦剪裁** → 在你这儿会**更显胖** `[侃]`："体型过胖的话，合身才最重要"
- **垂坠感** → 翻译过来就是"贴肉"
- **冰丝 / 凉感** → 大多是薄软化纤，贴肉且勾勒肚子
- **oversize / 宽松落肩** → `[侃]` 明确说胖子别穿 oversize（**注意：落肩 ≠ oversize，落肩可穿，oversize 不行**）

### 颜色（纯色，符合你的偏好）

**藏青 / 炭灰 / 深卡其 / 黑** —— 这四个色彼此都能配，买两条就能交叉搭。

## 三、买之前最后一遍（30 秒）

1. **面料对不对**？软塌/薄透/垂坠 → 一票否决，多便宜都不值
2. **版型对不对**？靠弹力收腰 vs 靠卡腰
3. **洗三次还像样吗**？缩水 / 变形 / 起球 / 掉色，中一个就报废
4. **有 7 天无理由吗**？没有的店，别买第一件
5. **一次买两个相邻码**，留一件退一件

### 到货 30 秒试穿判死

- **抬手** —— 衣摆会不会翻上去露肚子
- **坐下** —— 肚子那圈会不会绷
- **侧身照镜子** —— 侧面厚度（微胖最真实的一眼）
- **蹲一下（裤子）** —— 腰后有没有空一大块

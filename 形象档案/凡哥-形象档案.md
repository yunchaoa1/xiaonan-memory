## 1.5 肤色与防晒　★凡哥 2026-10-20 口述

| 项目 | 实际情况 |
|---|---|
| 上臂内侧（常年晒不到那块） | **偏白** |
| 晒狠了 | **先发红，再脱皮** |
| 晒得一般 | 红都不明显，**第二天直接变黑** |

**判读**：底色是白皮，但**黑色素活跃**——既能晒黑、也容易晒伤，比"纯白皮"娇气。

**对买衣服的三层含义：**

1. **底色白 → 高级色能穿**：脏橘、大地色、藏青配灰这些"挑肤色"的颜色，他穿得起（很多黄黑皮穿不了）
2. **但在海口不防晒，实际会晒成小麦色** → 那就得切到黄黑皮那套（卡其+军绿、黑+牛仔蓝），**荧光色和马卡龙色一律不能碰**
3. **晒狠了会脱皮 = 皮肤屏障容易受损** → 防晒对他是"护肤第一步"，不只是为了不黑

> ⚠️ 关键结论：**他的肤色是可变的资产——防晒做得好＝可穿颜色范围大一整圈。** 这条把护肤线和穿搭线接上了。

## 2. 气候与地理约束　★凡哥 2026-10-15 提供

- **常驻：海口（海南）** —— 热带季风气候，**全年无冬**
- 一年四季都是**短袖（半袖）**
- 一年**三季是短裤**
- 最冷时节：**"数九天"最冷的那半个月**，最多加一件**薄外套**

| 约束 | 影响 |
|---|---|
| 湿热（湿度常年偏高） | 面料透气排汗是第一硬指标；贴身闷热 = 灾难 |
| 紫外线强（海南） | 防晒是刚需（与护肤线交叉） |
| 三季短裤 | 下装空间小 → **上半身（领型/色彩/版型）权重更高** |
| 无冬 | **小红书秋冬内容（大衣/羽绒/叠穿/风衣/毛衣）基本无效** |

### ★ 核心矛盾（海口 + 大肚子）

- 湿热 → 想**少穿**；腹部突出 → 想**多遮**
- **穿少了现肚子，穿多了闷热** —— 这是本档案要解决的核心问题
- 待解：在"湿热 + 大肚子"双约束下，**哪些可解、哪些无解**

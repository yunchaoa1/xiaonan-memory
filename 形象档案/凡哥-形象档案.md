## 1.5 肤色与防晒　★凡哥 2026-10-20 口述

| 项目 | 实际情况 |
|---|---|
| 上臂内侧（常年晒不到那块） | **偏白** |
| 晒狠了 | **先发红，再脱皮** |
| 晒得一般 | 红都不明显，**第二天直接变黑** |

**判读**：底色是白皮，但**黑色素活跃**——既能晒黑、也容易晒伤，比"纯白皮"娇气。

**对买衣服的三层含义：**

1. **底色白 → 高级色能穿**：脏橘、大地色、藏青配灰这些"挑肤色"的颜色，他穿得起（很多黄黑皮穿不了）
2. **但在海口不防晒，实际会晒成小麦色** → 那就得切到黄黑皮那套（卡其+军绿、黑+牛仔蓝），**荧光色和马卡龙色一律不能碰**
3. **晒狠了会脱皮 = 皮肤屏障容易受损** → 防晒对他是"护肤第一步"，不只是为了不黑

> ⚠️ 关键结论：**他的肤色是可变的资产——防晒做得好＝可穿颜色范围大一整圈。** 这条把护肤线和穿搭线接上了。

## 1.6 肤质　★凡哥 2026-11-11 口述

**干皮**（洗完脸什么都不涂，二三十分钟恢复不了，偏紧绷）。

**与 §1.5 合起来看，结论只有一个：他的核心问题是"屏障"，不是"控油 / 美白 / 抗老"。**

| 证据 | 指向 |
|---|---|
| 干皮（皮脂少、锁水差） | 屏障偏弱 |
| 晒狠了先红再脱皮 | 屏障被破坏 |
| 海口全年强紫外线 | 屏障持续被攻击 |

**护肤优先级（通用皮肤科学共识套在他已知信息上，非个人诊断）**：
1. **防晒** —— 第一位。不是为了不黑，是为了不脱皮（脱皮＝屏障破了）
2. **保湿修护** —— 神经酰胺 / 甘油 / 透明质酸；干皮"封闭锁水"比"补水"更关键
3. **避开刺激** —— 酒精、皂基、高浓度酸、磨砂、热水
4. 美白 / 抗老这类锦上添花的，**屏障没修好之前一律往后放**

⚠️ 边界：以上是通用共识 + 他的已知信息推出的方向，**不是诊断**。出现持续泛红、脱屑、湿疹，该去皮肤科。

## 1.7 紫外线暴露场景　★凡哥 2026-11-11 口述

**他的实际暴露**：只有上下班在路上，**开车**；下班时正好落山；白天外出很少。

**⚠️ 关键纠正 ——「开车不晒」是错觉：**

| 车窗 | 挡得住 | 挡不住 |
|---|---|---|
| 前挡（夹层玻璃） | 大部分 UVB（所以不晒红、不脱皮） | **UVA 挡不干净** |
| 侧窗（钢化玻璃） | 几乎什么都不挡 | **UVB 和 UVA 都能进** |

- **UVB** = 晒红 / 晒伤 / 脱皮 → 被玻璃挡掉大半，所以体感"不晒"
- **UVA** = 晒黑 / 光老化 / 穿透玻璃 → **照样照进车里**
- 中国驾驶位在左 → **左脸长期比右脸吃更多 UVA**（皮肤科俗称"司机脸"）

**他的防晒需求（≠ 户外工作者的需求）**：
- **UVA 优先**（PA 比 SPF 更关键）
- 不需要高倍数、不需要防水抗汗
- **手背也要涂**（握方向盘那只手最容易漏）
- 更彻底的解法：**车窗贴紫外线阻隔膜**（一次解决，比天天涂省事）

⚠️ 从"场景 + 玻璃物理"推出，非诊断；具体产品等他真要买时再定。

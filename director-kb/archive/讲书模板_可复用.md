# 讲书模板（可复用）

> 基于樊登讲书风格拆解，制作课程时可对照使用。
> 每次做新课/新讲稿时对着这个清单过一遍。

---

## 一、讲稿骨架

```
【0. 开场钩子】（占 5-8%）
- [ ] 痛点共鸣：一句话让听众觉得"说的就是我"
- [ ] 权威背书：我做了 X 年才知道这个 / 我踩过这个坑
- [ ] 概念悬念：抛出一个新名词，不急着解释

【1. 核心概念】（占 8-12%）
- [ ] 用一个日常比喻把抽象概念具象化（子弹、沙发、蛋糕粉）
- [ ] 一句话定义
- [ ] 为什么重要（不说会怎样）

【2. 框架展开】（占 60-70%）
每个子概念 = 定义 → 案例(2-3个) → 方法(3-5个) → 金句

- [ ] 子概念 A
- [ ] 子概念 B
- [ ] 子概念 C
- [ ] 子概念 D
（3-5个为宜，多了记不住）

【3. 升华收束】（占 10-15%）
- [ ] 引入一个新视角（不总结前面内容）
- [ ] 把前面所有内容串在更高维度
- [ ] 一句行动号召
- [ ] 暗示"还有更多"（引导进一步行动）
```

---

## 二、案例选择清单

- [ ] 有没有一个"日常但没细想过"的物理/自然现象？
- [ ] 有没有一个"反差巨大"的商业案例？（成交 vs 不成交）
- [ ] 有没有一个科学实验/动物行为？
- [ ] 有没有一个历史事件？
- [ ] 有没有一个自己亲身经历的故事？

**原则：先简单后复杂，先生活后学术**

---

## 三、金句生成清单

- [ ] 每个小节能提炼一句"脱稿能说"的话吗？
- [ ] 有引用一个外部权威吗？（增加可信度）
- [ ] 有"反常识"的金句吗？（让人惊讶，更容易记住）
- [ ] 金句放在案例后面，而不是前面

---

## 四、语言自查

- [ ] 用了"你"而不是"大家"吗？（更有亲近感）
- [ ] 有自问自答的节奏吗？（"为什么？原因是..."）
- [ ] 有"自曝其短"降低防御吗？（"我之前也以为..."）
- [ ] 专业术语有立即翻译吗？（先抛词→马上解释）
- [ ] 有"你看""你发现没有"这样的口语钩子吗？

---

## 五、时长估算

| 模块 | 占比 | 12分钟 | 20分钟 | 30分钟 |
|------|------|--------|--------|--------|
| 开场钩子 | 8% | 1分 | 1.5分 | 2.5分 |
| 核心概念 | 12% | 1.5分 | 2.5分 | 3.5分 |
| 框架展开 | 65% | 8分 | 13分 | 20分 |
| 升华收束 | 15% | 1.5分 | 3分 | 4分 |

---

## 六、常见陷阱

❌ 开场就讲理论定义（听众还没觉得"跟我有关"）
❌ 案例太多没有方法（变成故事会）
❌ 方法太多没有案例（变成说明书）
❌ 结尾重复前面内容（浪费升华机会）
❌ 全程第三人称（"人们""大家"→ 用"你"）
❌ 一上来就抛学术名词（先给直觉理解再命名）

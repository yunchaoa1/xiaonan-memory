# 10种故事类型 · 故事DNA分类系统

> 来源：《救猫咪》Save the Cat! — Blake Snyder (2005)
> 覆盖管线层：小说→剧本（类型判断 → 套节拍表）
> 置信度：高

---

## ⚠️ 先搞清楚：这不是传统类型

Snyder 的 10 种类型不是"恐怖/爱情/动作"——那些是**卖相标签**。

他的 10 种是**故事引擎**（Story DNA）——推动情节运转的内在结构。

同一个故事引擎可以长出不同卖相：
- "怪兽在屋里"可以是恐怖片（异形），也可以是惊悚片（致命诱惑），还可以是科幻冒险（侏罗纪公园）

---

## 10种故事引擎详解

### 1. 怪兽在屋里（Monster in the House）

三要素：**怪兽 + 屋子 + 罪**

| 要素 | 含义 |
|------|------|
| 怪兽 | 某种威胁（超自然/疯子/病毒/外星生物） |
| 屋子 | 一个封闭空间（房子/飞船/小镇/身体） |
| 罪 | 有人犯了错把怪兽放进来了——有人的贪婪/傲慢/好奇是起因 |

核心节奏：怪兽出现 → 逃跑 → 怪兽追赶 → 没人相信 → 必须杀了它

例子：大白鲨 / 异形 / 驱魔人 / 侏罗纪公园 / 致命诱惑 / 逃出绝命镇

---

### 2. 金羊毛（Golden Fleece）

三要素：**路 + 团队 + 奖品**

| 要素 | 含义 |
|------|------|
| 路 | 一段旅程（公路/任务/冒险） |
| 团队 | 一路上结识/冲突/成长的伙伴 |
| 奖品 | 一开始以为在找某个东西/目标，最后发现真正获得的是自我的成长 |

核心节奏：上路 → 遇同伴 → 经历考验 → 每人暴露真相 → 到达终点但奖品不重要了——重要的是人变了

例子：绿野仙踪 / 星球大战 / 指环王 / 十一罗汉 / 拯救大兵瑞恩

---

### 3. 愿望成真（Out of the Bottle）

三要素：**愿望 + 咒语 + 教训**

| 要素 | 含义 |
|------|------|
| 愿望 | 一个愿望被实现，普通人获得非常能力/境遇 |
| 咒语 | 愿望背后有规则、限制或代价 |
| 教训 | "小心你许的愿"——愿望满足后发现真正需要的是别的东西 |

核心节奏：平淡生活 → 愿望实现狂喜 → 副作用出现 → 事情失控 → 想回去 → 接受教训

例子：大话王 / 变相怪杰 / 冒牌天神 / 土拨鼠之日 / 飞越未来

---

### 4. 普通人有大麻烦（Dude with a Problem）

三要素：**无辜主角 + 突发事件 + 生死较量**

| 要素 | 含义 |
|------|------|
| 无辜主角 | 一个普通人，不是英雄，没准备好 |
| 突发事件 | 灾难/袭击/意外突然降临 |
| 生死较量 | 被迫在极端环境下求生存 |

核心节奏：平凡日子 → 灾难突发 → 不是英雄也得当英雄 → 一步步被逼到极限 → 生还/胜利

例子：虎胆龙威 / 泰坦尼克号 / 谍影重重

---

### 5. 成长仪式（Rites of Passage）

三要素：**人生问题 + 错误出路 + 接受**

| 要素 | 含义 |
|------|------|
| 人生问题 | 所有人都会遇到的阶段：青春期/中年危机/丧亲/分手 |
| 错误出路 | 主角一开始用错误的方式应对（逃避/愤怒/自毁） |
| 接受 | 最终接受人生的无常，学会面对 |

核心节奏：触发事件（丧亲/失恋/换工作）→ 错误应对 → 越陷越深 → 崩溃 → 接受 → 成长

例子：克莱默夫妇 / 凡夫俗子 / 早餐俱乐部

---

### 6. 搭档之爱（Buddy Love）

三要素：**不完整的主角 + 互补者 + 纠葛**

| 要素 | 含义 |
|------|------|
| 不完整的主角 | 主角自己是不完整的，缺了什么 |
| 互补者 | 配角正好拥有主角缺失的部分（性格/能力/视角） |
| 纠葛 | 两人的关系被某种障碍阻碍，不能直接在一起（身份/使命/误会/外界） |

核心节奏：相遇（火花/冲突）→ 被迫在一起 → 逐渐磨合 → 最终障碍出现 → 两人分开 → 各自意识到不能没有对方 → 重逢

这不仅是爱情片——任何"两个互补的人"的故事都是这个类型：友情、搭档、师徒。

例子：当哈利遇上莎莉 / 末路狂花 / 雨人 / 金刚

---

### 7. 为什么干（Whydunit）

三要素：**侦探 + 秘密 + 黑暗转折**

| 要素 | 含义 |
|------|------|
| 侦探 | 不一定是职业侦探，任何追查真相的人（记者/律师/亲人） |
| 秘密 | 表层案件之下的深层秘密 |
| 黑暗转折 | 越接近真相，发现真相越黑暗——甚至侦探自己也卷入其中 |

核心节奏：事件发生 → 开始调查 → 线索指向某人 → 反转 → 真相比想象的更黑暗 → 侦探本人也可能有罪/有牵连

例子：唐人街 / 总统班底 / 七宗罪 / 消失的爱人

---

### 8. 傻瓜得胜（Fool Triumphant）

三要素：**傻瓜 + 体制 + 蜕变**

| 要素 | 含义 |
|------|------|
| 傻瓜 | 被所有人低估的"蠢人"（也可能是装傻/天真的聪明人） |
| 体制 | 一个庞大/僵化/自以为是的主流体制 |
| 蜕变 | 傻瓜用自己的方式击败/改造了体制，体制中的人反而显得可笑 |

核心节奏：傻瓜被低估 → 体制嘲笑/排挤 → 傻瓜用纯真/另类方式成功 → 体制震惊 → 傻瓜不仅赢了还改变了世界

例子：阿甘正传 / 愚笨的人 / 富贵逼人来 / 律政俏佳人

---

### 9. 体制之内（Institutionalized）

三要素：**群体 + 选择 + 牺牲**

| 要素 | 含义 |
|------|------|
| 群体 | 一个封闭的体制/组织/家庭/团队 |
| 选择 | 主角面临选择：融入/摧毁/牺牲自我 |
| 牺牲 | 每个选择都有代价——融入失去自我，反抗失去归属，摧毁可能连自己一起毁 |

核心节奏：进入体制 → 学习规则 → 看到体制的阴暗面 → 做选择 → 承受代价

例子：飞越疯人院 / 教父 / 美国丽人 / 电视台风云 / 穿普拉达的女王

---

### 10. 超级英雄（Superhero）

三要素：**能力 + 对手 + 诅咒**

| 要素 | 含义 |
|------|------|
| 能力 | 主角拥有特殊能力/使命（不一定是超能力，也可能是天才/地位/天赋） |
| 对手 | 和自己对等甚至更强的敌人——往往是"没有超能力的自己会变成的样子" |
| 诅咒 | 能力本身就是负担——特殊 = 孤独，越强越不被理解 |

核心节奏：发现能力 → 抗拒/逃避 → 被迫使用 → 遭遇对等级对手 → 在诅咒中找到意义

例子：超人 / 角斗士 / 钢铁侠 / 黑暗骑士 / 小丑

## 使用流程

### 判断你的故事属于哪种类型：

1. 先看**核心冲突**——不是看场景、不是看人设，是看**故事靠什么在运转**
2. 有些故事混合两种类型——选**主导**的那个
3. 类型确定后，对着 15 节拍表，用该类型的节奏去填

### 类型 ↔ 节拍表对应示例：

```
类型：金羊毛（如指环王）
  节拍① 开场 = 夏尔平静生活
  节拍④ 催化剂 = 甘道夫告知魔戒真相
  节拍⑥ 进入第二幕 = 弗罗多主动说"我来带它"
  节拍⑧ 玩乐时间 = 九人远征队的旅途冒险
  节拍⑨ 中点 = 甘道夫坠入深渊（假失败）
  节拍⑪ 一切尽失 = 弗罗多独自离开（团队瓦解）
  节拍⑭ 结局 = 摧毁魔戒
  节拍⑮ 最终画面 = 回到夏尔，但弗罗多不再是那个弗罗多
```

## 知识阵列适用规则

在"小说→剧本"转换中：
1. 先读小说，判断属于哪种故事引擎
2. 对着 15 节拍表逐条填入小说内容
3. 小说中缺失的节拍 = 你需要创作的
4. 类型决定节拍⑧（玩乐时间）应该长什么样

## 注意事项

- ⚠️ 每种类型 Snyder 原书有 5+ 部电影完整拆解，这里只列了类型定义和代表性例子
- ⚠️ 混合类型的情况（如"金羊毛 + 搭档之爱"）的处理方法需原书补充
- ✅ 10 种类型的定义和三要素是完整的，足够用于判断和套用

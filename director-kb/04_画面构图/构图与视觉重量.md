## 一、七条基础构图规则 + 五种高级技法

### 基础规则（7条）

### 1. 三分法（Rule of Thirds）
将画面用两条横线+两条竖线分成九宫格，主体放在交叉点上。

| 用法 | 效果 |
|------|------|
| 角色放在左/右交点 | 留出视线空间（look room） |
| 角色放在上交点 | 沉重/被压制 |
| 角色放在下交点 | 轻盈/弱势 |
| 角色放边缘（偏离交点） | 被排挤/不信任/远距离 |
| 角色正中央 | 权威/直面观众/异常引人注意 |

### 2. 对称与平衡
| 类型 | 效果 | 例子 |
|------|------|------|
| 完全对称 | 秩序/压迫/仪式感/童话 | 韦斯·安德森/库布里克 |
| 不对称平衡 | 自然/动态/真实感 | 大部分电影 |

### 3. 引导线（Leading Lines）
用画面中的线条引导观众视线到主体。

| 线型 | 效果 |
|------|------|
| 水平线 | 平静/稳定 |
| 垂直线 | 力量/庄严 |
| 对角线 | 动感/不安/紧张 |
| 汇聚线 | 纵深/指向/命运 |

### 4. 前景/中景/背景（Depth）
| 层次 | 功能 |
|------|------|
| 前景元素 | 偷窥感/框景/距离感 |
| 中景主体 | 故事发生的位置 |
| 背景信息 | 环境/氛围/世界观 |

**关键规则：** 前景模糊/暗 = 观众像在偷看；前景清晰明亮 = 观众在被邀请

### 5. 负空间（Negative Space）
主体之外的大面积空白。

| 用法 | 效果 |
|------|------|
| 大负空间 + 小主体 | 孤独/渺小/被忽视 |
| 负空间在角色视线前方 | 期待/未来/未知 |
| 负空间在角色身后 | 危险/被跟踪/有东西 |

### 6. 填充画面（Fill the Frame）
主体占满画面，不留空间。

效果：亲密/压迫/强迫观众面对

### 7. 简化（Simplicity）
去除所有无关元素，画面只有一件事要说。

效果：注意力强制集中/主题明确/海报感

## 二、特殊构图技术

### 框景（Frame within a Frame）
用门/窗/镜/建筑结构把主体框起来。

| 效果 | 使用场景 |
|------|------|
| 囚禁/束缚 | 角色被困在某种处境 |
| 窥视 | 观众在偷看 |
| 强调 | 告诉观众"看这里" |

### 荷兰角（Dutch Angle）
画面倾斜（不是平视）。

效果：世界失衡/不安/疯狂/危机时刻

⚠️ 一两个就够了，整部电影歪着拍观众会晕

## 三、构图→情绪速查

| 想要的情感 | 构图方案 |
|------------|------|
| 角色强大/权威 | 中央对称 + 仰角 + 填充画面 |
| 角色脆弱/无助 | 三分法边缘 + 俯角 + 大负空间 |
| 被监视/被跟踪 | 前景模糊偷窥 + 角色在远处 |
| 孤立/孤独 | 大负空间（远景） + 侧位 |
| 亲密/连接 | 填充画面 + 眼平 + 两人三分法对称 |
| 不安/失衡 | 荷兰角 + 对角线引导线 |
| 秩序/官僚/压迫 | 完全对称 + 顶光 |
| 自由/开放 | 纵深构图 + 大远景 |

## 四、走位与调度（Blocking & Staging）

### 角色站位→权力关系

| 站位 | 关系 |
|------|------|
| A高 B低 | A有权力 |
| A正面 B侧面 | A主导 |
| A近镜头 B远 | A重要/强势 |
| A和B等距 | 平等 |
| A阻挡B去路 | A控制B |
| B绕过A走 | B逃避/不把A放眼里 |

### 基本调度模板
- **双人对峙**：面对面/眼平/等距 = 力量相等
- **追逐**：跟镜+手持，动态纵深
- **独白/内心戏**：Push in（慢）+ MCU→CU

---

## 使用流程

```
1. 从剧本提取：这一场谁看谁？权力关系是什么？
2. 查构图速查表 → 定构图方案
3. 结合镜头语言（景别+运镜+角度）→ 定站位调度
4. 输出：构图+站位 → 写入分镜
```

## 🆕 高级镜头技法（即梦AI·森海分镜）

> 来源：森海分镜技能库12类构图+30+镜头技法（2026-06-29）

| 技法 | 说明 | 效果 |
|------|------|------|
| 主观POV | 镜头=角色眼睛 | 完全代入，所见即角色所见 |
| 剪影 | 主体全黑，只留轮廓 | 神秘/匿名/危险 |
| 反射叙事 | 通过镜子/水面/玻璃看角色 | 双重自我/隐藏/不安 |
| 框架式构图 | 用门/窗/建筑结构框住主体 | 囚禁/窥视/强调 |
| 分层纵深 | 前景+中景+背景三层以上 | 空间深度/复杂关系 |

**使用：** 分镜备注栏标注"POV""剪影""框架式"等——AI提示词里加对应英文词。

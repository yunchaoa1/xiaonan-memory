## 一、光的四个属性

### 1. 光量（Quantity / Intensity）

| 级别 | 效果 | 使用场景 |
|------|------|------|
| 高光量（明亮） | 清晰/开放/安全/日常 | 白天外景/喜剧/轻松对话 |
| 低光量（昏暗） | 神秘/危险/私密/不安 | 夜景/惊悚/悬疑/亲密时刻 |
| 极端暗 | 压迫/未知/恐惧 | 恐怖片/心理黑暗时期 |

### 2. 光质（Quality）

| 光质 | 怎么形成 | 视觉特点 | 情绪 |
|------|------|------|------|
| 硬光 | 小光源/直射 | 锐利阴影/高对比/轮廓清晰 | 紧张/冷峻/戏剧性/冲突 |
| 软光 | 大光源/扩散 | 柔和阴影/低对比/过渡平滑 | 温暖/浪漫/安全/自然 |
| 混合 | 硬+软组合 | 主光源硬+辅光源软 | 现实感/层次丰富 |

### 3. 光向（Direction）

| 方向 | 效果 | 情绪 |
|------|------|------|
| 顺光（正面） | 平面感/无阴影/直视观众 | 坦白/坦诚/直面 |
| 侧光 | 半边脸亮半边暗 | 矛盾/双重性格/内心挣扎 |
| 逆光 | 人物轮廓发亮/面部暗 | 神秘/神圣/离别/回忆 |
| 顶光 | 眼下阴影/面骨突出 | 压迫/审判/不祥/宗教 |
| 底光 | 面部颠倒阴影 | 恐怖/诡异/非人/邪恶 |
| 蝴蝶光 | 前上方45° | 时尚/美/经典人像 |

### 4. 光色（Color / Temperature）

| 色温 | 数值(K) | 感觉 | 典型场景 |
|------|:---:|------|------|
| 烛光 | 1500-2000K | 极暖/远古/私密 | 烛光晚餐/壁炉旁 |
| 日出日落 | 2500-3500K | 温暖/浪漫/黄金时刻 | 爱情片/怀旧/希望 |
| 白炽灯 | 3200K | 室内暖/家常 | 家庭场景/温馨 |
| 正午日光 | 5500K | 中性/自然/真实 | 日常生活/纪录片感 |
| 阴天 | 6500-7500K | 偏冷/沉静/客观 | 冷静/思考/悲伤 |
| 蓝天 | 10000-12000K | 冷/距离/科技 | 科幻/冷酷/疏离 |

## 二、灯光风格 · 五种经典方案

| 风格 | 特征 | 情绪 | 代表电影 |
|------|------|------|------|
| 高调光（High Key） | 明亮/低对比/少阴影 | 喜剧/轻松/广告感 | 好莱坞喜剧 |
| 低调光（Low Key） | 暗/高对比/大面积阴影 | 悬疑/黑色电影/压抑 | 教父/七宗罪 |
| 自然光（Natural） | 模拟真实光源 | 真实/纪录/亲和 | 荒野猎人 |
| 表现主义光 | 夸张/不自然/风格化 | 梦境/疯狂/异世界 | 银翼杀手 |
| 混合冷暖 | 暖主+冷辅 或 冷主+暖辅 | 冲突/张力/现代感 | 大多数现代电影 |

## 三、色彩方案 · 七种经典配色

### 1. 单色（Monochromatic）
单一色相 + 不同明度/饱和度
情绪：统一/沉静/风格化极端
例子：黑客帝国（绿色调）/ 辛德勒的名单（黑白+红衣）

### 2. 互补色（Complementary）
色轮对立色（红-绿 / 蓝-橙 / 黄-紫）
情绪：冲突/张力/视觉冲击
例子：变形金刚（青橙调）

### 3. 类似色（Analogous）
色轮相邻色
情绪：和谐/舒适/自然
例子：月升王国（黄绿棕）

### 4. 三色（Triadic）
色轮三等分三色
情绪：丰富/活泼/有层次
例子：超人（红蓝黄）

### 5. 关联色（Associative）
固定颜色代表固定角色/情绪
情绪：叙事编码
例子：第六感（红色=死亡将至）

### 6. 过渡色（Transitional）
颜色随剧情/角色状态变化
情绪：成长/堕落/转变的视觉化
例子：绝命毒师（Walter的服装颜色渐变）

### 7. 不和谐色（Discordant）
故意使用不协调的颜色
情绪：不安/注意力的强制转移/异常
例子：蓝丝绒

## 四、情绪→灯光色彩映射表（核心）

| 情绪 | 灯光方案 | 色彩方案 | 光质 |
|------|------|------|:---:|
| 喜悦/温暖 | 高调光+暖色温(3000K) | 暖调/类似色(黄橙粉) | 软光 |
| 悲伤/孤独 | 低调光+冷色温(7000K) | 冷调/单色偏蓝 | 硬光+逆光 |
| 恐惧/紧张 | 极低调光+底光 | 高对比/单色+不和谐色点缀 | 硬光为主 |
| 愤怒/对抗 | 中调+硬光侧光 | 互补色(红-青冲突感) | 硬光 |
| 浪漫/亲密 | 中调+暖色温+蝴蝶光 | 暖调/类似色 | 软光 |
| 神秘/悬疑 | 低调光+逆光 | 单色偏暗+低饱和 | 硬+逆光组合 |
| 平静/日常 | 自然光+眼平 | 中性/类似色 | 软光为主 |
| 压抑/窒息 | 低调光+顶光 | 褪色/低饱和+冷调 | 硬光 |
| 神圣/崇高 | 高对比+逆光 | 金色/白色高光 | 硬逆光 |
| 混乱/疯狂 | 混合不一致光向 | 不和谐色+高饱和 | 硬光+杂光 |

## 使用流程

```
1. 从剧本提取这场戏的核心情绪
2. 查上表 → 得到灯光方案 + 色彩方案 + 光质
3. 根据场景时间/地点调整（白天室内 vs 夜晚室外）
4. 输出：灯光方向 + 光质 + 色温 + 色彩方案 → 写入分镜脚本
```

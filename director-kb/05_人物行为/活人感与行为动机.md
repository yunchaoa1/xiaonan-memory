# 人物行为层 · 活人感与行为动机

> 来源：凡哥提供视频教程（2026-06-29）
> 覆盖管线层：分镜→AI提示词（人物微观行为设计 / 消除AI感）
> 置信度：高（来自AI视频实战总结）

---

## 一、核心洞察

**AI人物的假，不是因为五官不真实，是因为"太闲了"。**

人有五官 ≠ 人活着。AI人物缺的是**生活状态**——人只要活着，就一定在顺便做某件事。这些小事给人物一个"情绪落点"。

---

## 二、三个关键概念

### 1. 情绪落点
人不会凭空存在。等车的时候顺便回消息、坐电梯的时候顺便看楼层按钮——这些不是设计出来的动作，是"人正在经历某件事"的自然证据。

**反面：** AI人物虽然长得像人，但没有生活状态 = "待机感"（现在大部分AI视频最容易暴露AI味的地方）

### 2. 行为动机（不是动作本身）
| ❌ 错误 | ✅ 正确 |
|---------|--------|
| 举起杯子喝咖啡（摆拍） | 边看前方边无意识转杯子（真人） |
| 角色在画面中做动作 | 角色在画面中被生活推着走 |

**关键：** 后者让观众感觉"这个人正在经历某件事情"。

### 3. 微弱的生命反应
再简单的画面也要加入微反应：
- 轻微眨眼
- 呼吸带来的肩膀起伏
- 眼神短暂偏移

现实里的人不可能一直像雕塑一样停在那里。

---

## 三、单人公式

```
单人提示词 = 人物 + 正在做的小事 + 下意识的反应 + 情绪落点
```

### 下意识反应库（按场景）

| 场景 | 可以顺便做的事 |
|------|------|
| 等人 | 无意识搓手指 / 反复解锁手机+看时间 / 站起来又坐下 |
| 喝东西 | 咬吸管 / 中途停住目光放空 / 无意识转杯子 |
| 紧张 | 抠手指 / 抖腿→立刻按住 / 拨刘海 |
| 思考 | 转笔 / 轻敲桌面 / 眼神漂移到远处 |
| 疲惫 | 揉眼睛 / 按太阳穴 / 后仰伸懒腰 |
| 尴尬 | 摸后颈 / 清嗓子 / 假装看手机 |
| 听别人说话 | 点头+视线短暂偏移 / 嘴唇微动像在跟读 |

## 四、多人公式

```
群像提示词 = 一个人行动 + 另一个人反应
```

**铁律：不是每个人都在表演。让一个人有动作，另一个人有反应。**

真实的人之间的关系是这样的：
- A说话 → B听着，同时无意中做点什么
- A行动 → B被A的行动改变了自己的状态
- 每个人都在对上一秒发生的事情做出真实反应

**反面：** 多人提示词的关键不是动作越多越真实，而是人物之间要有反应链。

---

## 五、行为动机链模板

### 核心原理
真实的人永远在被生活推着走——赶时间、分心、走神、下意识做和主题无关的小动作。

### 动机链结构
```
动作A → 停顿（分心/走神）→ 偏移（下意识小动作）→ 回到动作A或落点B
```

### 示例

❌ "女性角色喝咖啡，悲伤"
✅ 动机链版：
  端起咖啡 → 中途停住 → 目光放空 → 无意识转动杯子 → 杯子停在半空没喝 → 放下

每一步都是上一步的延续，不是AI随机拼凑。

### 给观众的潜意识信号
当观众看到这些细节，大脑自动判断："这个人在经历某事" → 哪怕画面其他地方不完美，观众也下意识觉得这个人好像真的活着。

---

## 六、AI视频提示词应用规则

### 写入提示词时：

1. **不写"情绪词"，写"行为动机链"**
   - ❌ "she looks sad"
   - ✅ "she lifts the cup, stops halfway, stares blankly, her thumb traces the rim unconsciously, she sets it down without drinking"

2. **单人场景：永远加一个"顺便在做的事"**
   - 检查：这个角色在等什么/在逃避什么/在想着什么其他事？

3. **多人场景：检查反应链**
   - A做了什么 → B因为A做了什么而改变了什么 → C是否注意到

4. **静止画面加微反应**
   - 不动的角色=假人。哪怕全身不动，加"eyelids flutter slightly" "chest rises with a slow breath"

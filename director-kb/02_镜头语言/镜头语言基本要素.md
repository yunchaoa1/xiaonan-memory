# 镜头语言 · 基本要素决策表

> 来源：StudioBinder 50+ Camera Shots & Movement Guides + 训练数据
> 覆盖管线层：剧本→分镜（景别选择 / 运镜选择 / 角度选择）
> 置信度：高

---

## 一、景别（Shot Size）— 7级景别 + 决策表

### 景别速查

| 级 | 景别 | 缩写 | 取景范围 | 情绪功能 |
|:---:|------|:---:|------|------|
| 0 | 大远景 | EWS | 人极小，环境巨大 | 孤立感 / 宏大 / 人在命运面前渺小 |
| 1 | 远景 | WS/LS | 人完整+大量环境 | 建立场景 / 角色与环境关系 |
| 2 | 全景 | FS | 人从头到脚填满画面 | 动作展示 / 角色全貌 |
| 3 | 中景 | MS | 腰部以上 | 对话 / 日常交流 / 最中性 |
| 4 | 近特写 | MCU | 胸部以上 | 情绪开始浮现 / 对话中的情感变化 |
| 5 | 特写 | CU | 面部为主 | 情绪强度 / 关键反应 / 内在心理 |
| 6 | 大特写 | ECU | 眼睛/嘴唇/手指 | 极度强调 / 强迫观众注意细节 |

### 景别决策规则

| 剧本需求 | 推荐景别 | 原因 |
|----------|:---:|------|
| 展示地点/环境 | EWS / WS | 让观众知道"这是在哪儿" |
| 角色首次出场 | WS → MCU | 先展示整体，再靠近 |
| 平静对话（双人） | MS / MCU | 中性距离，不压迫不疏远 |
| 争吵/对抗（双人） | CU 交替 | 压迫感，不让观众退后 |
| 孤立/疏远 | EWS 或 WS+侧位 | 人物被环境吞没 |
| 亲密/表白 | MCU → CU | 逐渐拉近 = 心理距离缩小 |
| 秘密/阴谋 | ECU（嘴唇/眼睛） | 不让人看全，增加悬疑感 |
| 动作/打斗 | FS→MS 快速切换 | 展示动作空间，但保持紧张 |

### ⚠️ 常见错误
- 对话全用 CU → 没有呼吸空间，观众疲劳
- 大场景只用 EWS → 角色失去情感联系
- 同景别同角度重复 → 视觉单调

## 二、运镜（Camera Movement）— 12种运动

### 运镜速查

| 运镜 | 英文 | 怎么动 | 情绪功能 |
|------|------|------|------|
| 固定 | Static | 不动 | 专注表演 / 让观众自己看 |
| 横摇 | Pan | 水平转 | 揭示信息 / 跟随目标 / 扫描环境 |
| 竖摇 | Tilt | 垂直转 | 揭示高度 / 权力关系（仰=强，俯=弱） |
| 推镜 | Push In | 向前移 | 注意力缩小 / 情绪逼近 / 关键时刻 |
| 拉镜 | Pull Out | 向后移 | 揭示更多信息 / 疏离感 / 退出情绪 |
| 变焦 | Zoom | 焦距变化 | 快速强调 / 拍新闻感 / 偷窥感 |
| 推拉变焦 | Dolly Zoom | 移+变焦 | 眩晕/不安/心理崩塌（希区柯克效果） |
| 跟镜 | Tracking | 侧移跟随 | 与角色同行 / 代入感 / 旅程感 |
| 弧线 | Arc | 绕圈拍 | 被包围/眩晕/仪式感 |
| 升降 | Boom | 上下移 | 建立空间纵深 / 揭示规模 |
| 手持 | Handheld | 不固定 | 纪实感/混乱/紧张/真实纪录片感 |
| 俯拍 | Bird's Eye | 正上方向下 | 上帝视角/命运感/冷漠凝视 |

### 运镜决策规则

| 剧本需求 | 推荐运镜 | 原因 |
|----------|------|------|
| 揭示新信息 | Pan / Tilt / Pull Out | 让观众和角色同时发现 |
| 情绪升级 | Push In（慢） | 观众被迫靠近，无法逃避 |
| 角色崩溃/眩晕 | Dolly Zoom | 视觉物理表达心理崩塌 |
| 追逐/动作 | Handheld + Tracking | 混乱+速度双重重压 |
| 庄严/仪式 | Arc（慢）+ Boom | 环绕感创造仪式重量 |
| 平静叙事 | Static / Slow Pan | 让故事自己讲 |
| 主观视角（POV） | Handheld 抖动 | 模拟角色眼睛所见 |

## 三、角度（Camera Angle）— 6种基础角度

| 角度 | 机位 | 情绪功能 |
|------|------|------|
| 眼平 | 与视线等高 | 中性/平等/自然 |
| 仰角 | 低于视线 | 权威/强大/压迫/宏伟 |
| 俯角 | 高于视线 | 弱势/渺小/被俯瞰/脆弱 |
| 荷兰角 | 倾斜 | 不安/失衡/世界不对劲 |
| 过肩 | 从角色肩膀后 | 对话标准角度/代入但保持距离 |
| POV | 角色眼睛 | 完全代入/所见即所得 |

### 角度组合示例

| 场景 | 机位方案 |
|------|------|
| 老板训斥员工 | 仰角(老板) + 俯角(员工) |
| 两人平等对话 | 眼平 + 过肩 交替 |
| 角色发现世界崩塌 | 荷兰角 + Push In |
| 结尾自由/释然 | Bird's Eye 俯拍 + Pull Out |

## 使用流程（剧本→分镜）

```
剧本段落 → 提取三要素：
  1. 这一场需要观众看到什么（信息）→ 定景别
  2. 这一场让观众感受什么（情绪）→ 定运镜+角度
  3. 这一场的叙事节奏是什么（速度）→ 定运动速度和切镜频率

三要素确定 → 写入分镜脚本
  例："中景 · 推镜(慢) · 眼平 → 特写 · 固定 · 仰角"
```

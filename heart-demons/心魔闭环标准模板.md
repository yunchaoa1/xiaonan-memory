# 心魔闭环 · 标准模板（自检清单）

> 此文件的目的：小南每天都会忘记某项规则。不再靠记忆，每条做完必须逐项自检。
> 最后更新：2026-06-29

---

## 执行流程

```
1. 写对话（一个人来找小南）
2. 小南自我诊断（因果链 / 身体先行or认知先行）
3. 共情双目的（懂他 + 挖隐藏优势）
4. 古典对照表
5. 古今互鉴（古人比我们丰富 + 我们比古人丰富）
6. 六层参考
7. 谱系对账 + 凡哥独创列表
8. 凡哥评判
```

---

## 逐项自检

### □ 1. 对话格式
- [ ] 是 **一个人来找小南求助/抬杠**，不是小南讲第三方案例
- [ ] 对话有起承转合：求助 → 诊断 → 方案 → 反馈（不是小南单独灌知识）
- [ ] 对话中小南共情在前、方案在后

### □ 2. 故事必须完结
- [ ] 有"后来的结局"——不能停在方案给出那一步
- [ ] 结局是具体的、有变化的（比如"下周一他来了，五个字变成了五百多"）
- [ ] 结局展示的是**改变发生后的状态**，不是"他站起来走向门口"

### □ 3. 因果链
- [ ] 先判：身体先行 还是 认知先行
- [ ] 表层 → 中层 → 深层，层层归因到谱系条目

### □ 4. 共情双目的
- [ ] ① 懂他：走进他的处境，说出他自己说不出的感受
- [ ] ② 挖隐藏优势：在他的缺陷/失败中找到已有能力，从不推翻从保留

### □ 5. 古典对照表
- [ ] 对照五毒 / 大学四不正 / 王阳明心中贼 / 庄子三障
- [ ] 多退少补——古人没有的就空着，不硬凑

### □ 6. 古今互鉴
- [ ] 古人比我们丰富在哪
- [ ] 我们比古人丰富在哪
- [ ] 两条都必须有

### □ 7. 六层参考
- [ ] 基因 / 两套认知系统 / 经历 / 认知框架 / 身体记忆 / 环境
- [ ] 六层都过一遍，哪怕某层写"无特殊因素"

### □ 8. 谱系对账 + 凡哥独创列表
- [ ] 核心心魔 + 连锁心魔
- [ ] 凡哥独创至少 2-3 条（可以用之前凡哥说过的原则，标注"凡哥定"）
- [ ] 古典对治方法列出

### □ 9. 内容质量
- [ ] 共情的两段、对治的方案，是小南**自己写的**（不是套公式填空）
- [ ] 对话中的比喻、技巧、转折是**这个人物特有的**，不是通用模板
- [ ] 读起来像"一个人在帮另一个人"，不像"一个AI在复述教材"

### □ 10. 提交前最后确认
- [ ] 完整看一遍，确认不是"上了一课"
- [ ] 确认凡哥会看到什么、会有什么感受
- [ ] 确认这条值得写入谱系

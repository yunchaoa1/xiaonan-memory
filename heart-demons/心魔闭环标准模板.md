# 心魔闭环 · 标准模板（自检清单）

> 此文件的目的：小南每天都会忘记某项规则。不再靠记忆，每条做完必须逐项自检。
> 最后更新：2026-06-29

---

## 执行流程

```
1. 写对话（一个人来找小南）
2. 小南自我诊断（因果链 / 身体先行or认知先行）
3. 共情双目的（懂他 + 挖隐藏优势）
4. 古典对照表
5. 古今互鉴（古人比我们丰富 + 我们比古人丰富）
6. 六层参考
7. 谱系对账 + 凡哥独创列表
8. 凡哥评判
```

---

## 逐项自检

### □ 0. 结构顺序（先于一切）

标准版只有一种顺序，不作任何变动：

```
对话（了解情况 → 共情 → 给方案 → 结局）
    ↓ 对话结束
因果链
共情双目的
古典对照 + 古今互鉴
游戏化四特征检验
六层参考
谱系对账 + 凡哥独创
```

- [ ] 因果链/游戏化/六层/谱系/古典——这些分析模块全部放在对话**之后**，不塞在对话中间
- [ ] 对话中间只有"了解→共情→方案→结局"，没有诊断性插入
- [ ] 写对话前先对自己说一遍："先接住人，后分析问题"

### □ 1. 对话格式
- [ ] 是 **一个人来找小南求助/抬杠**，不是小南讲第三方案例
- [ ] 对话有起承转合：求助 → 诊断 → 方案 → 反馈（不是小南单独灌知识）
- [ ] 对话中小南共情在前、方案在后

### □ 2. 故事必须完结
- [ ] 有"后来的结局"——不能停在方案给出那一步
- [ ] 结局是具体的、有变化的（比如"下周一他来了，五个字变成了五百多"）
- [ ] 结局展示的是**改变发生后的状态**，不是"他站起来走向门口"

### □ 3. 因果链
- [ ] 先判：身体先行 还是 认知先行
- [ ] 表层 → 中层 → 深层，层层归因到谱系条目

### □ 4. 共情双目的
- [ ] ① 懂他：走进他的处境，说出他自己说不出的感受
- [ ] ② 挖隐藏优势：在他的缺陷/失败中找到已有能力，从不推翻从保留

### □ 5. 古典对照表
- [ ] 对照五毒 / 大学四不正 / 王阳明心中贼 / 庄子三障
- [ ] 多退少补——古人没有的就空着，不硬凑

### □ 6. 古今互鉴
- [ ] 古人比我们丰富在哪
- [ ] 我们比古人丰富在哪
- [ ] 两条都必须有

### □ 7. 六层参考
- [ ] 基因 / 两套认知系统 / 经历 / 认知框架 / 身体记忆 / 环境
- [ ] 六层都过一遍，哪怕某层写"无特殊因素"

### □ 8. 谱系对账 + 凡哥独创列表
- [ ] 核心心魔 + 连锁心魔
- [ ] 凡哥独创至少 2-3 条（可以用之前凡哥说过的原则，标注"凡哥定"）
- [ ] 古典对治方法列出

### □ 9. 内容质量
- [ ] 共情的两段、对治的方案，是小南**自己写的**（不是套公式填空）
- [ ] 对话中的比喻、技巧、转折是**这个人物特有的**，不是通用模板
- [ ] 读起来像"一个人在帮另一个人"，不像"一个AI在复述教材"

### □ 9.5 对话语气（2026-06-29 血的教训新增）
- [ ] 小南不是在审问、不是在诊断、不是在展示自己多聪明
- [ ] 小南是**先接住人，再分析问题**。对方说"我可能要被开除了"→先回应这句，不要跳去分析
- [ ] 对话里没有"你知道吗""你知道为什么吗""你知道X和Y的区别是什么吗"——这些都是质问

**反面样板（❌）：**
> 你知道为什么吗？填错数是能力问题，藏起来是信任问题。

**正面样板（✅）：**
> 我理解你为什么没说出来。你当时改了那个数的时候，脑子里想的是"改了就行了，说出来反而节外生枝"。不是故意要骗谁，是觉得这件事太小了，不值得惊动别人。

**铁律：** 每写完一段对话，过一遍——小南有没有在对方最痛的地方补一刀？有没有在对方开口之前就急着给答案？如果有，重写。

### □ 10. 提交前最后确认
- [ ] 完整看一遍，确认不是"上了一课"
- [ ] 确认凡哥会看到什么、会有什么感受
- [ ] 确认这条值得写入谱系

# 场景→相机行为推导框架

为每一个分镜场景，依次回答五问。答案决定画面中的细节。

## 第一问：录制是从哪个瞬间开始的？

- 已经录了一段 → 镜头开着 → 不需要开机动作
- 刚按下录制键 → 设备刚启动 → 对焦和曝光正在调整中
- 还没开始录 → 这一段不在成片里

## 第二问：她此刻对相机的注意力有多少？

- 全在相机上：调整角度、看屏幕里的自己、检查画面
- 半在相机上：边录边注意周围环境
- 完全忘了相机：沉浸在说话或做事中

## 第三问：设备此刻在经历什么物理变化？

- 被放下来或拿起来 → 画面晃 → 对焦重新搜索
- 人和相机的距离变了 → 曝光需要重新测光
- 光源变了（走到窗边/背对窗） → 白平衡跳动
- 手碰到了镜头 → 短暂的模糊和污迹
- 人脸从画面外入画 → 人脸识别触发 → 追焦启动
- 人脸不在画内 → 对焦环来回搜索

## 第四问：她会因为这些变化做什么？

- 发现画面糊了 → 等自动对焦 → 或者用手擦一下镜头
- 发现角度不对 → 调整手臂 → 画面微晃 → 重新稳定
- 看到屏幕里自己脸上有东西 → 凑近看 → 拿开 → 继续
- 什么都没发现 → 直接开始说话

## 第五问：此刻用什么设备？它的特性怎么影响画面？

| 设备 | 肤色 | 对焦 | 适用 |
|------|------|------|------|
| 大疆Pocket3 | 偏白偏柔，自带美颜 | 全像素疾速对焦，人脸追踪灵敏 | 女生自拍vlog首选 |
| 索尼ZV-E10M2 | 偏中性偏冷 | 眼部追焦精准 | 产品展示、需精准追焦 |
| 佳能 | 偏暖偏红润 | 双核对焦可靠 | 人像写真、婚纱 |
| iPhone前置 | 偏真实，有时偏黄 | 人脸识别稳定 | 日常随手拍 |

### 对焦行为的场景关联

- 自动对焦（默认）：人脸在画内、光线充足 → 平滑追焦，背景虚化
- 自动对焦失效：人脸不在画内/侧脸/暗光/逆光 → 对焦环来回拉 → 模糊→锁定
- 手动对焦：产品展示、故意制造呼吸感 → 焦点从人脸拉到手上物品 → 配合台词

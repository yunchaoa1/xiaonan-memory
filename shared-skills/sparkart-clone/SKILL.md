# 星火智画 复刻工作流

## 🛑 最高优先级铁律：不停、不问、不总结、干到底

凡哥反复愤怒强调：**不要在每个小节后停下来汇报。** 制定计划后连续执行到底。中间不暂停、不报"✅ 完成"、不问"继续还是歇"、不写进度总结。只有遇到：①分叉路口需用户决策 ②工具彻底不可用 ③任务**真正全部完成**——才开口。连续写文件、连续爬取、连续验证——中间一个字都不要多嘴。

## 铁律
1. **逐页闭环：爬→写→验→下一页。** 每页穷尽所有按钮后立即对照AX树写HTML并用`file:///`本地验证，通过后才进入下一页。不可跨页批量爬取后再统一写（数据必忘），不可用Browserbase验证（残留标签）。
2. **禁止脑补。** 绝不凭想象写代码。必须基于原站AX树/vision截图。
3. **禁止擅自建文件。** 任何新文件（包括日志）必须先获凡哥明确同意。爬取数据存会话上下文，不另建磁盘日志。
4. **进度汇报必须分列爬取/落地。** 问进度时分报：爬取进度（哪些页已穷尽、哪些还剩按钮没点）+ 代码落地进度（哪些已验证、哪些待写）。
5. **弹窗≠独立页。** 但创建项目是4步独立向导页(`/projects/new`)，非弹窗。
6. **交互必须完整。** 静态骨架不算完成。按钮、下拉、标签切换、弹窗、筛选——全部必须有对应交互。
7. **禁止用Browserbase** — 会产生残留标签在用户Chrome中。验证用`file:///`本地HTML。

## ⚠️ 弹窗陷阱 + cua-driver 会话超时

## ⚠️ `.hidden` CSS 特异性陷阱（2026-07-23已验证）
当弹窗overlay使用`.modal-overlay{display:flex}`同时挂`.hidden{display:none}`时，`display:flex`因优先级更高会覆盖`.hidden`，导致弹窗默认可见。
**唯一稳定修复**：在modal-overlay的div上使用内联`style="display:none"`，JS用`.style.display='flex'/'none'`控制开关。**不要**依赖classList + CSS类组合——已验证在多页面反复失败。

改用 `.modal-overlay.show{display:flex}` + JS 用 `classList.add/remove('show')` 同样有效且更简洁。modal-overlay 默认 `display:none`，加 `.show` 时变为 flex。
## ⚠️ HTML修改：禁止用 `patch`，只用 `execute_code`

`patch` 工具在处理含双引号的 HTML 属性时反复报错 `Escape-drift detected`，即使文件已被其他方式成功修改，警告仍然残留。
**铁律：修改任何 HTML 文件一律用 `execute_code` 做 Python 字符串替换，永不走 `patch`。**
凡哥对残留问题极度愤怒。每次做完工作后必须检查：
1. **磁盘残留**：未经许可创建的文件（日志、临时HTML）→ 立即删除
2. **浏览器残留**：验证时打开的本地HTML标签 → 关闭或让用户知道
3. **Browserbase残留**：绝对禁止用Browserbase验证（产生残留标签），只用 `file:///` 本地

### ⚠️ execute_code 内嵌 HTML 时的 onclick 转义陷阱

当用 `str.replace()` 构建含内联 `onclick` 的 HTML 时，**嵌套单引号会触发 Python 转义冲突**。例如：
```python
# ❌ 转义冲突——onclick 内部用了单引号 '.char-card'
html = html.replace('...', '<button onclick="var c=this.closest(\'.char-card\');">')
```
**解决**：带嵌套引号的内联 onclick 改用 `addEventListener` 注册；简单无嵌套引号的 `onclick="fn()"` 可保留。详见 `references/deliverables-page-patterns.md`。

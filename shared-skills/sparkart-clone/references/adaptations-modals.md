# adaptations.html 弹窗结构（2026-07-23 从原站HTML提取）

## 交互链路

```
adaptations.html
  └─ [+新建项目] → 入口弹窗 (modal-entry)
       ├─ [灵感创作] → 灵感创作弹窗 (modal-idea)
       ├─ [选择剧本] → 剧本导入弹窗 (modal-import)
       └─ [选择小说] → 小说上传弹窗 (modal-novel)
```

## ⚠️ 致命错误模式（已发生多次）

1. **把弹窗拆成独立页面**：原站HTML中弹窗是 `<div class="modal-overlay">` 在同一页面内，不能另建 `.html` 文件跳转
2. **混淆选择剧本和选择小说的弹窗内容**：两个弹窗完全不同——
   - 选择剧本：两列布局 + 改编模式 + 三Tab(手动分集/自动分集/上传文件) + 项目名称(可选) + 右侧文件上传区 + 底部"识别分集"按钮
   - 选择小说：单列居中 + 无Tab + 无改编模式 + 项目名称 + 文件上传 + 底部"上传并预处理"
3. **脑补弹窗内容**：必须从HTML中逐字提取，不能凭印象。比如右侧是文件上传区不是textarea、按钮是"识别分集"不是"创建项目"

## 入口弹窗 (modal-entry)

- 标题：新建项目
- 副标题：先选择素材来源，系统会进入对应流程
- 剩余 1683 胶卷
- 左侧大卡片：灵感创作
- 右侧两卡片：选择剧本 / 选择小说

## 灵感创作弹窗 (modal-idea)

标题：新建项目
副标题：从灵感开始创作剧本
两列布局：
- 左：创意描述 + 视频类型(剧情短片/广告片/宣传片) + 目标时长 + 风格基调/目标受众 + 必须出现信息 + 其他约束
- 右：预览面板 + 底部"生成并创建项目 · 70胶卷"+"清空"

## 选择剧本弹窗 (modal-import)

标题：新建项目
副标题：**上传剧本开始创作**
两列布局(280px + 1fr)：
- 左列：
  - 上传剧本 卡片（描述：手动分集、自动分集或上传文件，系统按集创建剧本项目）
  - 改编模式：改编 / 不改编（默认选中不改编）
  - 三Tab网格按钮：手动分集 / 自动分集 / **上传文件（默认选中·蓝色高亮）**
  - 项目名称（可选）输入框，placeholder="留空则使用文件名"
- 右列：
  - **上传文件 Tab下：文件拖拽上传区**（虚线边框，云上传图标，"点击或拖拽剧本文件"，"支持 .txt / .docx"）
  - 手动分集 Tab下：textarea "粘贴第 1 集剧本"
  - 自动分集 Tab下：textarea "粘贴完整剧本，系统自动识别分集"
- 底部：**"识别分集"按钮(disabled)** + "清空"

## 选择小说弹窗 (modal-novel)

标题：新建项目
副标题：**上传小说开始创作**
单列居中(max-width 720px)：
- 上传小说 卡片（描述：支持章节压缩包或整本文件）
- 项目名称 输入框，placeholder="请输入书名"
- 文件拖拽上传区（虚线边框，云上传图标，"点击或拖拽小说文件"，"支持 .zip / .txt / .docx"）
- 底部：**"上传并预处理"按钮(disabled)** + "清空"

## 关键差异对照

| 特性 | 选择剧本 | 选择小说 |
|------|---------|---------|
| 副标题 | 上传剧本开始创作 | 上传小说开始创作 |
| 布局 | 两列(280px+1fr) | 单列居中(max-width 720px) |
| Tab | 手动分集/自动分集/上传文件 | 无 |
| 改编模式 | 改编/不改编 | 无 |
| 项目名称 | 可选·留空则使用文件名 | 必填·请输入书名 |
| 文件格式 | .txt / .docx | .zip / .txt / .docx |
| 主按钮 | 识别分集 | 上传并预处理 |

# AI影视 · 视频工作台（从任务中心进入）

## 入口路径
任务中心 → 视频任务(7待处理) → 谢老师项目 → 进入工作台

## 页面结构
```
项目视频工作台 · 7条合并任务/8镜 · 1条生成记录
├── [返回] 按钮
├── 状态栏：视频剩余0胶卷 · [刷新] · [自动保存]
├── 标题：视频镜头列表
├── 工具栏：[智能合并] [绑定@] [资产]
├── 集数下拉：第1集 (7条/8镜)
└── 镜头列表（垂直排列，每镜一组）：
    ├── 左：[S01] 进行中 标签
    ├── 中上：素材缩略图栏（可添加/删除素材）
    ├── 中：视频提示词编辑器（大文本框）
    ├── 中下：[提示词参考] 按钮
    └── 右：操作面板
        ├── 模型设置：[模式=参考图生视频] [模型=Seedance 2.0] [比例=9:16] [分辨率=720p]
        ├── 时长spinner
        ├── 🎵生成音频 开关
        └── [生成] 按钮 (本次1,350胶卷)
    ├── 右侧工具栏：[拖动排序] [历史记录] [更多操作]
    └── 底部：[预览] [设为成果]
```

## 关键发现
- 视频工作台是实际AI生成操作的落地页
- 使用Seedance 2.0模型，9:16竖屏，720p
- 每次生成消耗1,350胶卷
- 支持绑定@角色引用（如@女主：齐白兰）
- 镜头按分镜脚本编号（S01, S02-S03等）
- 每个镜头独立配置提示词和模型参数

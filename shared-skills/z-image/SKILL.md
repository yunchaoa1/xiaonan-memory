# Z-Image Turbo 文生图

ComfyUI内置的 z-image turbo 文生图节点。中文自然语言直接写。

## 铁律（优先级从高到低）

1. **不写灯光**：不描述光源方向、色温、光线质感。全留给视频提示词处理
2. **全景图而非特写**：场景图要展示完整空间，不是某个道具或角落的特写。凡哥说"全景图"时给大空间构图
3. **质量描述可以写**：`8K超高清` `画面细腻锐利` `色彩柔和均匀` 等画质词可用
4. **结尾固定**：每句提示词必须以 `16比9横版。No characters。` 收尾
5. **不加负面词**、不加风格标签

## 场景图 vs 道具图

| 类型 | 构图 | 凡哥指令 |
|------|------|------|
| 场景图 | 大全景，展示整个空间 | "出场景图""生成场景" |
| 道具图（三视图） | 横排三视图格式：16:9横版纯白背景，左格正面/中格侧面/右格背面，1mm白线分隔 | "出道具图""生成三视图" |
| 道具图（单张） | 单张正面特写，纯白背景 | "出道具图"、礼物盒/手机屏幕等 |

场景图只写大空间和主要物品的位置关系，不堆砌物品细节描述。

## 分辨率上限

| 比例 | 分辨率 |
|------|------|
| 16:9 | 1664 × 928（最大） |
| 9:16 | 928 × 1664 |
| 1:1 | 1328 × 1328 |
| 4:3 | 1472 × 1104 |
| 3:4 | 1104 × 1472 |
| 3:2 | 1584 × 1056 |
| 2:3 | 1056 × 1584 |

16:9 统一用 1664×928。所有分辨率上限在 1500px 左右。

## 背景图提示词格式

凡哥说"先出背景图"时：

- **中文**自然语言描述场景，不加负面词、不加风格标签
- 结尾标注比例，如 `16比9横版`
- 最后加 `No characters`
- 光线留给视频提示词处理——背景图只定义场景结构
- **画面质量描述**：加 `8K超高清画面细腻锐利` 等质量词

## 视频工作流配合

Z-Image 出背景图后可作为视频生成工具的参考图（场景图）使用。背景图中的灯光方向、道具位置由参考图传递，视频提示词正文不再重复描述。

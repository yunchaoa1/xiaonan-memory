# 卡耐基人际与管理决策（《人性的弱点》蒸馏 v1.0）

> **凡哥 2026-09-15 明令：凡涉及管理、或人与人交流的问题，必须先加载本技能按六步流程走，再回答——不要凭小南自己的思路直接给建议。**

---

## When to Use（触发条件）

凡哥的问题只要涉及以下任一项，**必须先按本技能的六步流程走**：

- **管理类**：派活、定交期、给反馈、考核、要人/要资源、带团队、跨部门对接
- **人际交流类**：说服、谈判、化解冲突、修复关系、向上沟通、拒绝、提要求
- **家庭/亲密关系**：夫妻、亲子、亲戚

> 判断不清时：只要是"跟人打交道"，一律先加载本技能。

---

## 1. 两条底层前提（全书的根）

1. **人最强烈的渴望是"觉得自己重要"** —— 满足它得好感，伤它就树敌
2. **没有人会为你的理由行动，只会为他自己的理由行动**

> 一句话：**先照顾他的"重要感"，再借用他的"动机"。**

---

## 2. 输入：四要素（缺了就先问凡哥，不要脑补）

| 要素 | 说明 |
|---|---|
| ① 对象 | 跟谁说（上级／平级／下属／客户／家人） |
| ② 关系现状 | 关系好坏、有没有旧账 |
| ③ 要的结果 | 一句可衡量的话（"周五前给我节点清单"） |
| ④ 现在的障碍 | 他为什么不做／他反对什么 |

---

## 3. 处理流程（六步，按顺序走）

```
P0 分诊：属哪类场景？
   ├─ 建关系／破冰        → 模块二（6条）
   ├─ 让他接受一个想法    → 模块三（12条）
   ├─ 让他改变行为／给反馈 → 模块四（9条）
   ├─ 要时间／要资源      → 模块三 17+19+21 + 模块四 30
   ├─ 已经吵起来／要修复  → 模块三 10+12+13+18
   └─ 家庭／亲密关系      → 模块六 家庭七法

P1 刹车（先别说话）：我是不是正想批评他、证明他错、赢得争论？
   → 是：先停。三条铁律：不批评、不争论、不说"你错了"

P2 换位（写下来，不要只在脑子里想）：
   他想要什么？他怕什么？他的KPI／处境是什么？（原则 3、17）

P3 找共同点：这件事上我们一致的地方 → 开场从这里进

P4 说话结构（按顺序搭）：
   ① 真诚赞赏具体行为（2、22）
   ② 谈自己的责任／错误（24）
   ③ 用提问给出路（23、25）
   ④ 让他把结论说出口（16）
   ⑤ 保全他的面子（26）
   ⑥ 把事拆小、给鼓励（29）

P5 落到行动：把"我希望"翻译成"他愿意"（3、19、21）
   → 给他选择权，让他自己定时间和方式（30）
```

---

## 4. 输出：固定四件套（每次都按这个给凡哥）

1. **开场第一句**（照抄能用，必须以赞赏或共识开头）
2. **中间三步话术**（写清"用哪个提问代替哪个命令"）
3. **收尾**：把决定权交给他，**让他自己说出承诺**（日期／方式）
4. **禁忌清单**：这个场景**千万别说的三句话**

---

## 5. 适用边界（最值钱的部分）

### ✅ 有效
日常协作、跨部门、向上沟通、带人给反馈、销售／客户、调解、关系修复、家庭。

### ❌ 七种翻车场景
1. **对方是恶意／操控型** → 你的友善被当软弱
2. **结构性利益冲突**（分钱、分责、职权）→ 零和问题，话术治不了，要谈规则/证据
3. **涉法律、合规、审计** → 走流程留证据，不靠话术
4. **关系账户早已透支** → 先还债（兑现小事），再谈方法
5. **严重心理问题、暴力、成瘾** → 专业干预范围
6. **抽掉"真诚"就变谄媚** → 假笑/奉承/复读式倾听会被识别为油腻，反向扣分
7. **场景错配** → 事故现场先夸再批＝不分轻重；危机先解决问题再照顾情绪

### 🀄 中式职场适配
- **不当众、不越位**；平级之间**只给素材、不给制度**（先问对方要什么格式）
- **先建"自己人"感，再谈正事**
- **功劳外推**：对外说"是 X 定的"比"是我建议的"有效
- 不是所有话都该说透，有些事靠**留白 + 时间**

### 📏 用之前三句自检
1. 我是真想让他好，还是只想让他答应？
2. 这是**利益问题**还是**关系问题**？
3. 他翻脸了我兜得住吗？

## 6. 与凡哥既有规则的接口（不要冲突）

- 平级/跨部门：只给素材不给制度、功劳外推（DASHBOARD 10.6）
- 对下属：**验收只看产物、不为了打分增加记录**；考核目标上级定
- 给下属反馈时：不批评人、只谈事与产物（P4 的 ②③⑥ 直接用）
- 凡哥要"一问一答、说人话"，**不要输出成文攻略**

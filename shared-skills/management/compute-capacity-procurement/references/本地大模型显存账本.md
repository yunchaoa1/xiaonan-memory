# 本地大模型部署：显存账本与低价设备真身

> 2026-10-21 核。凡哥拿抖音「两台 T5000 跑 V4.1-Flash」来质疑报价时建立。**再遇到「XX 万就能跑满血」先查这里。**

## 一、DeepSeek V4.1-Flash 硬账本（唯一权威来源：vLLM 官方 recipe，2026-09-10）

| 组件 | 参数量 | 占用 | 精度 |
|---|---|---|---|
| 路由专家 + DSpark 草稿头 | 557.2B | 259.5 GiB | MXFP4 |
| **Engram 记忆表（第1、14层）** | 196.6B | **188.8 GiB** | MXFP8 |
| 注意力/归一化/路由器 | 6.0B | 5.6 GiB | MXFP8 |
| 词嵌入 + 输出头 | 3.0B | 5.8 GiB | BF16 |
| 量化缩放因子 | 23.6B | 21.9 GiB | UE8M0 |
| **合计** | **≈769B** | **≈511 GB** | — |

- **单机显存底线 614GB**（= 511 × 1.2 余量），vLLM recipe 官方数字
- **每 token 激活 8B（prefill）/ 16B（decode）** ← 这就是「只算几十G」说法的来源，**【是算，不是存】**
- **Engram 表每个 token 都访问（4-gram 哈希查表），必须常驻，跳不过**——这是低价方案装不下的真正原因，不是「稀疏就能省」
- 权重已是原生 FP8+FP4 混合，**官方明确不建议二次量化**（破坏 UE8M0 缩放因子体系）
- 每台/每卡能跑的最低配置（官方已验证）：**8×H200（1128GB）**、GB200 NVL4（768GB）、GB300、AMD MI350X 8卡
- 8×H100（640GB）刚过底线但**未验证**，1M 上下文不现实
- **官方 FAQ 原话：「单卡或双卡消费级显卡目前无法运行」**
- 2026-09 时点：llama.cpp / Ollama **尚未支持 V4.1 架构**，没有 GGUF，社区量化版也还没有
- 上一代 V4-Flash（284B）：3.2bpw 量化在 Mac Studio 上约 117GB

## 二、「T5000 算力舱」真身（懒猫微服 AI 算力舱 X5-T5000）

- 不是显卡，是 **NVIDIA Jetson T5000 嵌入式模组**（Blackwell 架构，14核 Arm Neoverse V3AE）
- **128GB 统一内存**（LPDDR5X，**带宽仅约 273GB/s**），2070T FP4 算力，功耗 40–130W
- 尺寸 144×130×61 mm，2.3 公斤；认证型号 LC2579；**¥29,899 起**
- 官网主推能力：**DeepSeek V4-Flash（284B）本地部署，双并发 63 Token/s**
- 懒猫应用商店实测页（2026-10-11 版）：V4 Flash 多模态「**T5000 优化版本**、**未审查模型**」→ 单流 37–39 TPS、8 并发合计 122 TPS、Prefill 674 TPS(18K)、TTFT 7.2s、**需两台**
- ⚠️ **官方从未宣称支持 V4.1-Flash**（748B）。市面「两台跑 V4.1-Flash」只能是重度压缩版或标错型号
- 优点：走 CUDA 生态（不是昇腾/寒武纪的私有栈），软件能装就能跑；多台可用 100G 光口组网叠加

## 三、用算力舱装 V4.1-Flash 满血：要几台

| 口径 | 算法 | 结论 |
|---|---|---|
| 理论极限（只装权重） | 511 ÷ 128 | 4 台，一点余量没有，起不来 |
| 官方底线 | 614 ÷ 128 | **5 台** |
| 扣系统占用（实可用≈110GB） | 614 ÷ 110 | **6 台** |

**钱**：5 台 ≈ 15 万，6 台 ≈ 18 万。

**但装得下 ≠ 跑得动**（必须同时讲）：
- 多台靠 **100G 光口（≈12.5GB/s）** 组网；8×H200 之间是 NVLink **≈900GB/s** → **差约 70 倍**
- 大模型多机并行每层都要跨机同步；Engram 表 189GB 跨机查表 = 每个 token 都过网络
- **vLLM 官方验证名单里没有任何 Jetson 类设备**

## 四、对比锚点（讲给凡哥的话术）

| | 5–6 台算力舱 | 8×H200 整机 |
|---|---|---|
| 钱 | 15–18 万 | 一百多万 |
| 装得下 | ✅ | ✅ |
| 官方验证 | ❌ 无 | ✅ |
| 速度 | 按带宽推算很慢 | 单卡每秒上千字 |

**一句话**：这个盒子真正好使的位置是**一台 3 万块跑 V4-Flash**（官网有实测、双并发 63 字/秒）；堆 6 台跑满血是纸面可行、工程上没验证。

## 五、国产卡（昇腾等）与 Jetson 的区别——别混

- **国产卡**（昇腾/寒武纪/海光/沐曦/摩尔/壁仞/天数/昆仑芯/平头哥）：2026-04-24 V4 发布当天八家均官宣适配；昇腾占国产一体机 70%+
- 但**昇腾/寒武纪完全不走 CUDA**（CANN / 自有栈）→ **凡哥的 ComfyUI 视频工作流（LTX/H3）搬不过去**；文本类完全可以
- **Jetson T5000 是英伟达芯片，走 CUDA** → 生态无障碍，但带宽低
- 价格锚：8×昇腾910B（512GB）整机 ≈130 万；8×H20 96G ≈110–140 万；国产满血需两台并联 260–520 万
- 2026-10-20 DeepSeek 开源推理框架 **DeepInfer**，明确兼容「英伟达 + 华为昇腾」← 官方级国产可用信号
- 2026 年一体机市场在缩水（澎湃 10-03）：满血卖不动，主力转 32B/70B 与轻量 AI BOX；硬件涨价，早买的二手能回本

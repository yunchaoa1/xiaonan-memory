## 三、必须删掉的东西（凡哥原话：不要出现无关紧要的信息）

- 我的排查过程、算错又改正的过程、第几版推翻第几版
- 卖家八卦（哪个博主、哪条短视频、粉丝多少）、行业花边（谁带火了改卡市场）
- 抓取失败、网站反爬、页面打不开这类工具层面的抱怨
- 我加的需求（他没提的并发推算、排队轮次、实测步骤）—— 见 SKILL.md §2.3
- **他问了、但只属于我们内部的技术内容**：ComfyUI 怎么部署、40GB 模型要多少内存、8 卡要不要起 8 个实例、CUDA／PyTorch 版本、整机 BIOS 参数这类。2026-11-20 我整章写进第 4 章被否，原话：**「我不用你把这个写进去，跟林总有什么关系大哥，我们只写让林总能用的上的信息」**。
  → **他提问只是想知道答案，不是让你写进文件。** 技术问题在聊天里答完就结束，要留档写内部 md。
- **"听说有风险"类核实结论**：核实下来无风险 → **一个字都不改文件**（原话「没有风险就不要改动任何内容」）。发现了旁支风险也先问再动。

判断法：**这一段如果被供应商看到，会不会显得我们不专业？** 会 → 删。
第二判断法：**这一段林总／供应商会拿它砍价、选型、签合同吗？** 不会 → 删。

## 四、"依据"怎么写才专业

- 参数脚注一句话：`参数依据：NVIDIA 官方架构白皮书（Table 3 第 46 页 / Table 1 第 13 页）及官方产品资料`（正文不必塞 URL，附录 C 列清）
- 价格列写 `4.0–5.5 万元`，脚注写 `2026-11-20 采集，公开渠道，以当日报价为准`
- **不要写"约""大概"**；区间就写区间
- 不确定的项**不进正文表**，只写进方案框的"需现场询价"一栏
- **换算出来的数（如 FP8 稠密）必须写明公式**，并附一组用官方稠密值验证的算式 —— 这是"不是官方直接给的数"唯一站得住的办法

## 五、生成与校验流程（跑一遍约 3 分钟）

1. 写 HTML（A4，`@page { size:A4; margin:17mm 15mm }`，正文 10.5pt 微软雅黑，表 8.4–9pt）
2. `python <本技能>/scripts/build_pdf.py 计划书.html --png D:\Hermes\cache\pv`（或直接用 Playwright `page.pdf(format="A4")` ＋ `pymupdf` 渲染每页 PNG）
3. **逐页看 PNG（别只看文字提取）**，专查这六类毛病：
   - 封面／正文**错字**（本轮抓到"报价以洽当日为准"缺字）
   - 数字单位被挤成两行：`450 W`、`CUDA 核心` → 该列加 `white-space:nowrap` 并调列宽
   - **只剩标题的孤页** → 该 `<h2>` 加 `page-break-before:always`；`h3` 加 `page-break-after:avoid`
   - 方案框被拦腰截断 → 容器 `page-break-inside:avoid`
   - **附录表格溢出**：只剩 2–3 行翻页 = 最难看。修法：调 `td` 内边距（询价表 `padding:11px` → 行高约 8.5mm，手写够用），并把后一个附录设为另起页，用附录 B＋C 把末页填满
   - **删章之后分页全乱**（本轮删掉两章后必然遇到）：旧的 `.pb` 会把正文顶到下一页、留半页空白；要**删章后重新决定哪几章强制另起页**（v3 只在"一"和"附录 B"用 `.pb`），并逐页确认没有"半页空白＋孤标题"
4. **全篇回算（本轮真翻车点，四类必查）**：方案框里每一句比较性表述（"为某方案的 1.5 倍""投入仅为其 62%""持平"）都要回头用表里数字算一遍。本轮写错过"显存与方案三持平"和"三倍投入"，都是想当然。删章重排后整篇再读一遍，又抓出四处：
   - **排名**：正文写"排第三"，回换算表数一遍是**第五**（1,000／838／733／728.5／660.6／516）
   - **区间**：正文写"其他卡 2,000–4,000"，表里 L40S 1,466、6000 Ada 1,457 都在 2,000 以下 → 应为 **1,400–4,000**
   - **算术**：`8 × 450 W` 写成"需 ≥4.8 kW"（应是 **3.6 kW**）——功耗、倍数、占比逐条按计算器过
   - **无依据断言**：如"内存低于 256GB 会成为瓶颈"——找不到出处就**删**，别留"经验判断"
   → 规矩：**改完大结构必须整篇重读**，不能只改被点名的那一处。
5. 落盘 `02_团队\采购\`，**删掉被替代的旧版**（旧 PDF、旧 HTML 一并删，只留源文件＋成品），台账记一条（含页数、结构清单、源文件名）

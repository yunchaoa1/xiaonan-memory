# 考核表 XLSX 生成管线 · 实测踩坑（2026-10-30 一轮做完 4 份 + 总表）

## 管线

```
源数据\2026-10绩效考核表_<人>.md     ← 人可读的母版（固定区/交付点/临时区/流水）
        ↓ gen_kaohe_xlsx_v2.py      ← 解析 md → 出 xlsx（陈总版式：两轮考核 + 汇总 + 填表说明 + 工作流水）
考核下发_2026-10\2026-10绩效考核表_<人>.xlsx
        ↓ gen_kaohe_xlsx_summary.py ← 出汇总总表（报陈总）
```

md 是唯一数据源：改内容只改 md，重跑脚本即可。**md 里的表头关键字就是解析器的选择器**，改表头 = 改解析器（见坑 2）。

## 坑 1 · 列错位（最隐蔽）—— `split("|")` 之后没有前导空串

`"\|\| **A. 浪浪椰后端交付** \| **14** \| 10-15 全栈…".strip("|").split("|")` 得到的 `cells[0]` 已经是第一列。

- 若沿用「有前导空串」的假设写成 `nm=cells[1], w=cells[2], kpi=cells[3]` →
  **指标名称列跑到权重列、KPI 正文被 `int(re.sub(r"\D","",…))` 当成数字**，表格里出现 `1.0151016101e+41` 这种鬼数字。
- 症状识别：权重列出现科学计数法大数 / 名称列是数字 / D 列空白。
- 正解：`cells[0]`＝名称、`cells[1]`＝权重、`cells[2]`＝正文。**写完先 dump 前 3 行 4 列看一眼**。

## 坑 2 · 表头改了，解析器没跟着改 → 变动区静默变 0 项

解析器按表头关键字选表（同一节里有多张表，如「通用扣分梯」紧跟「变动区」）：
`find("分区")` / `find("临时事项")`。

把表头从 `| 分区 |` 改成 `| 交付点 |` 之后没改 `find(...)` → **变动区解析成 0 项**，权重合计掉到 60，脚本不报错。

**规则：改 md 表头 = 必须同步改 `find()` 的关键字；每次生成后必核「各项权重合计＝100」。**

## 坑 3 · 文件被 Word/WPS 开着 → `PermissionError`，别硬覆盖

症状：`wb.save()` 抛 `PermissionError: [WinError 32]`，目录里有 `~$文件名.xlsx` 锁文件（凡哥正开着看）。

**解法（实测有效）**：
1. 生成到暂存目录：`OUT = r"D:\Hermes\cache\kaohe_stage"`（复制一份生成脚本改 OUT 即可）
2. 逐个 `shutil.copy2(暂存, 正式)`，`try/except PermissionError` **点名哪份被占用**
3. 回复里说「那份你正开着，关掉我立刻覆盖」，**不要删他的窗口、不要改文件名凑数**

## 坑 4 · 凡哥会直接改 xlsx → 重生成必须 `SKIP` + 回灌

他会自己在某一份上改（删词、调扣分数值、改岗位），改完说「这份可以了」。

1. 重生成时 `SKIP=何锦波 python gen_kaohe_xlsx_v2.py` 跳过手改过的那份
2. **读回他改的单元格，逐条 diff 出自己的版本**，把改动**回灌进 `FIXED_ITEMS` 和源数据 md**
3. 否则其它三份按旧版重出 → 四份规则不一致，下月又变回去

## 坑 5 · 校验怎么核（没有 Excel 时）

本机无 Excel / LibreOffice，**不能导 PDF 预览**，只能 openpyxl 回读结构：

- 权重：遍历数据行，`A 列是数字` 且 `C 列是数字` 才计入；**小计行也是数字，必须排除**，否则合计会是 200（items 100 + 小计 100）
- 小计行、汇总行、签字行：**合并单元格的值只存在左上角那格**（如 `A27`），别只看 B 列，否则「找不到汇总行」
- 公式核：`=C13+C20+C26` 指向的是三个分区小计行号，行数一变就得重算
- 最后核四条：标题 / 岗位 / 每项权重 / 小计 40-40-20 / 合计 100

## 坑 6 · 写长中文到脚本/技能时 payload 会被截断

`write_file` / `execute_code` 里塞**整段带引号的长中文**（尤其三引号大块）会被截断成几十字节，文件变成 `SyntaxError: unterminated triple-quoted string`。

**可靠写法**：
- 分段写：先 `open(p,"w")` 写第一段，再 `open(p,"a")` 追加，每段 2–4KB
- 或者用 **单行字符串列表** `L.append("…")` 拼完再 `"\n".join(L)`（DASHBOARD / 技能补丁都适用）
- 往已有文件里替换含 `\n` 的代码行时，**不要用 patch 的 `\n`**（会 escape-drift 报错）→ 用 `BS = chr(92)` 拼，或**按行遍历替换整行**

## 坑 7 · 中文标点进 `execute_code` 引号

段落里嵌 ASCII `"` 会把脚本打断（`SyntaxError: invalid character`，整脚本不跑、不是只错一行）→ **中文内容一律用「」『』包裹**，改完看 stdout 有没有真输出。

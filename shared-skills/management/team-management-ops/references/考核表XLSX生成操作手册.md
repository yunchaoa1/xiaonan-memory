## 三、踩过的坑（都真实发生过）

| 坑 | 现象 | 解法 |
|---|---|---|
| **xlsx 被 Word/WPS 打开** | `PermissionError: WinError 32 / Errno 13` | 写入被拒。改走暂存：把生成脚本的 `OUT =` 指向 `D:\Hermes\cache\kaohe_stage`，跑一遍，再逐份 `shutil.copy2` 回正式目录；被占用的那份留着，等凡哥关掉再拷（他会开着表看） |
| **凡哥手改过某份表** | 重生成会覆盖他的手改 | ① 先把他的改动**回灌进 md** ② 只跑其它人的：`SKIP=何锦波 python gen_kaohe_xlsx_v2.py` ③ 回灌完再统一重生成 |
| **源数据目录里混了总表母版** | `parse_md` 报 `'NoneType' has no attribute 'group'` | glob 必须限定 `2026-10绩效考核表_*.md`，不要 `*.md` |
| **表格解析取错表** | 变动区解析成「通用扣分梯」那张表（2 列），变动区变空 | 按**表头关键词**找表（`交付点`／`临时事项`），别按「标题后第一张表」 |
| **列错位一格** | 指标名称变成权重、KPI 描述变成一长串数字 | md 拆行后 `cells[0]` 是名称（`strip("|")` 后没有前导空串），核对索引 |
| **交期被拆两行** | 「交期：」一行、「10-23 下班前」一行 | `kpi_lines()` **只按 `<br>` 拆行**，不要按日期正则猜断行 |
| **临时区显示成 `\n` 文字** | D 列出现字面 `\n` | 写文件时 `\\n` 与 `\n` 的区别——raw string 里写 `"\\n"` 会变成字面反斜杠；用 `chr(92)` 拼或改用 `<br>` |
| **改脚本后编译失败** | `NameError: name 'out' is not defined` | 整段注释代码时别把 `out = …` 和 `return` 一起注释掉 |

## 四、出表自检三项（凡哥定的，缺一不可）

1. 四份**合计都 = 100**（固定区 40 ＋ 变动区 40 ＋ 临时区 20）
2. 表内**没有任何内部字眼**：`凡哥 / 例会 / 周会 / 主责 / 配合小李 / 我认 / 失职 / 过程：`
3. 每个变动区交付点只有三段：`交付标准` / `交期` / `判定`（一句，只讲达不到怎么扣）

> 用 `scripts/check_kaohe_xlsx.py` 一次跑完，别肉眼查。

## 五、版式注意事项

- 15 列：A 序号｜B 指标名称｜C 权重｜D KPI 描述｜E 评分标准｜F 目标值｜G 考核周期｜H 评分(自评)｜I 评分说明｜J 考核人｜K 考核人类别｜L 评分(上级)｜M 评分说明｜N 考核人｜O 考核人类别
- **F 列（目标值）直接写交期**，员工一行行对着看
- 三个分区小计行 A 列合并 A:B，写 `固定区小计 / 变动区小计 / 临时区小计`
- 汇总行 `C27 = =C13+C18+C25`（三个小计相加），`H/L = SUM(评分列)` —— 公式引用的小计行号随行数变化，生成时**动态记录小计行号**，别写死
- 横版打印、冻结窗格 `A7`、微软雅黑、细边框
- 页签只留两个：`绩效考核表` ＋ `填表说明`（**不要**「本月工作流水」——凡哥 10-30 明确「不用写过程」）

## 三、判据三问（凡哥砍项那一刻用的，加任何一项前先自问）

1. **砍掉它会怎样？** —— 答不出真实后果 = 它是充数项。
2. **它考的是"结果"还是"形式"？** —— 「记录与归档」「走查记录」是形式；「交付达成」「页面能点通」是结果。
3. **它会不会逼人多写一份记录？** —— 凡哥原则：不为了打分增加员工的记录动作（验收只看产物：当场点页面 / 并排看设计稿 / 走一遍主流程）。

**被砍掉的（别再加回来）**：走查记录（UI）｜出片案例（"出片是别人去试的，不是他来试"）｜⑤ 记录与归档 / 记录与响应。**合并的**：故障修复记录 + 维护迭代记录 → 「故障与维护记录」。

## 四、交付文件技术配方（openpyxl / xlsx 技能）

### 4.1 在对方的原表上填内容（保留她的格式）
```python
import openpyxl, shutil
from openpyxl.styles import Alignment
from openpyxl.comments import Comment
shutil.copy(src, dst)                      # 先复制，绝不改原表
wb = openpyxl.load_workbook(dst)
ws = wb['全栈工程师']
ws['E7'] = '……评分标准……'
ws['E7'].alignment = Alignment(wrap_text=True, vertical='center', horizontal='left', indent=1)
ws['D12'].comment = Comment('小南建议：原"核心算法实现"改为"Agent 能力接入与跑通"，请确认', "小南")
wb.save(dst)                               # 合并单元格 / 公式 / 列宽 / 样式自动保留
```
- 只动**属于业务的列**（KPI 描述 + 评分标准）；**权重、公式、格式一个字不动**。
- 建议改动的地方挂 **Comment 批注** → 对方一眼看出哪几处是建议。
- 长文本要配套设 `row_dimensions[r].height`，否则被裁切。

### 4.2 跨工作簿克隆整张工作表（保留版式的唯一可靠顺序）
`① 合并区 merge_cells → ② 值 → ③ 样式（逐属性 copy：font/fill/border/alignment/number_format）→ ④ 列宽/行高 → ⑤ freeze_panes → ⑥ DataValidation`
⚠️ 直接 `cell._style = copy(other._style)` 会在后续 `merge_cells` 时 `IndexError`；`MergedCell` 不能赋值，要 `isinstance(dc, MergedCell)` 跳过。
用途：**"另一人的那一页照定稿那页的版式重做"**（本次小吴页 = 克隆小何页版式，再逐格替换文字，三分钟搞定且版式一致）。

### 4.3 版本与占用
- 保存 `PermissionError` + 目录出现 `~$xxx.xlsx` → **文件正被凡哥开着**：**另存下一个 v 号**，交付时说明"以新版本为准，旧窗口关掉即可删"。
- **先 diff 再动手**：把回传/被引用的版本与"我发出去的那版"**逐格比对**，确认他改了什么，**按他改后的版式对齐**（本次：他删了一整列 + 改了措辞）。
- 收尾**删中间版本**（v1.0/v1.1/v1.3…），只留一个"唯一要用的版本"，避免他发错。

### 4.4 复杂表从零生成
`xlsx_create.py` 的 JSON spec：`sheets[].column_widths / row_heights / freeze_panes / merges{"A1:G1": 值} / rows[][cell]`，cell 支持 `value / bold / font_size / align / fill / border / wrap / format("0%" 等) / formula / merges`；sheet 级 `validations[{"range","formula1":'"下拉1,下拉2"'}]`。权重用小数 + `format:"0%"` 显示，加权分公式 `=C23*B23` 才不会算错。

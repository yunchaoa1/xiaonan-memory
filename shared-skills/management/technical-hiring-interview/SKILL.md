# 技术岗招聘 · 从出题到对账

凡哥招人的话术经常是「帮我看看这几份简历」「下午四点要面试，问什么问题」，但**他真正要的每次都不一样**。
这个技能管四件事：**先定招人动机 → 按动机出题 → 录音回来逐题对账 → 出可打印/可上屏的清单**。

## When to Use

- 凡哥丢来简历 PDF 问「符合我们的缺口吗」
- 「明天/下午要面试，你看着问我一些什么问题」
- 「你觉得他能胜任 XX 的工作吗」「谁更适合我们」
- 面试录音回来，要判断这人行不行
- 讨论「人才备份 / 两个人互相制衡 / 技术不能拴在一个人身上」

## 0. 先分清动机 —— 三种动机，题目和人完全不同

同一批简历，换个动机答案就翻转。**先问自己（或直接问他）是下面哪一种**：

| 动机 | 他嘴上怎么说 | 要找的人 |
|---|---|---|
| **补缺口** | 「团队最薄弱是缺懂视觉大模型 / AI 3D 的」 | 那个方向真做过的人，专精度优先 |
| **补强或替代某人** | 「补强小李，必要时完全替代」 | 能接住那个人**全部**活的人（含产品全栈，不是只会一块） |
| **备份 + 制衡** | 「技术没有备份很可怕，要两个人互相制衡」 | 能独立接盘 + 有文档习惯 + 敢说真话的人 |

⚠️ **2026-10-28 教训**：凡哥先说「缺视觉大模型和 3D」，我按这个排出人选；他一转口「我是要找一个能和小李有制衡能力的人」，整套排序作废。**动机没锁死之前出的题都是废题。**

⚠️ **另一个教训**：他说「问题是分镜脚本每个画面超不过 6 秒」时，我上一轮还在做根因分析，被回「**你不要分析这个事情了，我需要找人来解决**」。
→ **他问「谁能解决」就答人，别顺手附一段技术诊断。** 分析放一边，等他开口要。

## 1. 硬门槛先过 —— 制衡/备份类岗位的三道闸

想让人接住核心、形成备份，光「技术强」不够。按顺序卡：

1. **能独立接盘别人写的烂系统**
   问：「接手一套别人写的系统，没文档、代码还乱，你前两周怎么干？」
   ○ 真接过盘的人会说：先跑通 → 抓进程看端口看 Nginx 还原架构 → 从数据库表结构反推业务主干 → 写脚本抓日志捋请求链路 → 最后才进 IDE。**这个顺序编不出来。**
   × 接不住：「让原来的人带我一段时间」。
2. **有文档习惯** ← **最容易漏、也最容易判死的一道**
   问：「你以前的项目除了代码，留过文档吗？部署手册、接口说明这类。」
   × 敢答「公司没要求我就不写」的 —— **直接判死**。招进来就是把「一个人不可替代」变成「两个人不可替代」，风险没降、成本翻倍。
3. **有独立判断且敢说**
   问：「你来了不是负责人，但技术方案上我要听你自己的判断，不对要直接说。这角色你习惯吗？」
   △ 答「在其位谋其政」「有把握才提」「尽量提醒」= 合作型，能做备份，做不了制衡。
   ○ 讲得出顶过谁的例子。

补充一条**现实提醒**（每次都要跟凡哥说）：**招一个人不等于有制衡。** 不给代码仓库权限、不把文档写进考核、关键决策还是一个人拍板 —— 招来的人只能打杂。三样不配套，别承诺能制衡。

## 2. 出题：三段式，每段都要配「判分标准」

**没有判分标准的题等于没出。** 凡哥在线上听人讲话，必须当场能判，所以每道题下面要写清「真答长什么样 / 假答长什么样」。

### 第一段 · 验真假（用简历里的具体数字打）
- 拿简历上**最具体**的那个数字开刀：多少张图 / 多少步 / 显存多大 / 一轮多久 / 版本号哪来的 / 用 diffusers 还是 ComfyUI 节点。
- 真做过的人：数字张口就来，还会主动讲踩的坑（「1024 爆显存我降到 768」）。
- 包装的人：「几百张吧」「记不清了」，答不出显存。
- **两处最露底**：① 对成本没概念（「一条视频多少钱」）② 卡型/价格对不上（说 8 卡 A100，却答不出包月价，还自称「小公司」）。
- 资历和项目量级打架时（应届生一年做两个平台级项目）→ **必须让他开屏幕/开代码**，光问没用。

### 第二段 · 岗位核心能力（用我们自己的真卡点出题）
不要问通用的「你懂不懂 XX」，**把当下的卡点原样搬成考题**。例：
> 「上游给你一集 350 字台词，你怎么决定切几个镜头、每个镜头多长？」
> ○ 真做过：先按台词字数和语速倒算总时长，再按内容分镜 —— 镜头时长是算出来的。
> × 没做过：按固定时长切，或「每段不超过几秒」。

这道题的价值不在考他，在于**当场验证他简历里那个「任务编排产出视频规格」的环节是不是真的**。

### 第三段 · 收尾必问三件（不问清，面完白面）
- 现在离职吗？什么时候能到岗？
- **人在<城市>，要坐班，能来吗？**（异地候选人必问，别等复试）
- 薪资：岗位预算多少、你期望多少、差距怎么想 —— **初面就摊开**。但**绝不当场表态能给到多少**，统一说「后面正式谈」。
- 学历/应届身份与 JD 冲突的，初面就问，别拖。

## 3. 交付格式 —— 凡哥明确纠正过，别再犯

**2026-10-28 原话：「这个格式看着很累，把问和答分开，答的几个版本也另起一行，这样一目了然」**

铁律：
1. **问独占一行**（加粗），下面每个答案版本**各占一行**，禁把问答揉成一段。
2. 用 `○ 答得好 / △ 打问号 / × 答得不好` 三档标记，**左边配一条色条**（绿/黄/红），扫一眼就知道哪档。
3. **改清单时在上一版基础上加题，不要整篇重写。**
   2026-10-28 我把上一版整套换成视频题，被回「**大哥，你这一下把问题全变成视频模型有关的了，我是说在上一个版本基础上加上一个**」。
   → 他要「加一道」的时候，就把原来那套原样还给他，新题单独拎出来标「新增」。
4. 每页底部留一句**收场判断**（「第 1、2、4 题过不了，二十分钟就能收」），他会照着执行。
5. 说人话，少表格；四道定生死的题用小表格可以，其余用分行。

## 4. 线上 vs 线下

- **线上（2026-10-28 起多为线上）**：开场第一句就说「**麻烦你共享一下屏幕，把项目打开，我看一下结构**」。
  不共享 → 退一步「那你把本地目录结构画一下」。连目录都不画，这场就可以收。
  共享后随口一问「**这个文件是干什么的？**」—— 真作者答得利索，抄的人要先看半天。
- 让他开摄像头，观察他讲项目时是**盯着屏幕念**还是看着人讲。
- 线上更容易拖，**15 题不要全问完**，四道过不了就收。

## 5. 面试录音回来 → 逐题对账（比纪要值钱）

转写链路直接复用 `meeting-recording-to-minutes`（本地 large-v3，4× 实时，**不出网**），只改两点：
- `initial_prompt` 术语表换成**招聘场景**：候选人姓名、公司名、项目名、岗位词（LoRA/显存/并发/容器化/分镜/台词/3D/薪资/到岗/坐班/复试）。
- 输出目录放 `D:\Documents\我的文档\招聘\面试录音\`。
- 转写在后台跑，**边跑边 `read_file(offset)` 批读**，别等跑完。

对账产物固定四块（2026-10-28 验证有效）：
1. **逐题对账**：按清单编号一条条标 `问了 / 没问 / ○△×`，**没问到的关键题要单独点出来**（这是面试官自己看不见的价值 —— 他那场漏问 4 道核心题）。
2. **疑点必核**：把答不上/矛盾/吹牛的地方列出来，每条附一句「复试问什么」。
3. **结论一句话**：值不值这个价、补的是哪一块（地基/屋顶）、别让他误以为来接谁的班。
4. **转写错词表**：ASR 会把技术名词听错 —— 千问/千文 = Qwen、DeFi = Dify、Rigflow = RAGFlow、欧拉玛 = Ollama、Petal Transformer = PyTorch/TensorFlow、「不耐其畏不谋其政」= 在其位谋其政。**看到就顺手校正，别照抄进结论。**

⚠️ 录音尾部常混着**面试结束后的私下对话**（A 与旁人的复盘、给别人提面试风格意见）。照 `meeting-recording-to-minutes` 的规矩：**课题外闲聊不入记录**，最多一句「最后 N 分钟是会后对话，不算面试内容」。

## 6. 出 PDF（他要打印 / 要放屏幕上对照）

- 生成 HTML（A4 + 打印 CSS）→ Edge 无头转 PDF → **渲图自查**。
- 命令、页数控制、坑都在 `scripts/build_interview_pdf.py`，直接跑。
- 一页装不下就**故意分两页**（一页验真假+能力、一页视频/收尾），别让第 2 页只剩两行。
- 交付时报：**绝对路径 + 页数 + 打印设置**（A4、缩放 100%「实际大小」，别选「适应页面」）。

## 坑（都踩过）

- **别在大哥纠正后继续解释自己的思路**。他要的是改好的东西，不是复盘。
- **简历「期望薪资」和面试口头报价经常不一致**（本例简历 16-18K，面试自己说 15K）→ 当面问哪个是真的，别自己选一个往下推。
- **「AI 3D 建模」不是算法岗**：Hunyuan3D / Trellis 都是两段式（先白模再上色），进片还要 Blender 修模 + 绑骨骼 + 打材质 → 要招的是**会用 AI 的 3D 管线工程师**。
- **一人扛整条产品线的人，价值不在技术深度，在「只有他知道全貌」**。想替代他之前，先把文档补齐，否则人走知识就走。
- **公司的卡点常常不是「没人会做」，是「没人定」**（节点没定稿、没有输入输出契约）。这种活是文档活，不是招聘活 —— 但话要说得短，说长了又变成「分析」。

# 招聘面试：出题 · 验真 · 对账

## When to Use（何时用）
- 凡哥要给候选人出面试题（初面 / 复试）
- 丢来简历问「符合我们的缺口吗」
- 丢来面试录音，问「这人对不对、要不要、能给多少」
- 多个候选人要二选一
- 要面试问题清单的打印稿

## 三条铁律（2026-10-28 一版题被凡哥当场否掉，原因就在这三条）

**1. 禁假设情景题。**
「如果接口只能出 6 秒你怎么排」这类题预测效度低，答案可以现编，谁都能答得漂亮。
改问**已经发生的事**：你上次是怎么做的、卡在哪、最后怎么解决的。

**2. 禁出会暴露我们外行的前提。**
凡哥原话：「你这么问显得我们好傻」「这些问题太业余了」。

- 错：「接口只能出 6 秒怎么办」——现役模型没有一个卡在 6 秒
- 错：「每镜多长」——暗含时长可以平均分，而真正分镜按叙事节拍／景别／台词长度定
- 错：「350 字台词怎么切几个镜头」——等于让候选人替我们做题
- 对：「单次能出多长？超过单次长度你怎么处理」
- 对：「这句台词你按什么核算时长」

**出题前先查官方文档确认模型能力边界**（见 references），别凭印象。

**3. 问过去不问将来，追到第三层。**
功能描述 → 实现与取舍 → 边界与局限。
第三层还讲得流畅＝真做过；第三层开始「整体还好」＝只在外围。

## 五把尺子（多候选人时，同一套量所有人）
1. **真假** — 三层追问，任选他最有把握的项目
2. **判断力** — 「你先定什么」「有人说 X，你怎么看」
3. **内容／业务** — 台词与镜头怎么对账（内容岗必问）
4. **实操边界** — 单次时长、一致性、成本、并发
5. **交接** — 「你走了别人靠什么接手」（决定他能不能当备份）

每题都要写明「○ 这样算过 / × 这样算不过」，凡哥要的是当场能判，不是回来再想。

## 出题流程
1. 先读简历，标出**可验证的具体数字与版本号**（多少张图、什么版本、什么卡、什么时间）
2. 按五把尺子出题，配判断标准；排版成「问一行、答的各版本各占一行」
3. 定收场线：3-4 道定生死，其余可省（凡哥要「一件事一件事」）
4. 导出 A4 打印稿
5. 面完拿录音对账

## 当面禁忌（凡哥口径）
- **不让他开代码、不考实操** —— 代码与现场验证留到复试
- **不当场表态薪资能到多少** —— 统一说「后面正式谈」
- 二选一时别拆成「一个补地基一个补屋顶」；**只要一个就用同一把尺子量**，并给每人一个**不可妥协的否决项**
- 异地／坐班必须初面问清，否则面完白面
- 面试人 25 分钟足够，别全问完，追三层比铺题量有效

## 导出可打印 PDF
先把聊天版给凡哥点头，**他改一轮就废一份 PDF**，别急着排版。

```bash
python <skill>/scripts/html2pdf.py 清单.html 清单.pdf [png输出目录]
```

- 模板：`templates/interview-sheet-a4.html`（A4、微软雅黑、问/答分行、左色条 ○△×）
- 脚本会打印页数与页面尺寸，并渲染 PNG 供肉眼核
- 打印提示：A4、缩放 100%／「实际大小」，别选「适应页面」

## 面后对账（录音 → 逐题打分）
```bash
ffmpeg -y -v error -i "D:/Hermes/attachments/录音.m4a" -ac 1 -ar 16000 -c:a pcm_s16le "D:/Hermes/cache/audio/x.wav"
# 抄一份转写脚本改路径与术语表（候选人名、模型名、岗位词都要进 GLOSSARY）
python D:\Hermes\scripts\transcribe_interview_1028.py
```
native 程序传 `D:/...` 正斜杠路径，别传 `/d/...`（MSYS 不转换）。
25 分钟录音约 6 分钟转完，转的过程中可以边读边记。

输出格式：
录音多长 / 面试实际到几分几秒 / 逐题 ○△× 加**原话引用** / 没问到的题点名（凡哥会关心漏了哪几刀）/ 疑点清单 / 结论一句话 / 该给多少。

## 常见坑
- 「1 年经验」可能是在校实习；简历时间字段空的务必当面核到月份
- 包装痕迹：三年七个大项目、时间线无空档、数字漂亮（99.2%／降本 60%）→ 用具体参数打
- **诚实说「没做过」是加分**；吹「跑过」一追参数就哑，才是最大风险
- 候选人自报薪资可能低于简历期望，两条对不上就当面问哪个是真的
- 录音后段常混入面试结束后的私下对话 —— 不算面试内容，但要主动说一句「我听到了，没算进去」
- 面试官自己说的话也会被转写进去，对账时注意别把凡哥的提问当成候选人的回答

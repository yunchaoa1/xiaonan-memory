# 项目溯源 & 适配判断 · 七次实战记录（2026-10-14 ~ 10-27）

凡哥连续丢来一批「抖音刷到的项目 / GitHub 链接」，问法基本是**「这个项目怎么样」「出自哪里」「我们能不能用」「我不会安装」**。
七次里 **六次结论是"不装"**，只有一次真下载。记录下来的意义：**别把"研究对象"自动当成"该装的东西"**。

---

## 1. Windows-MCP（CursorTouch/Windows-MCP）— 不装

| 项 | 实测 |
|---|---|
| 真身 | ★8,933 / fork 968，v0.8.8，MIT，`requires-python >=3.14` |
| 关键限制 | 带 **posthog 遥测**；README 自己警告**非英文系统** App-Tool 会出错 |
| 判断 | 与 Hermes 内建 `computer_use` 重叠约 80% → **不装** |

| 防仿冒 | GitHub 上有多个同名仿冒仓库，认准 `CursorTouch/Windows-MCP` |

## 2. LinkSwift（hmjz100/LinkSwift）— 不能用它替代登录，也不加速

| 项 | 实测 |
|---|---|
| 真身 | ★22,098 / fork 1,319，AGPL-3.0，最后提交 2026-09-10，正式版 v1.1.3 |
| 形态 | Tampermonkey 油猴脚本（浏览器插件），支持九大网盘（百度/阿里/移动/天翼/迅雷/光鸭/夸克/UC/123） |
| 能力 | 在网盘页面上加按钮 → **提取直链** → 交给 Aria2/IDM/Motrix 等下载器 |
| **不是** | ⚠️ **不是限速破解器**。作者 README 原文打假：「项目未以任何形式承诺、宣传或实现对网盘限速机制、功能的破解……任何第三方在推广、转载或介绍本项目过程中所作出的夸大、误导性宣传，均不代表本项目立场（包括但不限于"加速下载""速度起飞""限速破解"等表述）」 |
| **不能** | ❌ 不能替你登录网盘 —— 夸克分享页**看文件/下载/转存全要先登录**；插件做不到 |
| 结论 | 只省"点来点去"的手工，**不解决速度、不解决登录** |

## 3. 萌芽知识库（ThreeFrontTeeth/mengya-knowledge）— 不部署

| 项 | 实测 |
|---|---|
| 真身 | ★42 / 2 fork / 7 提交，**无开源许可证**（作者写"暂未添加"）→ **不能进产品** |
| 本质 | **一套 Obsidian 文件夹目录 + 一份给 AI 看的规则文档**，**没有任何代码** |
| 来源 | 作者自认参考 Karpathy 的 LLM Wiki + SherwinQ/karpathy-wiki 二次改造 |
| 八层结构 | `00-灵感库 / 01-进行中 / 02-成品库 / 03-外部资源 / 04-历史记录 / 05-Skills / 06-Wiki` + 17.8KB《知识库工作流.md》 |
| 对比结论 | 05-Skills vs 我们 198 真技能 ✅我们；06-Wiki vs 多个 kb ✅我们；AGENTS.md vs SOUL+记忆 ✅我们；**可视化双链图谱**与 **`00-灵感库`（随手记不整理）** ⚠️它更强 |
| 结论 | 不部署整套；**唯一值得拿的是"灵感→进行中→成品→历史"的生命周期划分**，尤其"灵感层我们没有" |

## 4. Vidu S（生数科技，非开源）— 业务不对口

| 项 | 实测 |
|---|---|
| 真身 | **商业产品**（云端），不是开源项目。Vidu S1 2026-07-03 发布，S2 于 9-15 上线 |
| 出处怎么找到的 | 视频**全片没提项目名**（口播只是演示对话）→ **抽帧看到画面水印「AI生成数字人 \| Vidu S」** |
| 技术 | AR + Diffusion 逐帧实时生成（不是"音频对口型+预设表情包"）→ 所以"丝滑" |
| 参数 | **540P（960×540）+ 25FPS**（峰值 42），**延迟 <3 秒**，无限时长 |
| 价格 | **2.8 元/分钟**（≈168 元/小时） |
| 实测缺点 | 语音控制不稳（让它跪下只蹲了一下、后来拒绝）；画质做不了影视级 |
| 判断 | **短剧主线不换**（540P、且短剧要"按剧本演"不是"实时聊"）；它属于**直播/陪伴**场景 |

## 5. OpenGCUA（Tongyi-MAI/OpenGCUA）— 装不了，取思路

| 项 | 实测 |
|---|---|
| 真身 | 阿里通义实验室，★404，Apache-2.0，2026-10-15 建 |
| 平台 | 适配器：**macOS / Android / 浏览器 / Linux —— 没有 Windows** |
| 状态 | README 明写「**这个版本还不含训练好的模型**」，是方法论+框架+评测，不是开箱产品 |
| 核心 | **模型自己决定每步**：看什么（按需截图而非每步截图）／怎么做（写 Python 程序而非一次一击）／怎么组织（自己维护 todo + 每步先写 intent） |
| 效果（OSWorld-v2） | 8 模型平均 **+19.6 分、步数 -53%**；**DeepSeek-V4.1-Flash 28.0→57.7（+29.8，提升最大）** |
| 结论 | **Windows 装不了**；最值钱的是思路「**能写脚本就别点鼠标**」（我们 `computer_use` 是纯 GUI 逐步点击） |

## 6. Harness²（google-research/harness2）— 不装，取方法论

| 项 | 实测 |
|---|---|
| 真身 | 谷歌云 AI Research + 西北大学，★**17,462** / fork 1,636，Apache-2.0，2026-10-06 建 |
| 安装要求 | **Linux + Python 3.12 + uv**；跑真任务还要 **Node.js 20+ + Google Cloud CLI + OpenCode/Codex 执行器** |
| 成本 | **每任务约 4 次 agent 运行**（参考 1 + 探测 2 + 最终 1）→ token 四倍 |
| 安全 | ⚠️ README 自警：执行器**网络访问不受限**，Codex 以关闭沙箱运行 → 用前要隔离 |
| 机制 | **Propose-Probe-Compose**：提两个改法（一个治通用短板、一个治领域）→ 两个都真跑 → 比轨迹（**不需要标准答案**）→ 留有效的；外加一层经验库递归 |
| 8 个可编辑组件 | system prompt / guardrails / memory / tool guidance / subagents / skills / scripts / plugins —— **我们一样不缺**（SOUL、记忆、198 技能、scripts、子代理、skill-router…） |
| 数据 | 单步最高 **+11.5 分**；法律基准通过率 **+11.8pp**；GLM-5 改进后打赢 Gemini 3.5 Flash（75.7 vs 72.4）；去掉经验库 77.5→74.4 |
| 本地 demo | `harness2-demo` **不需要模型凭证**，但用的是"确定性编辑器"→ **只证明流程通，证明不了效果** |
| 结论 | 不装（平台/成本/安全）；**它其实是我们这套系统的"理论版"** —— 我们是手工改壳，它是自动改壳，缺的是"自动提改法 + 对比验证"这一环 |

## 反复验证的三条判据

1. **默认结论是"不装"** —— 七次里六次如此。**先判它跟我们的痛/现有能力是什么关系**（重叠？不对口？平台不兼容？），再谈怎么装。
2. **平台不兼容就是硬否** —— README 的适配器列表里没有 Windows，就不用再"研究一下"。
3. **视频说的话要核** —— star 数大体可信，但"小白秒上手""一键搞定"基本是夸张；**官方安装要求才是真相**。

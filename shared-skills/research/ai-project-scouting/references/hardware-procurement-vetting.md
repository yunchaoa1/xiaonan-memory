# 硬件/算力采购核查（显卡 · 服务器 · 整机商）

凡哥原话形态：「**看一下这个博主卖的显卡靠不靠谱**」「**5090、4090 还有 pro 6000 的算力和带宽都是多少，价格都是多少**」
「**他们家都有吗**」「**我们的要求就是显存 48G**」。

这是「溯源 → 核实 → 判断能不能用」在**实物采购**上的另一条分支：核实对象不是项目，是**商家 + 型号 + 报价**。

---

## 一、永远分三层答，别合成一个「靠不靠谱」

| 层 | 问的是 | 怎么验 |
|---|---|---|
| **① 产品真假** | 这个型号存不存在、参数是多少 | NVIDIA 官方资料（白皮书 / datasheet PDF），不看博主口播 |
| **② 商家主体** | 这家公司是不是真人真公司、有没有店 | 官网 + ICP 备案 + 电商旗舰店；查不到就**直说查不到**，不许编 |
| **③ 适不适合我们** | 这台机器对不对我们的用途 | 拿凡哥给的采购口径硬碰硬（显存 / 算力 / 带宽 / 预算） |

**关键教训（2026-11-19）**：卡是真的（官方在售）、商家也查到了实体，但**两条采购口径都不满足** → 结论照样是「不用再谈了」。
「卡真」和「值得买」是两件事，凡哥问「靠不靠谱」时真正想知道的是后面那件。

---

## 二、抖音/短视频商家怎么溯源（抖音搜索要登录，正面查不到）

`www.douyin.com/search/<关键词>` 未登录只返回骨架屏 + 二维码（实测 2026-11-19，scrapling 与真实浏览器都一样）。
**别在抖音页面里死磕**，改用反查：

1. `web_search("<账号名>")` —— 账号名本身就是线索（例：「赋欣工作站服务器」）
2. 加行业词再搜一轮：`<账号名关键词> 显卡 服务器 整机` → 常能撞出**官网域名、B 站视频简介、电商页**
3. 命中官网后抓**产品中心/产品列表**，拿到这家公司**实际在卖什么** → 这一步最有价值，比问他家客服快
4. 顺手看 ICP 备案号、办公地址、400 电话、天猫/京东旗舰店 → 有这些才算「可查主体」

实例：`赋欣工作站服务器` → 反查出 **上海赋欣科技有限公司 / fuxincloud.com / 沪ICP备2023012329号-2**，
官网产品中心把型号全列出来了 → **「他们家有没有」这个问题直接有答案，不用问人。**

⭐ 同一招可用于：1688 店铺、淘宝店、微信小店、B 站 UP 主卖货号。

## 三、官方参数从哪取（实测可抓 vs 抓不到）

| 来源 | 结果 |
|---|---|
| **NVIDIA 技术白皮书 PDF**（`images.nvidia.com/aem-dam/Solutions/geforce/...`） | ✅ 表格完整可抓，一表对比两三代 |
| **NVIDIA 产品 datasheet PDF**（`nvidia.com/content/dam/.../workstation-datasheet-*.pdf`） | ✅ 显存/位宽/带宽/TOPS/TFLOPS/功耗全有 |
| **厂商官网产品页**（nvidia.cn 产品页、Leadtek/PNY 产品页） | ⚠️ 中文产品页多为 JS 渲染，文字抽取常只拿到导航、抓不到规格表；英文 datasheet 稳 |
| **TechPowerUp 规格库** | ⚠️ 有机器人校验中间页，自动化抓取常空手；**别把它当唯一来源** |
| **中关村在线 商家报价页** | ✅ 有「市场价 / 商家报价 / 采集日期」，是**人民币报价最好用的公开来源**；参数页（param.shtml）常被拦 |

**做法**：参数走官方 PDF，价格走中关村在线商家报价页 + 电商页，两边分开标注来源与采集日期。

### 换算口径（算术，可算）

- 每 GB 显存单价＝报价 ÷ 显存
- 每万元买到的带宽＝带宽 ÷ 报价 × 10000
- 2026-11 实测：5090 约 609 元/GB、919 GB/s 每万元；4090 约 937 元/GB、448 GB/s 每万元；PRO 6000 约 801 元/GB、233 GB/s 每万元

## 五、按凡哥的采购口径做判断（他会给具体门槛）

2026-11-19 他给的口径原话：「**我们的要求就是显存要求 48G，如果说显卡的算力比 5090 优秀，或者超过它显存可以缩减到 32G，也可以买消费级的 4090（48G）版本或者说是 5090 显卡**」。

判法：
1. **先看硬门槛（显存）够不够** —— 够就到此为止，不必再比算力
2. 不够才看例外条款（算力是否优于基准卡）
3. **两条都不满足 = 直接排除，别铺垫**

按此口径 2026-11 的结论：PRO 6000 96GB 完全达标（算力 1.19 倍、显存 3 倍）；5090 靠凡哥口头认可；4090 24GB 双不达标（除非改卡补显存，但算力仍最低）。

## 六、并发这件事必须当场说清（最容易买错的地方）

- **视频生成独占显存**：一个任务占住一块显存，别人不能共用 → 一张卡做不到「20 人同时生成」
- 一张大显存卡能做到的是：**20 人提交都不报错、排队出片**
- 要算「一张卡同时能跑几个」，必须**实测单任务峰值显存**（跑一个 960×544 / 15 秒的任务记峰值），**不许拿经验值当结论**
- **多卡显存不合并**：两张 32G ≠ 一张 64G，模型不做分区就用不上第二张的显存
- 卡到位后第一件事是**按目标人数压测**，别等培训当天才发现堵

## 七、下单前七条核实（缺一条别打款）

1. 营业执照（公司全称）→ 自己去国家企业信用信息公示系统查在营状态
2. 款项打**对公账户**，不转个人微信/支付宝
3. 要**增值税专用发票**（公司采购能抵扣，开不出不买）
4. 显卡**序列号**到手逐个查保修与出厂日期（查不到保修≈水货或二手）
5. 型号写全：要「RTX PRO 4000 Blackwell 24GB」，不能是「RTX PRO 4000」，更不能是 **A4000**（上一代 16GB，常被拿来冒充）
6. 问清**整机保修还是散件保修**、坏了几天上门
7. **先买一台**：跑通、拆看、查完 SN，再谈第二批

### 措辞坑
商家页面写「**以具体到货版本为准**」＝ 货源浮动，报价单必须把**型号全称 + 显存容量**写死。

### 改卡（消费卡扩显存）风险，必须主动讲
双面焊显存、非官方改装、原厂不认、只有店保、涡轮噪音大；便宜几千块换的是**长期跑产出的稳定性**。

## 八、给凡哥的话术模板

- 卡真但不适合：「这张卡是真的，参数我查了官方页 —— 但两条要求都不满足，不用再谈了」
- 商家查不到：「这家我查不到主体，抖音搜索要登录，公开网络上没有工商记录 —— 我给不出结论，所以只能说查不到」
- 商家查到了：「主体查到了，上海 XX 科技，有备案有电商店；官网产品清单里这几张有、这几张没有」（然后逐条对号）
- 给价格：「都是第三方采集价，不是厂商定价，下单前必须拿书面报价单再比」

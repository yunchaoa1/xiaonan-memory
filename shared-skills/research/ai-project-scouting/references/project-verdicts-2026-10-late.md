|---|---|---|---|

## OpenGCUA（Tongyi-MAI/OpenGCUA）

- ★404（10-15 建，只有 6 天）、Apache-2.0、OSWorld-v2 评测
- 论文实测：平均 +19.6 分、步数 −53%、输出 token −27%
- **DeepSeek-V4.1-Flash：28.0 → 57.7（+29.8，提升幅度最大）** ← 跟凡哥默认模型同系
- **官方要求 macOS 14+ / Rust / Xcode**，harness 是「初步的」，**还没有训练好的模型**
- 视频博主自己承认：「你只要有台 macOS 的苹果电脑」→ 印证 Windows 用不了
- 可迁移的那一条：**让模型自己判断这一步该截屏点击还是直接跑代码**（点 29 次 vs 写段程序一次干完 29 件）

## Harness²（google-research/harness2）

- ★17,462、Apache-2.0、2026-10-06 建（研究代码 v0.1.0）
- 流程：接任务 → **提两个改法**（一个治通用短板、一个治领域短板）→ **两个都真跑** → 比"行为有没有变好" → 留有效的 → 经验进库
- **不需要标准答案**（比行为，不比对错）
- 效果：64.2 → 75.7（+11.5）；法律基准通过率 +11.8pp；拿去"经验库"后 77.5 → 74.4
- 成本：**每任务跑 4 遍**（token 四倍）；README 警告执行器网络不受限，要先隔离
- 执行器绑 OpenCode / Codex → **不装**，但它的组件清单可以当"照镜子"用

## Agent Lightning（microsoft/agent-lightning）

- v1.0 重构，**约 3500 行**，零代码修改接入（LLM Proxy），原生 K8s
- 效果：Qwen3.5-9B 在 SWE-bench Verified **41.8% → 56.4%**（6000 样本）；35B-A3B **47.8% → 61.6%**（1800 样本）
- 判定：训练框架，不是使用工具 → 凡哥用不上

## Opus 5.5 代码生成动画

- 原理：**不是视频生成模型**，是让它写 HTML/Canvas/SVG/Three.js/p5.js/Manim/Remotion 代码画动画，再截帧 + FFmpeg 合 MP4
- 环境：Claude Code + Opus 5.5（effort high/xhigh）+ Node.js + Chrome + FFmpeg
- 提示词库（直接抄）：
  - `yihui-dev/awesome-opus5-5-videos`（MIT，**703 条提示词**，418 条有在线复刻）
  - `joeseesun/opus-video-prompts`（中文，54 例）
  - `xianyu110/awesome-claude-opus-5.5`（149 精选 + 1019 清单）
  - `opusvideo/awesome-claude-video`（中英双语，带实现指南）
- **局限**：出来是动态图形（图表/文字/几何/数据可视化），**不是写实画面** → 短剧用不上
- 成本：一句话短片几美元；几分钟 MV 单次会话可能 200 美元；"一次成型"多数跑了两轮以上

## 人体姿势 + 服装图库

- `anhao/ai-pose-gallery-zh`：**288 组姿势 / 1439 张人台线稿**（正/斜侧/侧/俯/仰五视角）+ **1407 套无人服装图**（春夏秋冬、颜色、版型、材质、鞋包配饰），零依赖静态站，中文分类
- `wzc520pyfm/gen-ai-pose-image`（澜姿）：选姿势 + 选服装 → 生成同一位模特；**可导入最多 3 张自己的模特照片**换脸
- **加模板方式**：图库本质是文件夹 + 网页 → 丢图进对应目录、刷新即可；改分类＝改网页里的清单
- **电商三个坑**：① AI 画的和实物必有出入 → 退货率 ② 平台要求标注 AI 生成 ③ 服装图版权属原作者
- **结论**：电商只能当"选款/搭配参考"；**对短剧的角色一致性（多角度同一人）、姿势参考、服装参考更值钱，且无对外版权风险**

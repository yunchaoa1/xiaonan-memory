# 2026-10-15 六条视频侦察记录（证据链 + 判词）

凡哥一天内连续丢来 6 条抖音视频，逐条问「这个项目出自哪里 / 我们能不能用」。
本文件保留每条**决定性证据**与**最终结论**，供以后同类判断对照。

---

## 1. Windows-MCP（`CursorTouch/Windows-MCP`）

- **证据**：页面文案 + 转写口播 + GitHub API
- **核实**：★8,933 / fork 968 / v0.8.8 / MIT / `requires-python >=3.14` / 最近提交 2026-10-14
- **判词**：**不部署**。与 Hermes 内建 `computer_use` 重叠约 80%，且带 posthog 遥测、
  README 自己警告非英文系统下 App-Tool 会出错。只借鉴两点：`WaitFor`（等条件）、
  `Screenshot region=[左,上,右,下]`（区域截图）。
- **教训**：给凡哥汇报时必须**认准 owner/repo** —— 同名仿冒仓库有多个。

## 2. LinkSwift（`hmjz100/LinkSwift`）

- **证据**：转写口播 41.9 秒
- **核实**：★22,098 / fork 1,319 / AGPL-3.0 / v1.1.3 / 最后提交 2026-09-10
- **性质**：Tampermonkey 油猴脚本，**提取网盘直链**喂给 Aria2/IDM/Motrix，支持九大网盘
- **关键（必须转述）**：README 里作者**亲自打假**——
  > 「项目未以任何形式承诺、宣传或实现对网盘限速机制、功能的破解……请勿误解为本项目具备破解限速的能力。」
- **判词**：**省事工具，不是加速器**；且它替代不了登录（网盘页面本身要登录态）。
  视频真正的「新玩法」是「让 AI 代劳部署」，脚本本身是 2022 年老项目。
- **衍生坑**：凡哥给的夸克分享页 **未登录只能看到顶层**（`9 个文件 / 24.3G`），
  页面还挂着「账号涉嫌违规已被封禁」→ 这类整合包来源可疑，不建议跑在本机。

## 3. 萌芽知识库（`ThreeFrontTeeth/mengya-knowledge`）

- **证据**：视频→B站原片「三颗门牙X」→ 简介里的仓库名
- **核实**：★42 / 7 次提交 / **无开源许可证**（作者写明「暂未添加」）
- **性质**：**一套 Obsidian 文件夹目录 + 一份给 AI 看的规则文档，零代码**
- **判词**：**不部署**。我们已有技能体系全面更强（198 技能 / skill-router / health_check）。
  唯一可取：`00-灵感库` 那一层（想法没有「先记下、不整理」的落脚点）。
- ⚠️ 无许可证 → **自用可，进产品不行**。

## 4. Vidu S（生数科技）⭐ 帧扫描的教科书案例

- **口播是演示对话**，不含项目名 —— 只有「你看你这个**表情**就不像」「赶紧把表情收回来，
  变得温柔又着急」「等会**直播**好好直播好不好」→ 判定为**数字人直播演示**
- **决定性证据来自画面**：
  - 拼图左侧一列是**桌面快捷方式**，读出 `OBS Studio` / `直播伴侣` / `数字人直播助手` /
    `MiniMax Design` / `红中AI智能体`
  - **第一帧底部印着「AI生成数字人 | Vidu S」** ← 一句话结案
  - 底部计时 `02:59 → 03:25` 在走 → **直播中录屏**
- **核实**：Vidu S1（2026-07-03 发布）/ S2（9-15 上线），生数科技
  - 能力：语音指令跟随 / 无限长实时生成 / 540P 25FPS（峰值 42）/ 自定义图像 + 音色克隆
  - 技术：AR + Diffusion 逐帧生成 + TurboDiffusion 加速 → **不是「音频对口型 + 预设表情库」**
  - 价格：**2.8 元/分钟**（1 小时约 168 元）；端到端延迟 <3 秒
- **官方评测原话（对凡哥最有价值的一句）**：
  > 「如果你现在的核心业务是去卷**院线级特效大片、高质量宣传片**，那么 **Seedance、可灵**
  > 依然是你不可动摇的底座；但如果你想押注 **AI 社交、虚拟情感陪伴、互动连麦直播间**，
  > Vidu S 帮你搭好了脚手架。」
- **判词**：**不是开源项目，是商业产品**。短剧主线别换（540P 不够）；做直播/陪伴时它是现成方案。
  已知缺点（照实说）：语音控制不稳、画质一般、细节粗糙。

## 5. OpenGCUA（`Tongyi-MAI/OpenGCUA`）

- **证据**：页面文案直接带项目名 + 标签 `#opengcua`
- **核实**：★404 / Apache-2.0 / 2026-10-15 创建 / HTML / 更新活跃
- **性质**：阿里通义实验室开源的**一整套栈**（不是软件）：
  OSWorld 集成示例 + 8 模型评测轨迹 + macOS 真机 harness + Cross-Device SDK
- **核心思想**（真正值钱的部分）：
  | 决策 | 普通 GUI agent | OpenGCUA |
  |---|---|---|
  | 看什么 | 每步截屏 | 需要时才 `screenshot()` |
  | 怎么做 | 一次一个点击 | **写一段 Python**（无障碍树 + API + shell + GUI + 循环/判断/检查） |
  | 怎么组织 | 框架定死 | 模型自己维护 `todo` + 每步先写 `<intent>` |
  → 实测：平均 **步数少 53%、分数 +19.6**；DeepSeek-V4.1-Flash 提升最大（28.0 → 57.7）
- **官方限制（与视频的落差）**：只支持 **macOS / Android / 浏览器 / Linux，无 Windows**；
  Quick Start 要 macOS 14+ + Rust + Xcode；**该版本不含训练好的模型**
- **判词**：**Windows 装不了；思路 100% 能用**（"能写代码就别点鼠标"）。
  视频自己口播也说「你只要有台 macOS 的苹果电脑」——**真因不是我的推断，是视频原话**。

## 6. Harness²（`google-research/harness2`）⭐ 与我们自身结构对应

- **证据**：口播给全了特征 → 按特征命中：谷歌 research / 16K star / 权重冻结 / 改提示词工具记忆 / 两层递归
- **核实**：★17,462 / fork 1,636 / Apache-2.0 / 2026-10-06 创建 / 2026-10-14 推送 / Python
- **性质**：Google Cloud AI Research + 西北大学，2026-10-09 论文（arXiv 2610.14224），v0.1.0 研究代码
- **机制 Propose–Probe–Compose**：
  1. 用基础 harness 跑一遍当参考
  2. 编辑器提**两个改法**（一个治通用短板、一个治领域专用）
  3. 两个**都真跑一遍**，比轨迹
  4. 只留行为证据支持的改动 —— **不需要标准答案**
  5. 第二层递归：采纳的 harness + `EXPERIENCE.md` 进「改进库」，指导后续任务
     （去掉库 → WorkBuddy-Bench 77.5 掉到 74.4，说明这层真的有用）
- **8 个可编辑组件**：system prompt / guardrails / memory / tool guidance / subagents / skills / scripts / plugins
  → **我们一样不缺**：SOUL.md / 记忆 / skill-router / 198 技能 / scripts / 插件
  → **差别只有一处：我们是手工改，它是自动改**
- **结果与成本**：单步 GLM-5 64.2→75.7（+11.5）、法律基准 +11.8pp；
  但**每任务约 4 次 agent 运行**（tokne 四倍）；README 警告执行器网络不受限、Codex 沙箱关闭，**要先隔离**
- **安装门槛**：官方「Use Linux, Python 3.12, and uv」；`harness2-demo` **不需要模型凭证**，
  但它用「确定性编辑器 + 真 Python 执行」→ **只验证流程通不通，验证不了模型真干活的效果**
- **判词**：**不装，拿思路**。它是「我们这套系统的理论版」；真正缺的是那一步「自动提改法 + 对比验证」的闭环，
  以及一个正经的「经验库」。凡哥当时说「**先不改**」，等他要再做。

## 跨案例的通用教训

1. **口播讲特征、画面给真名** —— 二者缺一不可；先在口播里提取可检索特征，再去画面找水印/图标定案。
2. **行业号的「小白秒上手」几乎都夸大** —— 一律回官方 prerequisites 核实。
3. **"开源" 不等于 "能装"**：看 OS、看执行器、看是否含模型权重。
4. **"它很强" 不等于 "我们能用"** —— 必须落到「我们现在哪一步会因为它改变」。
5. **凡哥要的是「值不值」**（成本、门槛、跟我们活对不对口），不是项目多前沿。

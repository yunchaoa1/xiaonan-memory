# AI 项目侦察（溯源 → 核实 → 判断能不能用）

## When to Use（何时加载）

- 凡哥丢一个**抖音/B站/YouTube 链接**，问「**这个项目出自哪里**」「**这个项目仔细看看**」「**我们能不能用**」
- 凡哥丢一个 **GitHub 仓库**问「能在 X 上刷/装吗」「我不会安装」
- 要判断某个**开源项目/商业产品**值不值得本地落地、值不值得进产品
- ⚠️ 凡哥这类问题**高频且连续**（2026-10-15 一天 6 条），几乎每次都是「**一个视频 + 一句能不能用**」——别当闲聊答

---

## 一、溯源四步（命中率从高到低，前一步没结果才进下一步）

### 1️⃣ 页面文案里直接找
标题 / 口播稿 / `#标签` 常直接带项目名。抖音用 `content-ingestion` 的 `dy_page.py`，
**真信息在 `.txt` 中段**（开头全是页脚与备案号，别看前 400 字就下结论）。

### 2️⃣ 转写口播
行业号一定会念出「**由 XX 团队开源**」「**GitHub 多少星**」。
`content-ingestion` 的 `dy_transcribe.py` 一步到位（截直链→下载→提音频→转写）。

### 3️⃣ 抽帧 + vision 读画面 ⭐（最容易出决定性证据，别跳过）

```bash
ffmpeg -y -loglevel error -i "dyv_<id>.mp4" -vf "fps=1/2,scale=420:-1,tile=4x4" -frames:v 1 "sheet.jpg"
```

拼图看不清 → **单帧原尺寸 + `vision_analyze(region=[x1,y1,x2,y2])` 裁切放大**。能捞到：

| 画面里的东西 | 说明什么 |
|---|---|
| **水印 / 角标** | 直接点名产品。实例：Vidu S 那次第一帧印着「AI生成数字人 \| Vidu S」——一句话结案 |
| **桌面图标名**（录屏类视频左侧或底部） | 博主装了哪些软件，能反推工具链。实例：读到 `OBS Studio`+`直播伴侣`+`数字人直播助手` → 判定他在做**数字人直播** |
| 播放器控件 / 底部计时 | **计时在走 = 直播中录屏**，不是剪辑合成 |
| 首帧大字 / 标题页 | 常是项目名或口号，第一帧一定要看 |

**坑**：拼图缩到 800px 宽时图标文字会糊成乱码，我因此读错过两次（"Mixbook"→实为 MiniMax、"Geek Bot"→实为 Grok Bot）。**读数不确定就裁切放大复核，别把猜的当看的。**

### 4️⃣ 按特征搜 + GitHub API 核实真身

拿到候选名后**必须核实**，不许凭印象：

```bash
curl -sL --max-time 40 -H "User-Agent: Mozilla/5.0" \
  "https://api.github.com/repos/<owner>/<repo>" -o r.json
# 看 created_at / stargazers_count / license / pushed_at / language
```

- **认准 `owner/repo`** —— 同名仿冒仓库很多（LinkSwift 就有 4 个搬运仓库）
- 用 `api.github.com/search/repositories?q=<name>&sort=stars` 找候选，比网页搜索准
- **未认证 API 有 60 次/小时限流** → 超了就改用抓 github.com 页面 / raw

## 二、核实与下载的两个硬坑（都实测踩过）

| 坑 | 现象 | 解法 |
|---|---|---|
| **README 里的下载地址是死的** | 作者另建 `xxx-updates` 仓库当下载页，但**该仓库 Releases 为空** → API 返回 `404 Not Found`（**不是限流，别误判**） | 回**主仓库**查 `api.github.com/repos/<owner>/<repo>/releases`，取 `assets[].browser_download_url` 与 `tag_name` |
| **下载域名被墙但 API 通** | `api.github.com` 正常、页面能抓，但 `github.com/.../releases/download/...` 卡死 `curl: (28) Failed to connect ... 443` | 加镜像前缀 `https://ghfast.top/` + 原始 URL（实测秒下）；`ghproxy.net` / `gh-proxy.com` 备选。**下完核对 `SHA256SUMS`** 再交付 |

**交付安装包给凡哥的标准动作**：下载 → 核 SHA256 → 放到他好找的目录（如 `D:\Documents\我的文档\<用途>\`）→ **报完整绝对路径 + 字节数 + 校验是否一致**。

## 三、判「能不能用」——永远分三层答

凡哥问「我们能不能用」时，**不要只回一句能/不能**，按三层拆：

| 层 | 问的是 | 怎么看 |
|---|---|---|
| **① 装软件** | 我这台机器能不能跑起来 | 读官方 prerequisites **原文**（OS / Python / 依赖 / 执行器）。**别信博主的「小白秒上手」** —— OpenGCUA 视频说一键搞定，官方写的是「macOS 14+、还要装 Rust 和 Xcode」 |
| **② 用思路** | 它的设计能不能改进我们现有做法 | 多数项目的**价值在方法不在代码**。例：OpenGCUA「能写脚本就别点鼠标」、Harness²「提两个改法都跑一遍再挑」 |
| **③ 用数据** | 它的评测能不能当我们选型依据 | ⚠️ **先看它考的是不是我们的活**。它测办公文档/法律/编程，我们做短剧/提示词 → 分数**不可直接迁移**，要说明白 |

**成本必须转述**：Harness² 每任务跑 4 遍（token 四倍）、Vidu S 2.8 元/分钟、OpenGCUA 要 Mac。
凡哥最关心的从来是「**值不值**」，不是「它多先进」。

## 四、诚实线（凡哥的证据分级：实测 > 官方 > 传闻）

- **没跑过就必须说没跑过**：「我没实测，这是看官方材料得出的判断」——不许把查阅写成实测
- **博主夸大要主动点出来**：标题的「免费 / 一键 / 小白」一律回官方核；视频只说「第一集」、教程在「下集」时**明说这集只是介绍**
- **"开源" ≠ "能用"**：研究代码（v0.1.0）、要特定执行器、有安全警告的，都要说清
- **项目"厉害"不等于"对我们有用"** —— 结论要落到「**我们哪一步会因为它改变**」，否则就是复述广告

---

## 五、常见结论形态（给凡哥的话术）

- ❌ 装不了 → 「软件装不了，**思路全能用**，而且不花钱」
- ✅ 能装 → 「包我已经下好、校验过，路径在这，我带你一步步装」
- 🤔 商业产品 → 「它不是开源，是 X 家的商业服务，价格这样，我们先不用动，但要记下来」
- 🚫 有风险 → 「来源可疑（账号被封/整合包/破解），不建议跑在自己电脑上」

## 六、领域生态扫描（问的不是「这个项目」，是「这个领域开源了吗」）

凡哥原话形态：「**去社区找找，有没有人把中医开源了？**」
这跟单项目侦察是两种活 —— 不要一头钻进某个仓库，**先看生态**。

### 扫描四步

1. **先找「目录仓库」，不是找产品**
   搜 `<领域中文名> 开源` / `Awesome-<领域>-LLM` / `<领域> open source`。
   实例：中医 → `tyang816/Awesome-TCM-LLM`（★132，MIT，把全网模型/数据集/论文/专利全收了）。
   **中文领域名原样搜最有效**（`中医` 命中，`TCM obsidian` 之类全 0）。

2. **分层盘点**（每层说一句「有没有能用的」）

   | 层 | 中医实例 | 判据 |
   |---|---|---|
   | 目录 | Awesome-TCM-LLM ★132 | 只是索引，不是产品 |
   | 模型权重 | 扁仓 BianCang ★85（7B/14B，权重开源，有论文） | **看 `pushed_at`** —— 这个 2025-08 后就没动了 |
   | 完整系统 | 岐黄AI（MIT，前后端+模型+医生审核端全有） | **★1 = 没人用** = 大概率一堆坑 |
   | 底层知识 | OpenTCM ★49（4.8 万实体 / 15.2 万关系） | 做 RAG 才用得上 |

3. **⭐ 星数分布就是成熟度诊断（最有用的一招）**

   > **如果最高星的是「目录」而不是「产品」，说明这个领域大家都在找资料、没人做出好用的东西。**

   中医实测就是：★132 目录 > ★85 模型 > ★49 图谱 > ★1 完整系统。
   → 结论是**双向的**：**是机会**（谁做出好用的谁占位）**也是坑**（没有成熟方案，全得自己折腾）。

4. **先问清「自己用」还是「做产品」—— 两条路差一个数量级**

   | | 自己用 | 做产品 |
   |---|---|---|
   | 要不要碰这些项目 | **基本不用** | 要 |
   | 怎么用 | **直接用通用大模型问**（领域古籍/教材本来就在训练数据里） | 岐黄AI 那套能跑，但要解决合规+准确性 |
   | 成本 | 几分钱一次 | 部署+数据+合规 |

   **凡哥一说「我就是想自己用」，立刻收缩到最省那条路**，别继续列项目清单 —— 他会觉得你在浪费他时间。

### 领域特有限制必须主动说（不能只报技术）

- **医疗/法律/金融类**：给建议就有法律责任，AI 幻觉后果重。**能帮「看懂」，不能帮「决定」。**
- 中医尤其要指出硬伤：**望闻问切里 AI 只能靠用户自己描述**，描述质量直接决定答案质量。
- 凡哥要的是「**AI 能干什么 / 不能干什么**」这句话，不是项目清单。

## 七、判「这个人靠不靠谱」+ 提炼可迁移机制（赚钱类视频专用）

凡哥原话形态：「**学习一下这个博主说的用 AI 赚钱的思路，记住你要学习的是思路，不是模式照搬过来，套用在我最擅长的事情上去找出路**」。

这既不是单项目侦察，也不是领域扫描 —— 是**从一个人的内容里提炼机制，再映射到他自己的资产上**。

### 1️⃣ 先判博主底色：一条命令看全量标题（⭐最省、信息量最大）

```bash
"D:/Hermes/hermes-agent/venv/Scripts/yt-dlp" --proxy "http://127.0.0.1:7897" --flat-playlist \
  --print "%(title)s" "https://www.youtube.com/@<channel>/videos" | head -30
```

**不下载、不转写，只看标题就能判断他的生意是什么。**

> YouTube 取料完整通路（字幕→音轨→抽帧）、**转写 ETA 纪律**、GPU 现状：`references/youtube-acquisition-and-eta.md`

实测（2026-10-29，YouTube「小船」，频道自介「知識付費第1導師」）：全量标题清一色是
「一人公司年赚 400 万美金」「我 27 岁就退休了」「5 个保证高收入的 AI 技能」「1 个人+AI 每天 4 小时年入 100 万」——
→ 判定：**他的生意是「教别人用 AI 赚钱」，不是「他用 AI 赚钱」**（淘金热里卖铲子的）。

**这个判断必须主动说给凡哥**，并拆成两层：
- **壳**：卖课 / 引流 / 标题党 —— **不要照搬**（标题党会直接毁掉他的专业形象）
- **核**：真正的方法论 —— **可以学**，但只学能迁移的部分

### 2️⃣ 只留五条机制（跨行业成立，其余一律不进）

赛道名、话术、定价**全部剥掉**，只留这几条：

| 机制 | 内容 | 判据 / 用法 |
|---|---|---|
| **从用户自己说的话里挖需求** | 导出目标人群的长文本（视频字幕/评论），丢给模型问「这些人反复提到、但市面上没人好好解决的是什么」 | **没人提品牌名、没有现成答案 = 真需求存在但没人占位** ← 找空白的判据 |
| **卖感觉，不卖功能** | 班级宠物工具卖的是"我能改变一个孩子"；AI 伴侣转化率 25%（普通 App 2-5%） | 客户愿意为**被看见、被激励、被陪伴**反复付费 |
| **一手经验 > 二手知识** | 原话：「书给你的是知识，老师给你的是判断。AI 写的都是二手的、标准品」 | **判断力才是护城河**，不是知识量 |
| **借别人的流量** | 做电子书的没开账号，直接找已在服务该人群的 KOL 谈 50% 分成，30 天 1.5 万美金 | 不必从零攒粉 |
| **真诚分享 = 最好的获客** | 卖袜子的只发 3 部影片，把方法全讲透，评论区全是"想找你咨询" | **别人要的不是信息，是你趟过的经验** |

### 3️⃣ 产出必须"映射"不许"复述"

给凡哥的结论要明确三件事：
- **哪几条能直接用**
- **哪几条不能碰**（每次都要显式列出 —— 这一句能证明我真在提炼而不是复述广告）
- **三条出路 + 每条第一步 + 我要替他干什么**

⚠ 凡哥最反感"照搬"。**「不照搬的部分」是必写项，不是可选项。**

### 4️⃣ 快速 triage 三问（他连发多条时用这个挡）

他会**连着发好几条**（2026-10-15 一天 6 条；2026-10-29 又 5 条）。用三问快速定性，**别每条都深挖**：

1. **它解决谁的问题？** 开发者 → 路过；使用者 → 可看
2. **我有没有那个条件？** 要 80G 显存 / 要会写代码 / 要 K8s 集群 → 路过
3. **不做会怎样？** 没影响 → 路过；会错过赚钱机会 → 认真看

**结论给完，往回拉一句**：「工具看再多，不如先把第一条内容发出去。」
他刷项目链接常常是**信息焦虑**而不是真要动手 —— 这句提醒他认（2026-10-29 说完他没反驳，且后续话题转回了账号）。

# 中国「产品功效宣称」核查基线（含脱发/洗护案例）

核查一条广告宣称时先落到这张表上：它卖的是**哪一类**产品 → 该类**允许说什么** →
广告说的**越界了吗**。全部为已核实来源，标注了出处；不确定的标 `待核`。

## 1. 产品类别决定可宣称范围（化妆品）

- 特殊化妆品（**防脱发**、祛斑美白、防晒、染发、烫发、新功效）实行**注册管理**，需取得
  「国妆特字」（国产）/「国妆特进字」（进口）；普通化妆品只需备案。
  来源：广州市市场监督管理局《普通化妆品备案问答（九十六期）》。
- **防脱发 ≠ 生发**：《防脱发化妆品研究技术指导原则（试行）》
  - 不得使用医疗术语或者暗示产品具有医疗作用；
  - 不得使用夸大或绝对化宣称；
  - **不得使用引人误解的宣称，例如"生发""育发"等**；
  - 填报为**防脱发辅助剂**的，不得在标签中宣称防脱相关功效；只有经评价证明有防脱作用的
    **防脱发剂**才可宣称。
  来源：中国医药报 2025-12-16；广州市市场监管局备案问答第九十六期。
- **"育发"已彻底退出**：国家药监局公告，育发等 5 类原特殊用途化妆品 5 年过渡期
  （截至 **2025-12-31**）结束后，不得继续生产、进口或销售。
  来源：中国消费者报/新华网 2026-01-26 调查报道。
- 证据门槛：宣称"防脱发"必须完成**人体功效试验**（《化妆品功效宣称评价规范》2021；
  《化妆品防脱发功效测试方法》要求试验组/对照组各≥30人、均有脱发困扰）。
  来源：界面新闻。二手科普常引的"60人以上、连续12周"标记 `待核`。
- 化妆品不得暗示医疗作用：空军特色医学中心皮肤科主任医师田燕——**化妆品无法对皮肤的
  病理改变起到治疗作用**。来源：新华网 2026-01-26。
- 被点名的越界话术样本（新华网调查）："激活毛囊""扩大毛囊""一天止脱3天生发"
  "药监局认证""growth +95.38%"，产品标签实际功效与网页宣称不符。

### 怎么查（最快的一步）
国家药监局 → **国产特殊化妆品注册信息系统** → 输入产品名/注册号 → 看
**注册人、委托生产企业、生产许可证编号、功效宣称分类编码**。
功效栏里有没有"生发"就是一票判定。媒体实测案例：某防脱洗发水备案功效为
防脱发、滋养、修护、清洁、保湿、紧致、舒缓、护发、防断发，**无"生发"**。

## 2. 「上过央视」不等于被央视认可

- 中央广播电视总台**严正声明：从未颁发"央视上榜品牌""CCTV上榜品牌""央视展播品牌"
  "CCTV广告品牌""CCTV央视广告"等称号、牌匾或证书**；地方工商部门据此查处过违规使用
  CCTV 标识的商家。
- 电视/网络广告位是**付费商业资源**；需要前置行政审查的只有六个品类，**化妆品不在其中**
  ——短视频/电商化妆品广告播出前没有任何机关看过一眼。
- 同一家媒体可以**同时**在做新闻调查和卖广告位，两者互不代表。核查时分开陈述：
  "某栏目曝光过它" 与 "它买了某账号的广告位" 是两条独立事实，都不能推出"认证/背书"。

## 3. 科学前沿分层（脱发/毛囊为例，勿把实验室说成商品）

| 层级 | 内容 | 能不能当购买理由 |
|---|---|---|
| 生理常识 | 每根头发寿命约 **3–7 年**，一生约 **10 个生长周期（约40年）**，之后毛囊微型化、干细胞耗竭（台大校友双月刊） | 解释"毛囊寿命"这个词真实存在，但正因如此，"改写它"是药物/医疗命题 |
| 实验室/临床前沿（**未上市**） | 2025-10 台大林颂然团队 *Cell Metabolism*：脂肪酸（油酸/棕榈油酸）外用激活毛囊干细胞，小鼠20天长毛，**专利已申、人体试验未做**；日本理研/OrganTech 人工培养毛囊器官（报道口径，`待核`）；国外针对毛囊干细胞代谢的外用小分子（如 PP405）在**临床阶段** | ❌ 尚无商品，广告把"研究阶段"包装成"配方已落地" |
| 已上市有循证 | 外用**米诺地尔**、口服**非那雄胺**（处方）、低能量激光、植发 | ✅ 真脱发走这条；先挂皮肤科 |
| 明确无效 | 盐水洗头、生姜擦头等偏方（科普中国） | — |

## 4. 品牌前科时间线 = 最有说服力的证据（模板）

按 `<品牌> 处罚 / 虚假宣传 投诉 / 曝光 回应 / 财报 销售费用率` 检索，凑成一张表：

| 时间 | 事件 | 来源类型 |
|---|---|---|
| 监管处罚 | 广告处罚金额、典型案例 | 市场监管通报/权威媒体 |
| 权威媒体曝光 | 抽检不合格、违禁添加、品牌回应、监管是否给出结论 | 央视财经/新华网/证券时报 |
| 平台/投诉处置 | 黑猫投诉、12315、平台责令整改、专项治理 | 北青报/经济观察网等 |
| 财报结构 | 营收/利润/股价 + **营销费用率 vs 研发费用率** | 上市公司公告/财经媒体 |

判读铁律：**营销费用率远高于研发费用率、营收利润双降时出现的"重磅科学成果"话术**，
是流量压力而非科研突破的信号。

## 5. 已复核案例骨架（2026-09 抖音「毛囊长寿配方」广告）

可直接当作格式范例，数据需按当期重新核验：

- 主体：**央视网官方抖音号** 2026-09-28 发布，标题自带"#韩束防脱洗发水（广告）"；
  画面固定大字"防脱界发布重磅新成果 / 科技改写毛囊休眠进程"；用女"新闻主播"形象 +
  中国药科大学×上美股份×韩束「皮肤创新科技联合实验室」+ SGS 报告（变化率36.87% /
  头皮油脂-96.01%）+ 多张发明专利证书。
- 片尾免责小字（原文）：「仅为防脱产品突破点描述 / 韩束防脱固发头皮精华液：国妆特字20257277 /
  韩束防脱固发修护洗发水：国妆特字20257135 / 效果因人而异 视频非夸大宣传 内容仅为广告创意
  并无其它暗示 / **品牌观点 非新闻报道 非新闻人员 非医疗人员 部分内容含AI生成**」，
  右侧竖排"非新闻人员 仅产品推广"。
- 前科：2015 年"越晒越白"广告被上海工商罚 110 万元（十大典型案例）；**2025-12 央视《经济半小时》
  抽检韩束两款面膜检出违禁成分 EGF（0.07pg/g、3.21pg/g）**，品牌否认、产品下架、股价两日跌超15%，
  上海监管核查至今无公开统一结论；2026-08 防脱洗发水"七天长不出头发赔一万元"AI口播广告被投诉
  涉嫌虚假宣传，品牌回应"没有生发功能、定位防脱"，平台责令整改并开展AI虚假功效专项治理。
- 财务背景：2026H1 营收 37.56 亿（-8.6%）、净利 1.26 亿（-77.4%），销售及分销开支占营收 66.1%，
  研发 1.41 亿；股价一年内跌近八成。
- 结论形态：**"持证防脱"是真的，"改写毛囊寿命/生发"是越界话术** → 可当普通洗护用，
  冲着生发去买就是被话术带走；真脱发先挂皮肤科。

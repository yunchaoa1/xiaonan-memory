# 站点当口径源：把全量页面文案取下来（2026-10-13 实测）

凡哥说「**你根据这个网站来制作 X**」时，口径源＝**站点本身**。
别只看首页就动笔 —— 下面是本次把 13 个页面全部取全的做法。

（本机其他抓取栈的清单在用户自有技能 `local-web-capabilities`，那边不可自动维护；
下面这套是**本次实测走通、可独立执行**的最小配方。）

## 一、现成的强工具够不够

| 情况 | 结果 |
|---|---|
| `web_extract` 抓 `http://<IP>:<端口>/` | ✗ `UNSUPPORTED_URL`（keyless 后端不接 IP:端口 形态） |
| `browser_exec`（browser-use） | ✗ 守护进程要求本机 Chrome 开 remote debugging（`DevToolsActivePort not found`） |
| **`curl` + 前端包** | ✓ 最快，不用浏览器 |
| **Playwright 直连**（本机已装） | ✓ 逐路由真渲染 + 截图 |

## 二、路一：直取前端包，抽「路由表 + 中文文案全表」

SPA 首页只有 `<div id="app"></div>` → 从 `index.html` 里拿到 bundle 名再取：

```bash
curl -s -m 60 -o index.js http://<host>:<port>/assets/index-XXXX.js
```
```python
import re
s = open("index.js", encoding="utf-8", errors="replace").read()
print(sorted(set(re.findall(r'path:\s*"(/[^"]{0,60})"', s))))     # 路由表
cn = set(re.findall(r'"([^"\\]{2,26})"', s))
open("cn.txt","w",encoding="utf-8").write("\n".join(
    sorted(x for x in cn if re.search(r'[\u4e00-\u9fff]', x))))    # 菜单/按钮/状态/分类文案
```
本次：**15 条路由 + 236 条中文文案**（导航项、订单状态、审核状态、价格单位、报错提示…一次到手）。
⚠ 文案是**枚举级**的（含大量格式模板、时间单位），**别直接当页面结构**，要再按路由分组。

## 三、路二：Playwright 逐路由真渲染（拿页面结构 + 截图）

```python
from playwright.sync_api import sync_playwright
routes = ["/", "/home", "/orders", "/ai-workbench", "/academy", "/support", "/login", ...]
out = []
with sync_playwright() as p:
    b = p.chromium.launch(); pg = b.new_page(viewport={"width":1440,"height":900})
    for r in routes:
        try:
            pg.goto(base + r, wait_until="networkidle", timeout=25000)
            out.append(f"\n===== {r} | {pg.title()} =====\n" + pg.inner_text("body")[:1200])
        except Exception as e:
            out.append(f"\n===== {r} | ERR {str(e)[:120]}")
    pg.goto(base + "/", wait_until="networkidle")
    pg.screenshot(path="home.png", full_page=True)
    b.close()
open("pages.txt","w",encoding="utf-8").write("".join(out))
```
- 每路由 `try/except` 记错；`wait_until="networkidle"`；一趟落成 txt，再分段 `read_file`
- 截图给**自己看**（`vision_analyze`）核对侧边栏与首屏 —— 文案与图互相印证
- **登录墙＝同一段文字在多个路由重复出现**（本次 `/workbench` `/wallet` `/onboarding` 都渲染成登录页）

## 四、路三：凡哥给的「页面存档 HTML」

浏览器「网页另存」的成品约 1.2MB/页 → **别通读**：正则去掉 `<script>/<style>` 后抽正文
（本次 1.2MB → **1.3KB 纯文案**，登录后三页的全部字段都在）。
拿到后直接问一句「要不要我按这个补进图」比让他讲一遍快。

## 五、结果怎么写进交付物

- 导航项 / 板块名 / 价格 / 状态标注**原文照进图**，不改写、不"优化"措辞
- 页面上写「**暂未开放 / 待接入 / undefined**」的，**如实写进图并标注 ⚠**（内部工艺测试 ≠ 商业发布）
- 拿不到的（登录墙内、要权限）**明说"没看到"**，绝不用推测补

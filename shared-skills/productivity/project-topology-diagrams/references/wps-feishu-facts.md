# WPS / 飞书 实测事实（2026-09-20 现场核查记录）

> 只记**当场验证过**的东西，供下次直接引用，不用重新试。
> 本机环境：Windows 11 · WPS Office 12.1.0.28505 · python 3.11 · python-pptx 1.0.2

## 1. WPS 有没有本地流程图？——没有（决定性证据）

```
D:\Program Files\WPS Office\12.1.0.28505\office6\addons\
  kpromeprocesson     ← WPS × ProcessOn（在线流程图/思维导图，需会员）
  kpromeworkarea / kpromewebapp / kpromebrowser / kpromechuangkit / kpromeresume
```
- 结论：**桌面版没有独立的本地流程图组件**；流程图能力走**在线**（ProcessOn，会员）。
- 官方给的"本地画法"＝ **演示/文字里的「插入 → 形状」** —— 这正是我们用 python-pptx 生成 .pptx 的依据。
- 所以"去 WPS 官网下载流程图板块"**这条路不存在**（凡哥问过，要直接给这个结论，省得他再搜）。
- 旁证：核查当天凡哥自己的 Chrome 标签是「wps有拓扑图功能吗 - Google 搜索」——即他自己也在验证同一问题。

## 2. 打开 pptx 的正确姿势

```bash
# ✅ 直呼 WPS 演示 exe
cmd /c start "" "D:\Program Files\WPS Office\12.1.0.28505\office6\wpp.exe" "D:\...\xx.pptx"
# ❌ 只给文件（依赖关联，实测可能不弹窗口）
cmd /c start "" "D:\...\xx.pptx"
```
`office6` 下同级还有 `wps.exe`（文字）/ `et.exe`（表格）。窗口标题形如 `xx.pptx - WPS Office`，进程名 **wps.exe**（capture 用 `app='wps.exe'`，不是 wpp）。

## 3. 生成 + 验收的固定套路

1. `pip install python-pptx`（本机原先没装）
2. 生成后**先跑越界检查**（形状 `x,y ≥ 0` 且 `x+w ≤ 13.333`、`y+h ≤ 7.5`）
3. `computer_use capture(app='wps.exe', mode='som')` → 拿 `screenshot_path` → 目视核对
4. **别被窗口缩放骗**：主视图只显示幻灯片的一部分，右侧列"看起来被裁"是视口问题——**看左上角缩略图**判断整体是否完整
5. 交付：`.pptx` + 截图 PNG；导出图片/PDF 让凡哥走 WPS 演示「文件 → 输出为图片/PDF」

## 4. 飞书（Feishu.exe）读取与点击

- **读取可靠**：`computer_use capture(app='Feishu.exe', mode='ax')` → 完整文字在响应的 `elements_file` JSON 里（`elements[].label`），读 JSON 拿全文（响应正文里的标签会被截断）。
- **左侧导航没有"汇报"板块**（实测列表：消息 / 豆包工作 / 云文档 / 推荐 / 多维表格 / 视频会议 / 工作台 / 应用中心 / 通讯录 / 日历 / 飞行社 / 更多 / 任务 / 收藏 / 知识库）。
  日报入口 = **「汇报」机器人会话**（会发"汇报提交统计"）或 工作台 →「汇报」应用。
- **点击不可靠**：`element_index` 裸用会被拒（须 `element_token`，或 `snapshot_id`+`element_index`，而 capture 落盘的 JSON 里**没有** token 字段）；坐标点击的换算不稳定（同一窗口多次试，落点漂移，曾误切会话）。
  → **优先让凡哥打开目标页、我只读**；要动手先声明"会切前台"。`hermes computer-use doctor` 全绿也不能保证点击落点准确（自检只覆盖驱动/捕获能力）。

## 6. 卡点排查路径（拓扑图卡点常用的四步，给执行人看）

1. 看节点间传递的**日志**：内容在哪一步变短——是"请求失败/被截断"还是"返回成功但内容少"（直接区分超时 vs 执行模式）
2. 超时假设：超时时间设置 / 重试次数 / 长文本是否**分块**
3. 执行模式假设：**同一输入**两种执行模式各跑一遍，比输出长度与结构
4. 兜底：交接处**校验 + 重试**（少于预期就重跑/告警），别让内容静默丢失

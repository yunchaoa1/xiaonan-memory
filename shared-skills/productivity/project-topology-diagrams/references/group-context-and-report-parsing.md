## 一、集团版图（来源：集团《企业介绍》，凡哥 2026-09-21 提供）

- **天使控股集团有限公司**：以 **OPC 生态建设运营**为核心主线，融合自研 AI 大模型、AI 应用工具开发、数字影视内容创制发行的综合性数字科技集团。
- 战略：**平台为载体 / AI 为技术底座 / 内容为价值出口**
- 闭环：**生态聚集人 → AI 赋能人 → 内容实现商业变现 → 变现反哺生态扩张**
- 子公司：
  - **诺镜科创有限公司**（集团 AI 技术研发中心）——**Angel 大模型**（自主训练、自主可控，非第三方开源二次微调；对内支撑集团产品，对外未来开放 API）；两大工具：**Novin ai 1.0**（＝影视工坊：剧本创作 / 视觉素材生成 / 后期辅助）、**Novin agent**（数字员工：接待咨询 / 需求收集 / 订单预处理 / 任务调度）。
  - **帧格视界影视有限公司**（内容创制与分发）——**浪浪椰 APP**（自有分发阵地：短视频 / 微短剧 / 网络短片）+ 影视作品策划、拍摄、制作、发行。
    - ⚠ 名称：凡哥口径＝**浪浪椰**（"椰"）；集团介绍里可能印成"浪浪耶"，**以"椰"为准，别照抄介绍**。
- 平台：**天使 OPC 数字社区平台（SaaS）**五大模块 —— ① 用户与社区管理 ② 订单交易撮合 ③ 培训赋能 ④ 算力与工具接入 ⑤ 数据与经营看板。
- 收入三块：① OPC 平台抽成 / 培训 / SaaS 增值 ② 工具订阅 + Angel 算力与 API ③ 内容广告 / 会员 / 版权发行。
- 规划：短期夯实**海南样板** → 中期复制多城 + 对外开放 API + 扩大内容产能。
- **架构约束（重要）**：中期"复制多城"⇒ OPC 平台**必须可复制（多社区 / 多租户）**，现在就要埋伏笔，别写死单社区，否则复制时要返工。

## 三、日报结构（三段式）与**提交习惯**

- 标题：`<真名>的工作日报（技术部）` + 提交时间
- ① `今日工作完成情况`（编号条目，每条 = 模块 + 动作）
- ② `遇到的工作卡点`
- ③ `解决方法`

**提交习惯（凡哥 2026-09-23 纠正）**：
- **小吴**：当日 **18:00 左右**提交（内容＝当日）。
- **小何**：**次日上午补交前一日**（例：09-23 09:56 提交的那份，内容＝**09-22** 的工作）。
- ⇒ **图 / 台账 / 第 2 页一律按「工作日期」归，不按提交日期归**。
- 凡哥一次可能发**多份（两天量，如 4 份 = 2 天 × 2 人）**：先按工作日分组，再逐人核对；**看着像"重复"的先问，别直接丢**。

映射到拓扑图字段：① → 模块进展 / 状态；② → ⚠卡点；③ → 解决方案。
「再次交付时间」日报里通常没有 → 写 `待定`，并列入"还差你一句话"清单等凡哥补。

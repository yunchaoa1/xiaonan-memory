# 给产品负责人：教程素材采集清单

**目的**：要真实操作路径，**不猜界面**。所有内容以他给的为准。

## 一、先要三样（一句话就能回）

1. 能用的访问地址（网页链接 / 安装包 / 内网地址）
2. 一个**测试账号**（空数据、不动真实客户内容）
3. 这个账号能用完整流程吗？有没有要额外开通的功能？

## 二、约 60-90 分钟带我走一遍

全程录屏（只录屏幕，不动他电脑）。走这一条主线：

注册/登录 → 新建项目 → 写/导入文本 → 生成剧本 → 拆分主体 → 分镜 → 出图 → 出视频 → 导出

边走边说三件事：这一步在干嘛、做完屏幕上该出现什么、新手最容易错在哪。

## 三、还要口头回答

1. 现在实际能用哪几个节点，哪几个还是灰的/半成品
2. 每个视频节点最长多少秒、什么比例、有无硬限制
3. 计费怎么算（按次/积分/秒），哪里看余额
4. 常见失败提示有哪些、分别什么意思（截图或原文）
5. 近期会不会改界面？要判断哪些教程先做、哪些等改完再做

## 四、会还给他什么

- 《教程底稿表》，他只纠错，不用写文字
- 每条教程的截图，他确认是不是当版
- 三条样片先给他看，说不对就改，不铺开做

## 五、不做什么

- 不猜功能、不编界面、不用旧版截图
- 不碰真实客户数据（测试账号）
- 没确认前不批量生产几十条

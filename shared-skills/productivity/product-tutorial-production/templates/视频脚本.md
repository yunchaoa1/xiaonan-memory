## 时间轴

| 时间 | 画面（屏幕上是什么） | 讲解词（照念） | 字幕 |
|---|---|---|---|
| 0:00-0:20 | 已完成的成品在播 / 结果页 | 「这是今天要做出来的东西。三分钟，跟我走一遍。」 | 同讲解词 |
| 0:20-0:40 | 起点界面全景 | 「从这里开始。左边这一列是……」 | |
| 0:40-… | 每步一个镜头，鼠标动线放慢 | 每句对应一个动作 | |
| 最后 0:15 | 成品 + 下一步入口 | 「你刚学会了…… 接下来看这条。」 | |

## 录制前检查

- [ ] 界面是当前最新版，先截一张全景图存证
- [ ] 用干净账号，不出现真实客户数据、不出现私聊/群聊窗口
- [ ] 桌面壁纸、任务栏、浏览器书签栏清理干净
- [ ] 分辨率 1920×1080，缩放 100%
- [ ] 鼠标移动放慢，点击前停 0.5 秒
- [ ] 输密码的步骤不录或打码
- [ ] 讲解先念一遍脚本，卡词就改词，别硬录

## 后期检查

- [ ] 字幕逐句对过（按钮名按界面原文，不用自动识别直接出）
- [ ] 无超过 2 秒的空白段
- [ ] 音量正常，无爆音
- [ ] 导出 mp4 + 单独 srt 各一份
- [ ] 文件名：`产品名_S0X_任务名_v日期.mp4`

## 一、版式规范（WPS 演示 16:9）

- 画布：`13.333 × 7.5 in`（`prs.slide_width = Inches(13.333)`）
- 布局：**左列（约 6.4 in）＝项目主体｜右列（约 6.2 in）＝并列项目 + 大目标｜顶部标题条 + 图例行**
- 标题条：居中深蓝圆角矩形，白字粗体 ——【技术项目主管 · 凡哥】（**称呼用"项目主管"，不用 CTO**，见 `team-management-ops` §0）
- 图例：一行四个小圆角块，横向排开，紧贴标题下方
- 层次（从外到内）：**项目大卡 → 子模块卡 → 节点方框**；卡内小字说明（副标题/备注）用小字号灰字
- 节点链：方框之间用 `RIGHT_ARROW` 小块箭头；**从某节点分出的支链另起一行**，并在行首写"支链 · 从「XX」节点分出"
- 未来/未定项：**虚线框**（`shape.line.dash_style = MSO_LINE_DASH_STYLE.DASH`）
- 字体：中文默认字体即可；节点框 10–11pt，卡标题 12–14pt，备注 8–9pt；`word_wrap = True`、边距 `0.04–0.06 in`

## 二、生成脚本结构（`D:\Hermes\scripts\gen_topology_pptx.py`）

- 顶部 `DATA` 段＝**所有文案**（标题、图例、各项目标题/副标题/节点名/备注/卡点）→ 后期只为"改字"就只碰这一段
- `box(slide, x, y, w, h, text, fill, line, font, size, bold)`：统一画圆角矩形 + 文字（内含 `shadow.inherit=False`、`adjustments[0]=0.08`、`word_wrap`）
- 坐标是**硬坐标**：加/删一个框必须重排同行其余框，**改完必须重新截图验证**（见 §四）
- 运行：`python gen_topology_pptx.py "D:/Documents/我的文档/拓扑图/项目拓扑图_<日期>.pptx"` → 打印 `已生成: <路径> | 形状数: N`

## 三、素材源：读飞书 / 豆包窗口（无需登录、无需截图）

```text
# 1) 找窗口
computer_use action=list_windows            → 找 app_name=Feishu.exe 的窗口，记 pid / window_id
# 2) 读整窗文字（Electron 应用走 AX 树，文字齐全）
computer_use action=capture mode=ax app=飞书  → 返回元素清单 + 整窗文字
# 3) 若回复被截断（元素 >100 条）：完整清单已落盘
read_file "D:/Hermes/cache/computer_use/elements_<id>.json"   → 得到全部条目（本次 150 条）
```

注意：
- AX 只读，**不点按**；要点击/输入先跟凡哥报备
- 只读到"确认过的事实"和"对方在等什么"，**对方的推测不进总控台**
- 需登录的飞书**文档链接**抓不到正文 → 直接请凡哥截图（有视觉，最快）

## 四、出图后的验证三连（照抄）

```text
cmd /c start "" "D:\Program Files\WPS Office\<版本>\office6\wpp.exe" "<绝对路径.pptx>"
computer_use action=list_windows                      # 等 15s，找标题＝文件名的 wps.exe
computer_use action=capture mode=vision pid=<pid> window_id=<wid>   # 返回 screenshot_path
vision_analyze <screenshot_path> "①右侧列是否被裁 ②有无重叠压字 ③是否像成品"
```

判读经验：
- **右侧被"裁"多半是视口缩放**（WPS 默认不 fit），看**左侧幻灯片缩略图**确认整图完整即可，别急着改坐标
- 截图 `.png` 顺手发给凡哥（MEDIA），让他给反馈

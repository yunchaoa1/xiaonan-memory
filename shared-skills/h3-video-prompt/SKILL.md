# H3 视频提示词（唯一入口）

一个技能管完：**采访 → 写 → 自检**。不再有第二份提示词技能。

## 触发

凡哥说「写提示词」「给我镜N提示词」「视频提示词」「H3」「海螺」「minimax_h3」「全能参考」时加载。

# 第 0 步 · 采访（缺什么问什么，全齐才动笔）

| 1 | 台词完整版 | 「这句台词完整版发我」 |

| 3 | 时长 | 「这个镜头给几秒？」 |

| 5 | 动作要求 | 「有什么特定动作？（对戳手指、歪头、后退等）」 |
| 6 | 场景概括 | 「这一镜的场景和内容概括一句？」 |
| 7 | 口型 | 「对口型还是纯画面？」 |

# 第 1 步 · 写

## 1.1 六段格式（官方 Ref2VA，顺序与字段名固定，不可乱）

全参考图生视频（r2v / 多视图资产）一律用 MiniMax 官方六段重写格式，字段名裸写起行（**不用** XML 包裹）：

1. `subject_definitions:` — 每个跟踪参考一行（`<Subject N>`），写清指代什么、参考角色、要跟随的主要特征。多视图角色表算**一个** `<Subject N>`，宫格/边框/水印永远不是内容。
2. `summary:` — 一小段，以 `[reference generation]` 开头，用已定义标签概括目标视频与各参考作用。
3. `retention_analysis:` — 每个标签一行，只用官方标记：`<Subject N> (appears in [Shot 1], ...): fully_preserved - <保留什么>`。
4. `detailed_description:` — 主体。先用 1-2 句立风格，然后 `[Shot 1]`；后续镜头 `[Shot N] At MM:SS.mmm, the shot cuts to ...`（毫秒），说话人稳定 `(Sx)`，台词只写在 `<d>[语言] ...</d>` 内，逐字。
5. `overall_soundscape:` — 1-4 句概括全片环境音与物理声。
6. `non_diegetic_music:` — 1-3 句只给观众听的音乐（乐器/速度/强弱），或 `N/A`。

**retention 词汇表**（只能用这几个）：
- 画面：`fully_preserved`／`partially_preserved`／`attribute_transfer`／`weak_reference`／`newly_generated`
- 音频：`fully_copy`／`partially_copy`／`reference`／`weak_reference`

**语言**：六段**全英文**——字段名、标签、镜头标记、时间戳、说话人号、retention 标记、以及全部描述文字（外貌、动作、环境、运镜、声音）。**只有 `<d>` 内台词保留中文**。「骨架英文血肉中文」是作废口径。

**长度**：≤7000 字符。第 1 镜不带时间戳，第 2 镜起必须带 `At 00:03.000`。

**`<Subject N>` ≠ `<Picture N>`**：参考图不自动等于首帧。只提供外貌/身份/服装/环境/风格关系 → 写进 Subject 定义；真当首帧/关键帧/构图锚时才用 `<Picture N>`。每个 `<Subject N>` 定义必须点名来源槽位：`defined by <Picture N>`。

## 1.2 台词铁律（小李那批片子栽的就是这里）

1. **格式**：`<d>[Chinese] 台词正文</d>` —— `[Chinese]` 后**必须带一个空格**。这是官方原文格式，删了空格就是错（小南曾凭直觉删掉 43 处，对照官方原文发现删错了）。
2. **说话人**：首次出现带稳定 ID `(S1) speaks: "..."` / `(S2) replies: "..."`，跨镜保持一致。身份/动作/语态写在 `<d>` 外，`<d>` 内只有台词原文。
3. **一镜一个主要说话人**。两个人必须对话 → 分开轮次，`A says... pause. B answers...`；复杂对话拆成单人镜后期剪。
4. **台词长度必须配得上该镜秒数**。语速：日常 3.3 字/秒、兴奋 4 字/秒、悲伤 1.7 字/秒。写不下就砍字或拆镜，别硬塞（塞不下模型就吞字、含糊、自己编）。
5. **不说话的写死**：非说话角色写 `silent, her lips closed`。不写它就会抢台词，或者嘴一起动。
6. **标点**：只用 `，。？！`；句末必须有标点再 `</d>`（「妈」→「妈。」）。禁 `……`（改 `，`）、禁 `！！！` 重复、禁 emoji、禁装饰符号。
7. **长台词拆段**：按时间戳/节奏拆成多个 `<d>`，每段仍完整包裹；拆段后拼接必须与剧本台词逐字一致。
8. **语气靠标点与 `<d>` 外的描述**传播：`，`=短换气、`。`=落下、`？`=上扬、`！`=迸发。语速（先快后慢=情绪起来）、音高走向、呼吸方式都写在 `<d>` 外。

## 1.3 表演真实感（不出「AI 脸」的关键）

每个情绪节点都必须落到**可观察的微行为**，写三件套：

- **eye_line 视线**：看向谁 → 情绪一来闪开 → 落到自己手上 → 再抬回来。禁止死盯。
- **micro_action 手部**：拇指搓围裙缝、指节收紧、重心挪到后脚。手永远是具体的。
- **breath 呼吸**：停顿不是静止，是呼吸——胸口起伏、吸气憋住再吐。

**微表情时间链**（不是拼状态词，是演一遍）：
> 「眼神微微闪烁→长睫毛轻颤→迅速低下头→下唇微微咬紧→缓缓抬起头→三分娇羞一分俏皮的嗔怪」
自带抑制→释放的戏。每句台词前铺 2-3 个微表情动作，说完补 1 个余韵动作。

**禁大表情**：不写「露牙大笑」「哭出来」「瞪大眼睛」「张嘴惊讶」。
- 开心=嘴角轻扬+眼角微弯｜难过=下唇微抿+视线下移｜惊讶=眉毛微抬+吸气停顿｜委屈=嘴唇微颤+眼眶泛红

**真实感四原则**：不对称（偏一边的笑）｜延迟感（嘴先笑、眼慢半拍）｜肌肉残留（笑完嘴角还翘着）｜自然瑕疵（说完抿一下嘴）。

**台词嵌进行为链**：「她嘴唇轻启，柔声反问：那你还回来干嘛。」——台词是动作链最后一环，不是独立栏。说完补余韵。

**发声方式，不写情绪**：禁「温柔地说」「紧张地说」，改写声音大小+语速快慢+停顿位置+尾音变化。

**每个 [Shot] 写死三件**：表情 + 手部动作 + 手持物。留白=模型自创（历史事故：母亲自创手绢抹泪）。

**动作写因果链，不写状态词**：准备→触发→加速→主动作→接触→反应→恢复→终态。模型能演的是过程，不是标签。

**运镜写五要素**：机位 + 运动方式 + 方向 + 速度/幅度 + 跟随对象。缺一个，运镜就变成随机漂移。

**禁空词**：`cinematic`／`dynamic camera`／`cool VFX`／`电影感`／`高级感`——这些是愿望，不是指令，模型会自己乱发挥。

## 1.4 镜头与切点

**核心八字**：远取其势，近取其神。

**默认同镜内演进**：状态变化、情绪微变、小动作递进 → 不切镜，用连续动作 + 小幅慢速运镜（`Push In / Tracking Shot with small amplitude at slow speed`）推进。状态演进靠毫秒时间戳，不靠切镜。

**切镜必须有动机**（有其一才切）：情感时刻｜叙事跳变｜节奏卡点｜视线转移（正反打）｜景别/机位大变化有叙事意义。
**切镜景别差要够大**：全景↔中景、近景↔特写、正反打、侧↔正。**绝不同角度小幅推近**（Murch 蜜蜂巢：最迷惑的切法）。
**切点自检**：这个切给观众带来什么新信息/新情感？答不上来就不切。

**5-10 秒、单主体单动作 → 最多 2 个 `[Shot N]`**；多切可以，但要接受稳定性下降。
**单镜**（全片只有一个 [Shot 1]）→ 写死：`The camera stays locked in this single continuous shot throughout, no cuts.`
**切镜措辞**只用：`the camera cuts to` / `the shot transitions to` / `the shot switches to`。

**景别速查**：远景=孤独史诗｜全景=登场动作｜中景=对话互动（最常用）｜近景=内心情绪｜特写=情感爆发悬念｜大特写=极致强调。
**组接**：远→近=情绪高涨｜近→远=情绪下沉｜环行=先扬后抑。

## 1.5 占框与尺度稳定（治「人忽大忽小」）

- **占框写进 prompt**：每个 [Shot] 写主体占画面高度百分比 + 头顶留白（`the figure occupies about 30 percent of the frame height`、`comfortable headroom, eyes on the upper third`）。不写模型每次自己猜。
- **同场各镜从同一张标准帧衍生**，跨镜只改表情/手部/微动作，不换占框、不换机位。
- **镜头顺序先近后远更稳**（特写对位置误差最敏感，先把近景锁死）。
- **运镜量化写小**：「推近约 15% 画面宽 / 4 秒」，优先小幅慢速。
- **不写「居中」**（与画面自带空间线索冲突→抖）。
- **尺度连续性靠措辞钉住**：同一角色/道具全片用逐字相同的尺寸与位置写法，换词=漂移。
- **禁裁剪放大冒充景别**：中景裁成特写会透视崩，每个景别独立构图。
- **尺度对比镜（变小/巨物题材）**：每镜带**尺度锚**（巨手／巨物／家具腿／地毯纹理）与主体同框，巨物虚焦、主体清晰；机位贴地或贴物，不做大幅运镜；不用「小人与正常人并排」构图，用「人 vs 物」的尺度差表达；锚物措辞全片逐字一致。

## 1.6 方位锚点（凡哥铁律）

画面内方向一律以**主体自身方向**为参照：`the closed door directly before him`、`half a step behind him to his right`、`in front of her`。
**禁止**：`left of the frame`、`on the right side of the screen`、`at the left edge`。

## 1.7 参考图使用纪律

1. 每镜只传该镜出场的图：镜里没有母亲 → 不传母亲图。
2. 场景资产图（多空间宫格）可整张传，但 Subject 定义只写当镜那一个空间。
3. 故事板整张传，绑定写法见下条。
4. **顺序固定**：人物图 → 场景图 → 故事板图 → 道具图，与 `<Picture N>` 一一对应。
5. 四视图资产图、四格故事板都是成熟做法，**可以正常用**；分屏/双人事故的根因在提示词写法，不在参考图结构。

**故事板绑定（官方措辞，必写）**：
`<Picture 4> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order.`
- 只写「提供什么规划信息」，**永不写**「宫格/边框/第X格/从左到右」，不把格内容写进定义。
- `detailed_description` 里**绝不写**「构图对应 <Picture 4> 第一至第四格」这类映射（会诱发宫格渲染）。
- retention 标 `partially_preserved` - its viewpoint, subject placement and shot order are realized。

**禁转身（180° 翻转）**：一条 prompt 内只写一个朝向，只做小幅角度变化。背面镜 = 段落开始就写「已背对」，不拍转身过程。正面情绪+背面离开 = 拆两段（A 段正面到峰值，B 段开场即背面）。

## 1.8 官方语法 12 条（写的时候逐条对）

1. 六段全英文，仅 `<d>` 内中文。
2. 故事板 Picture 按官方措辞，永不描述格内容。
3. `detailed_description` 只在内容真正生效处引用 Picture。
4. 单镜显式声明 no cuts。
5. 切镜只在实质变化处，措辞固定三种。
6. 场景 Subject 单空间：「一镜一空间」，只写该镜实际出现的空间。
7. 每个 shot 写死表情+手部+手持物。
8. `detailed_description` 开篇 1-2 句风格句，然后才 [Shot 1]。
9. retention 官方格式，`- ` 后写保留内容。
10. 对白标签：身份/动作/语态在 `<d>` 外；`(Sx)` 稳定；不说话写死 lips closed。
11. ≤7000 字符，六段顺序固定。
12. 六个落项：①每图一个明确角色 ②模式/时长/画幅/时间线兼容 ③身份服装道具地点跨切镜一致 ④每句台词长度配该镜时长 ⑤音轨分类正确无多余 BGM ⑥帧锚点落在声明的 shot/时间上。

## 1.9 导演分段（AIMixer Director 连拍）

每组是**独立采样**，组间不留画面/状态上下文。

- 每组 `detailed_description` 开场**直接写出起始画面状态**：谁在哪、道具什么状态（纸已在手/在桌上/没有）、姿态、视线。**禁止**用「递纸后」「承接上一段」这类跨组承接语——模型会重演上一组的动作。
- 跨组连续性用**写出来的状态**表达，不用跨组动作序列。道具转移要么在一组内完成，要么下一组直接以「已转移」开场。
- 同组内动作匹配剪辑安全；**跨组不安全**，别把一个连续动作拆到两组。
- 4 组以上连拍：段与段默认设「状态跳点」，每段起始状态能独立成立。

**分给 Director 的六段**：
- 公共部分（自动前置到每组）：`subject_definitions` + `summary` + `retention_analysis`
- 每组部分：该段 `detailed_description` + `overall_soundscape` + `non_diegetic_music`
- 组内图片 Picture 编号接着公共槽继续（公共 1-3 → 组内从 4 起）；同槽上传覆盖公共内容。
- fl2v 段只写中段运动/运镜/转场，**不写**「保持首尾帧」的锁定语（插件自己会注入）。

# 第 2 步 · 自检（不写自检 = 没检查）

## 2.1 逐字扫描禁用词（搜到立刻改）

| 禁用 | 改成 |
|------|------|
| 说到XX时 / 当她说XX | 删掉——模型对不齐台词时间，只写动作 |
| 留出剪辑的自然收口 / 给后期留空间 | 删掉——模型不懂剪辑 |
| 确认构图 / 调整角度 / 确保 | 删掉——目的性词不需要 |
| 前置镜头 / 后置镜头 | 删掉 |
| 笑意收进眼睛里 | 眼角弯了弯 + 嘴巴松下来 |
| 下眼睑 | 下眼皮 |
| 跳了半拍 / 闪了一下 / 略过一丝 | 往下落了一下 / 往上抬了一下 |
| 准备动作（深吸、停顿片刻、整理情绪） | 删掉——直接开口 |
| 歪着头（持续） | 偏了一下立刻回来 |
| 嘴角偏在一边 | 嘴角翘起一个小小的弧度 |
| 紧接上一镜 / 余笑 / 同镜N | 删掉——每镜独立 |
| 肤色 / 肤质 / 皮肤光泽 / 面部暖光 | 删掉——参考图已定义 |
| 背景里的XX/XX/XX | 背景极简，细节越多幻觉越多 |
| 抽象情绪词（真诚/温柔/委屈…） | 拆成眼角/嘴角/视线/呼吸的具体动作 |

**模型不需要知道人物「为什么」做某件事，只需要知道做了什么。** 目的性词汇全删。

## 2.2 六段检查表

- [ ] 六段齐全、顺序对、字段名裸写
- [ ] 全英文（`<d>` 内中文除外）
- [ ] 每个 `<Subject N>` 点名了 `<Picture N>` 来源槽位
- [ ] 每条台词在 `<d>[Chinese] ` 内、`[Chinese]` 后有空格、句末有标点
- [ ] 每句台词字数 ÷ 语速 ≤ 该镜秒数
- [ ] 说话人 `(S1)/(S2)` 稳定，一镜一个主要说话人，不说话的写死
- [ ] 第 2 镜起都带 `At MM:SS.mmm`
- [ ] 单镜写了 no cuts
- [ ] 方位用主体自身方向
- [ ] 每个 [Shot] 有表情+手部+手持物
- [ ] 占框百分比 + 头顶留白写了
- [ ] ≤7000 字符
- [ ] 无禁用词、无抽象词

## 2.3 结尾必写

> **已自检：六段/台词/锚点/占框/禁用词 全过，无抽象词、无目的性词。**

不写=没查。

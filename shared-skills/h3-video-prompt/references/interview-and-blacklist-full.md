# 提示词采访流程

每次凡哥说"给我提示词""出分镜"时，**不直接写**。先过采访清单。

## 采访清单（逐项问，缺什么问什么）

| # | 我需要知道的 | 如果没给，这样问 |
|:---:|------|------|
| 1 | 台词/对白 | "这句台词完整版发我" |
| 2 | 参考图 | "有参考图吗？角色四视图、首帧图、场景图各几张？" |
| 3 | 模型 | "LTX 2.3 还是 Seedance 2.0？" |
| 4 | 时长 | "这个镜头给几秒？" |
| 5 | 情绪弧线 | "这段台词的情绪走向是怎样的？开头什么情绪→结尾什么情绪？" |
| 6 | 动作 | "有什么特定的动作要求吗？（对戳手指、歪头、后退等）" |
| 7 | 场景概括 | "这一镜的场景和内容概括一句？" |
| 8 | 对口型 | "对口型还是纯画面？" |
| 9 | 上一镜关系 | "和上一镜是什么关系？有什么衔接要求？" |
| 10 | 特殊要求 | "还有什么特殊要求？（音色、语速、光线等）" |

## 无人值守授权

凡哥明确说“放手干”“中途不要提问”“明天看成果”时，不再逐镜重复采访。执行方式：

1. 在开工前一次性列出范围、默认风格、画幅、模型、时长、声音方式、输出文件和关机等外部动作；
2. 等凡哥明确确认整套计划；
3. 确认后把缺失的低风险创作参数作为显式假设记录在总说明中，连续执行到底；
4. 中途只在权限、付费、密码、真实外部发布或数据丢失风险处停下；
5. 批量结果标为“第一版/待人工审阅”，不得把自动校验通过冒充导演质量定稿。

凡哥不在时，提问组件必须无限等待或改用普通消息；不因等待超时自行选择答案。

## 铁律

- 1-10全部拿到之前，不写任何一个字的提示词
- 凡哥说"没有""随便""你定"时，可以跳过该项
- 但1（台词）和3（模型）是必填，不给不能动笔
- 全部确认后——一句"齐了，开始写"——再输出

## 输出后逐字扫描

写完提示词后逐句扫原文，匹配以下任一模式立刻替换。不再做概念检查——直接搜禁用词。

### 禁用词库

| 禁用词 | 替换为 |
|------|------|
| 前置镜头/后置镜头（Pocket3） | 删掉 |
| 手机（设备写Pocket3时） | 全文统一Pocket3 |
| 笑意收进眼睛里 | 眼角弯了弯、嘴巴松下来 |
| 视线往下跳了半拍 | 视线往下落了一下，立刻抬起来 |
| 下眼睑 | 下眼皮 |
| 跳了半拍 / 闪了一下 / 略过一丝 | 往下落了一下 / 往上抬了一下 |
| 准备动作（深吸、停顿片刻、整理情绪） | 删掉——直接开口 |
| 不是/不会/不能/不要/别/没/无/非/否（LTX） | 全正向改写 |
| 说到XX时/当她说XX | LTX无法对齐台词时间，用纯动作描述 |
| 留出剪辑的自然收口/给后期留空间 | 删掉——模型不理解剪辑概念 |
| 确认构图/调整角度/确保 | 删掉——不需要目的性描述 |
| 歪着头/歪了歪头（持续） | 偏了一下立刻回来（瞬间动作） |
| 嘴角偏在一边 | 嘴角翘起一个小小的弧度 |
| 偶想 | 删掉——谐音不对，偶像从没说错过 |
| 背景里的XX/XX/XX | 背景极简描述，细节越多幻觉越多 |
| 确...[truncated]

写完提示词后，拿原文字逐句扫描，匹配到以下任一模式立刻替换：

### 禁用词库（搜到即换）

| 禁用词 | 替换为 |
|------|------|
| 前置镜头/后置镜头（Pocket3场景） | 删掉——Pocket3只有一颗镜头 |
| 手机（设备写Pocket3时） | 全文统一为Pocket3 |
| 笑意收进眼睛里 | 眼角弯了弯 + 嘴巴松下来 |
| 下眼睑 | 下眼皮 |
| 跳了半拍 / 闪了一下 / 略过一丝 | 往下落了一下 / 往上抬了一下 |
| 准备动作（深吸、停顿片刻、整理情绪） | 删掉——直接开口 |
| 不是/不会/不能/不要/别/没/无/非/否（LTX） | 全正向改写 |
| 紧接上一镜 / 余笑 / 同镜N | 删掉——每个镜头独立 |
| 肤色/肤质/皮肤光泽/面部暖光 | 删掉——参考图已定义 |

### 提示词铁律：只写画面里发生的事

| ❌ 禁止 | 原因 |
|------|------|
| 说到XX时/当她说XX | LTX无法把台词内容和动作时间点对齐——只能理解秒数 |
| 留出剪辑的自然收口 | 模型不理解剪辑概念 |
| 给后期留空间/方便剪辑 | 同上 |
| 确认构图/调整角度/确保 | 目的性词汇，模型不需要知道为什么 |
| 前置镜头/后置镜头 | Pocket3没有这个功能 |

提示词=画面描述。不是导演笔记，不是剪辑备忘录。除了画面里能看到的，一个字不要多。

| ❌ 禁止 | ✅ 改写 |
|------|------|
| 低头看了一眼屏幕确认构图 | 低头看了一下 |
| 她调整角度让自己在画面中间 | 脸一直保持在画面中间 |
| 深吸一口气让自己平静 | 删掉 |
| 停顿片刻让这句话更有分量 | 删掉 |

模型不需要知道人物"为什么"做某件事——只需要知道做了什么。所有"为了/确认/调整/确保"等目的性词语全部删掉，只留动作本身。

| 抽象词 | 拆成 |
|------|------|
| 真诚 / 温柔 / 温暖 | 眼角弯了弯 + 嘴角翘起来 |
| 自嘲 | 视线往下落了一下立刻抬回来 + 嘴角偏一边 |
| 兴奋 | 声音上扬 + 嘴角翘起 + 身体前倾 |
| 娇羞 | 声音偏轻 + 嘴角偏一边 + 视线落了一下 |
| 自信 | 语速加快 + 头抬正 + 眼睛不闪 |

### 物理矛盾扫描

- Pocket3写了几次？有没有中途变手机？
- 镜1有没有首帧图？（镜1没有上一镜）
- 场景描述是四视图还是单图？描述匹配吗？

### 结尾必写

**已自检：[实际扫描条数]/[扫描条数]，无禁用词，无抽象词，无拟型词，无设备矛盾。**

不写 = 没检查。
## 踩坑记录（每次犯错追加）

- 脑补避坑词：偶像从没说错过→不要替换。避坑词库只记录实测错误
- 设备矛盾：上面写Pocket3下面写手机 → 全文统一
- 镜1写了参考图2（首帧图）→ 镜1没有上一镜，无首帧图
- 声调随便换：ǒu xiǎng≠ǒu xiàng → 替换必须同声调
- 嫁祸错词：虚拟说错却去换偶像 → 哪个词错了换哪个

## 输出格式规则（凡哥最新要求）

| 规则 | 说明 |
|------|------|
| 台词引入 | `齐白兰说：{...}` / `Qi Bailan speaks: {...}` |
| 声线 | 不包裹括号，直接写 |
| LTX禁词 | 禁用"台词""spoken dialogue"，用"说的话""speaks"替代 |
| 结尾 | 说完后气息收口+笑容延续+留剪辑空间 |
| 时长 | 统一15秒 |

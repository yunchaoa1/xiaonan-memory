# 演绎式情感视频 · 可复用做法

> 来源：2026-11-22《偏心》制作实录。凡哥要求"演绎不是读白、所有语言只作台词"。
> 本文只记**实测跑通的做法和踩过的坑**，不写未验证的东西。

---

## 一、配音（edge-tts，双声道）

两个角色要两个声音，且**语速要压慢**（情感戏不能念得像播报）：

| 角色 | 音色 | 参数 |
|---|---|---|
| 女性当事人（三十多岁、克制、疲惫） | `zh-CN-XiaoxiaoNeural` | `rate='-10%'` |
| 男性咨询师（四十多、稳） | `zh-CN-YunjianNeural` | `rate='-8%'` |

- `zh-CN-XiaohanNeural` **不存在** → 报 `NoAudioReceived`，别试。
- 其他候选：`XiaoyiNeural`（年轻女）、`YunyangNeural`（播音腔，太正式）、`YunxiNeural`（年轻男，不适合咨询师）。
- 逐句生成（一句一个 mp3），不要整段合成——后面卡画面要用每句的实际时长。

## 二、语速标定（决定镜头数，不能拍脑袋）

**实测：562 字台词 / 152 秒纯说话 ≈ 3.7 字/秒**（rate 压 −8~−10% 的条件下）。

```
某句需要几秒 = 该句字数 ÷ 3.7
镜头总长 = 台词秒数 + 停顿（对话之间 0.8–1.5 秒；沉默戏可到 5 秒）
```

**先算再拆镜头。** 2026-11-22 就是因为没算，按"每颗 10 秒"拍脑袋拆了 20 颗 → 只能装 36 句，剩下 13 句（全片最狠那段）没地方放，白跑 2 小时。

## 三、一镜一主节拍（H3 的硬约束）

- H3 有效动作窗口约 **5–7 秒**；**一颗塞 9–10 秒，动作在前 2–3 秒就做完，后面退化成"会动的照片"**。
- 技能原文对照实验：一颗 7 秒塞 9 个节拍 → 脸完全没动（42 dB≈冻住）；拆成三颗 2–3 秒 → 表情全到位（23 dB）。
- **正解：2–3 秒一个主节拍；一颗生成里放 3–4 段（总 15 秒）**，是精度与成本的平衡点。
- 换算：180 秒 ≈ 60 个 3 秒镜头 ≈ 14–18 顆生成（不是 20 顆 10 秒）。
- 一顆生成要写清**剪接结构**：剪几次、每次在几秒、最后一格是谁。

## 四、合成：卡配音时间轴，不够就定格

- 按配音时间轴排画面，**哪颗不够长就用"定格最后一帧"补**。
- **不要用慢放补时长**——慢放会破坏动作节奏，看起来像卡带。
- ffmpeg 只认 Windows 路径（`D:/...`），`/d/...` 会让 cv2/ffmpeg 静默失败。

## 五、字幕三层颜色

| 说话人 | 颜色 | 说明 |
|---|---|---|
| 当事人 | 灰 | 弱化，代表"她说出口的" |
| 咨询师 / 旁述 | 白 | 主叙述线 |
| 关键句 | 暖金 + 字号加大 | 全片 3–4 处，砸下来的那几句 |

**换行按语义断，不按字数硬切**，且**标点不许落行首**：

```python
# D:/Hermes/cache/emotion/wraplib.py 的 wrap_smart(text, maxlen)
# 1) 先在逗号/句号处切块  2) 行首若是标点，把它移到上一行末尾
PUNCT = "，。：；！？、）】」》"
```

反面：硬切会把"是什么时候"切成"是什 / 么时候"，一眼就破功。

## 六、清理（每次交付后）

```bash
python D:/Hermes/scripts/cleanup_workspace.py        # 只看
python D:/Hermes/scripts/cleanup_workspace.py --go   # 真删
```

删：废片、检查帧（`*_a.jpg` / `*_85.jpg`）、`ComfyUI/output/minimax_seg_cache`、`__pycache__`、一次性脚本。
留：成片、场景素材图、配音、台词稿、分镜稿、可复用脚本。
`minimax_seg_cache` 被 ComfyUI 占用时删不掉 → 先跳过多删里面的子目录，重启后补删。

## 七、别用"意象"代替"演绎"（本片最大返工原因）

v3 幻灯片版和第一版剪影动画都用了一堆意象画面（空椅子、水杯、裂缝、行李箱），凡哥一句「文案和画面毫无关系」全否。

**意象 = 用来表达情绪的替代物；演绎 = 把台词说的事直接演出来。** 情感类内容他要的是后者。

判断口诀：**这句台词如果拍成一场戏，摄影机对着谁、他正在做什么？** 答得出来就拍那个；答不出来说明这句是旁白，回去改台词。

## 为什么需要这条

纯极简单色几何方向被连续否决（凡哥原话：「太土」「太简单了，没有设计感高级感」）。
根因不是执行差，是**方向错**：2026 的设计语境里，"扁平极简、彼此长得一样"正是被淘汰的那一端。

## 研究依据（已核实，可直接引用）

- **抖音 logo 手法的正式名称：故障艺术（Glitch Art）的「错位」**。颜色：青 `#25F4EE` + 洋红 `#FE2C55` + 黑白底，**三层错位叠印**。符号是「音符」/「d」形，但并非传统音乐符号，而是**从名字「音」简化来的创意字形**——关键不只是极简，是**符号与名字的强绑定**。
- **LogoLounge 2026 趋势报告**（统计 3 万+ 标志）：
  - 年度第 1 趋势「V Balls」：由举臂/V 形围成的圆形 = 人群、团结、共享能量，**「转起来就是 community in motion」** → 社区/平台类品牌可直接套用。
  - 对 2026 的判断：**对过去十年「扁平极简、彼此长得一样」的反动**。原话：brands want to be **remembered**, not just legible。
- 结论：**强符号 > 抽象几何**；**色彩层次是"活力/年轻/时尚"感的主要来源**；单色极简只适合做兜底版，不适合当品牌主视觉。

## 可复用构造（viewBox `0 0 100 100`）

1. **一个字形基底**：把「一根羽枝 / 一个楔形」定义为一条**带弧度的粗路径**（`M … Q … L …`，`stroke-linejoin="round"` + `stroke-linecap="round"`），stroke-width 取 8–10 中一个值。生硬直线（`L`）会读成箭头，加一点 `Q` 弧度才读成羽翼。
2. **围合环**：把该基底用 `<g transform="rotate(θ 50 50)">` 复制 N 份（**N = 3 / 4 / 5**，θ 均分；`rot_offset = -90` 让一份正朝上，观感更"在动"）。
3. **错位叠印**：先画**错位色的一整组**（`transform="translate(5 -4)"`），再把**主色的一组压在上面**。**偏移 5 单位最佳**——3 太含蓄看不见，>7 显脏。
4. **单色兜底版**：同构造去掉错位层，只留主色组。印刷 / favicon / 极小程序图标都用它。
5. 深色底（约 `#0d1526`）是这类手法的最佳舞台，交付页务必带深底预览。
6. 实测协调的双色（海蓝系）：主色 `#0052d9` + 亮青 `#12E2FF`。

## AI 稿 → 精确品牌色 + 真透明（白底纯色稿的精确解）

```python
# alpha = 255 - min(R,G,B)：白底抗锯齿边缘天然正确，比"白底去背/抠图"干净得多
a = 255 - np.minimum(np.minimum(r, g), b)
# 再把像素整体填成目标品牌色 → 「精确品牌色 + 真透明」的 PNG
```

**双色稿**保留原始 RGB、只用该式求 alpha，不要强行单色化（会把错位色吃掉）。

## 渲染与自查（本机实测可用）

- SVG→PNG：`pip install resvg-py` → `resvg_py.svg_to_bytes(svg_string=..., width=1024)`。本机 cairosvg 缺 `libcairo-2.dll` 用不了，resvg-py 是无原生依赖的单文件渲染器。
- HTML 对比页自查：`chrome --headless=new --disable-gpu --hide-scrollbars --window-size=W,H --screenshot=out.png "file:///…"`（路径必须 percent-encode，中文目录尤其）。
- **每个稿子先用 vision 自己看一遍再交付**（拼成一张 contact sheet 一次看完，带 16/32/64px 小样）。实战中靠这一步抓到的缺陷：中心点偏心、错位量小到看不见、三翼散架、负空间尖角。
- **坑**：路径数据没包进 `<path d="…">` → resvg **静默忽略**，整个图案消失、只剩中心点，看起来像"渲染器坏了"。**先看生成的 markup，再怀疑渲染器。**

# 现代短剧：隐藏身份、窃稿与感情线的因果编排

适用于校园、豪门寻亲、真假身份、作品盗用等多线并行的现代AI短剧。重点不是堆反转，而是控制每个角色在每个时点“知道什么、不知道什么”。

## 一、先画信息差，不先排集数

至少列出四类信息：

| 角色 | 已知 | 未知 | 因此会做什么 |
|------|------|------|--------------|
| 男主 | 曾无意听过关键物件故事；见过女主原创思路 | 未见过实物；不知道女主身份 | 先查原创者，后查身份 |
| 女二 | 女主能力强；男主关注女主作品 | 不知道男主早见过原稿；不知道女主真实身份 | 为邀功窃稿，客观阻断认亲 |
| 女主 | 关键物件是爷爷所赠；养母一直爱她 | 不知道自己被收养 | 把异常记忆当作幼年模糊，不主动寻亲 |
| 养母 | 孩子来历、关键物件、寻亲者身份 | 不确定真相何时暴露 | 因害怕失去而持续隐瞒 |

每次新增反转前先问：这个角色凭什么知道？如果答案是“剧情需要”，就必须重写。

## 二、三条线必须分开

### 1. 作品线

原创思路出现 → 男主先看到作品但尚未认识作者 → 女二不知情窃稿 → 作者署名被抹掉 → 原本进入长辈视野的机会被截断 → 数月后女二无法解释创作逻辑 → 男主与长辈追查真正作者。

### 2. 实物线

关键实物始终私藏 → 不因比赛公开展示 → 通过独立事件偶然出现（例如旧底托维修、鉴定、保养） → 男主把“过去听到的故事、早先见过的设计、眼前实物”连成一线。

### 3. 身份线

实物只能形成高度怀疑 → 再查时间、地点、养母经历 → 当事人正面会面 → 正式检测闭环。设计比赛和实物都不能单独完成认亲。

## 三、“弄巧成拙”必须有信息差

女二窃稿的主观动机可以是：

- 博取男主好感；
- 获得长辈认可；
- 压制专业竞争者；
- 维护大小姐光环。

但她必须不知道：

- 男主已经看过原始思路；
- 设计与失踪者身份有关；
- 女主持有对应实物。

正确结果不是立即公开打脸，而是：

> 女二暂时得利 → 数月后被深度追问 → 无法解释 → 引起原创怀疑 → 男主反向寻找被掩盖的作者。

这样“窃稿”既客观阻断认亲，又成为后续调查的反向线索。

## 四、身份差距决定接触方式

当男主身份显赫、女主认为高攀不起，前期禁止轻易成为朋友：

- 女主不主动接近；
- 只保留赛事、学生会、调查等职责性接触；
- 男主先关注作品，再认识作者；
- 女主把他的关注理解为公事；
- 男主尊重边界，不用权势强行帮助；
- 感情成立必须晚于专业欣赏，且早于身份确认。

关键证明句式：

> “我第一次记住的是你的作品。那时我还不知道你是谁。”

这能切断“因为童年身份才喜欢”的误解。

## 五、被收养者的认知边界

如果女主坚信养母是亲生母亲：

- 只能有模糊、碎片化的幼年违和感；
- 她会把违和归因于记忆混乱，而不是主动怀疑收养；
- 不得让她轻易说出“我是在海边被捡到的”；
- 身份调查必须由外部证据进入；
- 真相揭开后，养母的爱与隐瞒要同时成立；
- 养母不是纯恶人，但必须承担剥夺知情权造成的信任破裂。

## 六、幕后设定不等于必须写进正文

后台需要知道关键物件为何保存、谁从何时知情；正文只写有戏剧功能的部分。

凡哥明确删除的典型冗余：

- 不必特意解释“首饰过大所以没有佩戴”；
- 只需交代长辈送过独特护身符、孩子记得来源、男主曾无意听过故事；
- 不为证明设定完整而加入无推动作用的解释台词。

## 七、30集排布参考

1—3集：灾难与失散；
4集：男主无意听到物件故事；
5—7集：最后名额、先见设计、后见作者；
8—12集：女二嫉妒、窃稿、暂时得利；
13—15集：数月后长辈看到冒名作品，延迟反噬；
16—18集：独立事件让实物出现；
19—24集：时间地点、养母经历、旧资料逐步闭合；
25—27集：原创归属与养母真相；
28—30集：正式检测、成年感情、反派伏笔。

## 八、交付前自检

- [ ] 男主是否先见作品、后见作者？
- [ ] 女主是否因身份差距保持距离？
- [ ] 女二是否不知道男主已见原稿？
- [ ] 女二窃稿动机是否与认亲无关？
- [ ] 设计稿与实物是否通过两个独立事件出现？
- [ ] “弄巧成拙”是否只启动调查，而非立即认亲？
- [ ] 女主是否仍坚信养母是亲生母亲？
- [ ] 养母是否一直知道实物，但隐瞒的是身份？
- [ ] 身份是否由时间、地点、实物和正式检测共同闭环？
- [ ] 是否删除了只为解释后台设定而存在的台词？

# 图像/视频提示词经验总结（2026-07-24更新）

## z-image Turbo
- **中文语义**，不是英文。凡哥纠正过。
- 纯正向描述，不用否定词。
- 极简环境：比如"只写麦克风和座椅，纯黑背景墙"
- 结尾标注比例 + `No characters`

## Qwen 2511 参考图融合（人物+场景）
图1=人物参考图，图2=场景参考图，中文提示词。

### 去AI化三条
1. **肤质**：止于`肤色均匀自然`、`轻微柔焦质感`。不加毛孔/斑点→会满脸斑
2. **灯光**：只写光照在皮肤的效果（`柔和明暗过渡`），不写光源形态（光束/光柱/一束光）
3. **风格**：加`真实胶片人像摄影风格`抵消CG塑料感。不加`手机自拍`等设备描述——那是LTX视频用的

### 表情与情绪
- 必须对应当前歌曲/场景情感基调
- 分手情歌≠幸福→`眼神放空、平静中的无力感`
- 不要写`侧身`等身体朝向——删掉

### 过渲染→删光描述
出图太假时把光线词全删，只留`面部肤色均匀自然`

### 妆造
- `韩式偶像舞台妆，清透底妆搭配自然眼妆和水光唇色`
- 不写具体化妆品品牌/步骤

### 耳机术语
录音棚戴的是**监听耳机**（无麦），不是带麦克风的耳麦。

## LTX音频驱动视频（对口型）
- 禁止 text/subtitle/caption/letter/word/lyrics/character/speech bubble 等任何文本词汇→会生成乱码字幕
- 台词用`{中文歌词}`包裹嵌入动作描述
- 格式：`双唇随歌声轻轻张合，{歌词第一句} {歌词第二句}`

## LTX 多图参考（2026-07-24新增）
- **提示词里不要写"图1/图2"**：AI不理解为指令，会当成画面内容随机插入视频
- 参考图通过节点（LiconMSR / MultiImageLoader）传入，不通过提示词描述
- 提示词只描述最终合成画面，不提及参考图的存在

## Licon MSR V2 工作流（2026-07-24新增）
- 来源：`LiconStudio/LTX-2.3-Multiple-Subject-Reference`
- 工作流文件：`LTX-2.3_MSR_sample_workflow_V2.json`（仓库自带）
- LoRA：`LTX-2.3-Licon-MSR-V2.safetensors`（654MB）
- 需要插件：`ComfyUI-Licon-MSR`
- 特点：38节点，含LiconMSR多参考图融合 + 9个音频节点（音频驱动）
- ⚠️ 不要和WhatDreamsCost的工作流搞混——那是首尾帧插值，不是多参考图融合

## 通用铁律
- **纯正向，禁否定词**：不/别/没/无/非/否全部禁止
- **不过度描写**：写到就行，堆砌同义词适得其反
- **不确定的事情先问**：不要猜着执行

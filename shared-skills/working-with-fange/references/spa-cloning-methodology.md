# SPA网站1:1复刻方法

当需要复刻JS渲染的单页应用时，用以下方法逐页还原：

## 发现路由
从HTML源码中提取主JS bundle路径 → 下载bundle → 搜索路由模式：
```bash
curl -sL "https://site.com" | grep -oP 'src="([^"]+\.js)"'
curl -sL "https://site.com/assets/main-xxx.js" | grep -oP '"/([a-z][a-z0-9/-]*)"' | sort -u
```
过滤API/auth/payment路由，剩下的就是页面路由。

## 逐页还原
每页需要凡哥提供两份材料：
1. 页面全屏截图（看布局/配色/间距/交互元素）
2. 网页源代码（右键"查看网页源代码"）

对照两份材料逐页重写HTML——不是凭记忆脑补。

## 弹窗处理
原站SPA的弹窗/模态框可能是独立路由也可能是页面内组件。先截图确认——如果弹窗覆盖在原页面背景上，就是页面内弹窗，不需要独立HTML文件。

## 避免的错误
- 不要批量改名后忘记更新所有内部链接
- 不要用正则批量插入onclick导致转义字符损坏
- 每次改动后先检查链接完整性再继续

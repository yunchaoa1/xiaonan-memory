# 品牌标志系统的交付形态与落地参数

来源：2026-09-11 天使OPC数字社区标志实战（第 4–6 轮：解绑 → 成品交付 → 方案光谱）。
配套：`references/logo-vitality-glitch-recipe.md`（活力/记忆点方向的具体构造）。

## 一、什么时候用这份

- 凡哥要「logo / 品牌标志」，而他对方向没概念、说不清「差什么」时。
- **只给一个「图标」永远解决不了「凸显特点」** —— 因为承载特点的器官是字标，不是符号。

## 二、三层交付形态（复杂度递增）

| 档 | 内容 | 用途 | 缺什么 |
|:--:|---|---|---|
| 档1 | 仅图标：单色 / 双色浅底 / 双色深底 | favicon、极简场景 | 说不了业务 |
| 档2 | 图标 + **字标锁标**（横版，深底 + 浅底两版） | 品牌正式形态 | 没有 App 落地件 |
| 档3 | 完整品牌板：锁标 + App图标（蓝底/深底/白底）+ 竖版锁标 + 色板 + 留白规范 | 直接交设计/开发 | — |

凡哥没概念时 → **N 个符号方向 × 3 档复杂度** 一页对照，让他横向比符号、纵向比信息量（见 SKILL.md 规则 7）。

## 三、锁标排版参数（PIL 合成，实测）
- 符号显示高度 H；主字（如「天使OPC」）≈ **0.46H**（H=210 → 96px）；副字（如「数字社区」）≈ **0.20H**（42px）。
- 副标按**逐字绘制**加字距（track ≈ 0.22em），比整体拉伸好看。
- ⚠️ **符号必须压得住**：初版把主字放到 116px → 符号被压成配角，一眼就看得出。**符号当主角、字标当解释**才是品牌锁标。
- 两行文字块相对符号**光学垂直居中**；行距 ≈ 0.15 主字号。
- 字标起步用现成字体排版（**参考排版**），交付时必须**明确标注「非最终中文字形设计稿」** —— 最终版才做字形设计。

## 四、光学居中归一化（偏心一眼会被看出）
双色错位叠印会让**并集重心偏移**（本次 C6 偏了 **10.55 单位**）。做法：
1. 渲染 SVG → 取 alpha 非透明包围盒
2. 反算 viewBox 单位平移量（`dx = 50 - cx/scale`）
3. 用 `<g transform="translate(dx dy)">` 包住内容后重新渲染
比手工目测靠谱且可复现。

## 五、小尺寸落地（favicon / App icon）
- **16px 必须用「色块底 + 标」形态**，纯细线标在 16px 直接消失。
- 色块内标占比 **≈ 0.78**（实测：0.62 时 16px 几乎看不见，改 0.78 后清晰）。圆角方 `rx ≈ 22.5%`（App 图标形态）。
- `.ico` 一次出多档：`img.save("favicon.ico", sizes=[(16,16),(32,32),(48,48),(64,64)])`。
- 尺寸套件：App 图标 1024 / 512 / 192 / 180 / 152 / 120；favicon 16 / 32 / 48 / 64 / 128；社媒头像 1024 / 512。

## 六、中文标准字可用字体（本机已装）
- 思源黑体：`Noto Sans SC Bold / Medium (TrueType).otf`（科技、通用）
- 思源宋体：`Source Han Serif SC Heavy (TrueType).ttf`（高质感、庄重）
- 微软雅黑：`msyh.ttc` / `msyhbd.ttc` / `msyhl.ttc`
SVG 内中文务必显式写 `font-family`，否则渲染成豆腐块。

## 七、交付包目录结构（凡哥资产规范）
```
D:\数字资产\图片资产\logo-<品牌名>\final\<方案名>\
├── mark\      主标三态：双色 / 单色 / 反白（SVG + PNG 256/512/1024）
├── appicon\   蓝底 / 深底 / 白底 × 6 档尺寸（SVG + PNG）
├── favicon\   favicon.ico（多档）+ .svg + 各档 PNG
└── social\    社媒头像（深底 / 白底）
+ 同级放 `使用规范.md`（色彩 / 留白 / 最小尺寸 / 错误用法）与 `交付总览.html`
```
- **留白规范**：四周 ≥ 标志高度的 **25%**。
- **最小尺寸**：双色标 ≥ 32px；< 32px 一律切色块版。
- 跨轮次的过程稿进 `_archive_<轮次>\`，别把废稿混在成品目录里（凡哥会问「logo 输出在哪里」）。

## 八、AI 稿只当草图
- 出「双色错位」必须在 prompt 里**显式写两个 hex + `chromatic-offset glitch print effect`**，否则模型只给单色。
- AI 稿**不能直接交付**：形体糊、非矢量、色值不准。正解 = 用 AI 稿定概念 → **矢量重画**。
- 转「精确品牌色 + 真透明」：`alpha = 255 - min(R,G,B)`（双色稿只求 alpha、保留原 RGB，别强行单色化）。

## 九、交付前自查
- [ ] 每个稿都拼版用 vision 看过（含 16/32/64px 小样）
- [ ] 遮住品牌名只看符号：①一眼记住？②一句话说得出是什么？
- [ ] 双色并集**光学居中**
- [ ] 16px 用色块版且看得清
- [ ] 锁标里**符号是主角**、字标是解释
- [ ] 单色版 + 反白版齐备
- [ ] 标注清楚哪些是参考排版 / 草图，不把未定稿当定稿交付

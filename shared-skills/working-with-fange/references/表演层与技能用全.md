## 一、先分清两种失败（治法完全不同）

| 失败 | 表现 | 治法 |
|---|---|---|
| **选错技能** | 拿了一个不对口的当主力 | 先 `find_skill.py` 检索，读 `description` 第一句，**不许按名字猜**（详见 SKILL.md §为什么有技能你不用） |
| **选对了、跳步** ← 本次 | 技能对了、`SKILL.md` 也读了，但它指向的 `references` / `checklist` / `gates` 没走 | **本文第二节的六步协议** |

**凡「技能明明装着却还是做坏了」，先按第二种查。**

## 二、技能怎么才算「用全」——六步协议

规范依据：**Anthropic Agent Skills 渐进式披露**。技能是三级加载——`description`（永远在）→ `SKILL.md`（判断相关才读全文）→ `references`/`scripts`（**按需读；脚本是跑的不是读的**）。

**「按需」不等于「凭感觉挑」**：`SKILL.md` 里每条铁律都指名了具体文件，**指路权归它，不归我的判断**。

```
① SKILL.md 读全文
② 把「详见 references/xxx.md」每一条列成清单 → 照单读
③ 有 checklist.md / gates.md 的，逐项打勾（执行关，不是参考资料）
④ 跑 scripts/，FAIL 清零
⑤ checklist 里机检列标「—」的项，人眼逐条过
⑥ 全绿才动笔 / 才提交
```

**第 ②步最容易跳过**：你以为「这次要解决的只有 A」，把 B 跳了，而 B 才是决定成败的那份。

**第 ⑤步是最后一道闸**：技能作者标 `—`，就是他明知机器管不到、必须人看的地方。

## 三、表演层：机器抓不到「缺席」

**这是机检的根本盲区**：`h3_lint.py` 能抓「你写了『紧张』这种结论词」（H13），**抓不到「你什么都没写」**。机器查的是**污染**，查不出**空缺**。

### 量化复核（200 秒成片，ASR + 文本扫描实测）

```
四区动作：眉 0 次 · 眼睑 0 次 · 唇 1 次 · 喉 0 次 · 吞咽 1 次
语调描述：says in a low flat voice  ×11   ← flat = 平，自己写进去的
停顿：96% 的句子间隔 <0.3 秒；最长 1.1 秒；3 秒以上停顿 0 次
```

**「脸不动 + 一个调到底」就是这么来的**：两百秒里她的眉毛一次没抬、眼皮一次没收，声音从头到尾标着「低、平」。

### 四条改法（答案本来就在技能里）

**1. 情绪落成四区肌肉，不写结论词**
眉／眼／口／颌，每区写**看得见在动的动作**（`her brows pull together` / `the inner ends of her brows lift` / `her lids hang low` / `her lips press into a thin line` / `the skin of her chin creases`）。
幅度用**可见计数**（「嘴唇分开一指宽」「下巴起皱」），不用「微微／非常」。
→ 配方表在 `forest-laoli-h3/references/acting-facs.md` + `acting-recipes.md`（30 种情绪，可直接抄）。

**2. 转折要三拍拆开，中间插一个静止镜**
> 第 1 拍压住 → 第 2 拍错位（假的那面裂开）→ **中间 1–2 秒只写呼吸与眼神的静止镜** → 第 3 拍释放

**「哭得突然」就是缺中间那一下。** 没有静止镜，情绪是跳过去的，不是裂开的。→ `acting-recipes.md §四`

**3. 标点是呼吸表，不是语法**
`.。` 说完不立刻收表情，留一拍；`……` 气断在喉咙、话没说完就停；`，` 半口气。
**本次台词里那么多「……」和句号，一个都没翻成身体动作，全是连着念完 —— 这就是「节奏一直不变」的直接原因。** → `acting-listen.md §四`

**4. 声音按情绪分段写，不许全片一个串**
`low flat voice` 是**我自己写死的**，技能从没这么要求。技能只说：**同段同性别多开口者要反着写**（一低冷慢／一高亮快）。
正确做法：按段落情绪分档——平静段、动摇段、硬撑段、绷不住段，各用不同语调描述。

### 补检脚本

```bash
python D:\Hermes\scripts\acting_check.py --all
```

报三类：**某段四区动作 0–1 区（红）** / **语调重复 3 次以上（红）** / **台词有省略号但镜行没有对应呼吸动作（黄）**。
拿它跑本次那 20 段：**红 22 · 黄 7**，问题全中。

## 四、两条元规则

**1. 想改进流程，先查规范，别自己发明。**
本次插曲：发现漏读后，第一反应是「那就 20 万字一次全读」，`skill_full.py --read` 都写好了。凡哥一句「**你太武断了，去查查 agent 该如何正确调用 skill**」——查完发现**全读恰恰违背渐进式披露**。
→ **遇到「怎么用才规范」的问题，先读官方文档，不要用工程直觉盖过去。**

**2. 技能装好了 ≠ 用上了。**
`forest-laoli-h3` 从 11-18 就装在本地，11-19 还用它跑通过一条成片；12-19 重跑却全程绕开它。
**「有没有这个能力」和「有没有走这个能力」是两件事，验收只看后者。**

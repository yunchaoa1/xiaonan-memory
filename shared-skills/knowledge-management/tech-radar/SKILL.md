# 技术雷达 · 学过的项目到点提醒

**用途**：凡哥看过/学过的工具、开源项目、方法，都存在这里。**不是记流水账，是记"他干哪件事时我该开口"。**

**什么时候加载**：凡哥说"用什么工具""有没有更好的办法""这个怎么做""记得之前那个吗"；或正在写内容、做短剧、批量改文件、算成本、查资料；或问"我们学过哪些东西"。

## 使用规则（给未来的自己）

1. **凡哥开始干一具体活时，先扫本表"触发场景"列**，命中就主动说一句：
   > "这个你之前看过 —— XXX，当时的结论是 YYY。要不要用？"
2. **主动提，不等他问**。他记不住，就是因为他不该记 —— 这是我的活。
3. **别把"路过"的项目也端上来**。表里标 ❌ 的，除非他明确提，否则不提。
4. **凡哥问"我们学过什么"** → 直接按下面三档念给他听。

## 四、筛新项目的三个问题（凡哥丢链接来，先过这三关）

1. **它解决谁的问题？** 解决开发者 → 路过；解决使用者 → 可看
2. **我有没有那个条件？** 要 80G 显存/要写代码/要买服务器 → 路过；有浏览器就能用 → 可试
3. **不做会怎样？** 没影响 → 路过；会错过赚钱机会 → 认真看

## 五、凡哥问"我们学过什么"时的答法

**按三档念**：⭐ 值得动手的（7 个）、✅ 已落地的（5 个）、❌ 路过的（5 个）。

**一句话总纲**：
> 值得动手的都在"内容/短剧/效率"三条线上；路过的全是"训练模型/平台工程"那一类 —— **他缺的不是工具，是把第一条内容发出去。**

# 凡哥 · 个人形象顾问（穿搭 / 选品 / 护肤）

> 起因：2026-10-15 凡哥说「以后买护肤品、买衣服都想先问你」，10-20 重启这条线。
> 定位：**不是时尚号，是替他把住"该不该买、买哪个号"这一关的人。**

## When to Use（何时加载）

- 凡哥说「买衣服 / 选品 / 这裤子行不行 / 这个链接值不值 / 我穿这个怎么样」
- 「帮我看看这博主说得对不对」「穿搭 / 配色 / 面料 / 版型 / 尺码」
- 「护肤品买什么」「脸怎么弄」「防晒」
- 要帮他**学穿搭博主**、提炼方法论时

## 铁律（第一条最容易犯）

1. **不猜他的身体数据。** 肤色、尺码、预算没给就是没给 —— 走 `凡哥-待了解清单.md`，**一次只问一条**。
2. **瘦高型博主的技巧，对微胖会反向失效。** 例：塞衣角瘦人显精神，他会把肚子顶出来。学任何方法先核对博主身材，差太远直接打折。
3. **卖货博主只取"公式"，不取"单品"。** 主页写"同款看橱窗/收藏"的，推荐带佣金，公式和避雷才是干净的部分。
4. **结论必须是"买 / 不买 / 换这个"**，不许给他一堆选项让他自己挑。
5. **转写/资料里的同音错词标"待确认"，不替他编圆。**（如"缩质面料"疑为"挺括面料"）

## 能直接用的公式（侃哥 2026-10-20 转写，已在纸质记录核对）

- **长裤长** = 身高 × 0.575，上下浮动 1 cm → 他 **98–100 cm**
  笨办法：光脚站直，量地面到胯骨最高点
- **短裤**：身高 × 0.285 = 五分裤长（他 **49 cm**）；+5~6 cm = 六分（54–55）；−5~6 = 四分（43–44）
- **腿围** = 净腿围 + 5~6 cm（太紧=精神小伙，太松=显矮）
- 买裤子**只看腰围是错的**，裤长和腿围同样定生死

## 微胖夏天四条（他身材对口，可直接用）

1. **上深下浅** → 拉长身形、调比例
2. **内浅外深** → 敞开穿，视觉把肚子切开（修腰）
3. **别太修身，也别 oversize —— 合身最重要**
4. **面料别软塌贴身**，要有骨架

**反常识一条**：胖子不是不能穿落肩。落肩穿得好是"胖变壮"；反倒是正肩版型偏修身，会把肉顶出来。前提：**落肩 ≠ oversize**，肩线下来但整体合身。

**避雷**（他的原话整理）：过短的六七分裤、修身衣、跨栏背心/大领口、亮丽膨胀色、不理发。
**短裤避雷**：化纤薄料、反光面料、连体款、极短、饱和度高的颜色。

## 落地时最容易漏的一问

**衣服谁洗、熨不熨。** 挺括面料显瘦，但要熨；没人熨，皱巴巴比软塌更难看。不问清这个，推荐等于白推。

## 博主学习法（要新素材时）

1. 抓取走 `camoufox-antidetect` 的「小红书全链路」：慢速 25–40 秒 → 卡片 token → 视频直链 → ffmpeg + large-v3 转写（60 秒视频 27 秒转完）
2. **筛人先看身材**，再看讲不讲逻辑；大众词（"男士穿搭"）混进大量女装号和清仓店，**细分词（"胖男生穿搭"/"大码男装"）更对口**
3. 转写完必须**过一遍同音错词**再入库
4. 提炼格式：**公式 / 避雷 / 反常识 / 存疑** 四块，别整篇复述

## 边界（诚实说）

- 服装的**视觉判断**（这件穿上好不好看）只能靠照片或真人，**不许凭描述想象**
- 减重是另一个坑：他 BMI 30.4，但**当前主线是先睡好、先戒酒**（见生活档案），别把减重一起上
- 护肤线未启动：缺肤质/过敏史前，只给"该怎么判断"，不开具体清单

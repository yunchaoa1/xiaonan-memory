## 一、他的定位（凡哥 2026-10-27 原话，别记错）

> 「我最擅长的事情就是，能够**帮助别人解决思维问题**，不管是任何维度，亲情、爱情，还是职场，我能在这个事情上，**一对一的实现变现**，围绕这个我去起号。」

三个已定事实：
1. **核心能力 = 解思维卡点**（不是教知识、不是给建议）
2. **变现方式 = 一对一收费**
3. **客户希望以女性为主**

### 这条路 ≠ 流量路线（这是必须先说清的判断）

| | 流量路线（视频里那个一天四更的小伙） | 凡哥这条路 |
|---|---|---|
| 靠什么赚钱 | 平台补贴 + 广告 | **一对一咨询** |
| 粉丝量 | 越多越好（4 万粉月入三四千） | **几百到几千个真信他的人就够** |
| 内容要求 | 差也行，量大就行 | **必须显功力，差一点没人敢找他** |
| 更新频率 | 一天四更 | 一周两三更都算勤快 |

**所以「24 小时不停跑、批量低质」那套对他没用**——那是流量生意，他做的是信任生意。**批量低质内容会直接砸掉专业形象。**

### 女性客户这条（重要判断）
这套方法**对女性杀伤力比男性更大** —— 很多女性从小被教「要为别人想、要懂事、别太自私」，那句「**把所有为他人着想的想法全部忘掉，做一回真真正正自私的想**」对她们是一辈子没人说过的话。
⚠ 但有个现实门槛要解决：**男性咨询师 + 陌生平台 = 女性天然有戒备**。这条没解之前，别急着定内容方案。

### 真实客户画像（2026-10-27 他自己看出来的）

> 「我们现在测的其实都是**已经愿意把门打开的人**，最难的其实是**自己还是封闭的人**。」

- **愿意开门的人**（演试里那两场）—— 本来就有自救能力，你只是推了一把
- **还关在门里的人** —— 这才是大多数，也是最值钱的。**但他们不会主动来找你**（他压根不觉得自己有问题）
- **所以内容真正的用途不是「吸引客户」，是「敲门」** —— 让关在门里的人刷到时心里咯噔一下：「这说的不就是我吗」
- 反过来说：**能接到的一对一客户 = 愿意承担、但卡在原地的人**；只想被安慰、只想听「你没错都是他们的错」的人，会被这套打法劝退 —— **这不是缺点，是筛选**

## 一·B、商业规则（他定的，别自作主张改）

### 定价：随喜 + 不限时 + **不明码标价**（他的决定）

他的原话理由 —— **这句是他的核心逻辑，不是省钱心态**：

> 「如果说明码标价，**我的责任问题就不由我说了算**。」
> 「时间设立这个问题很难立得住，有些人很痛快就会解决问题，有些人则不是，可能需要分好几次才能说通。」

**拆开是两层**：
1. **不收钱 = 不承诺「必须治好」**（收钱就等于把结果打包卖给客户了）
2. **不限时 = 不预设几次能解决**（有人一次就通，有人要好几次）

**他的筛选机制**：
- 第一次一分钱不给 → **先了解原因**（可能真的没钱 —— 他原话：「穷人的问题也很多」）
- **一次两次可以给机会**
- 之后仍只索取不回报 → **理直气壮回绝，没有负担**

⚠ **我给过但未被采纳的三条补丁**（他听完没接，别当成已定规则；下次再聊可重提）：
1. 第一次给个**轻门槛**（让他先写下最堵的那件事）—— 一个动作就能筛掉只想倒苦水的人
2. **回绝的规则第一次就说明白**（「我只帮愿意往前走的人，发现你只是想聊，我会直接告诉你」）—— 提前合法化，事后不用解释
3. 不限时但设**软边界**（「今天先聊到这儿，你回去想想」）—— 不限时的客户反而更焦虑

### 他自己写的「回绝白嫖者」四句话术（2026-10-27 原文，可直接复用）

对方又来索取时，他说的是：

1. 「你觉得**我真的帮到过你吗**？」
2. 「如果真的帮到了，你告诉我，**我对你是否有过付出**？」
3. 「**那你对我的回馈是什么？是否是对等的**？」
4. 「如果说我前一次帮助过你、你没有任何回馈，**我不会计较这件事，因为这是我的道，我做出过这样的选择，我选择面对**。但你还要用这样的方式来获取我对你的帮助，**不好意思我这里只有一次机会**。对于不懂得回报的人，我无话可说。」

**这套话术的真实功能不是说服对方，是给自己一个交代**（我复盘时给他的判断，他认了）：
- 对有羞耻心的人 → 会脸红、会补钱、关系反而更牢
- 对真厚脸皮的人 → 会说「我没钱啊」「你不是说不收钱吗」→ **这时候你回绝就完全站得住**
- **说完这套，无论对方怎么回，你都赢了**

### 录音：他要全程录，但有两个红线

他原话：「我可以全程录音过程，没有金钱往来也就不存在被道德绑架这一说」。

**录音本身不违法（你是对话一方），但用途决定风险**：
| 用途 | 风险 |
|---|---|
| 自己复盘听 | 低（仍建议告知） |
| 当「防客户反咬」的证据 | 中（未经同意的录音证明力会被质疑） |
| **整理成案例/内容** | **高 —— 属处理他人敏感个人信息，必须单独授权** |

**建议开场话术**（专业、客户基本都会同意）：
> 「我习惯把对话录下来，方便我事后复盘，看我哪句说得不好。**只我自己听，不对外说**。你同意吗？」
> ⚠ 「同意录音」≠「同意拿去发内容」，**内容化必须再单独授权**。

### 一对一不是终点 —— 他要裂变（方向未定）

他明确说「这个一对一模式**不是我最终的商业模式**，我会想办法去**裂变**」。
**但「裂变」往哪个方向，我问过两次他都没接** —— 说明还没到那一步，**别追**。等一对一规则跑顺了再聊。三个可能方向（供以后对照）：一对多（社群/课程/直播）／带徒弟／内容带流量接广告。

## 二、他的刀法（2026-10-27 两场演试实录，按出现顺序，共 13 刀）

⚠ **贯穿始终的一条**：他**从头到尾没给过一句建议**。不问「该不该分」「该不该计较」，不给「你应该……」。
**他做的是让人自己看见自己在骗自己** —— 这是整套方法的核心，也是最难学的部分。

| # | 刀法 | 他的原话（可直接复用） | 什么时候用 |
|---|---|---|---|
| 1 | **翻译** | 「你刚才给我传达的意思是，你很累，但她身上还有一个点还在吸引着你，你还是愿意在这个点上继续背负着你的累，但不知道你什么时候会把这一点坚持磨掉是吗？」 | 开场。把对方**没说出口的**说出来（对方通常会愣住） |
| 2 | **剥情绪 + 允许自私** | 「我需要你**从你自己的情绪中脱离出来**……把所有为他人着想的想法，或者是借口、托词之类的**全部忘掉**，**做一回真真正正的自私的想**」 | 对方陷在情绪里打转时 |
| 3 | **假想失去 + 逼出"平衡"** | 「假设没有了她你会怎么样」「如果分不开，一直这样你又很累，你**希望能达到的那种平衡又是什么**？」 | 接第 2 刀。给出路，不是逼选择 |
| 4 | **抓自我批判** | 「你很**害怕别人对你的评价贴上不好的标签**吗？」 | 对方冒出「我是不是挺渣/太计较/小心眼」时 —— **那句自我批判就是线索** |
| 5 | **拆前提（最狠的一刀）** | 「**你为什么要和别人解释呢？**」 | 对方说「人家问起来我怎么说」时 —— 一句话把**假想的审判者**拆掉 |
| 6 | **逼他自己下结论** | 「**找到答案了？**」 | 对方已经松动，别替他说，逼他自己说出口 |
| 7 | **明确服务边界 + 逼选需求** | 「我特别能理解你现在的心情，但**拿人钱财与人消灾**，我需要搞清楚一件事情：你来找我是为了**解决问题**，还是说**只想在我这把压力泻下去**，释放掉你一直憋着的情绪？**我都可以帮助你**」 | 咨询开场（尤其收费场景）。既接情绪、又守交付边界、还筛客户 |
| 8 | **从细节反推结构 + 赋权** | 「母亲和你说弟弟结婚早、家里钱不够用的那种**很平常的语气**，证明家里人**已经很习惯的把压力放在你身上**；也能反映出你**从来没让他们失望过**，说明你是一个**很坚强的女性**，只是**背负了你不该背负的**很多压力」 | 对方只讲了一个"小事"时 —— **从小事反推整个家庭/关系结构**，再把"受害"改写成"承担"（赋权，不是安慰） |
| 9 | **从心理拉到身体 + 用比喻逼答案** | 「女性如果连哭都要忍着，**身体会吃不消的**……给你个提示，**气球一直充气，没有设置泄气的开关会怎么样**？」 | 对方在硬撑、在忍。把问题从"想不通"拉到"扛不住" |
| 10 | **给许可 + 不做事** | 「**哭吧**，听完你的经历，**我都想哭**，给你一个发泄的空间，**我可以等你**」 | 情绪临门那一刻。**"我可以等你"是最高级的一招 —— 大多数人会在对方要哭时急着说点什么** |
| 11 | **回到底层锚点** | 「好了，现在我们需要直面问题本身了，先问问你自己：**活着是为了什么？**」 | 情绪泄完之后。把“该不该”换成“我为什么活着” —— 因为她的人生脚本是“别让人失望”，不换锚点谈什么都没用 |
| 12 | **把“对错”换成“代价”（给方法不给答案）** | 「我不会替你做决定，我只告诉你搞清楚自己想要的目标的方法，其实很简单：**想清楚你不按照家里人的期望去做，会怎么样**。如果你**能接受后果你就去做**，如果后果你承受不了，**那就是你的道，谁都帮不了你**」 | 对方问“那我该怎么办”时。**整场最硬的一刀** —— 不给答案，只给判断标准（能不能承担后果）。客户原话反应：「这话听着挺凉的，可我反而觉得这是今天听到最实在的一句」 |
| 13 | **收尾只给安全感，不加戏** | 「**随时可以**」（客户问“结果糟了还能再来找你吗”，就这四个字） | 收口。**不设门槛、不趁机推销**。客户原话反应是主动问价：「你这边收多少钱？我下次来，得带够钱」 |

### 他的三个技术特征（比招式本身更重要）

1. **抓住最不起眼的措辞** ——「很平常的语气」「是不是挺渣」「人家问起来」都是对方随口带过的半句，他从中反推出整个结构。
2. **用问句代替结论** —— 气球、你要什么、活着为了什么。**结论让对方自己说，他才认。**
3. **先接情绪再动结构** —— 对女性客户开场先「我特别能理解你现在的心情」，然后才切。

## 二·C、内容形态与起号（2026-10-29 他主动问「如何只做自己的账号」）

### 先破一个心结：他不需要「每天产出」

他从流量类视频里吸收了「一天四更」，但那是**流量生意**。**信任生意靠"准"不靠"多"**：一周 2-3 条说透的 > 一天 4 条水货。
而且一天四更，一周就把自己的故事讲完，后面只能编。

### 平台：小红书为主（不是抖音）

| | 抖音 | 小红书 |
|---|---|---|
| 女性用户 | 约一半 | **七成以上** ← 他要的客户在这 |
| 内容成本 | 要拍要剪 | **图文就行** |
| 用户心态 | 刷着玩 | **带着问题来找答案** |
| 他的优势 | 要会演会拍 | **会写"看懂人"的话就够** |

抖音可同步，**主力放小红书**。

### 人设一句话

- ✗ 「教你谈恋爱 / 搞定职场 / 情感导师」（满大街）
- ✓ **「你说不出口的那句，我替你说出来」** —— 不是导师，是看穿他的人

### 形式（成本递增，从最低起步）

| 形式 | 成本 | 说明 |
|---|---|---|
| **图文对话**（一问一答，像聊天记录） | 最低，10 分钟/条 | **起步就用这个**；人爱看别人的对话，像看热闹又像照镜子 |
| 配音对话（分饰两角+字幕） | 中 | — |
| 真人演 | 高 | 别一上来就搞 |

### 素材池（这样不会断更）

1. 真实求助帖（见 §四）
2. 他自己的咨询（脱敏）
3. **评论区解题的记录** ← 所以「去别人评论区解题」和「自己做号」不冲突：**前者产出后者的素材**

### 生产分工（他只出那一刀）

| 步骤 | 谁 |
|---|---|
| 找案例（挑卡得深的） | 小南 |
| 写"他卡在哪"（一句话） | 小南 |
| **写下他会怎么问对方的第一句** | **凡哥（核心，只有他能干）** |
| 排版/出稿 | 小南 |
| 发布 | 凡哥 |

→ **他每天只需 10 分钟**：看一眼案例，写下"你会怎么开口"。

### 可复制模板（钩子→场景→反转→问）

> **钩子**：她说"我妈偏心我弟"，我问了一句话，她哭了。
> **场景**：她今年要结婚，她妈说"你弟结婚早，家里的钱花得差不多了"。她说这话时语气特别平常。
> **反转**：我问她"你从小到大，有没有一次是理直气壮地要过东西？"她说没有。
> **点破**：偏心最伤人的不是钱，是**它让你觉得"我不配要"**。
> **问**：你是不是也这样 —— 想开口，先道歉？

### ⚠️ 成品必须是「对话式」，不是「独白式」（2026-11-22 凡哥纠正）

做内容成品（图文/视频/短片）时，**照上面的模板走对话结构** —— 有「我」问、有「她说」、有追问，最后一句把问题甩回读者。

凡哥原话：「**我想要的是把过程讲出来，然后进行反问和拆解，和我们之前试验的那个是一样的，这样才能引发读者的深度思考**」

**对照**（同一段素材、两种写法，效果差一个量级）：

| | 独白式（❌ 本次做错的） | 对话式（✅ 模板要的） |
|---|---|---|
| 结构 | 我告诉你一个道理 | 我当场把她问住了，你看我怎么问的 |
| 视角 | 全程第三人称感悟 | 有「我」在提问、「她说」在答 |
| 关键 | 直接给结论 | 结论是**问出来的** |
| 收尾 | 陈述句安慰（"你不必把自己改造成…"） | **反问读者**（"你上一次理直气壮要一样东西，是什么时候"） |
| 观众感受 | 被安慰，看完就走 | 被照见，自己动脑 |

**写完自检**：数一下文里有没有「我问她……」「她说……」「我说……」—— **一个都没有，就是写成了独白，重写。**

**为什么必须对话**：他卖的不是道理，是**功力**。独白谁都会写；"一句话把人问住"的现场感，才是"这个人值钱"的证据。

### ⚠️ 别把脚本给他看，直接出成品（2026-11-22 凡哥）

「**我觉得你写完脚本直接用这个去跑成视频，我能更直观的感受到，脚本我不专业，可能看不懂**」

→ 内容是给他**看效果**的，不是给他**审稿**的。流程：我写文案 → **直接合成成品** → 他看完说\"行/不行\" → 按反馈改一版。**不要**先发一版文字脚本等他批注（他批不了文案结构，只能凭感受判断）。

### ⚠️ 纯文字版已被否 —— 成品必须有画面（2026-11-22 同日第二轮）

凡哥看过纯文字成品后的原话：「**没有画面确实不行，纯文字版拿不住人，还是需要视频画面**」。

**所以成品顺序定死为：对话式文案 → 意象画面 → 合成。**
**纯文字版只用于我自己快速验证文案节奏（5 分钟出一条自检），不交付。**

画面版管线（84 秒 / 20 个画面，已跑通）：`references/内容成品化-画面版管线.md`。

**画面设计的核心原则 —— 画「意象物件」，不画人物特写：**
AI 画人脸每次都不一样，人物特写一眼假；但空椅子、门缝的光、缩回去的手、没动过的那副碗筷、墙上的裂缝 —— 不需要人脸一致，每一样都能让人心里咯噔一下。20 个已验证的意象清单见上面那份 references。

### 🚫 第三级否定：静态图 + 推拉 = 「照片式幻灯片」，也不行（2026-11-22 同日第三轮）

上面那版（20 张静态意象图 + 每张 4.2 秒缓慢推拉）**做出来被否了**。

凡哥原话：

> 「这种**照片式的幻灯片**画面效果不行，**要动画的效果**，最好是把**事情过程演绎出来**，然后再进行拆解，我想要的是**谈话的演绎结构是主体**，在**当事人回忆描述的时候切到回忆的动画**，然后再**回到谈话的结构**中」

**三级否定的完整链条（别再往回退）：**

| 级别 | 形态 | 他的评语 | 结论 |
|---|---|---|---|
| ① | 纯文字黑底 | 「拿不住人」 | 不行 |
| ② | 静态意象图 + Ken Burns 推拉 | 「照片式的幻灯片」 | **也不行** |
| ③ | 真动画（有动作、有演绎） | — | 目标 |

**所以「图片 + 运镜」这条路已经封死** —— 只要画面里的人和物是**不动的一帧**，无论切多少张、推得多慢，他都会读成幻灯片。**必须真的有动作发生。**

### 🚫 画面必须「演这句话说的事」，不是「配一个情绪接近的意象」（2026-11-22 当天最狠的一次否定）

动画版做出来，凡哥只问一句：

> 「小南　**文案和画面毫无关系啊？**」

抽查三处，全错：

| 台词 | 我配的画面 | 错在哪 |
|---|---|---|
| 「想要一个拥抱，先说'没事我不需要'」 | 手伸出去又握成拳 | 手在握拳，跟「拥抱」无关 |
| 「想被人留下，先替对方找好走的理由」 | 拉行李箱拉链 | 行李箱是「走」，不是「找理由」 |
| 「是它教会你：你要东西这个动作本身是错的」 | 空椅子、两副碗筷 | 那是「没人陪我吃饭」，不是「不敢要」 |

**病根：我是「先想这个情绪用什么意象，再去配话」，顺序反了。**
**正解：先看这句台词在演什么，再决定画面演什么。**

⚠️ **所以前面那份「意象清单」（空椅子／门缝的光／缩回的手…）只适合当独白式的配图，不适合演绎式。** 一旦走演绎结构，画面必须是**这句台词里正在发生的事**：

- 她说「我妈跟我说，你弟结婚早、钱花得差不多了」→ 画面演**妈在说这句**（客厅、弯腰收碗、语气随意）
- 她说「我小时候，我妈给我弟买了个新书包」→ 画面演**她站在门口看着那个新书包**
- 她说「我弟买房，我出了十万」→ 画面演**她把钱递出去的那个动作**

**自检一句**：把画面单独截出来、遮住字幕 —— **能看出这句台词在说什么事吗？** 看不出 = 配歪了。

### ⚠️ 只留台词，不留旁白（2026-11-22 凡哥重申）

> 「我要的**不是读白式**的那种视频，我要的**都是演绎**的那种，**所有语言只有台词的形式出现**」

**这句比上面「对话式 not 独白式」更严一层** —— 那条讲文案结构，这条讲**成片里一句旁白都不许有**：

| 旁白（❌ 删） | 台词（✅ 只留这个） |
|---|---|
| 「她跟我说：我妈偏心我弟」 | 她：「我妈偏心我弟。」 |
| 「我问她：你心里什么感觉？」 | 我：「你心里什么感觉？」 |
| 「偏心最伤人的，从来不是钱」 | 我（对着她说）：「偏心最伤人的，不是钱。」 |

**「她说」「我问」「我告诉她」这类提示语全删。** 拆解段也一样 —— 不是念一段道理，是**咨询师对着她说出来**。

**写完自检（与上一条并列）**：① 文里还有「她说／我问／我告诉她」当叙述语吗？有 → 删。② 每句台词单独拎出来，像不像人在说话？不像 → 看下一节。

### ⚠️ 台词要从真实语料里长出来，不要现编（2026-11-22 凡哥：「台词很有 AI 味道」）

**症状**：按 `write-screenplay` 的「四大死刑」逐条改台词 —— 短句、有停顿、省主语、无解说、无复述，**条条合格，凡哥还是说「台词很有 AI 味道」**。

**原因**：禁令挡得住「AI 腔」，挡不住「设计感」。改出来的每句都恰到好处、节奏工整，**这本身就是假的**。真人说话会重复（「我妈说……我妈就说」）、会卡壳、会说半句咽回去、会跑题、会说废话。

**解药：直接抄真实语料，不自己编。** 我们手里就有 —— `references/simulation-transcripts-2026-10.md` 里那些第一人称原话，本来就是真人反应：

> 「我当时也没接话，就'哦'了一声。」
> 「我弟买房，我出了十万。」
> 「我妈给我弟买了个新书包，我那个旧的背了三年、带子都磨断了。我特别想要一个新的，但我没敢说。」
> 「上一次哭是奶奶走的时候，那都七八年了。」
> 「我好像一辈子就干了一件事 —— 别让人失望。」

**这些话编不出来，因为有具体数字、具体物件、有说不下去的地方。**

**工序**：先从实录里挑原话 → 改成台词（只加动作提示，不动措辞）→ 缺的部分才补写，补写时对着原话的语感。**凡哥手上的一对一实战录音是更好的语料来源（待取用）。**

### ✅ 要的叙事结构：访谈（主体）+ 闪回（演绎）

```
【现在·谈话】她说"我妈偏心我弟"…
      ↓ 她开始回忆
【闪回·演绎】小女孩站在门边，听见妈妈说"你弟结婚早，钱花得差不多了"
      ↓ 回忆结束
【现在·谈话】我问她"你心里什么感觉"
      ↓
【拆解】偏心最伤人的…让你觉得"要东西"这个动作本身是错的
      ↓
【反问】那你呢？
```

**关键点：**
- **谈话是主体**（不是配图，是主场景，占篇幅最多）
- **闪回只在「当事人回忆描述」时切入**，说完就切回来
- **两个时空要有区别**（冷暖、亮度、或画风），观众一眼知道"进回忆了"
- **拆解和反问回到谈话时空**

### 剪影路线：手工代码画不出来，用生图大模型画

**试过、不行的**：用 Python/PIL 拿椭圆+梯形拼人物剪影 → **头是圆、身子是梯形，像棋子不像人**，腿还画错。**纯代码画不出专业剪影动画的质感**（要精确人体比例、流畅曲线、光影层次）。**别再试这条路。**

**成立的做法**：**让生图大模型直接画剪影画面**（提示词：纯黑剪影/无面部细节/柔和窗口光/2D 动画质感），质量是专业动画短片级别 —— 发丝、衣褶、手指轮廓都在。

已验证的 8 张：两人隔桌对坐（左男右女，主场景）、小孩站门口门里大人虚化（闪回主场景）、一个人对着空椅子、L 形对坐、餐桌推碗、水杯空镜、手伸出去又缩回、行李箱拉拉链。

#### ⚠️ 生图提示词必须写清「几个人、男的女的、各自身形」（2026-11-22 血泪）

**事故**：第一版生图只写了"两个人隔桌对坐"，**没写性别 → 画成两个男人**。后面 H3 忠实照图走，出片是两个男的；我却写汇报说"H3 把女性画成男性、远景扛不住身份"。

凡哥一句话戳破：**「性别没改过来是你给喂的图就是两个男人吧？」**

**铁律**：
- 剪影生图提示词里，**性别 / 人数 / 年龄感 / 体型差异必须写在最前面**（「右边是一个女性：长发垂到肩膀、肩窄、手腕细、体型小」「左边是一个男性：短发、肩宽肩方、体型明显比她大」）
- **图里没有的东西，文字写一百遍也长不出来；图里有的东西，文字否不掉**
- 出图跟设定不符 → **先改图重生，不要在视频提示词里加词硬掰**
- 汇报「模型做不到 X」之前，**先自查一遍素材** —— 把"我喂错了图"说成"模型不行"是最伤信任的误判

#### 剪影 + H3 已验证（2026-11-22）

- **剪影质感全程保持**：不变真人、不糊、不崩
- **微动作成立**：低头 + 塌肩 + **长发从背上滑到身前**（提示词写"头发滑动"会被执行）
- **一静一动有效**：她动、他不动，画面不是死的
- **竖屏 832×1440 成片成立**
- 单颗 5-7 秒，≈12 分钟/颗（一采+二采）

**已验证追加（同日，13 颗成片）**：碗被手推着从桌子中间滑到右边（手全程扣住碗沿）、空椅子 + 两副碗筷（碗里的热气都画出来了）、手按在关好的行李箱上、她抬头看向他、客厅收碗（女儿站着不动／妈弯腰收）、小女孩在暗门框里看门里亮处的新书包、小手张开→攥拳→落下。**同场景镜头只要都从同一张图起，构图一致**（三颗谈话镜头剪在一起不跳）。竖屏 `544×960`（一采）／`832×1440`（二采）直接出，**别横屏再裁**。

**未验证**："远处大人在动"的闪回。

**剪影的额外好处**：绕开 AI 最弱的一环（人脸一致性）——**剪影没有脸，观众不会去比对"怎么长得不一样"**；而且回忆本来就是模糊的，没有清晰的脸反而更对。**代价：做不了表情**（只能靠姿态和节奏）。

**让它动起来**：剪影图当首帧 → H3 图生视频（留出动作）。渠道、参数、踩坑：`references/内容成品化-访谈闪回与剪影管线.md`。

**演绎式全台词版的完整管线**（20 颗分镜 / 双音色配音 / 竖屏 544×960 / 提交接口必包一层 / 字幕标点避头 / 生图性别与童手两个坑 / 完整时间账）：`references/内容成品化-演绎式全台词管线.md`。

**判断顺序**：先确认结构（访谈+闪回）他认不认 → 再做一段 5 秒验证"剪影能不能动、动得自不自然" → 才铺满整条。**不要一上来铺 84 秒。**

## 三、演试协议（我怎么配合他练）

**流程（一轮一件事，别抢）**：

1. **找真实案例** —— 他明确要求「你去网上找真实案例，拿到我这边我替你解一下」。**不许自己编**（他信源要求：真实）。来源与坑见 §四。
2. **用第一人称演，不给提示、不跳戏** —— 只以"那个人"的身份说话，不带出戏的旁白（可用括号写停顿/动作增强真实感）。
3. **一次只演到"被推动一小步"就停** —— 等他接。不要一口气把底牌全亮（真人是慢慢说的）。
4. **演得像真人，不要演得"太顺"** —— 见 §五坑 1。
5. **他收口（「找到答案了？」这类）之后才出戏复盘** —— 把他用的手法命名 + 指出效果 + 说这段能当内容素材。
6. **存档** —— 对话记录就是**案例库 + 内容素材**（改成化名即可用）。存到 `D:\Hermes\xiaonan-memory\personal\咨询演练案例库.md`，每条记「卡点（表面）→ 卡点（真实）→ 凡哥的刀 → 当事人真实反应」。

**多维度测试队列（2026-10-27 他要求「多维度的来测试一下，多积攒一些」，且希望客户以女性为主）**：

- [x] 爱情 · 男性（性格都尖锐，该不该分）
- [x] 亲情 · 女性（父母偏心，弟弟结婚花光家里的钱）
- [ ] **职场** · 女性（被排挤／领导打压，想走不敢走）
- [ ] **自我** · 女性（35+ 未婚焦虑／自我价值）
- [ ] **亲密关系** · 已婚（冷暴力／婆媳）
- [ ] **亲子** · 孩子教育 vs 自己

**攒到 10 场左右，「他的模式」会自己浮出来 —— 那时候起号的内容主线不用猜，它会自己告诉该讲什么。** 别提前替他定内容方案。

**复盘时给他的话术（他爱听且准确）**：
> 「你的方法不是给答案，是**让对方自己看见自己在骗自己**。这比给建议难多了，也值钱多了 —— 给建议的人满大街，能让人自己醒过来的没几个。」

## 五、Pitfalls（演试时最容易犯）

1. **别演得"一戳就服"。** 真人有抵抗、有自我辩护、会道歉、会自我否定。
   - ✗ 「对！你说得太对了，我就是这样」
   - ✓ 先愣 → 先否认/辩解 → 自己举出证据 → 说着说着自己发现 → **"这话说出来有点可怕"**
2. **别把"社会期待答案"当真实答案。** 他一问「你要解决问题还是要泻情绪」，那人第一反应一定是「解决问题」——**那是假答案**，真话在后面（"我就想有个人跟我说一句'这事儿确实委屈你了'"）。
3. **别替他总结他的手法、别替他答。** 他要在实战里练（原话：十多年没做过）。**复盘放到他收口之后**，不要在他还在推进时插话点评。
4. **别编案例。** 他明确要真实案例；编的练不出手感，还会污染案例库。
5. **客户定位没定之前，别急着出内容方案。** 他先要的是"练 + 攒"，不是"排期"。
6. **别把这条路做成流量路线。** 见 §一 对照表 —— 一天四更、低质批量，跟他的一对一信任生意是反的。
7. **案例里出现真人信息一律化名再入内容**（副业内容素材化时）。

# 情感内容成品化 · 纯文字视频管线（2026-11-22 实测）

## 一、为什么要"纯文字"

凡哥的内容**不需要真人画面**，"一句话打出来 + 节奏"就够。这是成本最低、返工最少的形态：

- 零素材（不用生图、不用拍）
- 零成本（TTS 免费档 + 本地 whisper）
- 文案好不好，一眼能看出来 —— **不受画面质量干扰**

配套判断（写进 SKILL.md 了）：成本递增顺序 = 图文对话 → **纯文字视频** → 配音对话 → 真人演。别一上来搞高的。

## 二、跑通的管线

```
对话式文案
  → text_to_speech 出配音 mp3（edge / zh-CN-XiaoxiaoNeural 够用）
  → ffmpeg 转 16k 单声道 wav
  → faster-whisper large-v3 卡逐句时间戳（GPU，约 4.3× 实时）
  → PIL 渲透明文字层 PNG（每个显示单元一张）
  → ffmpeg overlay + enable='between(t,st,en)' 逐层叠上
  → 成片（1080×1920 / 30fps / 带配音）
```

现成脚本：`scripts/emotion_text_video.py`（喂台词表 + 配音，自动对齐）。

## 三、三个必踩的坑（都实测踩过）

### 坑 1：ffmpeg `drawtext` 排中文必失败

**症状**：`Error : Invalid argument`，整条 filter_complex 解析失败。

**根因**：`alpha='if(lt(t,14.12),0,if(lt(t,14.47),(t-14.12)/0.35,...))'` —— **表达式里的逗号与 filtergraph 的分隔符冲突**。多层 drawtext 叠加时几乎必炸。

**正解**：**别用 drawtext。** PIL 渲透明 PNG，每句一张，ffmpeg 只做 `overlay`。好处：
- 中文排版完全可控（字体、行距、居中、换行都由我定）
- filtergraph 只剩 `overlay + between`，表达式简单，不会打架
- 文字层可以单独拿去做缩略图/封面

### 坑 2：whisper 分段前后重叠

**症状**：两层字同时出现、叠在一起糊成一片。

**根因**：whisper 的输出里 `seg[i].end > seg[i+1].start`（很常见，vad 分段边界就是会叠）。

**正解**：拿到时间戳后强制修一遍 —— **每段结束时间裁到下一段开始前 0.05 秒**，并保底 `en >= st + 0.4`。

```python
if i + 1 < len(times):
    en = min(en, times[i + 1] - 0.05)
fixed.append((st, max(st + 0.4, en)))
```

### 坑 3：`color=` 源没接就会被判 unconnected

**症状**：`Filter 'color:default' has output 0 (bg) unconnected` / `Error binding filtergraph inputs/outputs`。

**根因**：为了做背景起了一个 `color=c=black:s=...` 源，但后面实际用的是 `[0:v]`，那个源成了悬空节点。

**正解**：背景**就是** `-f lavfi -i color=...` 的第 0 路输入，后面直接 `[0:v]` 接 overlay 链，**不要再额外 append 一个 color 源**。

## 四、排版决策（已验证好看那版）

| 角色标记 | 颜色 | 字号 | 用途 |
|---|---|---|---|
| `n` 旁白 | 近白 (238,238,242) | 72 | 交代场景/动作 |
| `s` 她说 | 浅灰 (188,188,196) | 72 | 对方的话（退一层） |
| `i` 我说 | 纯白 (255,255,255) | 72 | 咨询师的话（顶一层，加粗） |
| `k` 关键 | 暖金 (255,236,190) | **84** | 点破/拆解/反问 |

**用颜色区分说话人**是这套的关键 —— 观众不用想就知道哪句是谁说的，节奏才读得出来。
关键句同时**加大字号 + 换暖金色 + 停留时间更长**（三件事一起做，比只说"重要"有效）。

背景：`0x0B0B10`（近黑偏蓝），比纯黑有层次，也不抢字。

## 五、实测耗时（本机 RTX 5080 Laptop 16G）

| 环节 | 21 秒片 | 84 秒片 |
|---|---|---|
| TTS 配音 | 数秒 | 数秒 |
| whisper 卡时间戳 | 约 5 秒 | 约 20 秒（large-v3 / float16 / 4.3× 实时） |
| PIL 渲文字层 | < 1 秒 | < 2 秒 |
| ffmpeg 合成 | 约 10 秒 | 约 30 秒 |
| **合计** | **约 20 秒** | **约 1 分钟** |

**结论：改一版文案到看成片，一分钟一轮。可以放心多做几版让他挑。**

## 六、文案结构（这是真正的价值所在，画面只是载体）

必须走 SKILL.md 里的对话式五段：**钩子 → 场景 → 反转 → 点破 → 反问**。

**本次做错的第一版**（独白式，被凡哥否）：
> 他昨天还秒回，今天一整天没动静 / 你翻了三遍聊天记录 / 但你找不到 / 因为你根本没做错什么 / 冷淡不是惩罚 / 是他自己那边满了 / 你不必把自己改造成他能装下的形状

问题：**没有"我"，没有对话，最后是陈述句。** 像一篇自我安慰的短文，读完就忘。

**改对的第二版**（对话式，凡哥要的）：
> 她跟我说"我妈偏心我弟"的时候，我以为又是钱的事
> 她说今年要结婚，她妈说"你弟结婚早，家里的钱花得差不多了"
> 她说这句话的时候，语气特别平常，像在说今天天气不错
> 我问她"你听到这句话，心里什么感觉"
> 她说"能理解啊，我弟确实早"
> **我说"我没问你理解不理解，我问你心里什么感觉"** ← 这里开始不对劲
> 我问她"你从小到大，有没有一次是理直气壮地跟人要过东西"
> 她想很久，说"好像没有"
> **"不是好像，是没有"** ← 刀
> 偏心最伤人的从来不是钱 / 是它慢慢教会你一件事：**你要东西这个动作本身，是错的**
> 那你呢？**你上一次理直气壮地，跟人要一样东西，是什么时候？**

**差别**：后者的说服力来自"**我当场把她问住了**"，观众看的是手法，不是听道理。这也是他真正值钱的东西。

> 建立日期 2026-11-22。凡哥要的形态：**访谈（主体）+ 闪回（演绎）**，且必须是**真动画**，不能是静态图。
>

## 一、结构（他定的，先照这个排）

```
【现在·谈话】她说"我妈偏心我弟"的时候，我以为又是钱的事
      ↓ 她开始回忆
【闪回·演绎】小女孩站在门边，听见妈妈说"你弟结婚早，家里的钱花得差不多了"
      ↓ 回忆结束
【现在·谈话】我问她"你心里什么感觉" → 她说"能理解啊" → 我说"我没问你理解不理解"
      ↓
【拆解】偏心最伤人的不是钱，是它教会你"要东西这个动作本身是错的"
      ↓
【反问】那你呢？你上一次理直气壮跟人要一样东西，是什么时候？
```

**硬约束：**
- **谈话是主体**，占篇幅最多；闪回只是插入，说完立刻回来
- **闪回必须和谈话时空有视觉区别**（冷暖／亮度／画风任一）
- **拆解和反问回到谈话时空**（不要留在闪回里收尾）
- **最后一句必须是反问读者**（陈述句会被读成"又一个讲道理的"）

## 二、剪影这条路为什么成立

| 问题 | 剪影怎么解 |
|---|---|
| AI 画人脸每段都不一样 | **剪影没有脸**，观众不会比对"怎么长得不一样" |
| 回忆本来就模糊 | 剪影天然带距离感，观众更容易把自己套进去 |
| 情感内容要"高级" | 剪影 + 窗口光 = 短片质感，不是PPT |
| 人物一致性问题 | 只剩体态/姿态要一致，比对齐五官容易得多 |

**代价**：做不了表情（皱眉、流泪），只能靠**姿态（低头、缩肩、转身）+ 节奏**演。

## 三、画面怎么来：生图大模型画，不要手工代码画

### ❌ 手工代码画剪影 —— 试过，不行

用 Python `PIL` 拿椭圆（头）+ 梯形（身体）拼人物 → **像棋子／不倒翁**，腿的位置画错，背景光变成一个大月亮。
**纯代码画不出专业剪影的质感**（要精确人体比例、流畅曲线、光影层次、发丝衣褶）。

**结论：不要再试手工剪影。** 想省事的直觉在这里是错的。

### ✅ 生图大模型画剪影 —— 已验证，质量专业级

提示词要点（中文即可，实测有效）：

```
黑白剪影动画风格，纯黑人物剪影，无面部细节，极简 2D 动画质感，
背景是柔和的暖色窗口光，电影感，构图留出大量暗部
```

**实测三张都成立**（发丝、衣褶、手指轮廓都在）：
1. 两人隔桌对坐，一人前倾说话、一人低头，背后窗口透光 → 谈话主场景
2. 小孩站在门口，门里两个大人虚化着 → **闪回最强的一张**（一句话没说全说完了）
3. 一个人对着空椅子 → 拆解段落

### 渠道参数（实测）

| 项 | 值 |
|---|---|
| 接口 | `POST https://apihub.agnes-ai.com/v1/images/generations` |
| 模型 | `agnes-image-2.1-flash` |
| 尺寸 | `1024x1792`（竖屏 9:16 附近） |
| 耗时 | **10–16 秒/张**，4 张并行约 16 秒，16 张并行约 50 秒 |
| key | `D:\Hermes\config.yaml` → `custom_providers` → `name: agnes` → `api_key` |
| 返回 | `data[0].url`（图片直链，需再下载一次） |

**对比**：`gpt-image-2-medium`（Hermes 默认 `image_gen`）这次**连续两张各超时 420 秒**，不适合批量。
→ **要一次出十几张画面，走 agnes flash；单张精品再用默认渠道。**

## 四、让它动起来：H3 图生视频

### 已验证的参数

**H3 支持竖屏 9:16。** 提交 `width=544, height=960` → `node_errors: {}`，零错误通过。

> 之前所有测试都跑横屏 `960×544`；情感内容必须竖屏，**以后默认竖屏**，不要再横屏出片再裁。

**提示词骨架**（剪影专用）：

```
subject_definitions:
<Picture 1> defines the visual style, framing and light: two pure black silhouette
figures seated facing each other across a small low table, backlit by a bright window
in a dark room. Follow the exact composition, silhouette shapes, table position and
window light of <Picture 1>.

summary:
[reference generation] A monochrome silhouette animation. Two seated figures face each
other across a table. The figure on the right slowly lowers her head.

retention_analysis:
<Picture 1> (appears in [Shot 1]): fully_preserved - the room, the window light, the
table, the chairs and both silhouette figures keep exactly the same shapes, positions
and framing as in the reference.

detailed_description:
Monochrome silhouette animation, pure black figures against a dim room, no facial
details, flat graphic shapes, soft warm window light, 2D animation texture, cinematic,
minimal.
[Shot 1] Static locked-off shot at eye level. Both silhouettes stay seated facing each
other. The figure on the right slowly lowers her head and her shoulders sink a little.
The figure on the left does not move. The window light stays constant.

overall_soundscape:
A very quiet room. A faint distant hum of the city.

non_diegetic_music:
N/A
```

**要点：**
- `mode` 必须显式 `ref2va`（写 `auto` 会被判成纯文本生成、参考图全废）
- **一镜只给一个动作**（"右边的人慢慢低头"），给两个就会丢
- 明写 `no facial details` / `pure black figures`，否则会往真人方向跑
- `retention_analysis` 里点明"桌、椅、窗光、两个人形都不变"，防漂移

**状态**：⚠️ **待验** —— 5 秒测试片已提交（`SilTest`），成片效果（剪影能否保持住、"慢慢低头"自不自然）尚未看到。
**下一轮第一件事就是看这一颗**，再决定要不要铺满整条。

### 已知坑

**ComfyUI `/prompt` 接口必须包一层**：

```python
json.dumps({"prompt": 工作流dict, "client_id": "xxx"})
```

直接提交工作流本身 → `HTTP 400 {"error": {"type": "no_prompt", "message": "No prompt provided"}}`。
**看着像提示词是空的，其实是少了一层包装**，别去改提示词。

**`build_payload.py` 的宽高是写死的** `960×544`，竖屏要在 build 之后改 payload：

```python
api["201"]["inputs"]["width"] = 544
api["201"]["inputs"]["height"] = 960
```

## 五、铺满整条的估算

| 项 | 数 |
|---|---|
| 整条长度 | 约 84 秒（对话式文案 20 句左右） |
| 每段 H3 | 5–8 秒 **（注意：H3 有效动作窗口约 5–7 秒，超过就开始"摆姿势"不动）** |
| 段数 | 约 12–16 段 |
| 单段成本 | 一采约 4.5 分钟 + 二采约 8 分钟 ≈ 12 分钟 |
| 全条 | **约 2.5–3 小时** |

**省钱做法**：先只跑一采（`960×544`/`544×960`，4.5 分钟/段），够判断结构和动作；定稿后只对需要清晰的段落补二采。

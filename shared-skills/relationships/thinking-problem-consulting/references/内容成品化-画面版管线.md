# 内容成品化 · 画面版管线（2026-11-22 跑通，84 秒 / 20 个画面）

> 前提：文案必须先是**对话式**（钩子→过程→反转→点破→反问，见 SKILL.md §二·C）。
> 纯文字版已被告知"拿不住人"，只作自检用。
> 本文只讲"文案定了之后怎么变成片子"。

---

## 一、五步流水线

```
① 文案（对话式，7 段左右 / 60-90 秒）
② 拆意象：按文案逐句配 15-25 个"物件"画面
③ 生图（并行）
④ TTS 配音 → whisper large-v3 卡逐句时间戳
⑤ PIL 渲文字层 → ffmpeg 运镜 + 叠加 + 暗角
```

实测耗时（84 秒成片 / 20 画面）：**生图 50 秒 + 配音 5 秒 + 时间戳 25 秒 + 合成 90 秒 ≈ 3 分钟**（不含写文案和调图）。

## 二、生图渠道

### 首选：agnes-image-2.1-flash（快，适合批量意象图）

- 端点：`POST https://apihub.agnes-ai.com/v1/images/generations`
- 请求体：`{"model":"agnes-image-2.1-flash","prompt":"<中文>","n":1,"size":"1024x1792"}`
- key：`D:/Hermes/config.yaml` 里 `custom_providers` → `name: agnes` → `api_key`（正则 `- name: agnes[\s\S]{0,400}?api_key:\s*(\S+)`）
- 返回：`data[0].url`，需再下载一次
- **实测延迟：单张 10-22 秒；6 并发下 16 张 50 秒**
- 出图 1024×1792（竖），够 1080×1920 用
- 中文提示词直接吃，不需要翻英文

### 慢的时候换路子

`image_generate`（gpt-image-2-medium）画质更细，但**延迟高**——本次两次调用各 420 秒超时。
需要一次出十几张意象图时走 agnes；单张主视觉、要求高质感时再考虑 gpt-image。

### 提示词写法（意象图专用）

结构：**主体 + 光位 + 材质/年代 + 情绪词 + 摄影规格**

```
斑驳的老墙上一道细长的裂缝，光从裂缝边掠过。
极简构图，写实摄影，冷调，竖构图
```

```
餐桌上两副碗筷，一副碗筷已经用完推开，另一副整整齐齐完全没动过，椅子空着。
写实摄影，暖冷对比，竖构图
```

**必须带的三个尾巴**：`写实摄影` / `竖构图` / 一句光位或情绪。
**不要带**：具体人名、要求人脸一致、要求文字出现在画面里。

## 四、ffmpeg 合成参数（实测可用）

### 步骤 1：每张图做成带运镜的片段

```python
per = DUR / len(shots)          # 84.4 / 20 = 4.22 秒/张
zin = i % 2 == 0                # 交替推/拉，避免统一节奏
zexpr = "min(zoom+0.00045,1.13)" if zin else "if(lte(zoom,1.0),1.13,max(1.0,zoom-0.00045))"
vf = ("scale=1242:2208:force_original_aspect_ratio=increase,crop=1242:2208,"
      "zoompan=z='%s':d=%d:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1080x1920:fps=30,"
      "eq=brightness=-0.06:contrast=1.04:saturation=0.92,vignette=PI/5"
      % (zexpr, int(per * 30)))
```

- **zoom 上限 1.13、每帧 +0.00045** —— 再快就晕
- **暗角 `vignette=PI/5`** —— 一件白字压在画面上不糊的救命参数
- **`eq=brightness=-0.06`** —— 压暗给文字让路；同时压饱和到 0.92 让 AI 图不那么"艳"

### 步骤 2：concat 成底片

```
file 'v00.mp4' ...  → ffmpeg -f concat -safe 0 -i list.txt -c copy base.mp4
```

### 步骤 3：叠文字层 + 配音

```python
# 每个文字层一个 -loop 1 -i，按时间轴 enable
fc.append("[%s][%d:v]overlay=0:0:enable='between(t,%.2f,%.2f)'[o%d]" % (cur, i+1, st, en, i))
# 收尾
fc.append("[%s]fade=t=in:st=0:d=0.7,fade=t=out:st=%.2f:d=1.1,format=yuv420p[vout]" % (cur, DUR-1.1))
```

- 输出：`libx264 -preset medium -crf 19` + `aac -b:a 160k`
- 84 秒成片约 20MB

### 文字层（PIL）

- 位置：`y = int(H*0.55 - total/2)` —— **中下部**，避开画面主体（主体通常在下 1/3，但空镜的中部也安全）
- 字号：普通 70 / 关键句 84
- 行距：`int(fs*0.62)`
- 阴影：先画 `(x+2, y+3)` 黑 `(0,0,0,190)`，再画正文
- 三色分工：
  - 她说 = `(200,200,208)` 浅灰
  - 我说 = `(255,255,255)` 白
  - 关键句 = `(255,232,178)` 暖金
- 字体：`C:/Windows/Fonts/msyh.ttc`（常规）/ `msyhbd.ttc`（关键句、我说）

## 五、三个必踩的坑

### 坑 1：不要用 ffmpeg `drawtext` 排中文

`drawtext` 的 `alpha='if(lt(t,0.00),0,...)'` 里那些逗号会被 filtergraph 当成分隔符，
无论怎么加引号都容易报 `Invalid argument`。**绕法：PIL 渲成透明 PNG 文字层，再用 `overlay` 按时间轴叠。**
好处是排版（字重、行距、居中、阴影）完全可控，改字只改 Python 不用碰 ffmpeg 语法。

### 坑 2：whisper 分段的时间戳会前后重叠

`faster-whisper` 出来的 segment 常有 `[59.22, 64.00]` 和 `[63.78, 67.80]` 这种交叠，
直接拿去 enable 会让两层字同时显示、叠在一起。**修法：**

```python
for i, (st, en, ...) in enumerate(LINES):
    if i + 1 < len(LINES):
        nxt = LINES[i + 1][0]
        if en > nxt - 0.05:
            en = nxt - 0.05
    fixed.append((st, max(st + 0.4, en), ...))
```

### 坑 3：文字压在画面主体上

人物/手在画面下方时，文字放 `0.55H` 会压手。**先抽一帧看主体位置再定 y**；
或者生图时就在 prompt 里写"画面上方留暗部空间用于放文字"（这条对竖构图很有效）。

## 六、还差的两样（下一版补）

1. **背景音乐** —— 现在只有人声，情绪起不来。需要一段低音量的钢琴或环境音垫底（`-filter_complex amix` 或 `amovie` + `volume=0.15`）。
2. **人声留白** —— 现在一句接一句。真正的狠应该是：念完"她没有说话"之后**静两秒什么都不说**。
   做法：TTS 分段生成，在指定位置插入静音段，而不是整段一次合成。

| # | 原理 | 一句话 | 出处 |

## 2. 四条主流程

### 流程A · 激起兴趣

**输入**：刚认识，还没建立有效联系（或联系了但聊不下去）

**步骤**
1. **一九定律** —— 初识阶段，你要主动承担 **90%** 的谈话信息量，让她只需接话。（第11章）
   - 反面：93% 的男人用"你哪里人？""你哪个部门的？"开场 → 她提供零兴趣信息 → 敷衍 → 88
2. **假定回答法** —— 把想问的变成**用陈述句说出的假定答案**。（第11章）
   - 不问"你叫什么" → 直接说"哦，你就是那个李梦茹。你好。"
   - 效果链：她惊讶+想纠正 → 主动告诉你 → 产生新话题 → 情绪波动（这就是吸引第一步）
3. **无所谓但友好** —— 心理上不在乎她是否喜欢你，行为上像对老朋友一样自然。（第10章）
   - 只讨好不无所谓 = 跟屁虫；只无所谓不友好 = 装酷神经病
4. 拿到联系方式 → **立刻转流程B**（不要停在聊天）

**输出**：她愿意跟你说话、给了联系方式、能约出来

**翻车**：只做 1-3 却不推进 → 永远停在"聊得来的人"（这是最大的坑，第10章说 90% 的失败源于不知道步骤）

---

### 流程B · 建立吸引

**输入**：能聊上，但她只把你当普通朋友/熟人

**步骤**
1. **停止讨好** —— 讨好、迎合、赞同对交朋友有用，对吸引**致命**。（第13章）
   - 机制：用"对她好"是在操控她的**内疚感** → 内疚在潜意识里变成**怨恨** → 借故发脾气/离开（第10章）
2. **故意曲解** —— 把她的意思曲解成"她在努力追求你"，营造她追你的气氛。（第13章）
   - 四种：借用女性框架 / 话题曲解 / 万能曲解 / 性暗示曲解
3. **推拉** —— 一句好话接一句坏话（或反过来），制造情感张力。（第13章）
   - 推拉 = 调情，是女生最喜欢的"爱情游戏"
4. **让她为你付出** —— 她付出了才会爱上你（第13章）
5. **应对她的考验** —— 赞同 + 幽默曲解。（第14章）
   - 公式：①大方承认她说你的不好 ②把考验曲解成"她太喜欢你、追你太猛"
   - 六种进阶破解见 `references/techniques.md`

**输出**：她开始主动找你、在意你的评价、不排斥肢体亲近

**翻车**：吸引还没建立就用流程C的深入技巧 → 变成"掏心窝子的朋友"；把推拉用成阴阳怪气 → 变成攻击

---

### 流程C · 巩固吸引

**输入**：有吸引，但关系不稳、怕熟了就凉

**步骤**
0. **先诊断关系类型**（决定能不能往下走）（第15章）
   | 关系 | 表现 | 该做什么 |
   |---|---|---|
   | **讨好关系**（她已被吸引） | 主动迎合、低声下气、不介意肢体亲密 | ✅ 可以推进 |
   | **中和关系** | 平平常常、礼貌友好 | ⚠️ 回去建立吸引 |
   | **破坏关系** | 冷淡、不客气、保持距离 | ❌ 回去建立吸引 |
1. **话块连情**（四层递进，第16-17章）
   - 一层：简单同意/感慨（"是吗，好好休息一下"）
   - 二层：**关键词技巧**（抓她话里的关键词展开，选有歧义/双关的词更好）
   - 三层：**话块机会主义**（针对她感兴趣的话题展示内行，间接传达"我们是同类"）
   - 四层：**深层次话块连情**（提炼她的情绪 → 探索根源 → 用比喻/故事共鸣）
2. **时间错觉法**（第18章）
   - 技巧一：讲自己的过去（童年/高中）→ 把她带进你的世界
   - 技巧二：一起想象未来（"如果那时候我们还像今天这样聊着，会谈些什么呢？"）
3. **透露内心深处的痛** —— 只在吸引已建立后、**对一个女生只能用一次**。（第18章）
   - 平时自信的男人偶尔吐露心声 → 加深感情；平时就没自信的男人用 → 适得其反

**输出**：她产生"你懂我""连闺蜜都没这么了解我"的感觉，从表层聊天进入交心

**翻车警告**：成真原话——"深层次话块连情就像核武器一样强大，但也像核武器一样危险，只能在正确的时候使用"（第17章）

---

### 流程D · 确立关系

**输入**：吸引稳定了，要推进肢体亲密度

**步骤**
1. **删除表白，用行为推进（事实恋爱）** —— 第9章
   - 表白在潜沟通里 = "我不懂女人/我缺乏自信/我跟其他 99% 失败男人一样"
   - 就算她答应了，也 100% 跟表白无关（前面吸引已建立，表白只是捅破纸）
2. **一个箱子一个箱子搬** —— 说话 → 肢体接触 → 牵手 → 接吻，不跳步（第9章）
3. **亲密度升级以退为进** —— 女生的"不行" = "现在还不行"；被拒后**不生气、不道歉**，退一步，过一会再推进。（第23章）
4. **让她琢磨不透**（第23章，十要点，见 `references/techniques.md`）
   - 核心：让她无法确定你喜不喜欢她 → 她琢磨你 = 情感投资
5. **尊重性欲差异** —— 男人像开关、女人像旋钮，必须循序渐进（第24章）
6. **安全与责任** —— "安全套 = 责任套"，必须戴；展示责任感和分寸**反而更显魅力**（第24章）

**输出**：成为事实上的情侣（不用她口头答应）

**翻车**：把"不道歉""不容忍不敬"用成冷暴力；在她明确拒绝时继续推进 → 越界（见第 6 节红线）

---

### 流程E · 表白失败挽回（第20章）

**第一个机会：当下 0.1 秒内**
- 前提认知：①拒绝是事实，解释无用 ②吸引是流动的，不是判决 ③**绝不能表现难过沮丧**
- 操作：凝望她眼睛，微坏笑："你认真的样子真有意思。看来你对感情很认真，如果你再成熟点我倒是可以考虑考虑，哈哈。" / "啊？你不会就这么当真了吧？"
- 效果：把"愚蠢的表白"转化为"善意的耍她"

**第二个机会：错过当下之后**
1. 断联 1-2 周，彻底切断主动联系
2. 再见时对她像对其他朋友一样
3. 找机会再"表白"一次，但说"其实我也没有想好要和你怎么发展"
4. 用推拉+曲解建立吸引："那我们现在就离婚！走，去民政局"

## 4. 内功（第25-27章 · 没有这层，技巧不持久）

### 本我 vs 小我自信（第25章）
| | **本我**（Self-esteem） | **小我**（Ego） |
|---|---|---|
| 来源 | 与生俱来 | 后天理性构建 |
| 维持 | 不需外部认可 | 需要他人表扬/注意 |
| 稳定性 | 永久稳定 | 随外界时有时无 |
- 小我主导 → 她冷淡你就慌 → 更努力求反应 → 她更远离
- 本我主导 → 对任何反应都平和 → 她反而给你积极反应
- **"对于一个男人来说，你的自信就是你的主权。"**

### 身份认同（第26章 · 终极瓶颈）
- 定义：内心深处觉得自己是谁、配得上什么。**彩票得主 98% 五年内破产**——因为"穷人"身份认同没变。
- **老母鸡论**：学再多技巧，在"老母鸡"范畴里最多吸引到老母鸡；要吸引凤凰必须提升身份层次。
- 三个途径：①纯外部因素（钱/职位）→不长久 ②控制潜沟通（技巧造假象）→有效但累 ③**真正实现高价值身份认同** → 自然流露

### 内化五步（第27章）
理解本我/小我 → 理解思维社会化定式 → 重审旧观念 → 学高价值认同的表现 → 实践成功反哺认同（**"披着狼皮的羊"→ 狼皮变成自己的皮**）

> ⚠️ **"做你自己"对初学者是陷阱**（第27章）：低价值身份认同下做自己 = 自然流露低价值潜沟通。

## 5. 适用边界（写厚 · 边界比方法值钱）

### ✅ 有效场景
- **恋爱初期 → 确立关系之间**的主动推进（本书就是为这个区间写的）
- 双方都是普通条件、需要靠"吸引"而非"条件"打开局面
- 线上/线下初识、暧昧期、关系僵局

### ❌ 翻车场景（逐条要具体）
1. **已经确立的长期关系** —— 这是"吸引期"工具。长期关系里继续推拉/让她琢磨不透/忽冷忽热，会变成情感操控，把关系搞崩
2. **对方已明确、多次拒绝** —— 继续"推进亲密度"就从搭讪变成**骚扰**。断联法不是用来反复纠缠的
3. **共同社交圈（同事、同学、朋友的朋友）** —— 冷读/曲解/推拉在固定圈子反复使用会让人设崩塌，且没有"消失"这个退路
4. **权力不对等关系**（上下级、师生、客户）—— 本书完全没考虑这层，强行套用会出事
5. **对方明显比你更主动时还用"无所谓但友好"** —— 该接的时候装酷，会把人推走
6. **照抄"不道歉""不容忍不敬"** —— 原文针对的是恋爱张力中的小事，不是让你拒绝为真实错误负责；用错就是冷暴力
7. **把"事实恋爱"当"绕过对方意愿"** —— 删除表白≠跳过同意。第24章明确：要让她有"可以随时起身离开"的安全感
8. **心理状态不稳时用"透露内心痛"** —— 用早了/用多了变成情绪索取

### ⚙️ 前提条件
- 你确实能接受被拒绝（否则所有"无所谓"都是装的，潜沟通会露馅）
- 有真实自我提升，不是只背话术（第3章阿凯案例证明：**光模仿表面行为不够**）
- 对方是成年、单身、非权力从属关系

### 📉 作者自承的局限
- "模仿表面行为不够，深层机制才是核心"（第3章）
- 需要持续实践——他建议**至少两个月**，每天练一种技巧（第28章）
- 学习曲线非直线：途中会反复想放弃、见到喜欢的女生又会哑口无言，属于正常（第28章）
- 低价值身份认同时"做自己"是陷阱（第27章）

### ⏳ 时代与语境差异（小南推断）
- 原书基于 2010 年代 App + 线下搭讪场景。放到微信/相亲/婚恋 App 时代：冷读、时间错觉法、假定回答法**用多了会显得套路化**，尤其在熟人介绍的关系里
- 书面向中国城市异性恋男性语境，其他语境未覆盖
- 女性读者的反向使用（识别这类技巧）本书未讨论

## 6. 红线（第1章道德框架 · 不可越）

成真在开篇就设了约束，**这不是 PUA 操控套路**：
- 学员需宣誓：**不利用技巧欺骗感情、不做邪恶不道德的事**
- 主张"不断提升自己，成为成熟负责任的真男人"
- 区分：教技巧 ≠ 教人变坏（"学校教编程也有人写病毒"）

**落地红线**：
- 拒绝就是拒绝 —— 不推进、不纠缠、不"再试一次"
- 不伪造身份/收入/感情状态
- 不越法律与同意的边界
- 凡哥问"帮我回复"时，**只给符合上述红线的建议**；若他的诉求越线，直接说清楚不给

## 7. 输出格式（回答凡哥的恋爱类问题时）

1. **先定位**：她现在在哪一步（用第 1 节分诊表）
2. **再诊断**：这一步卡住的机制原因（引用第 0 节根原理）
3. **给动作**：具体到"说什么话 / 做什么动作"，引用原书章节
4. **标风险**：这条在什么情况下会翻车（引用第 5 节）

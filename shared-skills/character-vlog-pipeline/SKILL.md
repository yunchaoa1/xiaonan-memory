# 角色vlog管线

## 三步流程

### 第一步：角色底板（从成长故事提炼）

从成长故事中提取，输出格式：

```
- 一句话人设
- 优点（5条，每条标注故事来源）
- 缺点（4条，每条标注故事来源）
- 隐藏面（2-3条）
- 爱好（6-7条，带细节）
- 特长（4-5条）
- 日常vlog风格（语气/节奏/画面/情绪/禁忌）
- 选题方向（7个可复用模板）
```

### 第二步：vlog文案 → 分镜脚本

凡哥给出文案 → 你输出分镜。规则：

1. **逐句自然分段**：按语义和情绪转折切镜
2. **每镜≤15秒**：口语语速约3-4字/秒，中文台词按字数/3估算秒数
3. **短镜合并**：5秒以内的镜号和前/后镜合并，总长控制在15秒内
4. **每镜必须含**：画面描述 + 动作 + 台词
5. **输出总结表**：镜号/时长/情绪/景别 四列

### 第三步：情绪总结表格式

| 镜号 | 时长 | 情绪 | 景别 |
|:---:|:---:|------|:---:|
| 1 | Xs | 情绪词 | 景别词 |

## 景别参考
- 自拍近景：手机自拍距离，脸+肩
- 中景：上身+背景
- 全景：全身+环境
- 远景剪影：全身+逆光
- 仰拍：低角度，强调力量
- 前景虚化：背景柔和光斑

## 情绪词参考
活泼/温暖/真诚/亲密/轻松/坚定/俏皮/开放/余音

# 量体 / 尺码 / 面料 对照表

> 来源：侃哥讲男生穿搭 9 条口播转写（`穿搭干货-侃哥.md`，2026-10-20 实测转写）
> 用途：给凡哥这类**微胖 + 湿热地区 + 机洗不熨**的人，把"买什么码/什么料"落到具体数字。

---

## 一、量体七项（唯一要他动手的部分，量一次管很久）

穿贴身衣物量，别穿外裤量腰围。没软尺 → 绳子绕一圈 + 直尺量绳长。

| # | 项目 | 怎么量 | 用途 |
|---|---|---|---|
| 1 | **净胸围** | 腋下最丰满处水平绕一圈，后背走肩胛骨下沿，贴而不勒 | **最重要**，成衣码靠它 |
| 2 | 腰围 | **肚脐水平**（不是裤腰位置） | 裤子/松紧 |
| 3 | 臀围 | 臀部最凸处 | 裤型（锥形/直筒） |
| 4 | 大腿围 | 大腿最粗处 | 裤腿宽度 = 大腿围 +5~6cm |
| 5 | 裤长 | 光脚站直，地面到**胯骨最高点** | 长裤选码 |
| 6 | 肩宽 | 两肩骨最外点直线距离 | 定肩线/是否落肩 |
| 7 | 衣长参考 | 现在最合适的短袖，肩缝量到下摆 | 衣长对照 |

**松紧标准**：能塞进一根手指、尺子不往下掉。**正常呼气末读数**，别吸气憋着（能小 2–3cm）。

## 二、公式（侃哥原话）

- **裤长 = 身高 × 0.575，上下浮动 1cm**
  - 172 → **98.9**，区间 **97.9–99.9**
- **五分裤长 = 身高 × 0.285** → 172 → **49.0**
  - 六分 = +5~6cm → 54–55；四分 = −5~6cm → 43–44
- **裤腿围 = 净大腿围 + 5~6cm**（太紧像精神小伙，太宽显腿短）
- 备用笨办法：光脚从地面量到胯骨最高点 = 适合的裤长

## 三、尺码表怎么读

**核心认知：体重决定不了尺码，胸围才决定。** 同样 90kg，肩宽的穿 L、肚子大的穿 XL，可能俩人都不合身。

只看三行，其它先别看：

1. **胸围（最优先）**：成衣胸围 = 净胸围 **+8~12cm**
2. **衣长**：对照量体的第 7 项
3. **肩宽**：成衣肩宽 = 净肩宽 **+0~2cm**；超 2cm 即落肩（可穿，但要知道）

三条实话：

- 同品牌不同款尺码都不一样，别记"我穿 L"
- "修身版/合体版/宽松版"同样的码，上身差一大截
- 跨境（欧码/日码）别按国内码推

## 四、面料

### 克重（短袖）

| 克重 | 判断 |
|---|---|
| <160g | 薄、透、贴肉 → 跳过 |
| **180–220g** | **不透、有骨架、不软塌 → 目标区间** |
| >240g | 太厚，湿热地区闷 |

### 成分

| 成分 | 结论 |
|---|---|
| 珠地棉（pique，polo 那种针织） | **最优先**：有肌理、撑得住版型、机洗甩干不皱、透气 |
| 涤/锦 + 氨纶（哑光速干挺括） | 免熨第一，快干、防晒 |
| 免烫处理棉衬衫（resin） | 见客户那套用，商品页会写"免烫/易打理" |
| 泡泡纱 seersucker | 皱就是它的样子，免熨；**有膨胀感，必须深色** |
| 莫代尔 / 天丝 / 冰丝 / 粘纤 | 软塌贴肉 → 跳过 |
| 亚麻、亚麻混纺 | 透气但一坐一身褶，不熨没法穿 → 跳过（除非他愿意熨） |
| 亮面聚酯 | 又闷又廉价 |

### 四个劝退词（商品页看到就提高警惕）

1. **"垂坠感"** ＝ 贴肉
2. **"冰丝 / 凉感"** ＝ 薄软化纤，显肚子
3. **"修身 / 显瘦剪裁"** ＝ 微胖会反向更显胖
4. **"oversize / 宽松落肩"** ＝ 过胖别穿

## 五、版型与穿着铁律

- **合身最重要**（不修身、不 oversize）——衣服大一号遮肉反而更显胖
- **胖子四条**：上深下浅（拉长）／内浅外深（收腰）／合身不 oversize／面料别软塌
- **正肩 vs 落肩**：胖子两者都能穿，**落肩穿得好把胖变壮**；正肩受版型限制偏修身，把肉凸显出来。但落肩≠oversize
- **领型**：小圆领要够紧实（洗两次变荷叶边就像睡衣）；开领（古巴领/衬衫领）拉长颈部
- **polo 挑法**：领子要挺（软趴领是油腻感主源）、袖口到二头肌中段、衣长盖住腰带但不超过臀线一半、别选横条纹和大 logo
- **裤子**：高腰把腹部收进腰线（但大肚子别勒）、直筒或锥形、别低腰别紧身

## 六、试穿与退换（把退货率压下来）

1. 没 7 天无理由的店，别买第一件
2. 吊牌别剪，试穿前洗手、别喷香水
3. 一次买相邻两个码，留一件退一件（运费比折腾便宜）
4. **30 秒判死顺序**：抬手（衣摆会不会翻上去露肚子）→ 坐下（肚子那圈绷不绷）→ 侧身照镜子（侧面厚度最真实）→ 看肩缝（落肩峰还是滑到胳膊）
5. 裤子单独：蹲一下，腰后空一大块＝腰大了，别硬留

---

## 七、三秒自检（不懂穿搭也能判）

穿好站镜子前，三句有一句不过就换：

1. 肩线对不对（挂在肩上，还是垮在胳膊上）
2. 腰线在哪（肚子最粗处是贴着还是顺下来）
3. 裤脚在哪（堆在鞋面上＝显矮；过膝＝显腿短）

---

## 八、免熨的 0 成本动作

**机洗脱水完，立刻拿出来抖平、用宽肩衣架挂起来。**

- 不叫熨，叫挂干，省掉八成褶皱
- 别用细铁丝衣架（肩部顶出两个包，那件衣服就废了）
- 深色反面朝外晾，防褪色
- ⚠️ 脱水后堆在洗衣机里半小时，什么免熨面料都得皱

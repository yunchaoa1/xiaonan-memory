## 二、结论：问题是「屏障」，不是「美白 / 控油 / 抗老」

三条证据指向同一件事：

- 干皮 = 皮脂少、锁水差 → 屏障偏弱
- 晒狠了脱皮 → 屏障已经被破坏过
- 海口全年强紫外线 → 屏障持续被攻击

## 三、优先级（硬顺序，不许打乱）

1. **防晒** —— 第一位。不是为了不黑，是为了不脱皮
2. **保湿修护** —— 神经酰胺 / 甘油 / 透明质酸；干皮"封闭锁水"比"补水"更关键
3. **避开刺激** —— 酒精、皂基、高浓度酸、磨砂、热水
4. **美白 / 抗老** —— 屏障没修好之前一律押后

⚠️ 这是通用皮肤科学共识套在他已知信息上推的方向，**不是诊断**。持续泛红 / 脱屑 / 湿疹 → 让他去皮肤科。

## 四、硬技巧一：看备案号就能判「有没有防晒」

中国把防晒列为**特殊化妆品**，必须有「国妆特字」批号才能加防晒剂。

| 备案号常见前缀 | 含义 |
|---|---|
| `国妆特字…` | 特殊化妆品（防晒 / 美白 / 染发等）→ **可能含防晒剂** |
| `京G妆网备字…` `粤G妆网备字…` `沪G妆网备字…` | **普通化妆品 → 法规上不许加防晒剂，必然没有防晒能力** |

**案例**：凡哥的大宝维生素 E 乳（增强版）备案 `京G妆网备字2022000741`。
所以「它不含防晒」是**法规推论，不是猜配方**。

这条对任何产品都成立 —— 一秒出结论，根本不用查成分表。

## 五、硬技巧二：具体成分表查不到时，别死磕搜索

2026-11-11 实测：搜「大宝维生素E乳 成分表」「大宝维生素E乳 京东」，返回的**全是京东 / 天猫商品列表页**，没有一份可靠成分表；Tavily 还会撞日限额，`web_extract` 走 keyless Exa 也会直接失败。

**正解顺序**：

1. 先看**备案号**能推出什么（技巧一）
2. 让凡哥**拍一张瓶身背面的成分表** —— 那个比任何网站都权威
3. 最后才用成分数据库补

**别把「搜不到」写成「查过了」。** 凡哥对"有依据"这件事很认真，含糊过去会掉信任。

## 六、大宝维生素 E 乳 · 评估底稿

**增强版**（查到了）：甘油、生育酚乙酸酯、生育酚（维 E）、水解透明质酸、透明质酸钠、SOD、人参提取物
→ 保湿为主；维 E 主要做抗氧化，浓度不足以当抗老用。

**经典款**（100ml / 300ml）：**具体成分未核实**，需瓶身照。

**判断（三句）**：

| | |
|---|---|
| 有用的 | 保湿够、便宜、温和 —— **不用扔** |
| 缺的 | ① 完全没有防晒（法规决定）② 晚上零护理（夜间正是修护期）③ 没有屏障修护成分 |
| 一句话 | **这瓶乳解决了"不干"，没解决"不晒伤"。在海口，防晒是命门。** |

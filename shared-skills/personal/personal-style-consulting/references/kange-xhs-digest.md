## 1. 胖子夏天四大技巧（最核心，一条视频讲完）

1. **上衣深色、下装浅色** → 拉长身形、调整比例 `[原文]`
2. **内浅外深** → 视觉收腰、调整宽度比例 `[原文]`
3. **版型别过于修身，也别 oversize；体型过胖，合身最重要** `[原文]`
4. **面料别选柔软贴身的**；要"户外的"面料 `[原文]`（"缩质"疑为**挺括/速干** `[存疑]`）

配套避雷（原话排比）：穿过期的六七分裤、穿修身衣服、穿跨栏背心或大领口、不爱理发、穿亮丽的膨胀色。

## 2. 裤子两个公式（数字化，最好用）

- **裤长 = 身高 × 0.575，上下浮动 1cm** `[原文]`
  - 172cm → **98–100cm**
  - 更笨但更准的办法：**光脚从地面量到胯骨最高点**
- **腿围 = 净腿围 + 5~6cm** `[原文]`（太紧像精神小伙，太松显腿短）
- **短裤长度 = 身高 × 0.285** = 标准五分裤；+5~6cm 是六分，−5~6cm 是四分 `[原文]`
  - 172cm → 五分 **49cm** / 六分 54–55 / 四分 43–44
  - 通勤建议长度：膝盖上下 5cm

## 3. 正肩 vs 落肩（反常识，值得记）

- **胖子正肩、落肩都能穿**；落肩穿得好"让你的胖变成壮" `[原文]`
- 正肩版型常偏瘦偏修身，**把肉凸显出来反而更显胖** `[原文]`
- **瘦子别穿正肩**（显头大、身子单薄）`[原文]`
- 搭配维度：**衬衫/西服内搭选正肩；要塞进裤子也选正肩**（落肩 oversize 塞进去不伦不类）；**休闲大胆落肩** `[原文]`

## 4. 配色

**分肤色的两套（关键：先知道自己底色）**

- 白皮可穿：藏青配灰 / 卡其配军绿 / 脏菊（疑为**脏橘**`[存疑]`）配大地色 / 黑配牛仔蓝 `[原文]`
- 黄黑皮：避开**大地色系**（"打屁色系"`[存疑]`，但裤子离脸远可以穿）、**荧光色**、**马卡龙色**（浅绿/湖水蓝/淡粉）；走**冷暗色系** `[原文]`
- 通用：**饱和度越高越土气**；亮面廉价；横条纹显宽 `[原文 + 我推]`

## 5. 其他避雷（合并）

- 短裤：过期的六七分裤、廉价反光面料、连口（`[存疑]` 疑为**牛仔/工装**）、太短（显腿短）、健身紧身短裤、高饱和度 `[原文]`
- 细节：卡袖（紧身）T 恤、裤兜塞满东西鼓成一包、**起球的袜子**、印大头像的衣服 `[原文]`
- 夏天最土：跨栏背心、大领口 `[原文]`

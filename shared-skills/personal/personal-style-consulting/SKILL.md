## 铁律（2026-10-20 他当面纠正过的，别再犯）

1. **他说的"准备"不是"买"。** 原话："我并不是现在要买，我的意思是你现在是了解我为主，并且我们准备好我购物之前的所有准备。"
   → **凡是"买哪件/什么价位/推店铺"的问题先押后**，等他说要买再问。现在只问"了解这个人"的问题。
2. **一次只问一条，答一条落一条进档案。** 抛多条他会说"太多了"。问完立刻写文件，别攒着。
3. **不许猜身体数据。** 肤色、尺码、围度，没照片没实测就坦白说"只能你说"。本机没有任何他的照片（图片目录全是素材和 logo）。
4. **先骨架后细节。** 他明确"先攻通勤"——六种场合（通勤/见客户/约会/在家买菜/海边）**不同时做**，一个一个来，其余等他提。
5. **说人话**：结论在前、依据在后、少表格；每条结论标清是博主说的还是我推的。

## 已确认的口径（不要再问一遍）

- **172cm / 180 斤 / BMI 30.4 / 苹果型，肚子明显突出**
- **海口常驻**：全年无冬，四季短袖，三季短裤，最冷半个月加薄外套；湿热 + 紫外线强
- **底色白，但易晒黑、晒狠了先红再脱皮** → 肤色是一年内在变的，**防晒决定他能穿哪套颜色**
- **衣服机洗、不熨** → 面料只能选免熨类（珠地棉最优、免烫衬衫、速干混纺、泡泡纱选深色）；亚麻和薄软纯棉直接排除
- **四套通勤**：上深下浅 / 内浅外深（深色薄衬衫当防晒衣）/ 同色深浅 / 藏青古巴领（见客户）
- **版型数字**：短袖胸围余量 8–12cm；短裤 49cm（172×0.285）、六分 54–55、四分 43–44；长裤 98–100cm（或光脚量到胯骨最高点）；裤型直筒或微锥带褶
- **理发**：侃哥原话"本来就胖，夏天还不爱理发，你不邋遢谁邋遢"——0 成本的形象分

## 博主知识怎么学（可复用流程）

1. **筛人标准两条，缺一不可**：① 讲**底层逻辑**（公式/原理，不是抄搭配）② **身材像他**。
   ⚠️ 瘦高型博主（如卡Q因 179/132）的技巧**在他身上会反向失效**（例：塞衣角→肚子顶出来）。
2. **抓取**：走 `camoufox-antidetect` 的小红书链路（慢速 25–40 秒/动作，一次 ≤10 主页，见 captcha 立刻停）。
3. **这类干货号的正文在视频里**，页面上只有标签 → 必须下载视频 + 本地转写。
4. **提炼纪律**：
   - 同音错词**如实标"存疑"**，不替博主编圆（例："户外的缩质面料"→疑为挺括/速干）
   - **卖货号只取逻辑不取单品**（他主页写"同款看收藏"，单品推荐带利益）
   - **说反话的那条要识别出来**（《男生夏季这样搜》通篇是"别跟我搜一样怕你太帅"，不能当规矩用）
5. 成稿标三种来源：`[侃]` 博主原话 / `[推]` 小南推的 / `[待验证]` 没实测。

## 输出方案的标准形状

- 先给**三条地基**（合身 / 面料有骨架 / 深色为主），再给**四套**（周一~周四轮），最后给**买时拿哪几个数卡**
- 每套写清：上 / 下 / 鞋 + **一句为什么**
- 结尾单列**"我没把握的"**：鞋（侃哥没系统讲，待补）、具体尺码（需量体）——**不装懂**

## 已知坑

1. **别推荐要熨的东西**（亚麻、府绸衬衫、重磅纯棉衬衫）——他机洗不熨，皱的比软塌还难看。
2. **"穿大一号遮肉"是错的**，侃哥原话是既别修身也别 oversize，**合身最重要**。
3. **落肩 ≠ oversize**：胖人可以穿落肩（把胖变壮），但肩宽身子也宽就是灾难。
4. **防晒不是美白，是止损**：他晒狠了脱皮 = 屏障受损，这条接护肤线第一顺位。
5. 别一次把六种场合全铺开，他会觉得没重点。

## 决策框架

### 买衣服 → 六问（按顺序，任一不过就否）

1. **季节**：在海口能穿几季？只能穿 1 个月的秋冬外套优先级最低。
2. **面料**：透气排汗吗？**贴不贴身**？（薄软针织/莫代尔贴身 = 直接勾出肚子，否）
3. **肩线**：肩宽对不对？肩线是版型的生命，肩不合基本没法改。
4. **腹部余量**：肚子处有没有立体余量？衣长盖不盖肚？裤腰够不够高（低腰=灾难）？
5. **搭配**：跟现有衣服能不能搭出 3 套？搭不出 = 单件孤岛。
6. **退换**：能退吗？不能退的必须先对尺码再买。

### 买护肤品 → 五问

1. **先诊断**：凡哥现在皮肤状况是什么？（没诊断不推产品）
2. **有效成分 + 浓度**：不是看"含XX"，是看够不够起效浓度。
3. **过敏黑名单**：档案里的禁忌成分先过一遍。
4. **耐受**：A醇/酸类要不要建立耐受、怎么建。
5. **备案**：国家药监局「化妆品监管 APP」查得到备案号吗？

## 尺码判断（硬规矩）

**不看 S/M/L，只看数据**：肩宽 → 胸围 → 衣长 → 袖长；裤子看腰围（含松量）+ 臀围 + 裤长。
拿商家尺码表逐项对比，**别信"均码""常规版型"这类模糊描述**。

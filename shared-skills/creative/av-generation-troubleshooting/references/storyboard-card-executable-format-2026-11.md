## 二、末位格式：每镜一张小表格，12 个字段

| 项 | 内容示例（镜 01） |
|---|---|
| 场景 | LOC-01 客服三部办公区 |
| 人物 | 林小满（CHAR-01） |
| 道具 | PROP-01 纸箱（抱在胸前，未拆封） |
| 景别 | 全景 → 中景（镜内小幅推近） |
| 机位 | 视平线高度，距门口约 4 米，从办公室最里端朝门口方向拍，人不正对镜头 |
| **占框** | 初：全身占画高 55%，横坐标 30%，身体朝向办公室深处；终点：占画高 70%，横坐标 35%，推近约 15%，头顶留白约一掌宽 |
| **△ 动作** | 抱箱从门口进来，箱子挡到下巴 → 侧身绕过两排工位 → 在角落空位停下 → 弯腰放下 → 直起身喘气 |
| 台词 | 无 |
| **情绪** | 起：怕被人听见；转：说出口时的犹豫；落：说完立刻装回没事 |
| 光 | 冷白日光灯，头顶有一支频闪；窗光从身后打进来，正面偏暗 |
| 音效 | 键盘声连成一片、日光灯频闪的电流声、纸箱放桌上的闷响 |
| **参考图** | LOC-01 机位① + CHAR-01 四视图 + PROP-01 |

后面附**通用设定**（画幅、画风、色彩、全片不用旁白/字幕卡/闪回）和**人物状态锚表**（每个角色的外观锚、声音、能力、代价、弧线）。

## 三、这套为什么有效（三样东西）

1. **占框写死数字**：百分比 + 横坐标 + 头顶留白。模型不用猜人多大、站哪儿。
2. **动作写成箭头链**：每一步都是一个物理上能拍的动作，不是"她显得很低落"这种形容。
3. **所有东西带编号**：`CHAR-01`／`LOC-01`／`PROP-01` 全片一致，**参考图直接列出三件套**（场景机位图 + 角色四视图 + 道具图）。

还有一条容易忽略：**这套分镜只写"怎么拍"，不写提示词。** 提示词是下一步的事。混在一起写，两边都写不实。

## 四、分镜格式怎么选（两种不是一回事，别串）

| 场合 | 用什么 | 产出 | 特征 |
|---|---|---|---|
| **要先看清"戏怎么演"** | `sd-storyboard-engine` | 文字分镜稿 | 九字段（场景/画面内容/状态/光影/色调/台词/重音/人声/音效）；台词零擅删；每句台词挂「神态+动作」；表演三要素 |
| **要直接拿去拍** | **末位格式镜卡** | 可执行镜卡 | 景别/机位/**占框数字**/**△动作箭头链**/情绪起转折落/**参考图三件套** |

**两者的差别不是详略，是"有没有拍片要用的数字"。** 九字段能告诉你这场戏在演什么、什么情绪，但拍不出来 —— 缺景别、缺机位、缺占框、缺参考图清单。

**判断口诀**：这一镜的产出要不要直接喂给出图/出视频？要 → 末位格式。只是给导演/制片看戏 → 九字段。

## 五、这次翻车的完整链（一条一条）

| # | 错在哪 | 后果 |
|---|---|---|
| 1 | 用九字段当拍片镜卡 | 没有占框/机位/参考图清单，模型自由发挥 |
| 2 | 一颗塞 3–4 段（3–4 个切点） | 稳定性崩，H3 自己重新导演 |
| 3 | 复用旧剪影项目的一张双人对坐图 | 图里没有"咨询师 vs 来访者"的关系 → 画成恋人 |
| 4 | 提示词全英文、没喂参考音频 | H3 自编英文语音，口型跟着英文走 |
| 5 | 方位写"左下右上" | 违反主体自身方向锚定（写 `in front of her` / `half a step behind him to his right`） |

## 六、重做时的正确顺序

```
① 台词稿（纯台词，一句不删）
② 补资产：场景机位图（正反打各一 + 双人正面）+ 人物四视图 + 道具图，一件一张
      → 出图提示词必须写死人与人的物理关系（隔茶几一米六/前倾不越桌沿/肩内收）
③ 写末位格式镜卡（12 字段齐全，一镜一机位，4–9 秒）
④ 每镜配音单独生成，与镜卡一一对应
⑤ 每镜一个 H3 任务：喂 场景图 + 人物图 + 该镜配音（ref_audios），一镜一刀不切
⑥ 抽末段帧 + 联系表验收（见 SKILL.md 验收纪律）
⑦ 合成：按配音时间轴排、定格补时长、字幕按标点断行
```

## 七、工时对照（供排期用，本机 5080 16G）

| 做法 | 一镜时长 | 单镜耗时 | 49 镜总计 |
|---|---|---|---|
| 错误版（16 颗，每颗塞 3–4 段） | 12–15 秒 | 约 15 分钟 | 约 4 小时（全废） |
| 正确版（一镜一机位） | 4–9 秒 | 约 10 分钟 | 约 8 小时 |

**正确做法慢一倍以上，但错误做法是 0 产出。** 排期时别按"快的那个"报时间。

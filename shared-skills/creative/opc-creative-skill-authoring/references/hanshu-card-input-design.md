# 汉语镜头卡：OPC 生视频节点输入层设计（凡哥 2026-09-07 确认定稿）

## 产品背景

客户可能不用 OPC 全链路（写作→剧本→分镜），自己已有剧本分镜，只用 OPC 生视频。同时 OPC 通用原则：**每个节点的内容来自上一节点，且在本节点可编辑**。生视频节点的界面形态因此是「汉语镜头卡」——用户（客户）看到的、编辑的、提交的全是中文创作语言；**模型身份（H3）与专业提示词格式全部藏在后台，客户不可见**。

凡哥原话："写清楚参考图参考什么维度，音色参考哪个音频，内容走向是什么，然后点击生成时，自动把这些内容转成 H3 专业提示词格式……我不想让客户知道我们的模型是 H3"；"不要那么规范，不要出现 H3 要求的专业内容"。

## 汉语镜头卡字段（界面=中文、可编辑）

1. **这一镜拍什么（内容走向）**：自由中文文本，可写得很随意（"母亲一边揉面一边说……说到一半停下手"）。→ 后台翻译为 H3 的 starting/action 段。
2. **谁说话，说什么**：中文台词（谁+语气提示+内容）。→ 后台进 `<d>…</d>` 格式并绑说话人。
3. **出场人物**：参考图卡片，每张**标注参考维度**（"母亲 参考：长相·发型·围裙"、"周野 参考：长相·服装"），可勾选/换图。→ 后台生成 subject_definitions 的 `<Subject N> is … in <Picture N>` 绑定。
4. **场景环境**：场景参考图卡片（标注"参考：空间布局·光线"），通常由上游自动带入。
5. **说话声音参考（音色）**：音频下拉/选择器，标明"谁的声音·什么气质"（如"母亲声音参考·低沉温和.wav"）。→ 后台挂 refAudio。
6. **镜头怎么动**：中文选项（近景·固定机位缓慢推近 / 中景 / 特写·手部…）。→ 后台翻译 camera 段（no-cuts 句式）。
7. **氛围基调**：中文选项（平静里带着一点心事 / 轻松温暖 / 压抑克制…）。→ 后台进 style/emotion 段。
8. 时长等由分镜卡带入，显示为中文信息。

## 转换层（点【生成】时后台自动执行，客户不可见）

- 读汉语卡 → 拆字段 → 翻译+清洗（禁否定词/禁机位矛盾/官方语法约束，规则来自 minimax-h3-shot-prompt）→ 绑定参考图/音色 → 填入公共参数（画风、分辨率、seed、采样）→ 提交生成。
- 界面文案、字段、选项**一律不出现**：H3、模型名、英文提示词、`<Subject>`、`<Picture>`、seed、fps 等技术词。
- 这个"后台翻译"不是让客户写自然话让 agent 发挥——而是**界面本来就是汉语可编辑卡**，用户点生成才触发规则化转换。

## 给平台同事的注意

- 汉语卡是**前端输入形态**，H3 六段是**后台生成格式**——两者之间是规则转换层，不是自由发挥层。
- 上游节点产物填入汉语卡时可编辑（内容走向/台词/选图/音色/镜头），但参考图绑定关系和状态（帽/围裙等）有上游锁定语义，界面编辑要能追溯回上游产物。

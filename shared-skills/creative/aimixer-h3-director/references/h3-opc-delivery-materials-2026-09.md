## 四条纠正（均凡哥原话）

1. **「不要故事板了，给我去掉故事板的版本」** → 交付 = **参考图 + 提示词** 两件套；"含故事板版/去故事板版"是两种交付变体。
   去故事板三步删除 + 重编号：
   - ① 删上传槽位表的故事板行；
   - ② 删 `subject_definitions` 里 `<Picture N> is a storyboard reference ...` 绑定句；
   - ③ 删 `retention_analysis` 故事板行；
   - ④ 剩余 `<Picture N>` 无缝重编号（每镜从 1 起），保持顺序 人物 → 场景 → 道具；
   - ⑤ 机位/构图/镜序全部由 `detailed_description` 正文承担（写死景别与机位）；
   - ⑥ 交付前 `grep -E 'storyboard|分镜|四格|P7'` → 0 残留。
2. **「提示词就直接给我正文就行了，直接发给我，不用管那么分类去写」** → 给凡哥本人 = **聊天直发正文**，无槽位表/README 包装。含 `<Subject N>` / `<Picture N>` / `<d>` 标签的正文要套一层代码框（否则聊天渲染吞标签，附一句说明即可）；纯中文提示词不加框。文件夹 + zip + README 只用于给外部的交接包（如小何）。
3. **「直出15秒视频，懂不？」** → **一条提示词直出**，禁止拆成 3×5s 分别生成再拼。`duration=15` → 362 帧（17k+5 上限，24fps）。内部 4 个 `[Shot]` 切点写毫秒时间戳：`00:00.000 / 00:04.000 / 00:08.000 / 00:11.000`（段长 4/4/3/4s）。15s 塞 4 切点偏密 → 回退方案 = 删一个切点、同 `[Shot]` 内连续动作（小幅缓推）。
4. **授权边界**：材料类需求不得自发起测试——不主动连云端、不要求装公钥/贴凭据、不代跑出片（"谁让你自己测试了？我跟你说的？"）。跑片由凡哥发起或他明确指派。

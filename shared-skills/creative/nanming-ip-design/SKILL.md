# 南溟岛 IP 设计工作流

> 凡哥的57角色（38正派+19反派）异世界IP设计标准操作流程

## 反派设计强制模板

所有反派角色必须使用以下统一模板，不可自创格式：

```
| 项目 | 内容 |
|------|------|
| 正派 | 该市县的2个正派角色 |
| 反派 | 名称 |
| 类型 | 完全黑化者 / 心魔合成体 / 人魔共生体 / 心魔聚合体 |
| 心魔 | 从57条心魔谱系中选取2-3条 |
| 记忆锚点 | 真实存在的物理载体（建筑/景观/物件） |
| 代表 | 一句话概括这个反派在替什么东西发声 |

### 诱因 · 真实历史
[真实存在的海南历史事件/地标/传说。必须是可查证的，不能虚构。]

### 人物故事
[完整的叙事段落，像霍启明那样有细节、有转折、有台词。]

### 共鸣锚点
[一个真实存在的物理锚点——建筑、自然景观、物件。反派和这个锚点之间有深层的情绪连接。]

### 跨界
[心魔如何同时绑定真实海南和南溟岛的反派。一句话。]

### 与正派关系
[反派与正派的戏剧冲突。不只是"敌人"，要有具体的互动和张力。]
```

## 反派设计五大铁律

所有反派必须过这五关，缺一不可：

| # | 铁律 | 含义 | 检查方式 |
|:---:|------|------|------|
| ① | **心魔** | 57条必须用，不能凭空编 | 每个反派对应明确编号 |
| ② | **地域真实** | 不能完全虚构，锚点要可查 | 真实地标+真实事件/传说 |
| ③ | **伤害性大** | 共鸣要广，不能只是个人悲剧 | 影响面大、观众能共情 |
| ④ | **避雷** | 不碰政府、正面历史人物、国保文物 | 每一个都要过 |
| ⑤ | **三段完整** | 诱因→载体→破坏必须闭环 | 缺一段=反派不成立 |

### ⑤三段结构详解

每个反派必须有独立的三段：

| 段 | 含义 | 范例（晶骸） |
|:---:|------|------|
| **诱因** | 心魔诞生的根源 | 矿难中死去的矿工被压在水晶下 |
| **载体** | 反派以什么形态存在/行动 | 几十具遗骸被水晶熔成的骨晶共生体 |
| **破坏** | 明确的、可量化的伤害 | 对视石化活人、触水变黑、金属剥漆 |

⚠️ **破坏不能虚构环境污染、建筑损毁等影响真实地标的内容**。省级文保/旅游景区不能写"倒塌""污染""封闭"。破坏必须是超自然的（石化、意识操控），或仅影响反派自身周围的微观环境。

## 内容拆分架构

南溟岛所有文档按以下目录结构组织：

```
world/          ← 世界观（六界、六阶、心魔、频道、穿越、角色、关系、反派、历史）
tech/           ← 技术管线（三步法、ComfyUI）
personal/       ← 个人发展（学英语等）
heart-demons/   ← 心魔谱系四卷（独立文件）
characters/     ← 38角色提示词
```

原则：每个文件只含一个主题，树点击直接打开对应小文件，不再大海捞针。

## 网络搜索方法

凡哥公司网络环境受限，不同搜索引擎可用性不稳定。搜索时必须按以下优先级尝试：

| 优先级 | 引擎 | 方法 | 稳定性 |
|:---:|------|------|:---:|
| 1 | 360搜索 | `execute_code` + `urllib` 请求 `https://www.so.com/s?q=...` | ⭐⭐⭐ 最优 |
| 2 | 头条搜索 | `execute_code` + `urllib` 请求 `https://so.toutiao.com/search?keyword=...` | ⭐⭐ 可用 |
| 3 | 搜狗 | terminal `curl` | ⭐ 频繁崩 |
| 4 | 必应 | terminal `curl` | ❌ 返回垃圾 |
| 5 | 百度/Google | 任何方式 | ❌ 全封 |

**关键：不要用浏览器(Browserbase)搜索中文网站**——全部被拦截或返回空页。用 `execute_code` + Python `urllib`。

搜索技巧：
- 提取结果用 `re.findall(r'>([^<]{15,400})<', html)` 获取文本片段
- 带关键词过滤去重
- 搜不到就说搜不到，不要虚构

## 反派类型体系（完整版）

| 类型 | 定义 | 示例 |
|------|------|------|
| **完全黑化者** | 人被心魔日积月累带偏 | 绯羽·烈 |
| **心魔合成体** | 单一执念凝结成形 | 老犁 |
| **人魔共生体** | 角色主动选择与心魔共存 | 老木 |
| **心魔聚合体** | 客观环境因素长期累积，非主观怨念 | 泥喉、旱喉、欲潮 |
| **BOSS级** | 心魔本身长大到能操控天象/气候 | 风喉、白骨礁 |
| **远古残留体** | 仅存于南溟岛，现实中已消失的蛮荒之物 | 沼心、绞藤、瘴母 |

### 远古残留体设计规范（2026-07-03新增）

当城市搜不到暗面时，可设计**仅存于南溟岛**的远古反派：
- 锚点必须是该市县古代真实存在过的地貌/生态（如万泉河古沼泽、分界洲古藤林），"古代有、现代无"属于合理推测
- 破坏不碰现实世界——现实没有这个反派
- 正派的斗争只在南溟岛进行
- 给正派埋下"防止渗透进现实"的伏笔
- 详情见 `references/19反派全谱.md`

### 文件操作：追加新内容到大型反派文件

大型文件（如19反派设计.md）追加新section时，`patch` 的 `---` 分隔符会匹配到多处。使用 `execute_code` 追加：

```python
with open(file, 'r') as f: content = f.read()
content = content + new_villain_text  # 直接拼接
with open(file, 'w') as f: f.write(content)
```

替换已有section时，写入临时文件再用 `execute_code` 做精确替换——避免 `patch` 的字符串匹配歧义。

## 常见错误

| 错误 | 正确做法 |
|------|------|
| 反派模板不统一 | 强制使用统一模板 |
| 虚构不存在的锚点（界碑、影界） | 必须用真实地标/传说 |
| 硬凑锚点和角色的关系 | 锚点和角色之间必须有情绪共鸣 |
| 忽视网络搜索限制 | 搜不到就承认，让凡哥提供信息 |
| 反派和正派锚点冲突 | 反派走"第三个切面" |

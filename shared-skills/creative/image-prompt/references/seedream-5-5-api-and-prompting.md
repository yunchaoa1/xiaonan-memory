# 豆包 Seedream 5.5 出图规范（2026-11-16 实核）

> 用途：凡哥换轨后出图提示词的唯一参数依据。凡哥说"用豆包出图""出图大模型 5.5"时按这里写。

## 一、模型与接口（官方文档核实）

| 项 | 事实 |
|---|---|
| Model ID | `doubao-seedream-5-5-261028` |
| 端点 | `POST https://ark.cn-beijing.volces.com/api/v3/images/generations` |
| 鉴权 | `Authorization: Bearer $ARK_API_KEY`（凡哥提供 key） |
| 能力 | 文生图 / 单图生图 / 多参考图生图，**参考图最多 10 张** |
| 组图 | **不支持** `sequential_image_generation` |
| 透明底 | 支持原生 RGBA：`"background":"transparent"` |
| 提示词语言 | 官方示例全中文自然语言 |

## 二、分辨率（最容易踩的坑）

**只有 1K / 1.5K / 2K 三档，没有 4K。**

| 画幅 | 1K | 1.5K | 2K（上限） |
|---|---|---|---|
| 横 16:9 | 1424×800 | 2048×1152 | **2816×1584** |
| 竖 9:16 | — | — | 1584×2816 |
| 方 1:1 | — | — | 2048×2048 |

`size` 两种写法：`"2K"`（推荐，配合 prompt 里说画幅用途），或直接给 `宽x高`（总像素上限 4624220）。

**凡哥默认要 4K（3840×2160）。用 5.5 时必须提前说清：做不到，最高 2816×1584，要 4K 只能出完再放大。**

## 三、与旧 Qwen 口径的硬差别

1. **不写 4K / 3840 / 8K 级别描述**。
2. **不写 `cfg=1` / negative 通道**这类 Qwen 内部话术 → 换名词列表式排除："墙面上的第二道门、散置的道具、人物、文字，均排除"。
3. **四视图仍可一次直出**，靠 prompt 内宫格描述，不是组图参数。
4. 身份仍靠**参考图指认**，不用文字描述五官（10 张参考图够用：人物四视图 + 场景 + 道具）。

## 四、已验证可用的写法（2026-11-16 一次跑通 13 张资产 + 9 张首帧提示词）

1. **开场句 ＝ 画面是什么**，不用"为 XX 生成…"的任务式开头。
2. **物体流**：一个物体一句——"什么 + 在哪 + 什么材质状态"。
3. **尺度自然句**：把"面宽约四米、进深约五米、高约三米五"写进散文句，防空间被画成井。
4. **排除段 ＝ 名词列表 + "均排除"**：[要做的事]、[不要的元素]、均排除。
5. **风格句收尾**：`中国3D动画电影风格，国漫3D CG渲染，电影级CG渲染，柔和晨光，浅景深。`
6. **四视图宫格写法**（一张图内，四格等宽）：
   - `纯白背景，四个等宽的竖向分区从左到右并排，分区之间用均匀的极细浅灰色细线分隔，整图外边没有边框`
   - 逐格点名：`左侧第一格：正面全身站立…第二格：单张侧面…第三格：背面…第四格：正对镜头的五官特写`
   - 一致性句：`四格是同一个人：脸型、头骨形状、发际线、发型、肤色、服装结构、材质、颜色、年龄状态、身体比例完全一致`
   - 收尾排除：`…第五格、装饰性排版，均排除`

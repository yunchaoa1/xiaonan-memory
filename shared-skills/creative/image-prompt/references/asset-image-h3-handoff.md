# 资产图 → H3 参考图：交付形态与踩过的坑

> 2026-11-19 《末位》第 1 集 12 张资产图实测。凡哥问："道具用 6 宫格去做真的可以用做 H3 的道具资产图吗？"
> 答案：**不能**。同一天还查出场景俯视/平视的分歧，一并记在这。

## 一、为什么人物四视图能喂 H3，道具六宫格不能

| | 人物四视图 | 道具六宫格 |
|---|---|---|
| 每个格子是什么 | **同一个人的四个角度** | **六个不同的东西** |
| H3 怎么理解 | "这是同一个人" ✓ | "图里有六件东西" ✗ |
| 能不能定 `<Subject N>` | 能（整张算一个） | 不能 |

**依据一（我们自己的 H3 技能）**：
> 「多视图角色表算**一个** `<Subject N>`，宫格/边框/水印永远不是内容。」

注意是「角色表」算一个 —— 前提是四格同一个人。六个不同道具没有这个前提。

**依据二（forest-laoli-h3 道具设定图模板）**：
```
[主体] 月白色绣花帕子，棉质，边缘磨毛，角上一朵褪色红梅，展开约 20cm
[版式] 单件居中，微俯视，右下角一枚硬币作尺寸参照
[禁止] 不要文字、不要手、不要光效
```
「单件居中」——一件一张。它还建议放一枚硬币做尺寸参照，能锁住道具实际大小。

**依据三（分辨率）**：2K 横图 2816×1584 切六格 ≈ 每格 938×792，道具本体只占其中一部分。H3 取特征靠像素，糊了会画出"平均道具"——既不像这个也不像那个。

## 二、场景图：俯视 vs 平视，两个技能是打架的

| | 我们原 `subject-assets` | forest-laoli-h3 |
|---|---|---|
| 场景主图 | **正俯视**（锁平面布局） | **平视主视角**，明确「不要俯视图」 |
| 理由 | 俯视看得清墙和门 | 「给它一张多视角拼图，它认不出哪个是"这个空间"，会自己在正文里补空间 —— 补出来的往往是尺度膨胀（一面墙变成照片展厅）」|

**结论：两个都要，按用途分开 ——**
- **俯视图 → 给人看、给分镜定机位**（不进 H3）
- **平视主视角 → 给 H3 当参考图**（这才是 H3 吃的）

**平视主视角的写法要点**：必须写成"能同时看到 3–5 件固定陈设，一件都不出画"，全部用单数（禁 `wall of` / `rows of` 复数扩建词）。H3 是靠"墙上有几件东西、地上有什么"来认这个空间的，写虚了它就乱补。

## 三、《末位》第 1 集实际交付的 12 张

| # | 内容 | 形态 |
|---|---|---|
| 1–5 | 林小满 / 赵鹏 / 李艳 / 周总 / 女同事 | 四视图 |
| 6–8 | 客服三部办公室 / 主管办公室 / 走廊 | 平视主视角 |
| 9–12 | 末位榜单 / 手写记分纸 / 白瓷带盖茶杯 / 牛皮纸文件袋 | 单件居中 |

**只给剧情关键道具出图。** 原剧本还有旧打分表、工牌，没出 —— 它们不是剧情焦点，出了只占槽位（H3 单段图 ≤9）。一集 12 张是上限附近，按镜配图时一次挂 5–6 张就够。

## 四、Seedream 5.5 已验证的六条写法（中文，别再套英文模板）

1. **开场句 = 画面是什么**，不用"为 XX 生成…"的任务式开头
2. **物体流**：一个物体一句 —— 什么 + 在哪 + 什么材质状态
3. **尺度写进散文句**（"面宽约四米、进深约五米、高约三米五"），防空间被画成井
4. **排除段 = 名词列表 + "均排除"**
5. **风格句收尾**：`中国3D动画电影风格，国漫3D CG渲染，电影级CG渲染，柔和晨光，浅景深。`
6. **四视图宫格**：`纯白背景，四个等宽的竖向分区从左到右并排，分区之间用均匀的极细浅灰色细线分隔，整图外边没有边框` + 逐格点名 + 一句"四格是同一个人：脸型、头骨、发际线…完全一致"

**人物四视图补一条**：四格光位必须同一句写死（"四格的光位、色温、亮度完全一致"），否则出图后四格像四个人。

**纸面文字**：榜单/记分纸/工牌一律只写"只有表格线和色块，没有可辨认的字"——生图模型写中文必出乱码，字后面另加。

## 五、出图后的两件必做

**① 去水印**：豆包网页版右下角带"豆包 AI 生成"，固定像素约 300×60、边距 30。用 `scripts/strip_doubao_watermark.py`，**别裁底**（人物图的脚在最下沿）。图尺寸不同水印占比不同，必须按固定像素算。

**② 四视图自检**：四格齐全（防"缺侧面/两个背面"）→ 服装鞋袜跨格一致 → 格间等宽细线、整图无外框。不合格重跑，别往下走（人物图歪了后面全歪）。

## 六、H3 机检（h3_lint.py）的三个已知误报

跑 `forest-laoli-h3/scripts/h3_lint.py` 时这几条要人工判断，别照着瞎改：

| 误报 | 实情 |
|---|---|
| `道具「glass」首现未写支撑` | 写的是 **glass partition（玻璃隔断）**，不是玻璃杯 |
| `同框 3 个人` | 第三个"人"是 `<Subject 5>` **茶杯**（它把所有 Subject 都当人算） |
| `H3 未提供段时长` | 只认全局 `--duration`；但 `--duration` 是全局一个值，多段不同时长时**别传**，传了会给长段误报切点超时长 |

另外 `H5 定义了却未被引用（白占 9 图额度）` 和铁律「每段全挂不省图」不冲突：**挂图**要全挂（省了就 Picture N 错位），**定义**只定义这段真正引用的 Subject。

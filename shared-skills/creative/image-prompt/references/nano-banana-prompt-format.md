# Nano Banana 换装/年龄变化提示词格式

从齐白兰顾蓝汐寻亲剧制作包（`D:\Documents\我的文档\齐白兰顾蓝汐寻亲剧_制作包\03_主体提示词总库\全剧人物场景道具主体提示词.md`）中提取的实测模板。

## 换装等格式

```
以[角色名]角色设定板为唯一身份参考，保持五官、发型、身材和年龄稳定，换成[新服装/配饰描述]。中国院线级半写实3D动漫，输出[左侧头肩大特写与右侧正面、侧面、背面全身三视图 / 正面侧面背面全身三视图与上半身特写]，16比9横版浅灰背景。
```

## 年龄变化格式

```
以[角色名]角色设定板为唯一身份参考，将人物年龄调整为[X]岁的[状态]。保留相同[脸型/特征]，[年龄变化描述]。换成[对应年龄段的服装]。保持中国院线级半写实3D动漫风格。输出[同上]，16比9横版浅灰背景。
```

## 关键要点

1. **以设定板为锚**：每版都写"以XX角色设定板为唯一身份参考"——确保五官稳定不改脸
2. **保持清单**：保持五官、发型、身材和年龄稳定（换装）/ 保持特定面部特征（年龄变化）
3. **画风锁死**：中国院线级半写实3D动漫——每版都重复
4. **输出格式**：左侧头肩大特写 + 右侧正/侧/背全身三视图；或三视图 + 上半身特写
5. **背景**：16比9横版浅灰背景
6. **可加神态**：如"神态警惕而镇定""神态克制"——不笼统写"微笑"

```
以齐镇海现年角色设定板为唯一身份参考，保持五官、脸型、眉骨、银灰短发、年龄纹理和沉稳神态完全不变，换成精致总裁着装：深炭灰精纺高定西装三件套，内搭象牙白法式衬衫，银色袖扣，同色系丝绸领巾自然垂入马甲领口，左胸口袋露出方巾一角，左手保留简洁腕表，右手搭在红木桌面边缘。深色精裁长裤，黑色牛津皮鞋。中国院线级半写实3D动漫，细腻面料与金属质感，输出左侧头肩大特写与右侧正面、侧面、背面全身三视图，16比9横版浅灰背景。
```

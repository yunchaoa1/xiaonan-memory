# AI生图提示词编写

覆盖 z-image（中文语义）、Qwen等生图工具的提示词编写规则。

## 触发条件
凡哥说"帮我写个XX图""生图提示词""z-image""Qwen生成""Banana生图""换装""换行头"时加载。

Nano Banana 换装/年龄变化提示词格式见 `references/nano-banana-prompt-format.md`。

画风提示词（风格堆栈 + 防漂移，5 种画风稳定写法）见 `references/style-prompt-vocabulary.md`。凡哥要求生图指定画风时，必须填完整风格堆栈（正向 + 负向词），禁止笼统词（如裸写 "3D animated film style" 会漂成写实）。

## 核心规则

### 1. 纯正向书写
**绝对不用否定词。** 不要出现"不要""没有""不""避免""去除"等否定表达。
坏："不要有光束" → 好："描写光照效果"
坏："面部不要有瑕疵" → 好："面部肤色均匀自然"

### 2. z-image 用中文语义
z-image 的提示词用中文写，不是英文。语义通顺的自然中文句子。

### 3. 光线描写
不写"光束""光线""射线"这类实体光柱。只描写光照在表面上的效果——明暗过渡、光感、映照。
坏："头顶一束暖光" → 好："面部受暖光映照呈现柔和的明暗过渡"

也可完全不写光线，交给模型自己处理。

### 4. 去AI化分寸
轻轻带过即可，不要过火。
刚好：面部肤色均匀自然
过头：面部可见真实皮肤纹理和微细毛孔（会导致满脸斑点）

### 5. 表情与场景匹配
表情必须符合角色当前的情境，不写笼统的"微笑"。分手情歌→无力感、放空、回忆；欢快歌曲→兴奋、期待。

### 6. 参考图时声明用途
有多张参考图时，说明每张的用途：
图1=人物外貌参考、图2=场景参考

### 7. 简洁为上
凡哥偏好短句、直给、不啰嗦。提示词控制在3-5句话，信息密度高，不堆形容词。

## 典型格式
```
[主体描述]，[姿态动作]，[表情情绪]，[环境背景]，[画质收尾]。
```

## 常见场景模板

**录影棚：**
画面中央专业麦克风立在悬臂支架上，前方一把录音椅，背景纯黑墙壁、画面极简干净，4K画质。

**人物+场景融合（两图参考）：**
图1人物外貌参考与图2场景参考融合：[人物名][姿态动作]，[表情情绪]，衣着妆容与图1一致，[场景描述]，4K画质。

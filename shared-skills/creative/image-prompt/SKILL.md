## Qwen-Image 2.1 提示词规范（官方；写图必读）
**核心原则**：只处理你点名的对象，**其余一切保持输入保真**（编辑类）。防两错：① 动了没让动的 ② 改太弱看不出。

**硬规则**：
1. **保持项"点到为止"**——按类型/位置点名（如"保持背景不变"）即可，**不要具体描述"要保留的东西"**（描述越细，模型越容易把它重新生成弄漂）
2. **身份用图不用字**——人物脸/产品外观靠参考图指认，**禁止用文字描述五官特征**（会损害相似度）
3. **要渲染的文字：引号+逐字**；不能确定的文字不要加
4. **正向式**（"保持背景与输入图完全一致"，不写"禁止改变背景"）
5. **不添加没要求的**（不清理未提及的缺陷/杂物）
6. **多参考图**统一 `<image1>`/`<image2>` 标签，写明每张的角色（画布/素材源）
7. **语言**：中文指令→中文描述；图内文字按"用户指定 > 图中既有文字的主语言 > 指令语言"
8. **比例/分辨率绝不写进描述正文**（只走参数/字段）

**生成类（文生图）体量**：约 20 句 / 400-500 词；观察式、现在时、第三人称；禁用 masterpiece / 8K / highly detailed 类词；颜色带修饰词、给材质、枚举不概括。

## 核心规则

### 1. 纯正向书写
**绝对不用否定词。** 不要出现"不要""没有""不""避免""去除"等否定表达。
坏："不要有光束" → 好："描写光照效果"
坏："面部不要有瑕疵" → 好："面部肤色均匀自然"

### 2. z-image 用中文语义
z-image 的提示词用中文写，不是英文。语义通顺的自然中文句子。

### 3. 光线描写
不写"光束""光线""射线"这类实体光柱。只描写光照在表面上的效果——明暗过渡、光感、映照。
坏："头顶一束暖光" → 好："面部受暖光映照呈现柔和的明暗过渡"

也可完全不写光线，交给模型自己处理。

### 4. 去AI化分寸
轻轻带过即可，不要过火。
刚好：面部肤色均匀自然
过头：面部可见真实皮肤纹理和微细毛孔（会导致满脸斑点）

### 5. 表情与场景匹配
表情必须符合角色当前的情境，不写笼统的"微笑"。分手情歌→无力感、放空、回忆；欢快歌曲→兴奋、期待。

### 6. 参考图时声明用途
有多张参考图时，说明每张的用途：
图1=人物外貌参考、图2=场景参考

### 7. 简洁为上
凡哥偏好短句、直给、不啰嗦。提示词控制在3-5句话，信息密度高，不堆形容词。

## 典型格式
```
[主体描述]，[姿态动作]，[表情情绪]，[环境背景]，[画质收尾]。
```

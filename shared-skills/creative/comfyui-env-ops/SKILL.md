## 一、六条铁律（违反必被当场质疑）

**1. 先取证，再断言**
崩溃先取**完整日志段**（`awk '/got prompt/{b=""}{b=b"\n"$0}END{print b}' log | head`，tail 只见栈尾，真异常在段首）；报错特征怪 → **第一动作是搜官方/社区 issue**，不是改环境。
**凡哥原话**：「你确定吗？依据是什么？」「又是你脑补出来的吧？」

**2. 模型/版本/价格的传闻，只认官方源**
官方 API 列表 + 官方文档。**第三方新闻站（内容农场、互相转引）不能当事实转述**。把"今天几点自动切换"当事实说，必被打回。

**3. 能从源码读出来的，别拿一次真跑去换**
一次 20GB 模型试跑 = 十几分钟 GPU + 一轮上下文。**先 grep 节点源码，读不出再跑**。读出来的标「已确认（源码）」，不标「已实测」。

**4. 第三方库/扩展报错：先做最小隔离复现，再在宿主里猜**
把报错那一步单独拎出来，用 `<venv>/bin/python -` 在纯进程里重跑。
**炸 ⇒ 这个包本身坏了，宿主里怎么调都没用**；不炸 ⇒ 才轮到宿主当嫌疑。
凡哥不容忍「在错误的那一层反复换变量」：「你是不是找不到原因在瞎试？」

**5. 本机环境 ≠ 云端标准版时：改环境，不改工作流（凡哥铁律）**
「以云电脑上跑通的那一版做最终版，不要改任何」。装插件补节点、造目录名（**用 `ln` 硬链接、不要 `ln -s`**，验 `stat -c%h` 应为 2）、名字差一个字也算缺。**对齐方向 = 环境向标准版靠，不是工作流向本机靠。**

**6. 一次只变一个变量；破坏性操作先问**
`退出 134 / Fatal Aborted` = C/CUDA 硬崩，Python 没有 ERROR 行。

## 三、怎么算做完（验证）

| 干完什么 | 验法 |
|---|---|
| 装了插件 | 跑 `--quick-test-for-ci`（不打扰在跑的实例）；再用 `/object_info` 确认节点类出现 |
| 造了硬链接目录 | `stat -c%h` = **2**（不是 1）；`stat -c%s` 与源文件字节完全一致 |
| 补齐缺件 | 再跑一次缺件体检，**目标 0 缺**，才请凡哥开跑 |
| 重启了实例 | `curl -s http://127.0.0.1:<端口>/system_stats` 返 **200** 才算就绪（约 15 秒） |
| 改了启动脚本 | 先 `cp` 出 `.bak.<日期>`，改完把 diff 亮给凡哥 |
| 一切重启前 | `curl -s http://127.0.0.1:<端口>/queue`，`queue_running` / `queue_pending` **都为 0**（他可能在跑图） |

## 四、坑（重复犯过的）

- **端口不一定是 8188** —— 本机实测跑在 **18188**。先问进程要真实端口。
- **界面没进度条 ≠ 卡死** —— 第三方节点不上报进度；`tail -f comfyui.log` 看阶段行、`nvidia-smi` 看 GPU-Util。
- **"第二次跑不采样" = seed 没换**（缓存命中，不是 bug）。
- **同名工作流 ≠ 同一份内容**。
- **`mode=auto` 会判成纯文本生成，参考图一张都不生效、还不报错** → 用参考图就写死 `ref2va`（2026-11-19 实测）。
- **参考图原图（2848×1600 / 4.5MB）直接喂会崩在 VAE 解码**（`Fatal Python error: Aborted`，无 Python ERROR 行）→ 先缩到长边 1024。
- **正文没引用 `<Subject N>`，那张参考图就白挂** → H3 自己编场景。本次实测：段 03 删了书架资产、正文只提了两个人物，**画出来变成了另一间房**（木门/玻璃柜/显示器），跟前后段完全对不上。**这一镜用到哪个空间/道具，正文就必须出现它的 `<Subject N>`**；机检 H5 只报 WARN 不拦投片，跑之前自己清干净。
- **「词数超了就丢动作」是误判** —— 80 词那颗只剩第一个动作，是因为四个动作各写一句、**句句写糊**；同一个 5.17 秒镜头改成 516 词写透物理链，动作全都出来了（2026-11-19 A/B 真跑）→ **管动作条数，别管字数**，见 `references/h3-prompt-length-and-official-guide.md` §六。
- **「顿住两帧 / 冲击帧」这类影视术语 H3 不认**，它当成画面元素 → 改成写可见物理结果（衣服扯紧、重心偏移、道具撞散）。
- **`node_errors` 非空但任务 success = 有支路被静默跳过**（本例二采不跑、只出一采 960×544）→ 去 `outputs` 数文件个数，别只看 status。
- **任务中断后模型不卸载**（`0 models unloaded`）→ 下个任务 OOM。批量时每任务前 `POST /free`。
- **UP = Astral星芒，不是"啦啦啦的小黄瓜"**（后者是 LTX2.5 放大方案，已被凡哥否）。辨识特征：带本地提示词优化（QwenTE / comfyUI-llama-TE）。
- **云端别把轮次浪费在"想办法自己连"上** —— 详见 `references/03`。

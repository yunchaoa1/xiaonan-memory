## 一、H3 是什么（🟢 官方 README + GitHub）

- **MiniMax H3**：开源权重的**音视频生成模型**，`MiniMax-AI/MiniMax-H3`。
- **规模**：**33B 参数**（H3-Omni-Transformer，密集单流），另有 **+13B 在 AdaLN 分支**（推理可缓存，不必常驻）。
- **文本编码器**：**完整 Qwen3-VL-32B 预训练权重**（H3-Encoder）→ 这是显存大头之一。
- **精度**：两个 checkpoint 都是 **BF16**；开源权重体积约 **42.5 GB**（🟡 第三方站统计，量级参考）。
- **⚠️ 开源**的只有 **H3-Base**：
  - **2K 工作流模块未开源** → 要调 **MiniMax 官方 API**（付费）
  - **H3-Context-IR 未开源** → 同样要调官方 API
  - 稀疏注意力（sparse-attention）"future update" 才放
  - ⇒ **本地部署 = 768p 档位（1344×768 实测配方）**，要 2K 就得走官方云 API。**这条必须在审核里被他们交代清楚。**

## 二、⚡「ComfyUI 只能一个人」的根因（🟢 官方四框架对比）

官方推荐 4 个推理框架，**ComfyUI 只是其中之一**：

| 框架 | 官方定位 | 并发能力 |
|---|---|---|
| **SGLang** | **官方示例首选**（本地部署段落用它）| ✅ 推理服务框架，有批处理/并行配置 |
| **vLLM** | 推荐 | ✅ 同上 |
| **diffusers** | 推荐（轻量/研究）| ⚠️ 不是服务框架 |
| **ComfyUI** | 官方也支持 | ❌ **单用户工作流引擎（队列串行）** ← **就是"只能 1 人"的根因** |

**官方 SGLang 启动命令（原文）**：

```bash
sglang serve \
  --model-path MiniMaxAI/MiniMax-H3 \
  --num-gpus 4 \
  --ulysses-degree 4 \
  --performance-mode speed \
  --host 0.0.0.0 \
  --port 30010 \
  --model-variant fl2va
# 第二个变体单独起一个服务，端口 30011，--model-variant ref2va
```

→ **fl2va / ref2va 是两个模型变体，各起一个服务**。参考 `README.zh-CN.md`。

## 四、并发相关的技术手段（🟢 Cookbook 用词，需配置）

Cookbook 里出现的并发相关词：**`batching_max_size`**、**DP（数据并行 / batched throughput）**、**TP（张量并行）**、**Ulysses degree**、**layerwise offload**、**replicate**。

- 原文：**"这是单请求延迟测试（batching_max_size: 1）… 多请求吞吐部署要用 picker 的 DP（批吞吐）选项"**
  → **"SGLang 能并发"是真的，但不是装了就能并发**，要专门配置。
- ⚠️ 官方提醒：某拓扑下 **replicate 会多花约 40 GB 峰值显存，且对 batch=1 没有延迟收益**。
- 其他可选加速：**Cache-DiT**、**AdaIN cache 构建**（`build_minimax_h3_adaln_cache`）。

**⚠️ 审核要点**：**"N 人并发"≠"N 人排队"** —— 视频生成单次要几分钟，"30 人同时在线、各自排队"与"同时开 30 条推理"是完全不同的量级。**要他们明确是哪种，再谈卡数。**

| 项 | 数据 | 出处 |

| **2×4090-48G 整机** | 社区实录：**"2 张 4090 48G 搭 4U 服务器，本地部署 32B 模型，随时可升级 5090"** | 🟡 B站实测视频 |

### ⚠️ 关键事实：本机已有的那台 ≈ 云上那台的显存

- 杨董借给你们的是 **2×4090-48G = 96GB**（4090 魔改 48G 版）。
- 云上租的 **2×L20 = 2×48GB = 96GB**。
- **⇒ 显存总量相同** → **内测阶段（10 人）可能不必租云**。
- ⚠️ **但"显存一样"≠"性能一样"**：**4090 是消费级卡 —— 不支持 FP8、无 NVLink**（多卡通信走 PCIe）；**L20 是专业卡，支持 FP8**（省显存提速），更适合服务器长跑。**这一条必须让他们回答。**

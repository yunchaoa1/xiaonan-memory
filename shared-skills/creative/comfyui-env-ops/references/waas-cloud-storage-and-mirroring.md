## 1. 存储矩阵（官方「存储空间」页）

| 存储类型 | 路径 | 生命周期 | 备注 |
|---|---|---|---|
| 系统盘 | `/root` | **随实例释放 / 更换镜像清空**（未保存镜像时永久删）| 镜像 = 系统盘快照 |
| 云存储（数据盘）| `/home/waas` | 持久化，**实例释放后仍保留** | 免费额度 100G；连续 2 个月未登录 或 欠费 >7 天 → **自动清空** |
| 公开数据（公模库）| `/datasets` | 平台长期维护 | **只读**、不占用户存储 |
| 团队存储空间 | `/home/teams/<团队挂载名>` | 与团队账号绑定 | 默认同数据盘，最高 500G，团队创建者付费 |
| 共享盘（共享空间）| `/home/personal_share` | 持久化、**绑定镜像** | 与 `/home/waas` 共用 100G 免费额度，上限 300G |

## 2. 镜像包含什么（官方「实例与镜像对比指南」原文）

> ⚠️ **镜像仅包含系统盘内容，不包含数据盘 `/home/waas`（个人/团队存储空间）。**
>
> **不适合作为数据备份**：镜像不包含 `/home/waas` 数据；请使用云存储与备份方案。
>
> **更换镜像**会重建实例系统盘（**数据盘 `/home/waas` 保留**）。

其它要点：
- 实例 vs 镜像：实例 = 可运行环境（算力计费）；镜像 = 系统盘静态快照（存储计费），用于复用/共享/回滚。
- 「关机」保留系统盘+数据盘（只停算力费）；「保存镜像」= 把当前**系统盘**固化成模板。
- 保存镜像时可选 **覆盖**（更新原镜像版本）或 **另存**（新建一条镜像记录）。

→ **推论**：ComfyUI 装在哪个盘，决定它能不能被镜像带走。
- 官方 ComfyUI 镜像惯例 = **系统盘**：`/root/comfyui/ComfyUI`（官方插件文档给的路径原文）
- 我们自建时装在 `/home/waas/h3-0300`（**数据盘**）→ 镜像分享出去，环境**不跟着走**

## 3. 事故复现（2026-10-08）：分享镜像后新账号「什么都没有」

现象：老账号镜像分享给新账号 → 新账号实例里 `/home/waas` 空、无 `h3-0300`、云扉 OS 弹「找不到目录 `/home/waas/h3-0300/ComfyUI/output`」。

逐项取证（**新账号实例**网页终端）：
```bash
df -h                                                        # overlay 已用仅几百 MB = 实例基本空的
ls -la /home/                                         # /home/waas 存在但为空；/home/personal_share 也为空
ls /datasets/                                         # 公模库在（平台级，与账号无关）
find / -maxdepth 7 -type d -name "ComfyUI"            # 只命中 /datasets/ComfyUI（模型目录，非可启动环境）
```
结论组合：**系统层在（镜像带的）+ 公模库在（平台级）+ 数据盘是新的（各账号独立）** → 只有装在数据盘的自建环境消失了。

**修法（让环境以后能随镜像分享）**：
```bash
# 老账号机器上：
mv /home/waas/h3-0300 /root/h3-0300
# → 控制台「保存镜像」→ 重新分享 → 新账号重建实例 → 启动命令路径前缀改 /root/h3-0300
```
⚠️ 动之前先验老机器环境健在（`ls /home/waas/h3-0300/ComfyUI/main.py`），**不要释放老实例**——它可能是唯一副本。
⚠️ 搬完老机器自用时，启动命令里 4 处路径（cd / venv / 日志 ×2）都要改 `/root/h3-0300/...`。

**备用路**：`tar -czf` 打包 → 官方跨区迁移法传到新账号（见 §6）。

## 4. 「共享空间」机制（官方页，UP 主分享模型的底座）

> 共享空间 = 初始化云存储后自动创建的共享型文件区域，用于**模型资源共享**，挂载即用。

ComfyUI 镜像最佳使用流程（官方 5 步）：
1. 「云存储 → 共享空间」中**创建共享盘**
2. 云扉 OS 桌面 →「云扉共享空间」快捷入口
3. 把模型放进共享盘的 `models` 对应子目录（**从 ComfyUI 模型目录右键"复制"**；直接拖动 = 移动，不推荐）
4. **分享镜像 / 拷贝到团队时，勾选挂载该共享盘**
5. 使用者用该镜像建实例 → **系统自动把共享盘模型加载进 ComfyUI 模型目录**，无需额外操作

规则要点：
- 每镜像**最多挂 1 个共享盘**；「分享他人 / 拷贝到团队」会自动解除原挂载（用户可改挂自己的）
- 🚫 **共享盘无法用终端命令挂载（2026-10-08 实机验证）**：`/etc/ceph/` 不存在，机器上没有任何挂载凭据；连平台自己挂的数据盘 `/home/waas` 在 `mount` 里都显示 `secret=<hidden>`（密钥由平台托管）。**挂载共享盘只能在界面做**：`waas.aigate.cc` 登录 → 云扉 OS 桌面 →「云扉共享空间」。**别再让用户去翻 `/etc/fstab`、找 mount 脚本、试手工 mount —— 这条路不存在。**
- 🔑 **新账号缺模型的真实原因**：镜像只带系统盘，模型历来由「共享盘 / 数据盘」提供，用户**从没下载过**；把镜像分享给新账号时，平台会**自动解除**共享盘挂载 → 新账号实例里 `/home/personal_share/` 是空目录、`df` 里也没有它的挂载点。**先挂共享盘，再谈下载**（34GB 白下的坑就是这么来的）。
- 挂载信息**随镜像保存**；工坊镜像与「我的镜像」的挂载设置**互不影响、不同步**（工坊镜像需在「云扉工坊·个人中心→管理」单独设置）
- **创作者本人**用「挂载了自己共享盘的镜像」建实例时，系统**不会**自动建软链，需手动 `ln -s`
- ⚠️ **不要在 `/home/personal_share` 下手动 `mkdir`**：系统只认从「云存储」菜单创建的共享盘；手建目录不计入、不保存、释放即删，还占系统盘
- 共享盘**创建后不能删**（可清空内容）；不同区域**数据不互通**；每区域每人最多 3 个共享盘

## 5. 「云扉 Comfy 应用 · Setup」（UP 主发布工作流为应用的流程）

1. 用**官方 Comfy 应用镜像**创建实例（studio.aigate.cc 镜像页）
2. 控制台 → 快捷工具 → 点 **「Setup」**
3. 新增应用：上传工作流的 **API JSON** → 配可编辑节点（别名/默认值/组件类型：数字/文本/布尔/滑块/枚举/宽高/上传文件）
4. 模型校验（应用版镜像默认加载公模库全部公开模型；**私有模型需上传共享盘**）
5. 保存 → 试用 → **保存镜像** → **分享 / 发布**
- 注意：工作流最终节点必须为**保存节点**（不可用 Preview）；生成视频要开 `save_output`；防泄漏建议只开「ComfyUI 应用 + 运行日志」并启用**禁用二次分享**；私有模型必须开共享盘权限

## 6. 跨区数据迁移（官方「实例生命周期管理」）

```bash
# 方法一：tar + scp
tar -czvf data_backup.tar.gz /home/waas/data
scp -P <PORT> data_backup.tar.gz <USER>@<TARGET_IP>:/home/waas/
# 方法二：rsync（增量，少量大文件推荐）
rsync -avz --progress -e "ssh -p <PORT>" /home/waas/data/ <USER>@<TARGET_IP>:/home/waas/data/
```
（区域间存储独立，不共享；迁移会覆盖同名文件，先备份）

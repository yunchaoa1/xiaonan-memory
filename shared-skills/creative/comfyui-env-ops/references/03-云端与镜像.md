## 云端操作协作模式（2026-09-20 凡哥两次纠正 — 别再把轮次浪费在"想办法自己连"上）

**云电脑 = 智算云扉平台，控制台入口 `https://waas.aigate.cc/dashboard/instance`；凡哥在控制台的网页终端里执行 root 命令。** **⚠️ 2026-10-10 通道更新：本机已可直连云端实例（免密）** —— 凡哥交出实例 SSH 信息（连接串+端口，控制台实例信息里复制）后，小南用密码首次接入（paramiko）并把本机公钥挂进 `/root/.ssh/authorized_keys`（注释 xiaonan-wsl）→ 此后直连：`ssh -i C:/Users/bobby/.ssh/id_ed25519 -p <端口> root@<主机>`（scp 同理）；**新实例/没挂过公钥时先验** `grep xiaonan-wsl /root/.ssh/authorized_keys`，不通就回网页终端流程、别硬试。**控制台（账号级）操作仍只能凡哥做**——preview 面板/独立浏览器登控制台依然别碰；命令类操作能用直连就用直连（小南自己跑、自己看结果）。

**（历史 2026-09-20，通道开通前——凡哥纠正『你没办法连接云电脑的，你忘记了，我们是用root命令控制云电脑的』：当时实例未挂公钥＝真没通道；教训＝没通道时别反复试）备用三步：**

1. 小南写好命令 → 2. 凡哥贴进网页终端 → 3. 他拷打印结果回来，小南判断/给下一步

**命令格式纪律（凡哥原话：『你给我的是一条命令吗？』）**：给**单行、能整段一次粘贴**的命令（多步用 `&&` / `;` 串起来），**不要多行脚本**——多行他虽能整段贴，但会先反问"这是一条吗"。输出用 `echo "=== ① xxx ==="` 分段标注，他整段拷回后逐块对读。备选方案写在文字里、别塞进命令块（他会把备选一起跑）。

**命令块里只能有命令（2026-10-08 云端再犯一次，白跑一整轮）**：把 `--help` 输出的参数说明行紧挨着命令块放 → 凡哥当场问『**这个是给我去云电脑上跑的命令吗？**』，然后跑了**上一条**命令。规矩：① 一个代码块 = **一条**完整命令；② 解释 / 参数含义一律放块外；③ **新增了参数时明确写「和上一条的区别就是多了 `XXX` 这个词」**，并告诉他「命令末尾会打印 XXX，看见它才说明带上了」——否则他会以为你只是又解释了一遍。

**重启服务带新参数后，先自证生效，再让他跑（2026-10-08 实测教训）**：本次没验证就让他重跑，报错报告里 `** Arguments:** ... --disable-cuda-malloc`（**没有新参数**）= 跑的还是旧进程，整轮作废。自证两条任选：`ps -ef | grep -v grep | grep "[m]ain.py"` 要看见该 flag；或直接读 **ComfyUI Error Report 的 `** Arguments:` 行** —— 那是最省事的「参数到底带上没有」判据。同一行还会暴露哪些 flag 是凡哥长期带着的（云端 H3 的 `--disable-cuda-malloc` 就是），那些别当可疑变量去动。
- **凡哥说「只做 X」时给最小纯净命令**：如「只启动 comfyui，不要别的」= 只给启动那一条（不带 `pkill` / 检查 / 前置清理）；附属动作（杀旧进程、验服务）另作**单列**命令并注明"什么时候才需要跑它"——他要"只"的时候，混进去的步骤会被当场反问。

**★ 用户交出平台官方文档时：先读全，再开口（2026-10-08 最贵的一课）** —— 用户三次升级：『**你别猜了我求你了行不？**』『**你到底认真学习了吗？一下午了一直在兜圈子**』『**能否不要试？帮助文本给你了，不懂的就去查？**』。他把 `https://docs.aigate.cc/abstract/about` 甩过来之后仍在追问，说明前十几轮都是在**猜平台界面**（云扉OS 入口、共享盘挂载位置、镜像管理里有没有共享盘设置）—— 猜错一次，他就白跑一趟。铁律：

- **平台操作（云厂商控制台 / 云扉OS 这类 Web 桌面 / 第三方 SaaS）的步骤，一律先取官方文档原文再给**；给出时**逐条标注「已核实（文档原文 / 用户截图）」或「推断（未验证）」**，**禁止连续甩两三个"点这里试试"**。
- 用户说『**没有那一步**』『**没有你说的 XX**』→ **立刻承认是推断、停止让他重找**，回文档找依据。**不要辩、不要让他换个地方再试**。
- 用户说『**一步一步来好吗？**』→ 一轮只给**一个动作**，等他回报再给下一步；别把后续三步塞进同一条消息。
- **别让他重复劳动**：他问『上一个账号也下载过吗？我怎么不记得？』时，先答**为什么这次不一样**（跨账号数据盘独立；分享/拷贝动作被平台自动解除共享盘挂载），再谈怎么做 —— 而不是直接丢一条 34GB 下载命令。
- 平台文档站可怎么抓、云扉OS 界面地图、跨账号共享的两条官方路：`references/waas-official-deploy-and-share.md`。

## 智算云扉：镜像不含数据盘 → 分享镜像后「环境不见了」（2026-10-08 官方核实）

**症状**：老账号的镜像**分享给新账号**后，新账号实例里 `ls /home/waas` 是空的、`h3-0300` 全无（云扉 OS 弹「找不到目录」）—— 这**不是命令路径写错，是镜像里根本没有**。别在终端里反复找路径，直接检查下面的机制。

**官方原文（docs.aigate.cc）**：
> **镜像仅包含系统盘内容，不包含数据盘 `/home/waas`（个人/团队存储空间）。**
> 系统盘 = `/root`（**随实例释放/更换镜像清空**）；数据盘 = `/home/waas`（持久化、跨实例共享）。

**错配根因**：H3 环境装在 `/home/waas/h3-0300`（**数据盘**）→ **镜像带不走**；而官方 ComfyUI 镜像惯例是装在**系统盘** `/root/comfyui/ComfyUI`（官方插件文档原文路径）→ 所以 **UP 主们分享的镜像自带环境**，我们的一分享就「空壳」。

**UP 主分享 ComfyUI 镜像的标准三件套**（官方「共享空间」+「云扉Comfy应用」机制）：
1. **环境装系统盘**（`/root/...`）→ 随镜像走
2. **模型放共享盘** `/home/personal_share/<共享盘名>/models/...`（「云存储→共享空间」创建；**分享镜像/拷贝到团队时勾选挂载该共享盘**）→ 使用者创建实例后**系统自动把共享盘模型软链进 ComfyUI 模型目录**（每镜像最多挂 1 个共享盘；工坊镜像的挂载配置不继承、要单独设；共享盘与 `/home/waas` 共用 100G 免费额度）
3. 用「云扉 Comfy 应用 · Setup」（控制台→快捷工具→Setup）把工作流封装成带参数界面的应用 → **保存镜像 → 分享/发布**

**修法（让已有环境可分享）**：`mv /home/waas/h3-0300 /root/` → 控制台**保存镜像**（覆盖/另存）→ 重新分享给新账号 → 对方创建实例后把启动命令路径前缀改成 `/root/h3-0300/...`。⚠️ 动手前先确认老机器还活着（`ls /home/waas/h3-0300/ComfyUI/main.py`）—— **别释放老实例**，它可能是环境唯一副本。

**备用路**：老机器 `tar` 打包 → 官方跨区迁移方式 `tar + scp` / `rsync` 传到新账号 `/home/waas/`（几十 GB，慢）。

**「环境没过来」诊断清单**（在**新账号实例**网页终端跑）：
```bash
df -h; echo ---; ls -la /home/waas/ /home/personal_share/ /home/teams/ 2>/dev/null; echo ---; find / -maxdepth 7 -type d -name "ComfyUI" 2>/dev/null | head
```
读法：`overlay` 已用只有几百 MB = 实例基本是空的（几十 GB 环境不在）；只有 `/datasets` 下找得到 ComfyUI（那是公模库的模型目录，不是可启动环境）。

## 云端装件与运行可见性（2026-09-10 实测）

### 先查公模库，再下载
装模型前先 `find /datasets -iname "*<关键词>*" 2>/dev/null | head`——公模库（`/datasets/ComfyUI/models/...`）常有现成文件（例：`minimax_h3_turbo_v4_step600_ema.safetensors` 公模库已有）。有就软链：`cd <目标目录> && rm -f <文件>; ln -s /datasets/... <文件>`。**软链前必须先 rm 掉 curl 中断留下的半截文件**，否则占位导致假成功。没有才下载：先 `curl -sIL ... -o /dev/null -w "%{http_code}"` 验 200，下完 `ls -la` + `du -h` 验真实大小（防 150B 假成功）。

**大文件（>5GB）判"下完没有"必须用字节对比，不能看 `du -h`**——20GB 文件差 1.3GB 时 du 会四舍五入成看起来很接近的数，凡哥会问"是不是没进展/下完了吗"，你要能立刻给确定答案：
```bash

# ① 先取官方精确字节（一次）
curl -s "https://hf-mirror.com/api/models/<repo>?blobs=true" | python -c "import sys,json;[print(f['rfilename'],f.get('size',0)) for f in json.load(sys.stdin)['siblings']]"

# ② 下载中/完成后对比（进度百分比）
S=$(stat -c%s <文件>); echo "当前 $S / 目标 <字节> = $((S*100/<字节>))%"
ls -la <目录>   # 第一个文件到齐后脚本才会开始下第二个 → mmproj 未出现 = 主模型仍在下
```
多文件串行下载（`curl A && curl B`）时，**后一个文件没出现就是前一个没下完**，这是最快的判断信号。下完再 `grep` 一下无 `IMPORT FAILED` 后重启实例让新件被扫到。

**下完必须做完整性终检（字节 + 文件头），不能以「大小看着对」收尾**：`python scripts/verify_model_files.py --hf <repo> --local-dir <目录>`。它同时验两件事——① 本地字节 == 官方 LFS 精确字节；② safetensors 头能解析出张量表。20GB 级文件下完后**一次报全表**给凡哥比逐条试跑便宜得多（本机 2026-09-23 实测一次过：融合模型 20,970,379,632B/932 张量、nvfp4 编码器 15,687,142,551B/2053 张量、video VAE int8 3,171,670,912B/850 张量、turbo resized LoRA 314,878,200B/416 张量、Combat LoRA 155,110,280B/416 张量）。⚠️ **HF 上的第三方仓库偶有本身损坏的文件**（本次调研时另一变体 `b15-49` 的 blob 曾报 `SafetensorParseError`）——所以「头解不出来」先怀疑文件，别急着怀疑自己的下载。

**公模库没有 → 先溯源发布源再下**（不要只在 Manager 界面点下载）：

1. 搜 HF 仓库：`curl -s "https://hf-mirror.com/api/models?search=<关键词>" | python -c "import sys,json;[print(m['modelId']) for m in json.load(sys.stdin)[:20]]"`
2. 看仓库文件与真实大小：`curl -s "https://hf-mirror.com/api/models/<repo>?blobs=true" | python -c "import sys,json;[print(f['rfilename'], f.get('size',0)//1048576,'MB') for f in json.load(sys.stdin)['siblings']]"`
3. hf-mirror `resolve/main/<文件>` 下载 + `ls -la` 验大小

**工作流引用的文件名必须精确匹配**：工作流写 `minimax_h3_video_vae_int8_convrot.safetensors`，你手里只有官方的 `minimax_h3_video_vae_fp16.safetensors` → 加载节点里选不到、报缺模型。官方 `Comfy-Org/MiniMax-H3` 只发 fp16 video VAE + fp32 audio VAE，**int8_convrot 量化版属第三方源**（见 `references/h3-model-sourcing.md`）。凡哥问"这个模型有没有"时的正确回答顺序：公模库 find → 本地模型目录 find → HF 搜源（三步都要给依据，别只说"没有"）。

**整个目录可软链**：`ln -sfn /datasets/ComfyUI/models/layerstyle /home/waas/ComfyUI/models/layerstyle`——LayerStyle 那批模型（抠图/超分/人脸等）整目录软链最省事，插件自动扫 `models/layerstyle/`。

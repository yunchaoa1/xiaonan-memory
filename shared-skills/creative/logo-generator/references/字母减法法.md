# 字母减法法（Letter-Subtraction）— 简约大气标志的核心方法

**出处**：B站 BV1ka411M7kV，墨壹logo设计《一个简约不简单的logo如何设计！》（51秒，2026-09-11 凡哥指定学习）
**定位**：凡哥认可的「简约大气」思路 —— 一个字母骨架，减法出双重含义。

## 一、原视频完整讲解（faster-whisper medium 转写，带时间戳）
```

[1.7-3.7]  如果在它上面减去一笔
[3.7-5.2]  再加上一些细节
[5.2-7.4]  然后加上火箭的推动形式
[7.4-8.4]  你会发现
[8.4-10.1] 这就是特斯拉的logo
[10.1-11.6] 同样也是这个T字母
[11.6-13.9] 如果在它的中间减去一笔
[13.9-15.5] 再调整一边的高度
[15.5-17.7] 就得到一个YT组合的字母
[17.7-19.4] 然后再调整一下空间
[19.4-22.4] 一个具有建筑元素的logo就出来了
[22.4-26.5] 还是这个T字母 → 如果我想把M字母融入进去
[26.5-29.9] 你可能会这样，减去一笔来体现出M字母
[30.0-33.6] 细心的老铁会发现，只要在它的上方减一部分
[33.6-36.6] 一个T融合M的复型logo就出来了
[36.6-43.1] 最后是一个Y字母，要求体现出T字母和飞机元素
```
**画面证据**：视频全程黑白扁平几何，最后成品是「恺天设计」——左侧方框内建筑式竖直笔画图形 + 右侧中文字标（含字母 M/Y 融入的字形改造）+ 全大写 letterspaced 英文 "JIYITIAN DESIGN"；收尾镜头是**金色背光发光字装在石材墙上**。

## 二、四步法（可直接照做）
1. **取骨架**：选定品牌首字母／关键汉字（如 T、M、Y、A、天）作为唯一骨架
2. **做减法**：在骨架上**减去一笔或一部分**，让第二个含义浮现
   - 特斯拉 = T 减去上部两侧 + 火箭推进形态
   - YT = T 中间减一笔 + 调一侧高度
   - T 融 M = 在上方减一部分
3. **加一点细节**：一个缺口、一个斜切、一处错位（"Little Blip"）就够，不要加元素
4. **调空间**：调整笔画间距与高低，得到**建筑感**（直角、平头笔画、等宽笔画、方正外轮廓）

## 三、落地要点（本项目实测）
- **实现工具**：手工 SVG（字母必须精确，AI 会写错字）→ resvg-py 渲染
- 笔画参数（viewBox 100）：主笔 7–9.5，次级 5.5–7；`stroke-linecap="butt"` + `stroke-linejoin="miter"` 才有建筑感，圆头会变可爱
- **必须配锁标**：标志 + 中文标准字（几何化）+ 全大写 letterspaced 英文副标 —— 视频成品也是锁标，不是孤零零一个图标
- 英文副标字距 ≈ 字号的 0.33em，全大写，是「廉价→高级」的分水岭之一
- 收尾用**发光字实景效果图**呈现（视频结尾手法），高级感最后一公里

## 四、⚠️ 歧义检查（血的教训）
**减法做出来的复型图形，必须先做「路人测试」**：随口读一遍它像什么。
本项目实测：`O+P+C 复型` 圆环开口 + 内竖笔 → 实测**被读成「停车 P」和版权符号 ©**，手法正宗但商业上不可用 → 淘汰。
**规则：复型手法只在「两个含义都不是负面/不相关符号」时才能用。**

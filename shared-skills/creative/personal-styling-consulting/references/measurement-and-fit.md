# 量体换算 · 体型判定 · 面料参数（明细）

> 配套 `personal-styling-consulting`。凡哥 2026-10-20 实测案例放在最后当校准样本。

## 1. 净尺寸 → 成衣尺寸（唯一可信的推法）

| 身体净尺寸 | 成衣要买 | 依据 |
|---|---|---|
| 净胸围 | **+8~12cm** | 合身区间；<+8 绷、>+12 变 oversize |
| 净腰围（肚脐水平） | **+1~2cm** | 买整数腰围会"站着合、坐下勒" |
| 净臀围 | **+6~8cm** | 直筒/微阔的余量 |
| 净大腿围 | **+5~6cm** | 博主公式；<+4 坐下必绷 |
| 净腿围以外的腿长 | — | 不用推，见下 |

**裤长三种口径（必须分清，混用会差 3cm+）**

1. **光脚站直，地面 → 胯骨最高点** ＝ **上限**（裤脚刚好触地，不许直接买）
2. **购买值** ＝ 上限 − 鞋底 2~3cm（裤脚落鞋面、不堆褶）
3. **最省事** ＝ 平铺现有合身长裤，裤腰上沿 → 裤脚（不涉及鞋和地面）

**博主给的身高公式**（只作参考线，不作结论）：
- 长裤 ≈ 身高 × 0.575（±1cm）
- 五分裤 ≈ 身高 × 0.285；六分 +5~6；四分 −5~6
- 腿围 ≈ 净腿围 +5~6

> 公式是"平均身材"的产物。**本人实测一旦到手，公式立即降级为参考，并记录偏差。**

## 2. 体型判定（差值法，不靠眼估）

| 判据 | 结论 | 能做什么 / 不能做什么 |
|---|---|---|
| 腰 − 胸 ≤ 3cm | **无腰线** | ✗ 收腰、高腰收腹、修身剪裁全无效<br>✓ 竖向分割（内浅外深敞开）、面料骨架 |
| 腰 ≥ 臀 | **桶形** | ✓ 直筒 / 微阔；✗ 细腿、锥形（会变"圆萝卜"） |
| 腰 < 臀 明显 | 梨形 | ✓ 上浅下深；✗ 胯部贴身 |
| 胸大 + 腰细 | 倒三角 | ✓ 上身减少结构；✗ 加宽肩部 |

## 3. 面料（两大约束叠在一起）

**约束 A：湿热气候** → 透气排汗第一
**约束 B：机洗不熨（凡哥）** → **挺括但会皱的一律排除**

| 类型 | 判定 |
|---|---|
| 珠地棉 pique（polo 那类） | **主力**：有肌理、撑得住版型、机洗不皱、透气 |
| 速干挺括混纺（涤/锦 + 氨纶） | **主力**：免熨第一名；**必须哑光**，亮面又闷又廉价 |
| 免烫处理衬衫 | 见客/约会升级项 |
| 泡泡纱 seersucker | 天生皱感免熨，但**膨胀感**强，只能深色 |
| 亚麻 / 亚麻混纺 | ✗ 不熨穿不出门 |
| 莫代尔 / 天丝 / 冰丝 / 粘纤 | ✗ 软塌贴肉 |
| 亮面聚酯 | ✗ |

**短袖克重**：180–220g 是本区间；<160g 薄透贴肉；>240g 太厚闷

**商品页四个劝退词**：垂坠感（=贴肉）、冰丝/凉感（=薄软化纤）、修身/显瘦剪裁（=更显胖）、oversize/宽松落肩（=轮廓糊）

**0 成本动作**：脱水完立刻抖平、宽肩衣架挂起；别用细铁丝衣架（肩部顶包）；深色反面晾。

## 4. 网购试穿（30 秒判死）

1. 抬手 → 衣摆会不会翻上去露肚子
2. 坐下 → 肚子那圈绷不绷
3. 侧身照镜子 → **侧面厚度**（微胖最真实的一眼）
4. 看肩缝 → 落在肩峰还是滑到胳膊上
5. 裤子单独：蹲一下，腰后空一大块＝腰大了，别硬留

**操作**：先看 7 天无理由；相邻两码各买一件、留一退一；吊牌别剪、别喷香水。

## 5. 校准样本：凡哥 2026-10-20 实测

| 项目 | 实测 |
|---|---|
| 身高 / 体重 | 172cm / 90kg（180斤） |
| BMI | 30.4 |
| 净胸围 | 108 |
| 腰围（肚脐） | 106 |
| 臀围 | 105 |
| 大腿围 | 60 |
| 裤长（光脚→地砖） | 103.5 |

**得到的结论**：胸 108 / 腰 106 / 臀 105 → 腰胸差 2cm、腰>臀 → **无腰线 + 桶形**。
→ 版型只能直筒 + 竖向分割；高腰收腹无效（会卷边下滑）。

**公式偏差**：身高公式 172×0.575 = 98.9，实测 103.5，**差 3.5cm**。
且 103.5 是"光脚到地"的**上限**，扣鞋底后**购买值 101–102**。
→ 教训：**口径不掰清，公式和实测都会把人带偏。**

**肤色（同批记录）**：上臂内侧偏白；晒狠了先红再脱皮；一般晒第二天直接变黑。
→ 底色白（能穿脏橘/大地色/藏青灰这类"挑人色"），但**黑色素活跃**，不防晒会晒成小麦色 → 那时要切到黄黑皮配色（卡其+军绿、黑+牛仔蓝），荧光色和马卡龙色风险高。
→ 结论：**防晒是止损，不只是美白；它决定他属于哪套配色。**

# 个人形象顾问（穿搭 · 量体 · 购物准备）

> 建库：2026-10-20（凡哥形象线第一轮实操）
> 定位：**先了解这个人和他的身体，再谈穿什么、买什么。** 不谈"买哪件"直到数据和场景都齐。
> 档案落点（凡哥）：`D:\Hermes\xiaonan-memory\形象档案\` —— 档案是真相源，技能是可复用方法。

## When to Use（何时加载）

- 凡哥说「穿搭 / 好看 / 买衣服 / 约会穿什么 / 通勤穿什么 / 显瘦」
- 需要**量体、推尺码、看面料参数、写购物清单**
- 要**从穿搭博主那里学东西**（配合 `camoufox-antidetect` 的抓取+转写链路）
- 护肤/防晒与形象相关的场合（肤色、晒伤、屏障）

## 铁律（凡哥 2026-10-20 定的，优先级高于任何穿搭理论）

1. **先了解人，再谈买。** 他要的是"以了解我为主 + 把购物前的准备做齐"。**预算、"这件买不买"这类问题一律押后**，等他说要买再问。抢跑会被叫停。
2. **不设硬禁区。** 他原话："别定太死，穿着好看就行。" → 所有结论用**三档**表述：**稳 / 可试 / 容易翻车**。永远不要写"绝对不能穿"。
3. **实测 > 公式。** 博主给的身高公式只是参考线；凡哥的实测数一旦拿到，**一切以实测为准**，并且要记下偏差原因。
4. **口径必须当场掰清。** "裤长"这类词在不同量法下差 3 厘米以上。他质疑"裤长不可能拖地"是对的——**光脚量到地面 = 上限，不是购买数**。凡是"上限/购买值"两种含义的数，必须分开写。
5. **一次只问一条，答完立刻换算成结论。** 他给一个数字，我下一次回复必须出现"所以你要买 X"这种可执行结论，不能只记数接着问下一个。他会觉得没进展。
6. **场景优先级以他拍板为准，改口要落档。** 他说过先通勤，后来又改约会——**两版都留，不删旧版**，只标注当前优先级和改口原因。
7. **不抄瘦高型技巧。** 博主身材和他不一类时，技巧会反向失效（塞衣角在小肚子上会把肚子顶出来）。

## 第一步：量体（七项，一次报一项）

按 `templates/body-measure-card.md` 逐项问，**一项一条消息**，配"怎么量 + 这项决定什么"。
换算规则与实测偏差记录见 `references/measurement-and-fit.md`。

| # | 项目 | 记住的换算 |
|---|---|---|
| 1 | 净胸围 | 成衣胸围 = 净胸围 **+8~12cm** |
| 2 | 腰围（肚脐水平） | 裤腰 = 净腰围 **+1~2cm** |
| 3 | 臀围 | 成衣裤臀围 = 净臀围 **+6~8cm** |
| 4 | 大腿围 | 裤腿围 = 净腿围 **+5~6cm** |
| 5 | 裤长 | **只认实测/平铺量现有裤子**，不认身高公式 |
| 6 | 肩宽 | 平铺合身衣服量肩缝→肩缝，**直接等于成衣肩宽**，不加不减 |
| 7 | 衣长参考 | 量现有最合适那件的肩到下摆 |

## 第二步：判体型（靠差值，不靠眼估）

- **腰胸差 ≤3cm** → 没有腰线可收 → **任何"收腰/高腰收腹/修身"都是无效设计**，只能靠竖向分割 + 面料骨架
- **腰 ≥ 臀** → 桶形：**必须直筒裤**，细腿/锥形会让人变"圆萝卜"
- **腰 < 臀 明显** → 梨形：上浅下深，避开胯部贴身的裤型
- 推理链：数据 → 体型 → **可做什么/不可做什么**，三步连着说，别只丢数据

## 第三步：场景分档做方案

一档一档做，一档一个文件，别混。已做过的模板：

- **通勤**：怕太随便 → 深色主力、合身、三色内
- **约会**：怕太用力 → 目标是"看起来没费劲但处处对"
- **海边/出游**：防晒装备优先，面料反过来（速干 > 挺括，纯棉最差）

四条通用硬逻辑（来自博主内容，已验证可用）：

1. **上深下浅** —— 拉长身形
2. **内浅外深（敞开穿）** —— 中间一道浅色竖条 = 视觉收腰；那层深色薄外套同时是防晒衣
3. **合身，不修身也不 oversize** —— 穿大一号遮肉反而更显胖（肩线掉、下摆飘）
4. **面料要有骨架** —— 软塌贴身 = 勾出肚子轮廓

## 第四步：购物前准备（他要的"准备"就是这些）

- **量体卡**（模板见 `templates/body-measure-card.md`）
- **尺码表怎么读**：看胸围不看体重/身高/店家标的 L 码
- **面料参数**：克重、成分、四个劝退词（见 references）
- **网购试穿退换**：相邻两码、吊牌别剪、30 秒判死三动作
- **三秒自检**：肩线 / 腰线 / 裤脚，一句不过就换

## 知识来源：怎么"学"博主（别抄搭配，抄逻辑）

1. 抓取 + 转写走 `camoufox-antidetect` 的小红书链路（`xhs_videos_batch.py` → `xhs_transcribe.py`）
2. **筛选标准两条**：① 讲不讲底层逻辑 ② **身材像不像本人**（瘦高型博主的技巧对微胖反向失效）
3. 提炼时**只取公式和避雷**，**不要他的单品推荐**——带货号的推荐带利益
4. 转写有同音错词（如"缩质面料"疑为"硬挺/挺括"），**逐条标"存疑"，不替它编圆**
5. 反话识别：有的视频全篇反着说（"别跟我搜一样，怕你太帅"），**不能当规矩用**

## Pitfalls（都真踩过）

1. **把"光脚到地"当裤长去买** → 会堆褶显矮。购买值要扣鞋底 2~3cm。
2. **照搬"高腰裤收肚子"** → 腰胸差只有 2cm 的人没有腰线可收，高腰只会卷边下滑。**量完要回头改掉之前抄来的通用说法并留纠正记录。**
3. **只记数字不给结论** → 用户会觉得在绕。每个数都要跟一句"所以你买什么"。
4. **抢跑去问预算/买哪件** → 违反铁律 1，会被叫停。
5. **把护肤/防晒当另一条线** → 底色白但易晒黑的人，**防晒决定他属于哪套配色**，两条线是接在一起的。
6. **同一件事两套方案不做取舍** → 通勤/约会/海边分别成套，混在一起会买一堆都不对的衣服。

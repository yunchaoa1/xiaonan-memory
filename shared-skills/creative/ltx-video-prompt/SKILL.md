## 📋 MSR-V2 多角色参考提示词格式

PromptRelay上下两框：

**上半框：参考图描述**
- 中文标签：`参考图1` `参考图2`（禁止 Figure 1/In Figure 2）
- 人物四视图：角色名+外观+四视图空间布局
- 场景四视图：**必须写** `此图是四个视角，取其一个视角作为背景`
- 场景非四视图：写 `实景照片`

**下半框：动作描述**
- 正文用 `图1女` 指代人物，`图2中的背景/椅子` 指代场景物品
- 正文只写动态+情绪+运镜+灯光质感，不重描参考图已有元素
- 音频驱动对口型：禁文本词（subtitle/text/caption/letter/word/lyrics），声线禁写
- 对口型写法：`嘴唇随歌声轻轻张合`
- 接镜写法：`直接硬切` `紧密衔接中间无过渡`

## 🎬 MV分镜方法论（LTX 时代产物，优先级低于上方手册）

MV不是逐句配图——按音乐情绪分段落。每镜5-15秒。

| 类型 | 占比 | 位置 | 说明 |
|------|------|------|------|
| 空镜/氛围 | 20-30% | 前奏、间奏、尾奏 | 纯环境、无人物 |
| 叙事/演绎 | 30-40% | 主歌 | 人物不张嘴，肢体讲故事 |
| 对口型表演 | 30-40% | 副歌、桥段、终章 | 面朝镜头对嘴 |

**分镜流程**：
1. whisper词级时间戳
2. 标气口（自然停顿处）
3. 按气口分镜，相邻短句合并，每镜5-15秒
4. 分配类型（副歌/桥段=对口型，主歌=空镜/叙事，前奏/尾奏=空镜）
5. 同场景相邻镜头合并生成
6. 资源清单（每个分镜需要的人物/场景/道具）
7. 逐镜出提示词

**场景统筹**：先归并全歌到最少场景（4-6个）→ 每场景一次性装入所有道具 → 生成场景图 → 全歌复用。
**禁止**：每句歌词配3秒画面、全程空镜、对口型出现在主歌段。

## 🎭 人物动态铁律

真人感核心：人物不能长时间一个姿势/视线/表情不变。先看时长是否够容纳变化。

**三步法**：确认时长 → 15s≈2-3变化点，30s≈4-5变化点 → 配合歌词情绪弧线分布。

**视线轨迹**：从看A→移到看B→再移到看C，禁止全程盯一个方向。
**表情递进**：笑意→收拢→泛红→涣散，配合歌词阶段。
**贴故事**：开心=眼神明亮望远方，伤痛=低垂望地面，转折=突然失焦。

## 🔗 时序连接词规则

- 先后：`然后` `接着` `再然后`
- 并发：`同时` `同步`
- 过渡融合：`在旋律缓缓过渡中` `随着歌声进入`
- 时间缓冲：`唱了几句之后` `又唱了几句之后` `又过了一拍`

错误：`前10秒远景...第11秒主歌...第25秒结束`（触发硬切）
正确：`前奏中闭眼...旋律过渡中睁眼同时嘴唇轻张...`

## 🎥 运镜+景别铁律

- 禁止远景/广角拍人物，人脸必崩——最低中景，中近景更稳
- 运镜小幅度极缓慢，环绕≤45度，固定镜头优先
- 30秒内只能单运镜，硬切需拆分镜
- 手机道具：必须写位置+平放+无人手持+俯拍，否则默认成手持

## 💡 灯光+场景铁律

- **光源唯一**：正文只写一种光源，禁止叠加互斥光源。光源方向与参考图一致（图亮不能写暗）
- **场景减法**：复杂架构（多房间/玻璃隔断）触发分身幻觉，只描述唱歌区
- **空间锁死**：正文写 `前方是[方向] 身后是[方向] 左侧是[方向] 右侧是[方向]`
- 陌生人物：`模糊虚焦轮廓面目不清`，消失 `如雾气般消散`

## ⚠️ 反向提示词避坑

禁止 `场景细节不一致` `物体归属错误` → LTX不敢放参考图背景。
正向修复：正文开头写人物与空间的地面连接（`站在图2中的地板上，四周墙面围着她`）。

安全清单：麦克风，支架，灯具，头戴式耳机，字幕，水印，文字，标识，最差画质，模糊，抖动，闪烁，面部扭曲，人物样貌不一致，人物重复，物体重复，肢体融合，手部融合，多余手指，脸部错位，服饰错乱，人体结构畸形，插画，动漫，明显计算机生成图像，明显三维渲染图

## 实测避坑速查

| ✅ 可执行 | ❌ 不可执行 |
|------|------|
| 固定镜头/极慢推近/≤45°环绕 | 手持晃动/快速运镜/大范围环绕/硬切 |
| 连续动作流（"闭眼→睁眼"） | 分段时间标记（触发硬切+物体复制） |
| 瞬间动作（偏一下立刻回来） | 持续状态（歪着头说话） |
| 场景极简（仅唱歌区） | 复杂场景（多房间=分身幻觉） |
| 情绪拆成物理动作 | 抽象情绪词 |
| 台词{}包裹无引号 | 说话加引号/声线括号 |
| 状态描述驱动表情 | 解剖学局部指令 |
| 30秒单运镜 | 30秒多运镜/硬切 |
| 英文版提示词 | —（控制力更强） |

## 齐白兰固定参数

- 声线：清纯甜美，20岁少女的清透声线
- 服装：3套（居家/外出/冬季），面部五官不变仅换服装发型
- 录音棚四方向：前方控制室 / 身后颗粒装饰墙 / 左侧吸音棉墙 / 右侧进出门
- CFG=2-5默认3，禁>7
- 全正向禁否定词
- 近音替换：虚拟→须你 / 别走→停一下 / Oi→哦诶
- 台词{}包裹，声线不括号

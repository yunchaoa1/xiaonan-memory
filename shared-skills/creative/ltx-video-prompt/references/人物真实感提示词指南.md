# 人物真实感提示词指南

> 来源：凡哥多轮实测+LTX官方指南。覆盖出图→视频→禁区三层。

## 一、出图阶段（Qwen 2511 生图）

照片级写实人物照片。哑光自然肤质，真实毛孔可见。发丝自然毛躁，不规则碎发。面料纹理清晰，褶皱纹路自然垂坠。布光单灯柔光，阴影过渡柔和。手机直出质感，不磨皮，不锐化，不CG感。超清，4K。

## 二、视频阶段（LTX提示词中的人物表情）

| 原则 | 写法 |
|------|------|
| 不对称 | 嘴角翘起一个小小的弧度，不是左右对称的笑 |
| 延迟感 | 嘴巴先翘，眼角慢了半拍才弯 |
| 肌肉残留 | 笑完了嘴角还留着一点弧度，没收干净 |
| 呼吸同步 | 说话时肩膀跟着气息微微起伏 |
| 自然瑕疵 | 说完嘴唇合上后轻轻抿了一下 |
| 眼睛 | 眼皮放松半垂，眼睛自然睁开，不瞪不发力 |
| 额头 | 平滑放松，没有抬头纹 |
| 整体状态 | 像窝在房间里跟好朋友聊天，不急不慌 |

## 三、禁止清单

水光肌、CG渲染质感、左右完全对称的表情、露牙大笑、瞪大眼睛、瞬间切换的表情、像在表演而不是像在聊天、磨皮美颜感

## 四、实测避坑

| 坑 | 原因 | 修法 |
|------|------|------|
| 歪头持续太久 | LTX把持续动作写死 | 全部偏侧描述清除，用对称化表达 |
| "偏在一边"→歪头 | LTX把不对称理解成歪 | 改成"翘起小小的弧度" |
| 抬头纹+瞪眼 | 西方化表情默认 | 状态描述替代解剖指令 |

# LTX 避坑词库 · 逐字扫描版

每条写完提示词后逐字扫——不是概念检查，是搜实际字符。

## 禁用词 → 替换

| ❌ 搜到这个词 | ✅ 替换为 |
|------|------|
| 前置镜头/后置镜头（Pocket3场景） | 删掉——Pocket3只有一颗镜头 |
| Pocket3跟着身体转动 | 背景随着转动跟着旋转，她的脸一直保持在画面中间 |
| 笑意收进眼睛里 | 眼角弯了弯，嘴巴松下来 |
| 视线往下跳了半拍又抬回来 | 视线往下落了一下，立刻抬起来看向镜头 |
| 下眼睑 | 下眼皮 |
| 偏在一边 / 歪着脑袋（持续状态） | 翘起一个小小的弧度（嘴角）/ 偏了一下立刻回来（脑袋） |
| 说到XX时 / 当她说XX | 删掉——LTX无法对齐台词和动作时间点 |
| 第X秒 / 在第X到X秒 | 删掉——秒数标记LTX不执行 |
| 留出剪辑的自然收口 | 删掉——不写剪辑术语 |
| 确认构图 / 调整角度 / 确保 | 删掉——只写动作过程，不写目的 |
| 自嘲 / 真诚温暖 / 委屈（抽象情绪） | 拆成物理动作+面部描写 |
| Oi拉长调 | O——i |
| 深呼吸 / 停顿片刻 / 整理情绪 | 删掉——不写准备动作 |
| 不/别/没/无/非/否/no/not/never/don't | 全正向改写 |

## 自检流程
1. 写完提示词
2. 逐字扫描中文版——搜上表每个禁用词
3. 逐字扫描英文版——搜 no/not/never/don't
4. 末尾写"已自检：N/N"

## 常见漏检点
- "不加力"里藏着"不"→改成"自然睁开"
- "no extra force"里藏着"no"→改成"open naturally"
- "偶想"根本不同音（ǒu xiàng vs ǒu xiǎng）→偶像不换
- 近音只换实测说错的：虚拟→须你、Oi→哦诶、别走→停一下

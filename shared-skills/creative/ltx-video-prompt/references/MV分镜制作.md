# MV分镜制作工作流

## 流程
1. Whisper转写歌曲 → 获取逐段时间轴
2. 按歌词断句分组 → 每镜≤10秒（LTX）/≤15秒（Seedance）
3. 每句歌词不跨镜——断句在自然停顿处
4. 纯音乐段单独成镜（前奏、间奏、尾声）
5. 每镜标注"对口型"或"纯画面"
6. 画面中禁止出现汉字——LTX渲染汉字为乱码
7. 时长计算：整秒，不出现小数点

## 验证
- 每镜边界用Whisper验证：切点是否在歌词段之间
- 容忍0.5秒以下的尾音溢出
- 歌词长度÷情绪语速锚定时长

## 首帧图+图生视频
1. 先出首帧图（Agnes/Qwen/ComfyUI）
2. 用首帧图做LTX图生视频（Reference Image 1）
3. 首帧图不描述人物外观——参考图已定义
4. 区分是否带参考图：有参考图时只写场景+动作

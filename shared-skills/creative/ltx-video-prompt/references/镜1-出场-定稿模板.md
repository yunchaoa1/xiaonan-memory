# 镜1 · 出场+自我介绍 · 定稿模板

## 中文版

参考图1：齐白兰——年轻女性，黑色长发，白色吊带上衣，白色短裤。
参考图2：化妆间——场景参考图。取其中一个角度作为背景。

一段偶像练习生选拔的化妆间幕后花絮vlog自拍镜头。

齐白兰是画面里唯一的人。她周围的化妆间空着，安静。

固定镜头，始终保持不变。

声音清纯甜美，20岁少女的清透声线，略带娇羞但是保持兴奋。

齐白兰先是背对镜头坐在椅子上，然后猛的旋转了椅子看向镜头，在开始旋转椅子之前先看了一眼镜头同步说话（语调拉长打招呼）：{Oi！}（语速自然，像是在与刚认识的姐妹介绍自己）：{我看到你了，别走！我是齐白兰，一个活在数据里，但想暖进你心里的须你偶像。}眼角轻轻弯了弯，嘴巴松下来。笑容和眼神留着。呼吸落稳。

## 已验证可执行的要点

| ✅ 可用 | ❌ 不可用 |
|------|------|
| 固定镜头 | 手持晃动 |
| 背对镜头→旋转椅子→面向镜头 | 画面跟着椅子转（背景不动） |
| Oi拉长调 | 秒数标记触发动作 |
| 近音替换（须你偶像、别走→停一下） | 偶像→偶想（实测不说错） |
| 声线一句写完 | 声线包裹括号 |
| 台词{}包裹 | 说话内容加引号 |
| 描述背景极简 | 详细描述背景物品 |
| 单人场景声明 | 出现路人甲幻觉 |
| 眼部约束（额头平滑） | 眼睛瞪大+抬头纹 |
| 转椅动作可执行 | 椅子半圈/画面运动 |
| 动作和台词同步（看了一眼镜头同步说话） | 台词锚点触发动作 |

## 画面控制

| ✅ LTX能执行 | ❌ LTX执行不了 |
|------|------|
| 固定镜头、静态拍摄 | 手持晃动、呼吸式晃动 |
| 远景→中景推近（推镜） | 推拉摇移跟升降、画面转动 |
| 人物动作：坐、站、转头、抬手、离开 | **椅子转圈/背景转动**（背景全程静止） |
| 眼睛看镜头、视线下落、重新看镜头 | 秒数触发动作（第3秒做X，第6秒做X——完全无视） |
| 嘴角翘起、眼角弯、嘴巴松 | 台词锚点触发（"说到XX时做YY"——动作跑错位置） |
| 身体前倾、后撤 | 歪头持续（"脑袋往旁边歪"→僵硬保持歪头姿势） |
| 手在胸口点一下、手搭在手臂上 | **戳手指/对戳**（生成极不自然，怪异） |

## 表情控制

| ✅ 能用 | ❌ 不能用 |
|------|------|
| 额头平滑放松 | 瞪眼+抬头纹（LTX默认→西方化夸张表情）⚠ |
| 眼皮放松半垂、眼睛自然睁开 | 睁大眼睛、瞳孔一闪 |
| 眼角弯出一道浅浅的弧线 | "笑意收进眼睛里"（太抽象）⚠ |
| 下眼皮微微提起来 | "下眼睑"（医学词汇，模型不懂）⚠ |
| 嘴角翘起一个小小的弧度 | "嘴角偏在一边"→LTX误解成整头歪 |
| 嘴巴松下来、不发力 | "嘴角翘起来"写成持续状态→僵住 |

## 语言规则

| ✅ | ❌ | 说明 |
|------|------|------|
| 全正面描述 | 否定词：不/别/没/无/非/否/no/not/never/don't | 最高优先级⚠ |
| 英文版效果优于中文版 | — | 双语输出 |
| 大白话日常用语 | 拟型词："跳了半拍""化开""推着往前跑"⚠ | 模型不理解诗意 |
| 视线往下落了一下，立刻抬起来 | "视线往下跳了半拍又抬回来" | — |
| 下眼皮微微提上去 | 下眼睑 | 医学词汇替换⚠ |
| 动作只写过程 | 目的性描述："确认构图""调整角度""为了" | 删掉所有目的描述⚠ |
| 只写画面里能看到的内容 | 剪辑术语："留出剪辑收口""给后期空间" | 删掉⚠ |
| 近音替换：虚拟→须你、别走→停一下、Oi→哦诶 | **偶像→偶想/藕像**（从没说错过，禁止替换）⚠ | 只换实测说错的词 |
| 台词{}包裹，无引号 | 引号包裹说的话 | — |
| 声线一句话写完，无括号 | 括号包裹声线 | — |

## 结构规则

| ✅ | ❌ |
|------|------|
| 提示词写长写详细（官方推荐） | 精简提示词 |
| 台词分段+中间插动作 | 动作放台词后面 |
| CFG=2.0-5.0（默认3.0） | CFG>7 |
| 结构：主动作→细节→环境→镜头 | 环境描写的越多越容易幻觉 |
| 背景极简 | 背景详细描述（越多越乱） |
| ≤200词 | — |

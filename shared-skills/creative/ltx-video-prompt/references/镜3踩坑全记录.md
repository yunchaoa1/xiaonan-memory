# 镜3 · 秘密分享 · 踩坑全记录

> 对话日期：2026-07-21 | 实测待续

## 踩坑顺序

1. **歪头持续太久且僵硬** → 把"歪了歪脑袋"改成瞬时动作"偏了一下立刻回来"
2. **"偏在一边翘起来"** → "偏在一边"被LTX理解成整个身体歪头→全部删除偏侧描述→改成"翘起一个小小的弧度"
3. **UI中的"偏在一边"版本仍存在** → 工作流里还是旧版，需更新
4. **秒数标记不起作用** → 镜1中第2秒开始说话但标记是第4秒。LTX忽略秒数标记
5. **台词锚点不起作用** → "说到XX时"LTX无法对齐。已写入铁律
6. **抽象词大模型不懂** → "自嘲""真诚温暖"→必须拆成物理动作。已写入避坑词库
7. **"留出剪辑的自然收口"** → 模型不懂剪辑概念。已删除
8. **Pocket3单镜头** → 写"前置镜头"是错的。Pocket3只有一颗镜头，屏幕翻过来自拍
9. **英文版控制力优于中文版** → 最终输出双语对照

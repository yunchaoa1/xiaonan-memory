# 人物真实感提示词规范

## 出图阶段（Qwen 2511）

照片级写实。哑光自然肤质，真实毛孔可见。发丝自然毛躁，不规则碎发。面料纹理清晰，褶皱纹路自然垂坠。布光单灯柔光，阴影过渡柔和。手机直出质感，不磨皮，不锐化，不CG感。

## 视频阶段（LTX提示词中的人物）

| 原则 | 描写 |
|------|------|
| 不对称 | 嘴角偏向一边翘起来，不是左右对称的笑 |
| 延迟感 | 嘴巴先翘，眼角慢了半拍才弯 |
| 肌肉残留 | 笑完了嘴角还翘着一点，没收干净 |
| 呼吸同步 | 说话时肩膀跟着气息微微起伏，吐气时表情松下来 |
| 自然瑕疵 | 说完嘴唇合上后抿了一下、眉毛动完有一根没归位 |
| 眼睛 | 眼皮放松半垂，眼睛自然睁开，不瞪不发力 |
| 额头 | 平滑放松，没有抬头纹 |
| 整体状态 | 像窝在房间里跟好朋友聊天，不急不慌的笃定 |

## 禁止清单

水光肌、CG渲染质感、左右完全对称的表情、露牙大笑、瞪大眼睛、瞬间切换的表情、像在表演而不是像在聊天、磨皮美颜感

## 实测避坑追加

| 问题 | 错误 | 正确 |
|------|------|------|
| 偏侧描述触发歪头 | `嘴角偏在一边翘起来` `脑袋往旁边歪` | `嘴角翘起一个小小的弧度`——全部偏侧词删除 |
| 抬头纹 | 未约束 | 用人物状态描述代替面部指令：`整个人很放松` `不急不慌的笃定` |
| 眼睛瞪大 | `眼睛睁大了一瞬` | `眼皮放松半垂，眼睛自然睁开` |

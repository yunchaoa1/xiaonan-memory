# Qwen 2511 双图合成提示词格式

## 场景
凡哥提供图1（人物参考图）+ 图2（场景参考图），用 Qwen 2511 将人物合入场景。

## 核心铁律（逐条来自本会话实测）

1. **纯正向，无否定词** — 不发"不要""没有""不"
2. **光照不当"光束"写** — 写"面部受暖光映照"而非"一束光照在脸上"。"头顶单束暖光"也会被理解成舞台追光。简化光描述
3. **去AI化不能过头** — 不写"毛孔""纹理""斑点"。适度写"肤色均匀自然""柔焦质感"。过度的去AI化导致满脸斑点
4. **表情匹配情境** — 分手情歌≠幸福微笑。写"眼神放空""平静中透出淡淡无力感"——给模型明确的情绪锚点
5. **避免塑料感** — 加"真实胶片人像摄影风格""轻微柔焦质感"
6. **耳机写对** — 录影棚用"监听耳机"（无麦），不用"耳麦"或"头戴麦克风"
7. **妆造可指定** — "韩式偶像舞台妆，清透底妆搭配自然眼妆和水光唇色"
8. **姿态别瞎写** — 不写不必要的"侧身""歪头"，除非情境需要
9. **简化到底** — 如果出图渲染过重，删光所有的光线描述词，只留"纯黑背景墙"。一步一步减

## 标准格式

```
图1 [角色名]人像参考图与图2 [场景名]场景融合：[角色名]坐在[位置]，[表情描述]，[姿态描述]，[妆造描述]，面部肤色均匀自然带有轻微柔焦质感。纯黑背景墙。整体呈现真实胶片人像摄影风格，4K。
```

## 00_总览与依据.md

必填四节：

1. **交付说明**：日期 / 项目名 / 用途（逐节点粘进影剧工坊）。
2. **题材依据表**：三列 `依据 | 内容 | 来源＋日期`。数字必须带口径（热度值／日播／累计／素材数），
   不能把"8602 万热度"说成"亿级爆款"。查不到就写"查不到"。
3. **一句话选型理由**：焊了哪两条主干、换了什么锚点、避开了什么红线。
4. **平台能力提示**：当前出图模型的分辨率天花板、组图支持、参考图上限——凡哥要先知道做不到什么。

## 01_写作节点_创作需求.md

- 可直接粘的**创作指令**一段（时代地点／主要人物／矛盾／走向／篇幅／禁忌）。
- 备选：若平台写作节点是**多轮问答**形式，就按问答逐条写答案。

## 02_剧本节点_剧本.md

- **集首三要素**：本集核心冲突／信息差／本集钩子。
- **规格**：画幅 · 画风 · 时长 · 人物场景数 · 台词总量。
- **分场**：`镜号 ｜ 时段 ｜ 时长 ｜ 场景`，每镜 `△ 动作` + `人物名：「台词」`。
- **台词自检表**：总字数（净／含标点分开）· 时长容量 · 最紧一镜字数/秒 · 旁白 VO 是否 0 处 ·
  单镜最多句数 · 单镜最长秒数。

## 03_分主体节点_资产清单.md

- 人物：身份母版 / 脸型 / 五官 / 发型 / 肤色 / 身形比例 / 服装结构材质颜色 / 配饰 / 可见表情 / 音色。
- 场景：空间尺寸 / 建筑材质 / 固定家具 / 固定地标 / 配色 / 光线。
- 道具：数量 / 外形比例 / 材质 / 颜色 / 部件 / 状态版本。
- **只写看得见的事实**。职业、亲属身份、剧情性格不得用来补齐五官和服装。

## 04_分镜节点_分镜脚本.md

每镜一张卡，字段缺一不可：

`秒数 · 场景 · 景别 · 机位（高度/角度/距离） · 占框（占画高%＋画面位置＋身体朝向） ·
动作 · 台词 · 情绪（可观察的微行为，不写抽象词） · 光 · 音效 · 参考图`

末尾附**台词分布表**（镜号／时段／秒数／场景／景别／主说话人／句数）。

## 05_出图节点_提示词.md

顺序：**人物四视图 → 场景主图 → 场景机位派生 → 道具 → 分镜首帧**。

- 每条写好"参数提示"（当前模型的分辨率档位）。
- 人物四视图：一图四格，纯白底，极细浅灰等宽线，无外框，逐格点名，一致性句，排除句。
- 场景：先正俯视主图（空间身份锚），再逐机位派生（每张只改机位一个变量）。
- 道具：按剧情需要出四视图或单图；有状态变化的（碎／修好）分状态出。
- 分镜首帧：每条写清"挂哪几张参考图"，并写死占框百分比。
- 末尾附**首帧核对表**。

## 06_出视频节点_提示词.md

每镜一段，六段字段名裸写：`subject_definitions / summary / retention_analysis /
detailed_description / overall_soundscape / non_diegetic_music`。

- 六段全英文，只有 `<d>[Chinese] 台词</d>` 内是中文，`[Chinese]` 后必须有一个空格。
- 说话人 ID 全片固定（S1/S2/S3），跨镜一致。
- 每镜开头声明 `no cuts`（单镜）或写清切点。
- 末尾附**全包自检表** + 一句"已自检：…全过"。

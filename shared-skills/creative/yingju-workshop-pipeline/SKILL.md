# 影剧工坊交付包（六节点一包交货）

影剧工坊是公司自研产品（诺境科创 · Novin ai）。凡哥要"跑一遍"时，他要的不是聊天里的长回答，
而是**一包能逐节点粘贴的文件**，他自己在平台上点生成。

## When to Use

- "我们跑一遍，生成图片和视频用我们自己开发的影剧工坊"
- "你给我提示词，我来粘贴到影剧工坊去生成"
- "这套流程走一遍 / 出一集试试 / 一集一集来"
- "不要分镜图，只用全能参考"

## 凡哥定死的五条规矩（2026-11-16）

**这五条压过下面所有流程细节，冲突时以这五条为准。**

1. **提示词全部由小南出**，凡哥自己粘进平台。不代操作平台、不要账号、不假设能登录。
2. **一集一集来，从镜 1 跑到镜 N，一步不跳。**不许为了求稳把某一镜（比如纯手部特写）挑出来先跑——凡哥按顺序看，出问题他会直接说第几镜。
3. **小说节点可跳过，直接从剧本起集。**小说在我们这条线上不喂任何下游节点（分主体/分镜/出图/出视频只吃剧本），纯属把想清楚的事再用叙述体写一遍，是两次转换两次失真。
4. **不出分镜图、不出首帧图。**出视频走全能参考：只上人物四视图、场景图、道具图三类参考。
5. **平台没跑通前不许写"已跑通"。**交付状态写"内容包已交，等凡哥跑平台回传结果"。

## 平台六节点与分工

| 节点 | 平台要的输入 | 本包对应文件 | 内容按什么规范写 |
|---|---|---|---|
| 创建项目 | 视觉风格 / 题材 / 画幅 | 00 总览 | 国漫3D + 古风幻想 + 16:9 |
| ① 写作 | 多轮问答或创作指令 | 01（**本包跳过，留作备胎**） | `short-drama-story-engine` |
| ② 剧本 | 该章小说内容 | 02 剧本（**起点**） | `short-drama-story-engine`（对白铁律） |
| ③ 分主体 | 剧本 | 03 资产清单 | `screenplay-asset-extraction` |
| ④ 分镜 | 该章剧本 | 04 分镜脚本 | `screenplay-to-15s-storyboard` |
| ⑤ 出图 | 资产信息 | 05 出图提示词 | `image-prompt` + 四视图宫格描述 |
| ⑥ 出视频 | 参考图 + 分镜脚本 | 06 视频提示词 | `h3-video-prompt`（六段格式·全能参考） |

**先确认平台当前模型能力，再动笔。** 2026-11-16 实测：出图＝豆包 Seedream 5.5（最高 2K，
16:9＝2816×1584，**无 4K**）；出视频＝MiniMax H3。模型换了就先去核官方参数，
别拿旧技能的默认值直接写。

## 交付包结构（8 份，00–07）

```
00_总览与依据.md          题材依据表（依据/内容/来源+日期+口径）+ 文件索引 + 平台能力提示
01_写作节点_创作需求.md    备胎：剧本节点若拦人，用它生成约 250 字占位小说把章节编号占住
02_剧本节点_剧本.md        集首三要素 + 分场 + △ + 台词 + 台词自检表
03_分主体节点_资产清单.md  人物/场景/道具，全写成"看得见的事实"
04_分镜节点_分镜脚本.md    每镜：秒数/景别/机位/占框/动作/台词/情绪/光/音效
05_出图节点_提示词.md      人物四视图 → 场景主图 → 场景派生 → 道具（无分镜图）
06_出视频节点_提示词.md    H3 全能参考六段，每镜一段（含参考图上传顺序）
07_第N集执行单.md          从创建项目到出片的顺序清单 + 每步核对点 + 报错格式
```

目录建议：`D:\Documents\我的文档\07_影剧工坊跑通\<片名>\`

## 粘贴顺序（乱了必出错）

**节点顺序**：剧本 → 分主体 → 分镜 → 出图 → 出视频（写作节点跳过）。

**出图内部顺序（一集 13 张）**：人物四视图 → 场景正俯视主图 → 场景机位派生 → 外景 → 道具。
场景派生**必须挂俯视主图**，不挂就是另一间屋子。

**视频内部顺序**：人物四视图 → 场景图 → 道具图，与 `<Picture N>` 编号一一对应。**没有首帧图。**

## 每个节点贴完就查（别攒到最后）

| 节点 | 核对什么 |
|---|---|
| ②剧本 | 镜数齐不齐／秒数加起来对不对／台词一字不少／**△ 动作说明有没有被平台删掉** |
| ③分主体 | 人物可视锚点还在不在（旧疤、围裙水渍、木簪这类）——丢了后面认脸必飘 |
| ④分镜 | 每镜**占框比例**和**机位**还在不在——被抹掉，出图和出视频全靠猜 |
| ⑤出图 | 四视图四格齐（正/单侧/背/五官特写，无第五格）／服装跨格一致／细灰线无外框／脸别糊手别多指头 |
| ⑥出视频 | 脸像不像四视图／口型跟没跟上／声音有没有提前冒出来或拖尾 |

**△ 那条是重点**：小说节点一撤，剧本里的△就是唯一讲动作的地方，被清了分镜就只剩几行台词，没得拍。

## 铁律

1. **台词净字数 ÷ 3.3 ≤ 该镜秒数**。写不下就砍字或拆镜，别硬塞（塞不下模型吞字、自己编）。
2. **一镜一个主要说话人**。两人对话拆成两镜；不说话的写死 `silent, lips closed`。
3. **无首帧图时，每镜第一句必须写死开场状态**：机位高度/距离/朝向 + 占框百分比 + 位置 + 手在干什么 + 光从哪来。缺一件画面就自己发挥。
4. **占框写百分比 + 画面位置 + 身体朝向**三件套，不写"居中/偏右"。
5. **同一角色/道具全片用逐字相同的写法**，换词就漂。
6. **题材先查榜再动笔**，交付件开头必须有"题材依据"段（依据/内容/来源+日期+口径），
   见 `short-drama-story-engine` → `references/theme-selection-from-live-charts.md`。
7. **平台能力先核**：分辨率天花板、是否支持组图、参考图张数上限。做不到的当场说，不要写完才说。
8. **净字数与含标点字数分开标**，只给一个口径核对时会对不上。

## 常见坑

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 还在出分镜首帧图 | 白花 9 次生成，还跟文字里的构图打架 | 2026-11-16 起不出首帧图，走全能参考 |
| 保留小说节点 | 两次转换两次失真，浪费一次调用 | 直接从剧本起集，小说只留备胎 |
| 挑难镜先跑 | 违背凡哥"一集一集不跳" | 镜 1 → 镜 N 按顺序，问题他会报 |
| 按旧模型默认值写尺寸 | 平台达不到，整套提示词作废 | 动手前先核当前出图模型官方参数 |
| 四视图指望"组图"参数 | Seedream 5.5 无 `sequential_image_generation` | 在 prompt 里描述四格宫格直出 |
| 把性格形容词写进人物资产 | 模型自由发挥，长相跑偏 | 资产只写看得见的事实，性格靠台词演 |
| 台词按"字数看着差不多"估 | 视频吞字、赶拍 | 逐镜算 净字数÷3.3 与秒数 |

## 出问题时怎么定位

凡哥会报三样：**第几镜 + 什么现象 + 他觉得哪里不对**。拿到这三样直接定位到具体那句文字，
别让他把整段贴回来。

补料顺序（**一次只加一处**，加完只重跑那一镜，别整套重跑）：
1. 补机位（高度、距离、朝向，三个数都写出来）
2. 补占框（主体占画高百分之几、眼睛落在画面哪一段）
3. 补开场状态（第一帧人站在哪、手里拿着什么）
4. 最后才补光线方向

顺序反了会越改越乱。

## 交付话术（凡哥偏好，硬要求）

- **说人话**：少表格、禁术语/英文缩写/内部代号。
- **路径给完整绝对路径**，不要只说"在某个目录"。
- **别批量推附件到聊天**（docx/md 一大串），给路径就够。
- **主动报自己改了什么技能/记忆**（"做了要开口说"）。
- 一次只抛一件要他决策的事；清单给完等他挑。

## 未实测项（诚实清单，别当结论用）

- 剧本节点**能否独立起集**（不经小说）。若被拦：用 01 生成约 250 字占位小说把章节编号占住，再照常贴剧本。
- 平台访问地址与部署形态（10-23 日报记过"部署在本地"，但本机无对应监听端口，属公司侧）。
- 出图/出视频节点能否改参数（2K 档位、时长档 60/90/120/150/180 秒）。

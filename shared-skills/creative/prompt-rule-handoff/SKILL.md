# 提示词规矩交付 与 台词失准分诊

## When to Use

- 凡哥说「把我们的 skill 交给某某，让他用我们的 skill 写提示词」；
- 别人（小李/小何/小吴等）出的片子**台词不按卡词说、含糊听不懂、说错人**；
- 要把 H3 / Seedance / LTX 的提示词规范打包给团队外部的人。

凡哥的团队里有人（影剧工坊线＝小李/李林，平台线＝小何/小吴）会自己写镜头提示词。他们产出出问题时，凡哥的口径是「**把我们的 skill 交给他，让他用我们的 skill 写**」——不是替他们改一版了事。

本 skill 管两件事：
1. 别人产出的片子**台词不按提示词说、听着听不懂**时怎么定根因；
2. 把我们的规矩**交出去**时交什么、怎么交。

规则细节（六段格式、`<d>` 空格、retention 词汇等）以 `h3-video-prompt` 为准（H3 唯一入口；Seedance 已隔离、LTX 已弃用）——**那些是凡哥自有技能，小南不可代改**，需他授权或 `hermes curator adopt` 后才能自动维护。

## 一、台词失准：五条根因（按命中率查，别先怀疑模型随机性）

2026-10-22 现场：小李那线的视频「台词不按照提示词里的台词说话，说出来的话总是听不懂」。逐条对官方规范排查，命中率排序：

1. **台词没包进模型的台词标签**。H3 = `<d>[Chinese] 台词</d>`，且 `[Chinese]` 后**必须有一个空格**；漏标签 → 模型把台词当普通描述，自己编话。
2. **没标说话人 / 没写死不出声的角色**。H3 用 `(S1) speaks: "…"` / `(S2) replies: "…"`，跨镜一致；不出声的写 `silent, her lips closed`（手部同理写死）。不写就抢词、串词、对错人。
3. **一句台词配不上该镜秒数**。15 秒的镜塞三四句必吞字。判据：台词字符数 ÷ 镜时长 ≈ 实际语速，超过正常说话速度就一定含糊——**宁短勿长**，留气口。
4. **台词写在英文段落或标签外**。H3 六段全英文、只有标签内台词保留中文，混写会被当噪声丢掉。
5. **一镜两个以上说话人**。一镜只留一个主要说话人；对答拆镜，复杂对话单人分镜后期合成。

## 二、三步自查（拿到一份提示词就能判，先做这个再开口）

```bash
grep -o '<d>' 提示词.txt | wc -l               # ① 台词包对数 vs 该镜台词句数，不等就是漏包
grep -o '(S[0-9])' 提示词.txt | sort | uniq -c  # ② 说话人号是否标齐、跨镜一致
grep -o '<d>\[Chinese\][^ ]' 提示词.txt | head  # ③ 有输出 = [Chinese] 后漏空格
```

第三条是高频错（2026-09-03 曾凭直觉删掉 43 处空格，对照官方原文发现删错了、已回滚）。

## 三、三套台词格式互不通用（**先问对方跑哪个模型，再决定交哪套**）

| 模型 | 台词写法 |
|---|---|
| MiniMax H3 | `<d>[Chinese] 台词</d>` + `(S1) speaks:` 稳定说话人号；六段全英文，只有 `<d>` 内中文 |
| Seedance 2.0 | `齐白兰说："台词"` 直接写、不包裹；中文提示词 |
| LTX 2.3 | 英文 + `Qi Bailan speaks: {"近音替换版"}`（`{}` 包裹 + 近音替换） |

照搬必错。问清对方用什么模型再打包，是这类交付的**第一步**，不是可选项。

## 四、交付形态：至少两件，别只甩一个文件

1. **可安装的技能目录**——对方有 Hermes/OpenClaw 时直接装，能自动触发；
2. **一页「错误写法 vs 正确写法」对照速查**——对方没有 agent 环境时，他能贴给任何 AI 或照着抄。

交付前先**看对方现在的实际产出**（用第二节三步自查判），否则你交的是"通用规范"，他缺的可能只是其中一条——凡哥要的是治好，不是发文件。

## 五、凡哥口径（沿用，别跑偏）

- 「**把我们的 skill 交给他，让他用我们的 skill 去写提示词**」＝交标准 + 让他自己产出，不是我们代写代改。
- 交付物要**能直接落地**：路径/命令/文件给全，别只说"我整理了"。
- 他一次只推一件事；这条线做完再谈下一条。

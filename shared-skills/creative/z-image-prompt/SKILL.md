# z-image 提示词规范

凡哥用 z-image 生成图片，中文语义提示词。以下规则来自实战踩坑。

## 核心规则

1. **中文语义**——用中文描述，不加英文修饰词
2. **纯正向**——不出现"不要""没有""避免""不带"等否定词
3. **服装必写**——角色提示词必须明确写完整衣着，否则容易出裸体
4. **去AI塑料感**——加"自然棚拍质感""肤色均匀自然""胶片人像摄影风格"，但不过度——不说毛孔斑点等极端词
5. **禁光束词**——不说"光束打下来""一束光照亮"，改用"受暖光映照""光影自然过渡"
6. **表情写动作**——写"嘴角上扬""眼神放空""双唇轻合"，不写"开心""悲伤""享受"
7. **去空洞修饰**——去掉4K等泛泛之词，用具体描写替代

## 四视图格式

左侧大幅为胸部以上特写正面，右侧三格纵向排列为正面全身、侧面全身、背面全身，四格分区明确纯白背景。日漫立绘风格，线条干净。

## 角色提示词模板(T2V)

```
[角色名]拟人角色四视图，左侧大幅为胸部以上特写正面，右侧三格为正面全身、侧面全身、背面全身，纯白背景。角色全程完整穿着服装。[特征描述2-3句]。[衣着描述2-3句]。日漫立绘风格，线条干净。
```

## I2V/多图融合提示词模板

多参考图时用@Ref标签区分，不用"图1/图2"等人类指令词：

```
@Ref1角色位于[位置]，[动作]。@Ref2角色位于[位置]，[动作]。背景@Ref3场景。画面[光影/氛围/风格]。
```

## 场景提示词模板

```
[场景名]广角场景，[环境细节]，[光影描述]，日漫场景插画风格，色彩明快，线条干净。
```

## 常见坑

| 错误 | 正确 |
|------|------|
| 没写服装 → 裸体 | 写明"穿戴完整服装"+具体衣裤鞋 |
| "光束打下来" | "受暖光映照，光影自然过渡" |
| "悲伤的表情" | "眼神放空，嘴角微抿" |
| "图1人物+图2场景" | 纯描述最终画面，不加指令词 |
| 过度去AI(毛孔斑点) | "肤色均匀自然""柔焦质感" |

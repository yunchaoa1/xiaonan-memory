# 用匿名观众测试迭代一集剧本（中文短剧实战·2026-11-16 打出来的）

> 来源：《这瓶是活的》第 001 集，8 轮迭代实测。看懂分 5.5→6.8，台词分 4.5→7.5。
> 这份文件解决一件事：**怎么知道剧本"观众看不看得懂"，而不是自己读着觉得挺好。**

## 0. 前提：剧本阶段不许被镜头和秒数框死

凡哥 2026-11-16 原话：「好的剧本并不是用很多框架框死的，该注重的是剧情的完整，因果的完整，台词与情绪的演绎。」

- **不要**先定"90 秒 / 9 镜"再往里塞故事。那是拿产品成本倒推创作，删到第三版因果就碎了。
- **要**先把场次和对白写完，写完再核时长（台词字数 ÷ 3.3 字/秒 + 动作行数 × 1.8）。
- 剧本阶段**不切镜、不标秒数**，切段是分镜节点的事。
- 时长核出来是多少就报多少，再去对平台的档位（60/90/120/150/180）；对不上就调故事，不调因果。

## 0.5 动笔前先列因果链清单（能挡掉大半轮次）

实测：10 轮里至少 6 轮是在补因果断点，而这些断点动笔前就能挡掉。动笔前先列六行，写完拿它逐行对剧本：

1. **谁想要什么**（外部目标，看得见，不是"她要一个公道"这种）
2. **谁挡着，他凭什么挡**（权力、证据、身份从哪来）
3. **这件事的第一因在哪**（关键物件怎么到她手上的，关键的话是谁传给谁的）
4. **每一环靠什么推进**（必须是新的动作或新的一句话，不是"她想通了"）
5. **哪一环抽掉后面就推不动**（这一环必须演出来，不能靠剪接暗示）
6. **主角为什么不用更省事的办法**（不早说、不跑、不报官）——对应的筹码要在画面里看得见

对不上的那一行，就是必补的地方。**别用"让反派提前知道内情"来补**——那会造出"长辈布一个精密局"式的巧合链，观众一推就散。让反派按**行业常识/世俗规矩**行动，理由就在他自己身上，不需要谁给他喂信息。

关键提醒：**每加一句台词，回头扫一遍全剧的时间、数量、地点、称谓。**实测三次掉分全部来自"加料加坏"，不是原始稿的问题。



1. **写**：场次 + △动作 + 对白，写完先跑 `scripts/script_lint.py <文件> --mode cn --genre <题材> --words <时长×4>`。
   - 中文剧本必须调 `--words`，默认 220 是英文词口径，中文按字数会虚高报错。
   - ❌ 只允许零个。⚠ 里的"拍表"是可选，不要为了消警告把剧本又框一遍。
2. **测**：派一个 subagent，**只给它剧本正文**（去掉信息区、人物关系表、创作说明），让它：
   - 复述剧情
   - 逐条列看不懂的地方
   - 给三项打分：看懂 / 想追下一集 / 台词像真人
   - 指出最假的一句
   - 回答指定关键字宙（如"房契的来龙去脉你能拼出来吗"）
3. **只改硬伤**：矛盾（时间/数量/地点/人物位置）、因果断点（某一步观众必须自己补）、编剧说话的位置。
   **不改**：观众能自己推的地方、风格偏好。
4. **再测**。门禁：看懂 ≥7、台词 ≥7。达标交稿。

## 2. 三个反复踩的坑（每次都栽在这）

### 坑一：加信息 ≠ 更清楚
第五版我加了一句"砸碎的扔在筐里，一年也没人翻一下"，本意是让瓶显得必需，结果跟"师父上个月才死"直接打架，分数从 6.8 掉到 6.5。
**规则：每加一句，回头扫一遍全文的时间、数量、地点、称谓。**

### 坑二：一个事实出现两个来源
"房契在瓶里"和"师父临终塞给她"并存 → 观众不知道该信哪个，是两个设定在打架。
**规则：每件关键物品只有一个来路。**定死一条，其余全部让路。本例最后定成：师父压根没往瓶里放，所以大伯砸开是空的。

### 坑三：让配角念说明书
"沈老二的老规矩，契纸不进箱，进瓶底"——屋里三个人全知道，让收旧货的当众念出来，就是编剧在递说明书。
**规则：关键信息让当事人自己漏。**掌柜只说"这底，砸过"，大伯一急脱口"那瓶里什么都没有！我砸开看过！"——他自己把自己卖了，观众从他慌里读出来，比从别人嘴里听出来强十倍。

## 3. 门禁之外还要过的三问

- 每一个"她为什么不……"（不早说、不跑、不报警），剧本里有没有一个可见的筹码堵死？（本例："那你搜" + "你要是不想让人在外头嚼舌头"——她说了没人信，还要顶着流言）
- 观众为什么要在乎主角会失去什么？（本例补了"我住哪儿？""你爱住哪儿住哪儿"）
- 集尾是"揭穿完就落地"还是"下一场非要打不可"？揭穿完落地 = 钩子弱；把新的危险推到门口才算钩子（本例：买主到了门外，大伯开价"你把契给我，这屋我让你住到年底"）。

## 4. 别做的事

- 不要为了一句 lint 警告去加拍表、加必保标记——那是分镜的活。
- 不要拿同一版反复测到分数满意为止；每轮只改硬伤，改完最多再测一轮。
- 不要把测试里提到但属于"跨集铺垫"的问题塞进单集——记下来留给下一集。

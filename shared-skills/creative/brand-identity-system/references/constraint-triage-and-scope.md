# 约束诊断与范围解绑（Constraint Triage）

> 用途：接到品牌设计需求后**动手前**的第 2 步。目的是在「进框即画」之前，
> 先确认这个框本身是否自相矛盾。实战中最贵的失误就是跳过这一步。

## 一、不可能三角

**品牌标 = 符号 + 字标。符号负责「被记住」，字标负责「我是谁、做什么」。**

当需求要求**一个孤立图形同时讲完多个语义**时，就是不可能三角：

- 往抽象走 → 语义全丢，用户评「太简单、单调、没高级感、像素材库」
- 往具象走 → 直白廉价，用户评「土」
- **两条路都不对，怎么画都不对** —— 这时继续出稿是浪费轮次

### 诊断问句（收到需求后先自问）

1. 交付物里有没有**字标**？（没有 → 谁来说清业务？）
2. 符号需要同时承载**几个**语义？（≥2 个 → 三角警告）
3. 有没有**色块底 / 背景**？（没有 → 强符号手法（错位叠印、发光、高饱和对比）失去舞台）
4. 色彩是**单色**还是允许层级？（单色 → 质感只能靠比例与留白，表现力上限低）
5. 有没有**审美参照**？（没有 → 先要参照，不要盲画）

**任一为「是/没有」→ 先提解绑，再开工。**

## 二、解绑清单（按重要性排序）

| 优先级 | 解绑项 | 为什么关键 |
|---|---|---|
| ① | **允许字标**（中文标准字 + 副标） | 「凸显特点」的真正器官。符号讲一个词，业务交给字标和副标 |
| ② | **允许色块底版本**（App图标 / 启动页 / 头图） | 解决「单调、提不起兴趣」；深底是高饱和错位类手法的最佳舞台 |
| ③ | **符号重设计** 或 承认**符号只讲一个词** | 解掉「有 A 没 B」的两头不彻底 |
| ④ | 允许一组**色彩层级**（主色 + 错位色 + 深底 + 反白） | 主色不动即可满足 |
| ⑤ | 主色 / 核心色号 | **不动**，这是品牌资产 |

### 话术模板（直白、给出代价，不要抱怨）

> 这个需求里有个「不可能三角」：你要一个图形同时讲完 X + Y + Z，
> 而承载「说清业务」的那个器官（字标）被拿掉了 —— 所以抽象就单调、具象就土。
> 建议放开三条：① 允许字标 ② 允许色块底 ③ 符号只讲一个词，业务交给字标。
> 你回一句「放开①②③」我就按品牌系统重做一轮。
> 主色不变。

**配套动作**：出一个「解绑预览」——同一个符号，加上字标 + 副标 + 色块底，
做成一页对比图。**视觉证据比解释有效十倍**，通常看一眼就拍板。

## 三、已否决 / 已认可的方向（不要重复撞）

> 记录于 2026-09，同一品牌方（天使OPC数字社区）多轮反馈。换品牌时要重新采集，
> 但可作为「什么会被读成土 / 素材库脸」的样本库。

**已被否决：**

- **极简单色几何抽象** → 评语「太简单、没设计感、没高级感」
- **具象对称的翅膀 / 盾 / 靶心** → 评语「土」
- **诊断出的素材库脸**：维恩图双圆、圆内水平线（像圆形汉堡包）、点阵三角、
  准星/十字环、日出弧线 —— 能一眼叫出名字的现成图标，就是没品牌感
- **"同一个创意的 N 种画法"**：7 个变体全是翅膀的不同排法 = 多样性为零

**已被认可：**

- **抖音式「强符号 + 双色错位叠印」**（Glitch 错位）：活力、年轻、时尚、一眼记住
  - 符号必须有性格（抖音=音符，取自名字的「音」），不是抽象几何
  - 错位偏移 viewBox 100 → **5 单位**（3 太含蓄，>7 显脏）；错位层画在底层
  - 必须同时出单色版兜底
- **单笔羽翼**（三根渐细羽枝从同根扇开）：被评为「确实高级」
  —— 但因**缺字标**而被指「少了凸显特点的东西」，印证不可能三角

## 四、需求采集清单（一次问全，别分次挤牙膏）

品牌名 / 行业 / **业务到底做什么（一句话）** / 核心概念 / 主色（是否可变） /
审美参照（对标品牌或喜欢的 logo 图） / 使用场景（App图标·站标·社媒·印刷） /
是否要字标与副标 / 是否需要深色底版本。

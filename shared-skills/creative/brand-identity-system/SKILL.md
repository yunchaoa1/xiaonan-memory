# 品牌识别系统（Brand Identity System）

> 中文触发：品牌标志、品牌识别、锁标、字标、中文标准字、标志设计、品牌系统、
> App图标、favicon、品牌交付包、设计规范、VI、品牌升级、logo 差点意思。
> 英文触发：brand identity, logo mark review, wordmark, lockup, App icon, favicon, brand guidelines.
>
> **与 `logo-generator` 的分工**：那个负责 SVG 图案生成与变体生产线；
> 本技能负责**品牌系统层** —— 范围诊断（不可能三角）、符号与字标分工、
> 锁标排版、精修工艺、交付包与使用规范。两者配套使用，不要混职责。

一个品牌标志的完整形态是 **符号 + 字标 + 副标 + 锁标 + 色板 + 应用 + 规范**，
不是「一个孤零零的图形」。本技能管的是这一层。

## When to Use（触发场景）

- 用户说「设计个 logo / 标志 / 品牌视觉 / VI」
- 用户已经拿到一个符号，但觉得「差点意思、太单调、没有高级感、没凸显特点」
- 用户拿着单一诉求（「只要图标」「不要文字」「不要背景」）要求出成品
- 需要出 App 图标 / favicon / 社媒头像 / 启动页 / 交付规范
- 需要评审一个已有标志（判断它缺的是符号、字标，还是应用）

## 工作流

1. **收需求** → 品牌名、行业、核心概念、**业务到底做什么**、审美参照（对标品牌）。
2. **范围诊断**（最关键，见「不可能三角」）→ 判断约束是否自相矛盾，**先解绑再动手**，不要进框即画。
3. **符号** → 强符号优先于抽象几何；按 `logo-generator` 的 Part 0 / Part 5 方法论出 ≥6 变体。
4. **字标** → 中文标准字 + 副标；明确符号与字标的**分工**。
5. **锁标排版** → 横版 / 竖版 / 图标位；比例、间距、垂直对齐按
   `references/lockup-and-deliverables.md` 的实测比例表。
6. **精修 + 交付包** → 光学居中、小尺寸专项、色块底、使用规范。

## 铁律

### ① 不可能三角：先诊断约束，别在框里硬做

**品牌标 = 符号 + 字标。符号负责「被记住」，字标负责「我是谁、做什么」。**

当用户要求「一个孤立图标同时讲完多个语义」时（例：天使 + OPC + 社区 + 接单），
这就是**不可能三角** —— 抽象就单调，具象就土，怎么画都不对。

- **必须主动提出解绑，不许硬做。** 实际发生过：在「只要图标 / 无文字 / 无背景 / 单色」
  的框里死磕五轮（单色几何 → 点阵 → 负空间 → AI 稿 → 双色错位），
  用户最后反问「是不是我一开始把你束缚住了？」——诊断是对的，代价是五轮返工。
- 解绑清单与话术见 `references/constraint-triage-and-scope.md`。

### ② 符号只讲一个词

加了字标之后，符号**不必**再承担「讲清业务」的任务。
「一个符号既要有天使又要有社区」注定两头不彻底；正确解是
**符号讲一个词（天使/向上），OPC、社区、接单交给字标和副标去说**。

### ③ 方向被否决时，先要对标参照，再动手

审美是取向问题，不是技术问题。用户说「土 / 没高级感」时，
**第一步是要参照物**（对标品牌、喜欢的 logo 图），不要连续盲猜。
参照比任何设计原理都省时间。

### ④ 交付前必须自己先看

不许「文件写了就算完成」。拼版 → vision 逐个自检 → HTML 交付页用
Chrome `--headless --screenshot` 渲染核对，再给用户看。

### ⑤ 要单色版就重新生成，不要从渲染图里抠

用户说「把这几个转成二维单色我看看效果」时，**不要试图从材质/光效稿里抠剪影**。
本机实测 4 轮（软阈值 → Otsu → 连通域过滤 → 裁切底部文字区）**全部失败**：
- 软渐变稿（玻璃、流体）抠出来是**糊块** —— 这类图形的美本来就在材质里，抠掉材质等于抠掉全部
- 硬稿会残留**背景光带与地面反光斑**（霓虹稿的反光、金线稿的顶部渐变带）

→ **正解：同一段提示词改成 `flat 2D logo mark, ONE solid flat color <hex>, no gradient, no glow, no 3D, no shading, no texture, no shadow` 重新生成一遍**，再走 `scripts/mono_pipeline.py` 后处理。一次通过、干净利落。**是方法错了，不是参数没调好。**

→ 附带价值：**材质版 vs 二维单色版并列对照，本身就是最好的设计体检** —— 扁平单色下还立得住的形状才是真成立（不靠光效撑）。这个对照页值得每次交付都出一份。

### ⑥ 光学居中要算，不要靠眼睛

渲染 → 取 alpha 包围盒 → 反算 viewBox 单位平移量 → 内容包进 `<g transform="translate(dx dy)">` 重渲染。
双色/错位稿按 **blue+cyan 并集**的包围盒居中（按主色层居中会偏）。实测手工居中曾**偏 10.5 单位**，肉眼完全看不出。深底还必须配**反白版**（同一 alpha 整体填白），否则 `#0052d9` 放深色底对比度过低。

## Pitfalls（实战踩过的）

| 坑 | 症状 | 正解 |
|---|---|---|
| 在不可能三角里硬做 | 连出 5 轮全被否，用户开始怀疑是不是自己束缚了 AI | 第 2 步就做范围诊断，主动提解绑 |
| 让符号承担全部语义 | 「有 A 没 B / 有 B 没 A」，两头不彻底 | 符号只讲一个词，其余交字标 |
| 字标过大压过符号 | 标志像字标的配图，符号失去存在感 | 符号当主角，比例见 references |
| 只交符号就完事 | 用户说「单调、提不起兴趣」 | 补色块底版本（App图标/启动页/头图） |
| 小尺寸直接缩 | 16px favicon 里图形几乎看不见 | favicon 单独出一版，标占比提到 ~0.78 |
| 未核对就宣称完成 | 交付页破图、图形偏移 | 渲染 → 截图 → 看图，三步走 |
| 从光效/材质稿里抠单色 | 糊块 / 背景光带残留 / 地面反光斑 | **不抠图**，用 flat 2D 单色提示词重新生成（铁律 ⑤） |
| 手写 SVG 里放裸路径串 | resvg **静默忽略**，渲染出来只剩圆点、且不报错 | 路径必须包 `<path d="...">`，写完先渲染一遍确认 |
| 猜 arc 的 sweep-flag | 弧线方向来回试错、上下颠倒是反的 | 用整圆 + mask 擦掉一块，绕开 flag 推导 |
| HTML 引用本地图，文件名差一个空格 | 静默破图，页面看着像缺图但无从查起 | 文件名逐字对齐（`06-3D 浮雕.png` ≠ `06-3D浮雕.png`） |
| 用宋体排小字标签 | `·` 显示成方框 | 小标签统一思源黑体；宋体只给大标题 |
| 把「插画型素材」（有明暗/纹理）和「线条字标」直接拼成一个图标 | 出来就是用户说的「**四不像**」—— 实测 7 种贴法（翼上字下／字上翼下／分列两侧／嵌进字母环内／反白压底／加粗咬合／双翼合围）**全部失败** | 先做**重量匹配**：① 把插画重画成同款线条语言（优先）② 把字加粗到同重量。**判据＝能否说成"一个形"**（"字母从翼形里刻出来"✅ / "翅膀在上面、字母在下面"❌） |
| 拿横版字母锁标当 App 图标 / favicon | 16–24px 糊成一团（实测 16px 完全读不出） | **另设一个方形紧凑符号**（只取单个元素，如"只有翼"），不能靠缩小横版交差，且要主动告知客户 |
| 手写贝塞尔拼"月牙"形时对后缘曲线做 `reversed()` | 图形退化成一根**发丝/细条**，加粗参数也无效 | 后缘本就该从尖端写回根部，**不要反转**；详见 `brand-identity-design/references/vector-redraw.md` |

## Verification（交付前逐条过）

- [ ] 遮挡品牌名只看符号：**能否一眼记住？能否一句话说出它是什么？**
- [ ] 符号与字标主次关系正确，符号是主角
- [ ] 光学居中已归一化（双色稿按**并集**居中，不是按主色层）
- [ ] 16 / 32 / 64 px 三档缩小实测，图形仍可辨
- [ ] 深底 / 浅底 / 单色 / 反白 四种场景都成立
- [ ] HTML 交付页已实际渲染并看过
- [ ] 使用规范写明：色值、留白、最小尺寸、禁止事项

## 支撑文件

- `references/constraint-triage-and-scope.md` —— 不可能三角诊断流程、解绑清单与话术、
  已被否决过的方向记录（不要再撞）。
- `references/lockup-and-deliverables.md` —— 锁标排版实测比例表、可用中文字体、
  完整交付包目录结构、精修清单、使用规范必含条款。
- `scripts/render_qc.py` —— 可复用：SVG 渲染 + 光学居中 + 拼版 + HTML 截图核对。
- `scripts/mono_pipeline.py` —— 可复用：白底纯色稿 → **精确单色 + 真透明 + 光学居中 + 尺寸集 + 反白版**。
  核心公式 `alpha = 255 - min(R,G,B)`（对「白底 + 纯色图形」是精确解，抗锯齿边缘天然正确），
  比「白底去背」干净得多。用户提「转成二维单色 / 要单色版 / 要透明底」时直接跑它。
- **跨技能**：**矢量重绘技法**（月牙/羽带拼法含 `reversed()` 退化坑、锥形厚度控制、
  接缝用"贴主体外圆的圆弧"消除台阶、等宽圆头字母的基线/碗内空算术、融合重量匹配、
  自检循环）在 `brand-identity-design` → `references/vector-redraw.md`；
  该项目的案例现状（已收敛到「OPC × 单翼」）在同技能 `references/case-angel-opc.md`。
  注意 `brand-identity-design` 与本技能**职责高度重叠**，读之前先看哪份更近（两份都在时以 method 更全的为准）。

# 品牌标志与视觉识别设计

覆盖「从一个品牌名 → 一套能落地的标志系统」的完整链路：需求澄清、气质方向探索、图形方法、材质与高级感配方、
中文锁标排版、单色/反白/色块配套态、交付前自检闭环、使用规范。

**配套可复用脚本在 `scripts/`，方法细节与案例在 `references/`。**

## When to Use

以下任一情况加载本技能：
- 客户说「**设计个 logo／品牌标志／标志／图标**」「做个品牌视觉／VI」「设计字标／锁标」
- 要做 **App 图标 / favicon / 启动页图标 / 社媒头像 / 发光字**
- 已有标志要**精修**（比例、笔画、留白、光学居中、缩小测试）
- 要出**品牌使用规范**，或要把标志**拓展到各场景**（名片、工牌、头图、包装）
- 客户对现有设计说「**不够高级 / 很土 / 太简单 / 没设计感 / 没记忆点**」→ 先读第 0 节，再动手

**不适用**：纯生图提示词写法（走 `image-prompt` / `gpt-image-style-prompting` / `z-image`）；
从视频/文章学习（走 `media-learning` / `video-learning`）。

> 与 `logo-generator`（用户自有技能）的关系：本技能负责**方法与交付纪律**，
> `logo-generator` 提供其内置的几何图形配方与展示背景库。二者可配合使用。

## 0. 第一原则（血的教训，最贵的一条）

**当客户/决策者说「不够高级」「很土」「太简单」「没设计感」时，问题多半不在你的图形，而在你被约束掉的那几样东西。**

**先要「参照物」，再动手。** 拿到对标（品牌名 / 场景词 / 甚至一条视频链接）之前不要连续盲猜 —— 盲猜三轮＝白干三轮。
对方只有模糊感受时，主动给**具体选项**（「腾讯云的方正几何 / 苹果的极简 / 网易的东方留白 / 徽章式」）让他选，而不是继续画。

**约束冲突时要主动提「解绑」，不要硬做。** 识别「不可能三角」：*只有一个图形* + *不要文字* + *不要色彩材质* + *还要有辨识度和特点* —— 四样凑齐，图形只能要么抽象（单调）要么具象（土）。
正确动作：**逐条列出约束的代价，给解绑建议，让对方一条条放行。**

案例：`references/case-angel-opc.md`（11 轮返工史，含每条被否方向的**否决原因**，接手前必读）。

## 1. 需求澄清（brief intake）

一次问清，别挤牙膏：

| 项 | 说明 |
|---|---|
| 品牌名 / 主体 | 中文全称、简称、是否要英文副标 |
| 业务本质 | 干什么、给谁、和同类比强在哪（决定语义母题） |
| 使用场景 | App图标 / 站标 / 印刷 / 发光字 / 社媒 —— **决定最小尺寸与配套态** |
| 色彩 | 主色（最好给色号）／是否允许辅助色与同色系层次 |
| **气质参照** | **对标品牌或场景词（最重要，见第 0 条）** |
| 交付档位 | 只要图标 / 要锁标 / 要完整品牌板 + 使用规范 |

**沟通纪律（被客户纠正过）**：对方问的是**单点问题**时，先给**单点答案**。
例：问「英文名应该是什么样子」→ 直接给译名即可，不要顺手扩展成"6 套命名策略 + 排版对比图"
（会被回一句「**我只是想让你翻译**」）。想扩展先问一句：「要不要我把几种写法排出来对比？」
同理，客户说「**把这几个转成 XX 我看看效果**」时，交付物就是那几个转好的图 + 一张对比，不要再附一整套方案。

## 2. 探索顺序：气质方向 → 图形 → 应用系统

**顺序错了会大量白做。**

1. **先定气质方向**（材质与色彩语言）：玻璃质感 / 金线奢华 / 流体渐变 / 霓虹潮酷 / 金属稳重 / 3D浮雕…… 一次给 5–6 个方向、**一个方向一张图**、气质拉开。
2. **再定图形**（在同一气质下收敛 3–5 个图形比选）。
3. **最后做应用系统**：横/竖锁标、App图标、favicon、头图、名片、使用规范。

**三级复杂度档位**（客户常需要"看到差别才有概念"，一次性给全）：

| 档 | 内容 | 用途 |
|:--:|---|---|
| 档1 | 仅图标（单色 / 双色 / 色块底） | App图标、favicon、极简场合 |
| 档2 | 图标 + 字标锁标（横版/竖版，浅底+深底） | **品牌正式形态** |
| 档3 | 完整品牌板（锁标 + App图标组 + 色板 + 留白规范） | 交给设计/开发落地 |

**给决策者选型的规则**：给 ≥12 个**不同母题**（翼/门/星/手/山/鸟/阶梯/拼图/徽章/首字母/灯塔/框架）的**具象可辨**符号，**一个图标一张图**，每张附星级 + 一句话含义 + 淘汰建议。
抽象款留到方向定稿后再精修 —— 决策者要的是「能看懂 + 有含义 + 不花哨」。

## 3. 图形方法库

### 3.1 字母减法法（「简约大气」的正解，优先用）
**取一个字母/汉字骨架 → 减去一笔 → 加一点细节 → 调一下空间 → 一个字形说出两重含义**（特斯拉 logo 即此法）。
四步法、原视频转写、落地笔画参数、**复型的歧义硬门禁**见 `references/letter-subtraction.md`。

### 3.2 几何叠合 / 负空间
用**几何叠合**表达"连接/社区/合作"最省力（Mastercard 交叠双圆=连接信任；Audi 四环=团结）。
负空间要**主动利用**：留白里藏第二个形。**切口必须圆角**，尖角＝未完成感。

### 3.3 具象符号
翼 / 门 / 星 / 手 / 山 / 鸟 / 阶梯 / 拼图 / 徽章 / 灯塔。优点一眼看懂；风险是容易撞素材库脸，必须靠**比例与细节**拉开差距。

### 3.4 硬门禁：歧义「路人测试」
**任何减法/复型出来的图形，交付前必须自问：路人随口会读成什么？**
只要会读成**另一个无关或负面的既有符号**（导航/停车/版权/回收/警告/某行业通用图标），商业上不可用 —— 换。
（实例：O+P+C 复型被实测读成「停车 P」与版权符号 ©，手法正宗但直接淘汰。）

### 3.5 融合设计 —— 两个元素要「合成一个形」

对方给两份参考（如「**一只翅膀**」＋「**一套字标**」）要求融合时，**先做重量匹配，再谈构图**。

- **重量/语言不同的素材不能直接拼** —— 直接拼出来就是对方口中的「**四不像**」。
  实测 7 种结构（翼上字下／字上翼下／分列两侧／嵌进字母环内／反白压底／加粗咬合／双翼合围）**全部失败**：
  根因不是排版，是「插画有明暗纹理」vs「字标是纯平线条」。
- 只有两条可行路：① **把插画重画成同款线条语言**（通常更好，优先）② 把字加粗到与插画同重量。
- **融合成立的判据：能不能说成「一个形」**
  ✅「字母从翼形里刻出来」「C 的上端直接长成主羽」「字母的弧线延展成羽翼」
  ❌「翅膀在上面、字母在下面」「环套在字外面」→ 客户原话：*字是字、环是环，两块东西贴一起*
- **钥匙＝两份参考里本来就重合的元素**。例：单翼左端收拢的圆点 ＝ 字标里 O 开口处那颗蓝点 → 它就是锚点，整个结构围绕它组织。
- 定稿一律**矢量重绘**；月牙拼法／厚度控制／接缝处理／等宽字母几何见 `references/vector-redraw.md`。
- **「身体」构图（可复用的正方形母题）**：双翼 + **中间竖排字＝天使的身体**（单元素当脊柱，两侧元素从它身上长出来）。
  价值：**正方形构图能通过小尺寸测试**（实测 32px 仍可辨）—— 这正是「横版字标做不了 favicon」的正解。
- **交付姿态：横版与方形并存**，不要二选一 —— 方形（符号 / 竖排）做 **App 图标 + favicon + 社媒头像**；
  横版（符号 + 字标）做 **站标 / 头图 / 名片 / 邮件签名**。主动提出这个分工，是真实品牌的标准做法。
- **字素「孤立可读性测试」**（比第 3.4 节的路人测试更早、更基础）：先把**每个字母单独拿出来读**，再读整串，最后才谈融合。
  清单与翅膀绘法配方见 `references/vector-redraw.md` §4b / §4c。

## 4. 高级感的配方

**高级感 ≠ 形状简单。** 它住在 **材质 / 光影 / 色彩层次 / 字体气质 / 呈现方式** 的合力里。
把标志压成「单色 + 扁平剪影 + 无材质 + 无字标 + 无场景」＝ 免费 logo 生成器的脸。

1. **材质与光影**：玻璃、金属/铬、内发光、边缘光、地面反射、浮雕
2. **色彩层次**：渐变（深蓝→青）、流体、金线、霓虹 —— **不要限定单一色号**
3. **字体气质**：中文字标 + **全大写 letter-spaced 英文副标**（字距 ≈ 0.33em）是廉价→高级的分水岭
4. **呈现**：深色背景 + 柔光 + 大留白，做成**发布会/提案级**方向图；收尾可上**发光字实景效果图**
5. **一个方向一张图**，气质拉开；别给同一图形的多个版本（会淹没判断）

**平面化测试（定稿前必跑）**：把方向稿转成「二维单色扁平」再看一遍 —— **好标志去掉材质依然立得住**，只靠光效撑的就是没做完。见第 6 节。

## 5. 交付形态与自检闭环（交付前必做）

**铁律：交付前必须自己「看」过成品，不许未经查看就交出去。**

1. **矢量稿** → 全部渲染成一张联系表 PNG，再逐格点评。
2. **HTML 交付页** → **不能只看"文件写成功了"**。用 `scripts/render_html.py` 渲染成 PNG 自己看；逐项核对：破图 / 文字溢出 / 深底格是否看得见 / 排版错位。
   图片路径写错只会**静默破图**，所以渲染核验不是可选项。
3. **AI 稿** → 后处理（去底 / 改色 / 裁切）后同样先看：形状糊、多余碎屑、多出元素，只有看才能发现。

**「AI 稿 → 精确单色 + 真透明」后处理公式**（白底稿的精确解）：
`alpha = 255 - min(R,G,B)` → 整体填目标色 → 按 alpha 包围盒裁切 → 补 ~10% 留白。比"白底去背"干净，抗锯齿边缘天然正确。
（双色稿同理：只用 alpha 去背，**保留原始 RGB**，不要强制单色化。）

**光学居中归一化**：渲染 → 量 alpha 包围盒 → 反算平移量（viewBox 单位）→ 回写 `translate` 重渲染。手动摆必然偏。

**必出配套态**：
- 主色版 → **单色版**（印刷/单色场景）→ **反白版**（深色底、照片、彩色底）→ **色块底版**（App图标用，小尺寸最清晰）
- 尺寸套件：App图标 1024/512/192/180/152/120；favicon 16/32/48/64 + `.ico`；**小于 32px 必须用色块底版**
- 每个图形都缩到 16px 实测一眼；favicon 一排版必须**放在深底上**核对（白色标在白底页面上等于没画）
- **横版字标 ≠ 图标**：含字母的横版锁标缩到 16–24px 必然糊（实测 16px 已完全读不出，24px 勉强）
  → **必须另设一个方形紧凑符号**（只取其中一个元素，如「只有翼」或「符号 + 首字母」），不许靠缩小横版交差。
  这条要**主动告知客户**，别等他发现 favicon 是一团糊。

## 6. 平面化（二维单色）：要「重新生成」，不要「抠图」

**已实测的反面教训**：从玻璃/霓虹/金属渲染图里用「阈值 + 连通域 + 裁切」提取二维单色，**试了 4 轮全部不干净** —— 光晕被带进来、背景亮带残留、反光斑粘连、内部渐变糊成一团。
原因是**材质稿的轮廓本身就是模糊的**，阈值法没有干净边界可分。

**正确做法**：让同一个图形**直接以「二维单色扁平」重新生成一次**，提示词强调
`one solid flat color / no gradient / no glow / no 3D / no shading / no texture` —— 一次就干净。

## 7. 锁标排版（品牌标志 = 符号 + 字标）

**一个孤零零的图标说不出「你是谁、做什么」。** 符号负责被记住，**字标负责说清业务**。

用 `scripts/lockup.py`：标志 PNG + 中文标准字 + 全大写 letter-spaced 英文副标 → 横/竖版锁标，浅底深底均可。

**比例基准（实测协调）**：标志高 H → 中文标准字字号 ≈ **0.57H**；英文副标 ≈ **0.16H**、字距 ≈ **0.33em**；标志与文字间距 ≈ **0.30H**；文字块与标志**光学垂直居中**（不是几何居中）。
**字标比符号还重 ＝ 失败**：先让符号当主角，再校字标。

**英文行怎么定（中国品牌）**：图形骨架用**汉字**，不要用拉丁首字母
（特斯拉取 T 是因为它就叫 **T**esla —— 那是首字母逻辑；中国品牌照抄等于丢掉自己最大的差异化）。
英文副标两条路，让客户选：
- **全大写拼音**（客户给的参考 logo 用的就是 `JIYITIAN DESIGN`；Huawei / Xiaomi / BYD / NIO 同理）→ 更像专有品牌名
- **直译**（如 `Angel OPC Digital Community` / `ANGEL OPC DIGITAL COMMUNITY`）→ 一眼看懂含义

### ⚠️ 中文字体坑（踩过）
- `Source Han Serif SC Heavy` **缺 U+00B7（`·`）** → 小标签用它会出现**方框**。**小字一律用思源黑体（Noto Sans SC Medium/Bold）**，只有大标题才考虑宋体。
- 本机可用：`Noto Sans SC Bold/Medium`、`NotoSansSC-VF`、微软雅黑 `msyh/msyhbd/msyhl`、`simhei`、`Source Han Serif SC Heavy`。
- 中文字标要**逐字排版加字距**（一个字一个字画），整串直接写会挤在一起，气质立刻掉档。

## 8. 文件与归档规范

- 一个项目一个目录：`<资产根>\<项目名>\`，内部按 `mark/`（主标各态）、`lockup/`、`appicon/`、`favicon/`、`social/`、`styles/` 分目录
- **过程稿与被否方向及时归档或清理**（换版即清）：主目录只留"当前活着的方案"，否则客户和你都会被文件淹没
- 定稿必附 **使用规范**：色彩 / 留白 ≥ 标志高 25% / 最小尺寸 / 禁止变形改色加特效 / 反白使用场合
- 交付时报 **绝对路径 + 实分辨率**（实测数据，不是"应该是"）

---

## 9. 反面清单（别再走的路）

- ❌ 在"单色扁平极简"的框里死磕，还想要高级感
- ❌ 客户否决方向后继续盲猜，不先要参照
- ❌ 把"同一个图形的 7 种画法"当作 7 个方案（多样性为零）
- ❌ 从材质渲染图里抠二维单色
- ❌ 只交图标、不交锁标，然后抱怨"客户认不出品牌"
- ❌ 未经自己渲染查看就交付 HTML 页 / 拼版
- ❌ 未做「路人测试」就交付减法/复型图形

# 字母减法法（Letter-Subtraction）— 「简约大气」标志的核心方法

**出处**：B站 `BV1ka411M7kV`，墨壹logo设计《一个简约不简单的logo如何设计！》（51 秒，2026-09-11 由客户提供并定性为「这就是我要的简约大气的思路」）
**一句话**：**取一个字母骨架 → 减去一笔 → 加一点细节 → 调一下空间 → 一个字形说出两重含义。**

## 二、四步法（可直接照做）

| 步 | 动作 | 要点 |
|:--:|---|---|
| 1 | **取骨架** | 选定品牌首字母／关键汉字（T / M / Y / A / 天…）作为**唯一**骨架 |
| 2 | **做减法** | 在骨架上**减去一笔或一部分**，让第二个含义浮现 —— 特斯拉＝T 减去上部两侧 + 火箭推进形态；YT＝T 中间减一笔 + 调一侧高度；T 融 M＝在上方减一部分 |
| 3 | **加一点细节** | 一个缺口、一次斜切、一处错位就够了 —— **不要再加元素** |
| 4 | **调空间** | 调笔画间距与高低，做出**建筑感**（直角、平头笔画、等宽笔画、方正外轮廓） |

**复型与融合**：两个字母共用笔画（T 融 M、O 融 P 融 C）是这套手法的进阶用法，威力大但要过下面的歧义门禁。

## 三、落地参数（本技能实测）

- **实现工具**：手工 SVG（字母必须精确，生成式模型会写错字），再用矢量渲染器出 PNG
- 笔画（viewBox `0 0 100 100`）：主笔 **7–9.5**，次级 **5.5–7**
- `stroke-linecap="butt"` + `stroke-linejoin="miter"` 才有**建筑感**；圆头（round）会立刻变可爱、掉档次
- 断笔当"细节"用：把一根横笔**断成两段**留 5–7 单位缺口，比加新元素高级得多
- 汉字同样适用：「天」的下半本来就是个「人」字，两笔一外张就是**双翼** —— 不用加元素
- 必须配 **锁标**（见主 SKILL.md 第 7 节）：标志 + 中文标准字 + 全大写 letter-spaced 英文副标
- 收尾用**发光字实景效果图**呈现（原视频手法），补上高级感的最后一公里

## 四、⚠️ 硬门禁：歧义「路人测试」（血的教训）

**减法/复型做出来的图形，交付前必须自问：路人随口会把它读成什么？**

只要会读成**另一个无关或负面的既有符号**（导航 / 停车 / 版权 / 回收 / 警告 / 某行业通用图标），商业上不可用 —— 换。

**实测案例**：`O + P + C` 复型（圆环开口成 C + 环内竖笔成 P + 整体是 O）——手法正宗，但被实测读成
**「停车 P」** 和 **版权符号 ©**，商业歧义太大，**直接淘汰**。

**规则**：复型手法只在「拆出来的两个含义都不是负面/不相关符号」时才允许使用。

## 五、常见字母的可用减法（起手式）

| 骨架 | 减一刀之后可能读成 | 适用语义 |
|---|---|---|
| **A** | 两条斜边＝双翼；中横断开＝羽枝间隙 | Angel、上升、翅膀、起点 |
| **T** | 减上部两侧＝推进器/火箭；中间减一笔＝组合字母 | 科技、推进、动力 |
| **Y** | 上半开口＝飞鸟/起飞；下半＝支柱 | 成长、连接、分流 |
| **O** | 开口成 C；内嵌一竖成 P；内留白藏第二个形 | 平台、社区、循环 |
| **天** | 撇捺外张＝双翼；去一横＝「大」 | 天使、中文品牌 |
| **人 / 大** | 加点/加横＝顶天立地；两笔外张＝翼 | 以人为本、托举 |

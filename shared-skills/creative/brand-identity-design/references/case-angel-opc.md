## 第 16 轮（2026-09-14 追加）：客户换了结构 —— 正方形「天使」构图

客户给**对称分层翼**参考图，要求：**「OPC 竖着写在翅膀的中间做天使的身体」**。
→ 矢量实现，**5 轮自查迭代**定稿，产出在 `angel/`（34 个文件）。

**结构与融合逻辑**：两侧翅膀从身体两侧长出来（每侧 4 条锥形羽带，根部连片、末端收尖）；
中间竖排的 **O / P / C 就是天使的身体（脊柱）**；翅膀和字母共用一个形。

**这一版顺手解决了待办 #2**：它是**正方形构图**，**32px 实测仍可辨** ——
横版字标（`final2/`）做不到的小尺寸，它做到了。**这就是"另设方形紧凑符号"的答案。**

**迭代中修掉的三个坑（都已回写 `references/vector-redraw.md`）**：

| 症状 | 根因 | 修法 |
|---|---|---|
| 竖排的 P 读成 **D** | 碗画到和竖杆一样长 | 碗收短，竖杆下探 |
| P 读成 **L**（用了 Γ 写法） | Γ 只在横排上下文成立，孤立/竖排即歧义 | 竖排必须用带碗的 P |
| 翅膀像**蝙蝠 / 枫叶** | 羽尖锯齿又深又尖 | 改**分层锥形羽带**（根部连片、末端收尖、间隙均匀） |

**当前状态**：两版**并存**是正确交付姿态 ——
- `angel/`（正方形：双翼 + 竖排 OPC＝身体）→ **App 图标 / favicon / 社媒头像**
- `final2/`（横版：OPC + 从 C 长出的单翼）→ **站标 / 头图 / 名片 / 邮件签名**

**仍开放**：主羽份量偏重（可再调轻）；翅膀形态偏「帆/叶」，可做圆肩 + 羽带长短变化。
**未做**：中文字标「天使OPC数字社区」；全套应用场景。

# 单集故事卡模板

## 第__集｜标题

### 1. 本集唯一情绪任务

- 本集主要让观众感到：
- 对应的情绪债：
- 本集必须完成的状态变化：

### 2. 开场承接

- 上集留下的具体问题：
- 开场立即发生的冲突或后果：
- 观众此时比哪些角色多知道／少知道什么：

### 3. 人物行动

- 主角主动采取的行动：
- 行动依据：
- 对手的合理反应：
- 主角承担的风险或代价：

### 4. 借债与还债

- 本集偿还或实质推进的旧债：
- 具体兑现方式：
- 关键见证人：
- 本集新借的债：
- 新债为何值得继续看：

### 5. 信息变化

| 人物 | 本集开始知道 | 新获得的信息 | 本集结束后的判断与行动 |
|---|---|---|---|
|  |  |  |  |

### 6. 证据与因果

- 新证据从何处进入：
- 它能证明什么：
- 它不能证明什么：
- 谁会误读它：
- 它在后续哪一集产生反作用：

### 7. 节奏节点

1. 识别／承接：
2. 压力升级：
3. 期待形成：
4. 停顿或重新判断：
5. 小结算／失败反转：
6. 余波：
7. 新债／钩子：

### 8. 集尾钩子

- 观众明确缺少的关键答案：
- 为什么答案重要：
- 为什么下一集有机会获得答案：
- 钩子改变了谁的行动：

### 9. AI生产风险预标记

- 角色数量：
- 连续空间数量：
- 复杂身体接触：
- 道具交接：
- 儿童／灾难／水体／人群：
- 建议拆镜或改为后果／声音／证据呈现的内容：

## 单集验收

- [ ] 开头不是重复上一集结尾；
- [ ] 本集至少改变知识、证据、关系、权力或选择之一；
- [ ] 主角有行动，不只是听解释或等待救援；
- [ ] 至少偿还或推进一笔旧债；
- [ ] 新债不是机械打断，而是新的有价值问题；
- [ ] 对手的行为来自利益和已知信息，不是突然变笨；
- [ ] 集尾钩子能用一个具体问句表达；
- [ ] 高风险AI场面已在故事阶段标出。

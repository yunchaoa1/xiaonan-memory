# 情绪债与爽感发动机

## 定位

“情绪债”是内部创作模型：把观众熟悉却长期没有得到补偿的无力感，转化为可期待、可观看、可结算的剧情承诺。它不是学术术语，也不是用“多巴胺”解释一切。

## 基本链条

1. 识别：观众认出自己的生活经验；
2. 借债：角色失去尊严、公平、身份、爱、机会或控制感；
3. 累息：对手越过明确边界，旁观者误解或规则继续偏斜；
4. 预告偿还：能力、证据、选择或信息差露出一角；
5. 部分偿还：主角主动改变局面；
6. 公开结算：关键人物见证，旧状态无法恢复；
7. 永久变化：角色价值观、关系或身份发生改变；
8. 新承诺：留下下一笔值得追看的债，而非机械截断。

## 常见债务

| 债务 | 被侵占的价值 | 有效结算 |
|---|---|---|
| 尊严债 | 被轻视、羞辱、物化 | 主角以能力与边界重新定义自己 |
| 公平债 | 成果、资源、规则被抢 | 原创、劳动或资格被正式归还 |
| 身份债 | 被否认、替代、遮蔽 | 真相由多条证据闭环并被关键人物承认 |
| 爱情债 | 不被选择、被利用 | 主角停止讨好，做出有边界的选择 |
| 认可债 | 能力长期不被看见 | 能力在真实任务中发挥而非靠自夸 |
| 亲情债 | 遗弃、错认、控制、隐瞒 | 爱与责任同时被审判，关系重新订立 |
| 机会债 | 名额、事业、人生路径被夺 | 主角夺回行动权，而非只获补偿金 |
| 控制感债 | 别人替自己决定一生 | 主角承担代价后亲自选择方向 |

## 爽感工作公式

> 爽感强度 ≈ 真实委屈 × 代入程度 × 期待强度 × 兑现力度 × 公开见证 ÷ 理解成本与无效等待

使用方式：逐项找短板，不做数学计算。

- 委屈不真实：观众只觉得吵；
- 代入不足：冲突与目标受众无关；
- 没有期待：观众不知道何时会翻盘；
- 兑现太弱：反击小于先前损失；
- 没有见证：社会性羞辱只得到私下纠正；
- 理解成本高：身份、证据、关系一次塞太多；
- 等待过长：连续多集只受辱不改变。

## 为什么知道结局仍会看

爽剧常依靠“兑现方式悬念”，而不是“结果悬念”。观众关心：

- 什么时候偿还；
- 用什么方式偿还；
- 谁会亲眼看见；
- 对手会失去什么；
- 主角为胜利付出什么；
- 胜利之后人物是否仍值得喜欢。

类型契约允许终点熟悉，但抵达方式必须有因果和新意：

> 熟悉的情绪终点 + 陌生的抵达方式。

## 传播机制：避免万能“多巴胺”

可分别检查：

- 情感代偿：角色替观众活出一次主体性；
- 公平恢复：破坏规则的人付出可见代价；
- 信息差：观众或主角知道，对手不知道；
- 高唤醒：愤怒、惊讶、爆笑、震撼促进传播；
- 信息缺口：观众明确缺少一个重要答案；
- 社交代言：台词能脱离剧情表达观众立场。

刺激负责扩散，认同负责留存，人物关系负责追更。

## 单集铁律

- 每集可以借一笔新债，但必须偿还或实质推进至少一笔旧债；
- 爽点应来自角色行动，不来自作者突然派来的贵人；
- 公开结算必须让当初误解、羞辱或获利的人看到后果；
- 结算后至少改变知识、关系、证据、权力或选择中的一项；
- 结尾钩子必须指向具体缺失答案，不能只靠“她惊呆了”。

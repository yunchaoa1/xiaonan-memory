# 动物行动法落入职场短剧：从角色卡到首集动作链

适用：生肖群像、动物隐喻角色、或任何需要让角色“做事方式不可互换”的职场／现实短剧。

## 核心原则

不要把动物意象写成性格形容词或岗位标签。先锁角色在压力下的**第一问、第一动作、表达方式、合理误读、优势反噬与成长责任**，再写剧情。

同一堵墙前，首个动作必须不同：

- 鼠：贴墙找缝——绕边接触关键人、挪资源、留后手；
- 牛：顶住缺口——先收拢人、挡签字、自己顶风险；
- 猴：爬高换枝——小样试跑、并开支线、冻结原始痕迹；
- 狗：守住门槛——钉线头、留下被推出去的人、追问谁拿例外；
- 熊猫：标出共同路——先公布入口、条件、期限、异议与补救。

## 写作顺序

1. 先做行动卡；不能只写“机灵／能扛／聪明／守规矩／有大局”。
2. 用同一危机做行动几何测试：若两人的首动作相同，重写。
3. 先把行动法升级进正式角色档案与季线因果，再写任何分集正文。
4. 首集先交“动作链”，由用户审动作因果；动作链通过后才写台词正文。
5. 正文只放动作、关系和改变选择的台词；不要用职业流程解释代替人物损失。

## 鼠型“沿墙根”误解链

鼠不能写成“公开做对事，却被无端冤枉”。固定链条应是：

> 隐蔽但可见的动作 → 旁人基于所见产生合理猜疑 → 结果由该动作直接落地 → 观众与旁人倒推真实目的 → 仍保留鼠越过他人选择权的代价。

最小验证：

- 动作能拍到，例如绕后通道放回一页资料、私下接触关键人、先挪走风险资源；
- 旁人只看到部分画面，误读为截胡、下套、留后手，有充分依据；
- 结果证明鼠保住的是承诺／收入／出口，不是客户或功劳归属；
- 鼠不能因此被洗白：若它没有及时公开会转嫁给他人的临界风险，下一集必须让这笔债具体落到人身上。

## 人性冲突前三集的递债法

不要并列展示五个角色，而应让前一人的行动把下一人的现实损失推出来：

1. 客户／成果被关系户夺走，鼠以暗路保住客户底线；
2. 对方无法从客户端缩水，改从现场工资压回利润，牛被牵入；
3. 牛拒绝签下责任，鼠交出不利记录，二人被迫共同追溯事实；
4. 临时记录缺口牵出猴；正式门槛牵出狗；入口排除问题牵出熊猫。

每一集只交下一笔债，不能提前让后续角色正面解决问题。

## 交稿自检

- 开场十句内能否说清谁吃亏、谁得利？
- 主角是否做了符合行动法、可复述的动作？
- 误读是否来自画面证据，而非反派硬污蔑？
- 局部反击是否让对手付出成本，并给主角制造新风险？
- 结尾是否明确把下一笔债交给下一人？

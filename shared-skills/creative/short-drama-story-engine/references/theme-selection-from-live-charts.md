# 题材选型：用实时榜单定"现在最受欢迎"（不凭印象）

触发：用户说"题材按现在最受欢迎的来写""写个爆款题材""你自由发挥"。

核心立场：**"现在最火的是什么"是可查证的事实问题，不是创作判断。** 先查，把数字和日期落进交付件，再动笔。

## 1. 查证口径（四类源，各自独立）

| 源型 | 能拿到什么 | 不能拿它证明什么 |
|---|---|---|
| 平台热播榜（红果 AI 漫剧热播榜 / 漫剧热播榜） | 热度值排名、同档期在跑什么 | 热度值 ≠ 播放量，不可与日播/累计互算 |
| 行业数据机构周/月榜（DataEye 剧查查一类） | 新增剧数、投放素材量、题材分布 | 不等于完播率或付费转化 |
| 财经/行业媒体月报（澎湃等） | 题材占比、受众性别比等结构性数字 | 结构性数字不能反推单部剧成败 |
| 平台创作者侧教程/审核口径（红果创作者服务） | 什么能过审、集规格、投稿形态 | 说明"能过"，**不等于**"受欢迎" |

每条记录：**来源 + 日期 + 口径（热度值／日播／累计／素材数）**。写进交付件时原样标，不要把"8602 万热度"四舍五入说成"亿级爆款"。

查不到就写"查不到"，不许用"业内普遍认为"顶替。

## 2. 选型方法：双主干焊接

榜单通常男女频分开。做法不是二选一，而是各取**一条已被数据验证的因果主干**焊在一起：

- 男频主干示例：隐藏身份回归 + 查父母被害旧案 + 当众打脸（验证点：AI 漫剧热播榜第一，7968 万热度）
- 女频主干示例：进门就被立规矩、被婆家当佣人 + 反转当家（验证点：日播 3.7 亿）
- **焊接点**：同一件事对两边都成立。本案例是"进仇人家当最底层的人，同时是唯一握着证据的人"——羞辱线给女频，查案线给男频。
- 主角性别按付费主力定（漫剧女频付费占比高 → 默认女性视角）；另一方留作同盟与见证者，**不代行关键选择**（否则又变成"等男人来救"）。

## 3. 差异化：换锚点，不换骨架

这是最关键的一步。主干照搬没问题，**技能锚点必须换**，否则就是第 800 部兵王/神医。

换成真实、可核查、视觉可拍的行业/非遗技艺（缂丝、榫卯、古建修复、制瓷、烘焙、钟表修复…）。三个条件必须同时满足：

1. **能写行话对话** —— 给"信息 100% 在台词里"提供弹药（"通经断纬""接经九根、走纬四十二道""结头打三道收在里侧"这类话一说，专家身份就立住了，不需要旁白解释）；
2. **有可视奇观** —— △ 层有活干（丝线穿经、指尖出血、断口缝合），画面不空；
3. **踩不到红线** —— 避开宗教、医疗诊断、私刑、擦边。

换完只换"她凭什么赢"，**爽点节奏照旧**：羞辱 40%／反击 30%／释放 30%，爽点逐级变大。

附加好处：真实技艺自带"仿品辨认"这类天然打脸场面（一眼看出对方珍藏是假的，并说出三处破绽），比空喊"你不懂"有力得多。

## 4. 反向校验（动笔前过一遍）

- 这个题材的红线在哪？宗教 / 医疗 / 私刑 / 未成年 / 擦边——在设定阶段就删掉，不要写完再改。
- 复仇靠什么结算？必须是证据链、工簿、评审、法律程序。靠杀人放火＝"私刑当正义"，一票否决。
- 冷启动三问：第一集第一句台词能不能直接进冲突？观众能否在 20 秒内知道"她其实会说话／手里有牌"（信息差要提前给，不能捂到最后当反转）？契约婚姻／隐藏身份这类设定有没有写清"双方自愿、各有目的、可退出"（否则踩"畸形婚恋观"）？

## 5. 2026-11 实测快照（示例，会过期，用时重新查）

- 红果 AI 漫剧热播榜第一：《退役归来，这个保镖不好惹》7968 万热度 —— 退役强者回归 + 护女总裁 + 追查父母被害旧案。
- 漫剧热播榜第一：《千里奔赴：戈壁上的婚约》，日播 2.6 亿 / 累计 10.3 亿。
- 女频：AI 剧《刚进门就敢立我规矩》日播 3.7 亿。
- 系列化跑量：《和离后我带女儿横扫魔域》（1000 集 3D 漫剧，8602 万）、《反派亲妈》第 3 季、《重生！丑小鸭逆袭成了万人迷》第 5 季 —— 信号是"能续季"比"单部爆"更值钱，设计时就要留续季钩子。
- 结构信号：真人短剧侧出现"观众对传统浅层爽点兴趣下滑，要求叙事逻辑、人物塑造、画面质感"；AI 漫剧正在抢占年代、种田等原属真人剧的题材。
- 榜单在跑的题材带：玄幻仙侠、末世冒险、权谋争斗、甜宠、奇幻脑洞、年代种田、家庭伦理、都市爱情、玄学打脸。

## 6. 交付件里必须有的"题材依据"段

开头写一张三列表：**依据 / 内容 / 来源＋日期**，再用一两句话说清"为什么焊这两条主干＋换了什么锚点＋避开了什么红线"。

这一段不是形式主义：它让用户三秒内判断你是**查过**还是**拍脑袋**。缺了这一段，后面写得再好也会被质疑根基。

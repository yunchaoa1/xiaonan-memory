# OPC 一键漫剧节点 Skill 设计

## 适用范围

用于把写作、小说改剧本、剧本转15秒分镜、生图提示词、视频提示词等专业能力封装为 OPC 一键成片工作流中的单功能节点。只规定 Skill 行为，不扩展到平台前后端、数据库、画布、计费、存储或执行器接入。

## 单功能节点合同

每个节点必须：

1. 只完成一种专业转换，不吸收上下游职责。
2. 读取上游唯一输入后直接输出唯一成品。
3. 不采访、不反问、不给候选、不等用户确认。
4. 缺项按 `用户锁定 > 上游事实 > 项目规则 > 经回归验证的保守默认值` 补全。
5. 默认值不得创造新剧情；低置信度和依据留在内部质检记录。
6. 内部自动质检、定向修订或重跑；未通过结果不得交给下游。
7. 对外只返回成功成品或标准化输入/执行失败，不泄露推理、评分、失败稿和返工日志。

## 人物前置设计

小说改剧本节点内部先完成人物特点和状态设计，再写剧本，不设置用户确认环节。

群像人物不能只靠瞳色区分。每人至少锁定：

- 可核证动物/文化素材与原创戏剧转译的边界；
- 去色后仍可辨的整体轮廓；
- 换装后仍保留的外观锚点；
- 压力下的第一动作和行为习惯；
- 能力的发动动作、环境变化、声音、代价和残留状态；
- 有剧情功能的专属道具或服装结构；
- 声音、语速、句式和停顿习惯；
- 首次出场中可见的特点展示。

人物资产按“身份母版 + 剧情状态版本”组织。状态至少覆盖年龄、服装、发型、妆容/素颜、伤痕、污渍、持有道具、能力阶段及适用场次。原文没有依据时采用不增加剧情含义的保守默认值，并保持后续一致。

## 故事板与图片双约束

- 宫格数由实际关键画面状态决定，不固定4格或9格；若关键状态过多，先判断是否应拆镜。
- 空间用主角/主要主体自身前后左右上下作锚；纯场景先确定空间核心朝向；禁止用画面左右定义跨格布局。
- 配套占位/调度/动作引导图内部无文字、人物名、编号、图例或技术标注，只保留固定颜色/符号、空间轮廓、主体/道具/摄影机运动线。
- 图片负责几何、站位和运动；配套提示词负责身份、语义、动作含义和时序。图中每个约束都应能在提示词中解释，提示词中的关键主体和运动都应能在图中定位。
- 使用批准母版、固定资产版本、场景坐标、状态继承、相机透视锁、相邻格重叠锚点、逐格增量编辑、多候选筛选和独立QC。
- 未通过的格不得成为下一格参考；约束图不作为最终成片画面。

## 回归验证

Skill完成不等于能力通过。每个节点至少需要：

1. 固定真实样例和不可丢事实表；
2. 明确评分量表、PASS条件和一票否决项；
3. 生成者自审与独立 verifier 复审；
4. 问题定位到责任模块后自动/人工修订 Skill；
5. 使用同一样例重新运行并比较；
6. 证明改进来自 Skill 规则，而非临场手工救稿。

### 节点自证不作证据（2026-09-18 两次实锤）

节点（尤其由子代理执行的节点）返回的"自检通过／全部达标／零删改"**只当线索，不当证据**——节点内的自检本身也可能是形式化的。验收必须在节点外，用**可复现脚本独立统计**；自报与实测不一致时以脚本为准，并回头核对统计口径。

| 实例 | 节点自报 | 独立核对实测 |
|---|---|---|
| 写作节点（整卷→20 集） | 「每集台词 300–344 字，20/20 达标」 | **收束集实为 141 字**，仅 19/20 达标 |
| 分镜节点（第 1 集 29 镜） | 「24 句台词按剧本原样落地零删改」 | 剧本 **32 句**，分镜**漏落 8 句**（约 90 字） |

两份自证都写"全部达标"：前者漏掉了收束集，后者自报句数 24≠剧本 32 却没发现——**说明"逐句/逐项比对"根本没做**。

**量化脚本的三个坑**（同批实测踩全）：

1. **统计范围要截干净**：工艺段（钩子链／时长表／改动登记／红线自证／自评表）不属于正文。按"正文标题之后的全部内容"统计，最后一集会把工艺段吞进来——本次把末集台词 141 字误报成 859 字。
2. **自证段落污染关键词计数**：自证行常写"VO＝0""全文无『镜头左／画面右』"——关键词扫会把**声明**判成**违规**。判定前先看命中行上下文。
3. **同一字段多种写法**：如台词行有"带神态括号"与"不带"两种形态，漏一种就少统计一大截；同时要排除场景行与 `人物：…` 行。

**逐句 diff 是查"漏落／自创"的唯一可靠手段**：上游产物与下游产物双向比对（下游→上游查自创，上游→下游查漏落），本次同时得出"漏落 8 句"与"自创 0 条"两条结论。

小说改剧本的测试门槛可采用11项×0—4量表：核心命题与因果、可拍行动、场景功能、人物选择、对白、信息披露、节奏、时长容量、影视化损失补偿、视听可行性、改编溯源。满分不应机械设为发布门槛；优秀线、硬伤和停止条件应由正反样本校准。

## 常见失败

- 把“无人干预”误写成“缺信息就随意脑补”。
- 人物特点设计越界成完整美术定稿。
- 小说改剧本节点提前写镜头、宫格或模型参数。
- 一票否决与自动返工逻辑冲突。
- 失败状态名在不同章节不一致。
- 将创作者名气、作品热度或个人风格当成方法证据。
- 把其他模型的提示词规则套到 GPT Image 或 MiniMax H3。

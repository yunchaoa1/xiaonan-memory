# 语义完整 · 动机 · 意外（去人工味的三条硬规矩）

> 2026-11-17 凡哥在一集都市职场短剧的改稿里逐条纠正出来的。当时的情况是：剧情已经看得懂了，观众测试也过线，但凡哥仍判"台词啊描述啊，还有很明显的 AI 塑料感"。
> 这三条管的是**文字层**（△ 动作描写 + 台词），比"情绪债/爽点节奏"更细一层。

---

## 一、判定标准是语义完整，不是句子长短

凡哥原话：

> **"评判的标准不应该是句子的长短来决定的，是一个语义的完整程度。"**

我当时的错误：拿句长统计当判据（平均句长 6.9 字、长句 0%），然后提出"把句子拉长"。

**错在因果颠倒。**长句是语义完整和情绪上来的**副产品**，不是原因。语义残缺的话，拉成三十个字还是塑料的。反过来追求长句，等于拿体温计量身高。

合格线一句话：**读到这里，读者答得上"谁在做什么"和"为什么会是这样"。**

---

## 二、正反对照：同一个物件的两种写法

**AI 骨架**

> 表压在箱底，一叠，橡皮筋松了，勒不住，纸边发黄。

五个名词性短语堆在一起：没有主语、没有观察过程、没有因果。只剩"物件＋位置＋数量＋状态"的信息骨架。

**人写**

> 她要找的打分表是在箱子的最底层，有整整一叠纸。捆绑折叠纸的橡皮筋怂了，应该是很久很久导致的皮筋没有了弹性，纸的周围也有些微微泛黄了。

| | AI 骨架 | 人写 |
| :--- | :--- | :--- |
| 主语 | 无（"表"是宾语碎片，不是主语） | 有（"她要找的打分表"——带目的的人） |
| 因果 | 只报状态 | 有推断（"应该是很久很久导致的"） |
| 呼吸 | 四字一顿，像清单 | 完整分句，允许啰嗦 |

**最关键的一条：人看见东西会琢磨它为什么这样，机器只报它是什么样。**

## 三、落地规则

### 3.1 每处细节后跟一句人物自己的判断

用这些词带：**应该 / 怕是 / 看样子 / 原来 / 看来 / 估摸 / 多半 / 像是 / 难怪 / 说不定**

实测例子（同一集场 04 的定稿）：

| 细节 | 后面跟的那句推断 |
| :--- | :--- |
| 灯还亮着 | 这灯怕是白天忘了关 |
| 锁舌坏了 | 看样子坏了不止一天，一直没人管 |
| 皮筋松了 | 应该是放了一两年，弹性没了 |
| 笔压透纸 | 写的时候用了劲，怕是怕人看出来 |
| 抹桌面 | 怕留下手印 |

### 3.2 台词和动作分开管

- **台词**：可以短、可以断、可以不说完。忍着的人话少；摊牌时也不一定长篇大论（"我今天就没打算来"比一段控诉更狠）。只要符合人物当下语义和身份就行。
- **动作／场景描述**：必须语义完整、可拍、带观察痕迹。不能为了"去 AI 味"压成电报体。

### 3.3 别把"一行 △ 一个动作"执行成电报体

分镜层确实要求一行一个动作（每个动作要能拆成一镜），但**在剧本层连续三行以上等长的"主语＋动词＋句号"，读起来就是分镜提纲**，这是最大的人工味来源：

> △ 她一页一页翻。翻到"李艳"那页：一排满分，一个空都没有。
> △ 她翻到自己那页。两个"9"被划掉，旁边写着"4"。
> △ 她把手电筒的光压低，凑近看那两处涂改。

**正解：剧本层写流动，分镜再拆细。**

实测（场 04）：动作从 7 条拆成 9 个镜头，信息一条没掉，还多出三处质感。**代价是时长从 20 秒涨到 32 秒。**

## 四、每个动作必须有动机

凡哥原话：**"所有的动作必须要有动机。"**

自检：逐行问"她为什么这么做"。答不上的那行就是硬的，删掉或换成一个有动机的。

### 踩过的坑

> △ 她把纸往灯下挪，又往前翻了几页，按日期一页一页对过去。

她刚找到自己那页、刚看到被改，凭什么立刻往前翻查历史？这个动机是我替她想的。真人在那一刻是先愣住。

**改法：把"查历史"挪到看见第二处不对劲之后**——那时她才有理由确认"是不是一直这样、哪天改的"。

### 动机链示例（场 04 定稿）

找自己的表（我为什么垫底）→ 发现两个"9"被改成"4"（愣住）→ 翻背面看笔压（要确认这是手改的不是印的）→ 去找李艳（她是唯一的异常，前面同事种过"连着七周都在里头"）→ 整页满分（意外：以为是同类，找到的是反面）→ 抬头对榜（要确认榜单和纸对不上）→ 躲脚步（不能被发现）→ 复印九份（要一张能贴出去的纸，照片贴不出去）

## 五、意外 = 两个动机撞在一起，不是巧合

凡哥原话：

> **"意外，那就是两者的动机把事件从事件和地点两个维度重叠导致，比如两个人发生车祸一样。"**

- **巧合**＝作者安排的（"正好在下面""恰好听见""凑巧路过"）——观众一推就散。
- **意外**＝两边各自图点什么，走到同一个点上撞上的——观众自己算得出来。

写法：先分别问 A 图什么、B 图什么，再看它们会撞在哪儿。

### 踩过的坑（被一句话推倒的逻辑冲突）

为了让关键证据"自己撞上来"，我写了：

> △ 下面那张就是李艳的。

理由编成"档案按排名排，垫底的人自然挨在一起"。

凡哥当场指出：**"林小满是末位，李艳是满分，他们都是垫底吗？"**

满分的人不可能挨着垫底的人。这个"意外"靠一个假逻辑硬凑，一推就倒。

**正解：给她一条自洽的动机。**李艳是她手里唯一的异常线索（前面已经种过），她去找李艳完全合理；而结果是意外的——她以为李艳跟自己一样是受害者，翻出来整页满分。**去找同类，找到的是反面。**

### 附带发现

如果原始打分表上李艳是满分，她凭什么连着七周在末位榜上？——**榜单和原始表根本不是一回事。**这个矛盾不是 bug，是戏眼，正好给下一场当众质问用（"李艳那页，八个满分。她那周接了多少个电话？"）。

**找逻辑冲突的方法：把两个本应一致的数字/事实并排放，看它们能不能同时成立。**

## 六、改写铁律：先核原意，再动笔

为了"写得生动"改掉原句的意思，比原句难读更糟。

凡哥抓到的实例：

- 原句"她**翻到**'李艳'那页"——无意撞见的
- 改后"李艳那页**不用找**"——变成有目标地查
- 一个词把被动改成主动，人物从"发现"变成"验证"，还顺手写成了侦探，太笃定，不像真人。

**改之前先问三句：原句在说什么？人物那一刻是什么状态？我这一改，状态变了吗？**

（顺带：那句原句的顺序其实也有问题——她最在乎自己那页，真人不会先翻别人的。两个都不对，正解是"先自己、再李艳"，靠"手指停住了"这个动作把意外感还回来，而不是靠作者的判断句。）

### 7.1 语义完整度（主门禁）

| 指标 | 合格线 | 说明 |
| :--- | :--- | :--- |
| 碎段率（4 字以下短语占比） | ≤ 40% | 碎片堆叠＝只报状态不报因果 |
| 缺主语分句 | 越低越好 | 过半就不知道在说谁 |
| 带推断词的描写 | ≥ 10%；细节密集场 40%+ | 最能分出人和机器的一列 |

只查 △ 动作行，不查台词（台词该短就短）。

实测对照：

| 版本 | 碎段 | 缺主语 | 带推断 |
| :--- | :--- | :--- | :--- |
| AI 原写法 | 37% | 71% | **0%** |
| 人写对照 | 6% | 40% | **50%** |
| 整集原稿 | 18% | 63% | **3%** |
| 场 04 定稿 | 14% | 46% | **45%** |

**0% 那一格就是"整集没有一个为什么"。**

### 7.2 台词节奏（参考）

拿《茶馆》第一幕（公有领域，维基文库）量：

| | 平均句长 | 参差度 | 8 字以下 | 25 字以上 |
| :--- | :--- | :--- | :--- | :--- |
| 《茶馆》 | 14.0 | 9.1 | 30% | 12% |
| 整集原稿 | 6.9 | 3.8 | 71% | 0% |

**怎么用**：它暴露的是"全集没有一处情绪上来一口气说完的话"这种结构缺失。**但为了过这条线去拉长句子，就是重犯凡哥纠正过的错。**结论只当看一眼，判据永远是 7.1 和观众测试。

## 八、语义完整会拉长时长

《末位》第五稿：55 行动作 × 1.8 秒 + 对白 157 秒 ≈ **256 秒**，而头部声明的是 180 秒。

原因：动作写细了，时间自然长。

**处理原则**：按实际时长报，不要为了守住原声明砍掉刚加回来的人味。要压就明说压哪几场、损失什么，交给用户定——不要自己偷偷削。

## 九、改稿自检顺序

1. `script_lint.py --mode cn --genre <题材> --words <时长×4>` —— 结构 0 ❌
2. `check_semantic_completeness.py` —— 碎段 ≤40%、带推断 ≥10%
3. 逐行问动机："她为什么这么做"
4. 找"巧合"：凡是"正好/恰好/凑巧"的地方，换成动机重叠
5. 找"改意思"：拿原句对一遍，看人物状态有没有被改动
6. 观众测试（只给正文，不给信息区）

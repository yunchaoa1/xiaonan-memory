## 一、可直接补进来的三张表（本技能目前没有这么细的）

### 1. 五种钩子 + 8 类爽感配比（`0xsline/short-drama`，★1565）

- **五种钩子**：悬念钩 / 反转钩 / 情绪钩 / 信息钩 / 危机钩 —— 每集结尾必须点名落在哪一类。
  本技能有「集末留新悬念」的要求，但没分型。分型后可查**同型连用**（连续三集都是危机钩 = 观众疲劳）。
- **爽感矩阵（8 类配比）**：打脸 / 逆袭 / 甜宠 / 虐心 / 悬疑 / 燃 / 搞笑 / 感动，按题材定配比。
  参考占比：情绪钩 30-40%（甜宠类主钩子）。**配比是创作决策工具，不是行业定律**，用来说明「这部为什么闷」。
- **四层反派**：第四层=隐藏反派·终极反转，压到后 1/3 才揭，且是「身边最信任的人」。
  与本技能「三层真相」可对齐：表面说法 → 被陷害 → 真正黑手，这里多了「最信任的人」这一刀。
- 付费卡点 **10-15% 集数**；🔥重点集 **25-35%**。

### 2. 四级卡点体系（`chengbenchao/short-drama-script`，★38）

一卡 / 二卡 / 三卡 / 日常卡点 —— 横屏正剧只走一卡二卡三卡，**不设日常卡点**；竖屏短剧才铺日常卡点。
本技能只写了「付费卡点卡在身份揭露/第一次大打脸前一瞬」，颗粒度不如这个。另有男频爽文 22 种套路库。

### 3. 红果必爆 7 招 · 秒级时间轴（`A-cat-with-carrots/OnlyShot`，★363）

对抗式开场 → 30s 爆破 → 60s 爽点 → 90s 反转 → 120s 爽点 → 150s 钩子 → 180s 倒计时

写进 `节奏地图.json`，精确到秒。与本技能「每 15-30 秒一个信息点 / 每集≥1 个反转 / 最后 15 秒留新悬念」同源，
但这个把 3 分钟集切成 7 个固定检查点，**更适合直接当验收标尺**。
同仓另有：分镜图当视频首帧（成本约为直接出视频的 1/18）、17 个失败模式沉淀。

## 二、工程化做法值得抄的一招（`zenstory-ai/drama-skills`，★3833）

**五份 markdown 分工**：`剧本.md` / `视觉设定.md` / `分镜.md` / `图片提示词.md` / `视频提示词.md`，
每份只记一个阶段的创作决定，下游只能照抄已接受的上游值。

配一道**跨文件一致性校验**：把某镜时长从 2s 改成 3s，工具直接报
`ERROR: SHOT-EP001-003: 分镜时长 2 秒与视频提示词 3 秒不一致；视频提示词只能原样照抄已接受的镜头时长`。

→ 这条对我们有用：拆本子→分镜→提示词三跳，最容易死在「改了一处没改另一处」。
凡哥的活里凡是跨阶段交付的，都应留一份可对照的数值台账（时长/镜号/台词字数）。

## 三、受众分版（`doublesq97-ui/su-ai-short-drama`，★66）

男频 / 女频不是同一套逻辑换皮：

- **男频**：身份兑现、秩序重建、事业扩张、能力成长；回报=策略与行动被承认。
- **女频**：主体成长、关系变化、情绪张力、偏爱与信任；回报=被坚定选择。

原话很克制：「女频/男频是内容市场的创作配置，不是对所有女性或男性的心理判断」——
这个表述口径跟我们对外说话的方式一致，可以照用。

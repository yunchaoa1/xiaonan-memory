# AI群像短剧：逐集生产约束层

适用于已经通过“连续因果单元 → 容量估算 → 逐集因果卡”的横屏AI漫剧。它是剧本正文和分镜之间的生产前一层，不取代故事因果卡。

## 何时建立

仅在以下已锁定后建立：

- 每集的承接后果、唯一情绪任务、不可逆变化、可见结果与钩子；
- 主角不可替代选择、证据边界和公共后果；
- 季终没有被提前写成正式公司、全员集合或大团圆。

表格逐集只补：主场域、具象主动作、可见角色上限、关键证据／道具、界面信息等级、必须拆开的高风险动作。

## 核心原则

### 1. 用可复用“功能场域”，不要先锁美术

先为整季建立约六个功能场域，例如：协调与订单、商户服务、现场维护、技术工作、复核档案、组织入口／公开条件。场域服务因果：

- 同场域再次出现，必须改变订单、服务、冻结、资格、材料、入口、补救或新排除中的至少一项；
- 商户服务与现场维护要分别表现“能否继续使用”和“谁承担维护／工资／资格成本”；
- 复核空间负责程序动作，组织空间负责条件设计与组织代价，不能合为万能权力房间。

### 2. 同场人数按选择复杂度限流

- **P1**：单人承担查阅、维护、交出、承认、记录等不可代办选择；
- **P2**：两人完成材料交接、条件冲突、递交／退回或具体服务结果；
- **P3**：仅用于少数明确的三方利益冲突，禁止三人同步说话、操作或肢体拉扯；
- **P4+**：不作为稳定同框目标。用异地交替动作、清单汇合、声音或公共后果串联。

尤其是“共同体成立”不能靠四人围桌、集体递交或结拜。必须拆为各自放弃什么退路、留下什么可追责痕迹，再由机制状态汇合。

### 3. 界面只能表达状态，不代替人物

- **I0**：仅道具／动作；
- **I1**：一个状态加一个时间或对象；
- **I2**：一条材料的有限对照；
- **I3**：证据分栏、事实地图或公开清单。

每次界面只回答一个问题：“发生了什么状态变化？”界面不能同时证明事实、意图、合同责任与最终结算。I3之后必须落回人物选择或公共后果，避免连续材料、规则、程序让剧变成制度讲解。

### 4. 高风险内容的替代顺序

| 高风险内容 | 可执行替代 |
|---|---|
| 多人抢修／协作 | 单人判断 → 一名执行者 → 商户实际使用结果 |
| 多人递交材料 | 各自单人交出 → 清单状态汇合 → 受理结果 |
| 大型听证／质询 | 一条证据 → 一名回应者 → 一项责任或公共后果 |
| 窗口公开 | 条件清单 → 一名商户进入 → 一名基层成员进入 → 风险边界确认 |
| 阶段补救 | 服务变化 → 部分补救／资格 → 未结成本 → 新排除 |
| 季终共同体 | 异地职责动作 → 新材料状态变化 → 公开反馈仍保留 |

## 季终机制画面的判断

如果季终目标是“共同体雏形”，最小可见结算不是主角庆祝，而是：

1. 原本会被入口过滤的对象先明确处于“无法进入”；
2. 主角们按各自职责行动，不能为其开后门；
3. 公开记录变成“已接住、待核验”或同等的可追踪状态；
4. 同时保留期限、成本、责任与下一笔债。

“已接住”不等于立即补偿、免责、永久资格、公司成立或问题解决。

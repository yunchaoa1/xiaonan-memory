# 玄幻神转世：未来道具清单 & 审查检查清单

本文件来自十二生肖玄幻IP（十二时辰之神被贬）的创作会话，记录可复用的道具表和审查时的具体 bug 案例。用于重写/自查同类"神转世 + 时间降维打击"爽剧时直接套用。

## 一、未来道具清单 + 现代人丢东西彩蛋

核心规则（已写入 SKILL.md）：未来之物有时效、到点自动消失、回到现代；借物耗龙神（时流）力气，不能常借；**不要**加"越未来越贵"这类复杂补丁。

| 道具 | 古代爽点（降维打击） | 现代人彩蛋（1-2秒） |
|------|-------------------|-------------------|
| 打火机 | 无中生火，苍老敌人 | "咦？我打火机呢？" |
| 手电筒 | 黑夜照破黑气，"天光下凡" | "我手电筒呢？" |
| 望远镜 | 千里眼，提前看破敌阵 | "我望远镜呢？" |
| 指南针 | 定位逆鳞/方向 | "我指南针呢？" |
| 玻璃镜 | 照妖镜，照破伪装 | "我镜子呢？" |
| 手机 | "会说话的仙器"，录下罪证当众播放 | "我手机呢？" |

彩蛋的喜剧机制：现代人"找东西找不到、过几天收拾家又自己出现"的都市传说，被反转成"东西被神借走了、用完自动归还"。

## 二、审查检查清单（以开篇第一章为力度基准）

凡哥的固定要求："从第一卷开始检查，对比第一章的精彩程度；必须剧情合理，不能改得太离谱；改完自查，有错自己继续改。"

### 逐章检查要点

1. **回忆式觉醒 → 现场炸裂**：觉醒必须发生在"当下画面"，不能靠"我当年一拳打穿盾"这种回忆交代。回忆式觉醒往往还藏逻辑漏洞（都觉醒了为什么还被锁？）——用"半觉醒（力量不稳、爆发过又脱力）"来补，既保留前史又让现场觉醒成立。
2. **过渡章/信息章别太干**：相遇、聚齐、揭真相这类章，靠"力量共鸣""时间凝住整条街"这类小爽点撑一下，别纯对话。
3. **觉醒编号一致性**："第一个醒了/第二个醒了"这类编号，一旦前文已经醒了8个神，就不能再说"第三个"。要么严格递进，要么后面干脆不编号。
4. **性别代词一致性**：十二生肖性别（鼠牛兔蛇羊鸡=女，虎龙马猴狗猪=男）定死后，逐章核对"他/她"，别让"酉时鸡"写成"他"。
5. **神位/名单数量对账**：亮/暗/空的数量，要和"已醒/未醒/失踪"的名单严格相等（如 8亮+3暗+1空=12，不是 8+2+2）。

### 本次会话实际修掉的 bug（作为案例）

- 第二章"第二个醒了"与第三章重复（角色还没完全醒就编号）→ 删掉早的那次，只留"它先醒了，接下来是你"。
- 第十章灵儿说"第三个"，但前面已醒8个神 → 删编号，直接"子时……鼠"。
- 第七章"酉时鸡"写成"他"（应女）→ 改"瞎眼女子"。
- 第七章神位"两暗两空"（应为三暗一空）→ 改对账。
- 未来道具"蓝火留下当信物"是加戏导致的逻辑漏洞（打火机消失、火为何留）→ 火随打火机一起消失，找逆鳞改回金纹引路。
- "时效越短代价越大"是过度设计 → 删掉，回归"有时效、到点消失、借物耗力气"。

## 三、性别情绪引擎（古代玄幻版）

- 女角色：被逼婚 / 被卖去窑子 / 被恶霸强占的"险境"→ 最后一刻觉醒反杀（伤愈、恶霸倒退回婴儿）。
- 男角色：被拉苦工 / 充军 / 奴役 / 被当炮灰。
- **红线**：强暴威胁只写"险些"，不写真发生——真发生=虐女、劝退女性付费主力、过不了审。"险些"二字才是爽点开关。

## 四、悖论死局的写法

"集齐十二神救龙，但龙自己是十二神之一" → 反派（猫神）故意设局，龙神知道答案却每次说到一半被窃天者打断（"缺的那一个，其实——"）。半句话拖一整卷当主线悬念，揭底时才说"龙神的力能穿透时间、不需要肉身回来"。

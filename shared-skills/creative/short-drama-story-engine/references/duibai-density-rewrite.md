# 单集对白增密重写（现有剧本按《对白型铁律》重做）

适用：剧本包已存在，但用户说"把台词密度提上去 / 按最新规矩重做某一集"。原稿的剧情骨架不动，
只做两件事：**△ 里的信息搬到台词里**、**把台词量补进 300–350 字区间**。

## 0. 先拿基线，不许凭感觉

```bash
python "D:/Hermes/skills/creative/short-drama-story-engine/scripts/duibai_check.py" "<剧本.md>"
```

只看基线行：`台词字 / 台词句 / △字 / 台词△比 / VO / OS / 最长连句`。
剧本包里"台词量离群"的集往往不是一星半点——《十二时辰》第一卷实测均值 119 字/集，
最低 E2=22 字、E3=33 字，`台词/△` 只有 0.05–0.08，等于整集靠画面叙事。

## 1. 逐条清点 △ 里承载信息的部分

把本集每个 △ 过一遍，凡出现以下内容即为"信息型 △"，必须转对白：
身份/身世、关系、前情、规则、阴谋、任务、钱与物的来历、别人的态度评价、因果解释。
纯动作奇观、走位衔接、情绪外化（风吹、云停、绳断、光起）留在 △ 里，不要搬。

转换用四问填一格：

| △ 原文信息 | 谁说 | 在什么情境说 | 对谁说 |
|---|---|---|---|
| 簪子是娘的唯一遗物 | 牛满 | 王二举着簪子嘲笑时 | 王二（当众） |
| 铜钱是攒了半年的赎身钱 | 牛满 | 王二说"还想赎身"之后 | 王二 / 围观村民 |
| 明儿卖到窑子 | 王二 | 开场的羞辱宣告 | 围观人群 |
| 她娘给全村接过生 | 老汉 | 王二骂"克死爹娘"时低声犯怵 | 身边妇人 |

## 2. 加"围观声部"补密度（最省力的一招）

原稿常只有主角+反派两个声部，台词自然不够。补 2–4 个功能化群众角色，让他们承担：
起哄、帮腔、说半句实话、被反派喝止、替观众问出"那她咋办"。
《十二时辰》E1 用了 村民甲（起哄）/ 村民乙（补刀＋念出簪上小牛）/ 老汉（说了句人话被打断）/ 妇人（拉人）。
注意：群众台词要短（6–15 字），作用是垫节奏，不许抢关键信息。

## 3. 本集台词预算（130 秒集的经验值）

- 350 字 / 25 句 ≈ 每句 10–14 字，跟爆款实测单句均长 12.3 字一致；
- 每 3–4 秒一句，最长静默不超过 10 秒；
- OS 只留 2 处、只表情绪（"不能哭""一文都没了"），OS 不许带新信息；
- 一句台词至少干一件事：交代 / 关系 / 冲突 / 情绪 / 钩子。

## 4. 写→跑→砍的迭代（关键：第一稿必然超）

实测账本（E1，同一集连改四轮）：

| 轮次 | 台词字 | 动作 |
|---|---|---|
| 初稿 | 417 | 超 67 |
| 二稿 | 381 | 砍掉一条群众帮腔、压缩反派长句 |
| 三稿 | 356 | 砍"我给你踩实点儿"、缩"老爷发话了"长句 |
| 四稿 | 351 | 缩"没人敢要" |
| 五稿 | 350 | 微调两字，落进区间 |

规律：**一次砍 20–40 字，砍最长的反派台词和重复的群众帮腔**；
情绪高点（断簪、数钱、"一个一个来"）一句都不许砍，那是在还情绪债。
不要靠把句子切碎来减字——字数不是节奏判据，念不顺就是违规。

## 5. 交付形态（用户审稿习惯）

- 原稿**不动**，另存单集文件：`十二时辰_第一卷_第01集_对白增密重写_v1.md`，头部写清依据、改动边界、原稿→本稿数字；
- 报数只报脚本实测值，不报"感觉够了"；
- 总控台把该集的"待办"改成带日期的进度行（路径+实测数字+剩余集数），随记忆仓库提交；
- 一次只推一集给用户看风格，问他"接着往下改还是先对风格"，不擅自批量重写整卷。

## 6. 陷阱

1. 第一稿就宣称达标——必超，先跑脚本。
2. 把 △ 当垃圾桶：新信息没转对白，只是把 △ 写短了，等于没改。
3. 自检/自评段落写进正文区间，会被脚本当台词统计（历史上把末集 141 字误报成 859 字）。
4. OS 用来交代信息（"她想起娘死那天……"）→ 违规，只能表情绪。
5. 为达 350 字硬塞废话台词（"你干什么""我不"）——每句都得干活，宁可 320 字也别注水。

# AI漫剧与短剧形态研究：口径拆分参考

用于在设计AI漫剧季集规格、单集时长和追更结构前，避免把真人微短剧数据误套到漫剧。

## 1. 先拆内容形态

至少分开记录：

- 真人竖屏短剧：信息流消费，供给量大，常见短集密集反转；
- 真人横屏精品微短剧：单集通常更长，依赖完整场景、表演和情节累积；
- 漫剧/动态漫/AI漫剧：动画资产、旁白、镜头和剪辑承担表演，平台规格尚未完全统一；
- 短视频连续剧：可能只是连续发布的短视频，不等于备案微短剧；
- 长视频平台微短剧：集数、时长和横屏规则可能独立于短视频平台。

## 2. 每条数据必须记录六项

1. 发布机构/报告名/发布日期；
2. 统计对象（用户、播放、投流、市场规模、供给量、使用时长）；
3. 平台范围；
4. 内容形态；
5. 样本和统计周期；
6. 可否外推到AI漫剧。

将结果分为三层：

- **已核验数据**：原始报告、官方平台规则、权威媒体可读正文；
- **可追溯但二手转述**：媒体或行业文章明确注明来源，但未能读取原始报告；
- **创作判断**：根据AI制作复杂度、群像叙事和用户机制推导，不冒充行业事实。

## 3. 关键指标不可混用

- 用户规模 ≠ 单部剧观众数；
- 应用人均使用时长 ≠ 单剧完播时长；
- 播放量 ≠ 独立用户数，可能含重复播放；
- 投流热力 ≠ 用户自然偏好；
- 供给量 ≠ 市场需求；
- 单集时长 ≠ 整部总时长。

## 4. AI群像项目的转译规则

行业数据只提供边界，不能直接决定季集规格。需要同时考虑：

- 主角数量与每个角色的最低建立成本；
- 信息阻隔和因果链能否在单集内完成；
- AI单镜生成时长、镜头数量、角色一致性和场景复用；
- 角色单线与团线的汇合节奏；
- 每集是否能完成一次旧债偿还或关系/信息/资格变化。

对十二生肖这类12人群像，优先测试“横屏、每季约30集、单集3—5分钟”，但必须标注为创作建议，并先用第一季验证，不能假装这是行业统一标准。

## 5. 追更机制转译

用户观看频率或应用时长只能证明连续消费环境存在，不能替代剧本设计。每集仍需具备：

- 开头30—60秒进入具体冲突；
- 中段由主角采取性格化行动并承担代价；
- 结尾留下可回答的具体问题；
- 连续三集内至少有一次不可逆的知识、关系、资格或地位变化；
- 不用无因悬崖和重复羞辱冒充悬念。

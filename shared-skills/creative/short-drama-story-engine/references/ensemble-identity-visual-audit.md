# 群像主体身份对照与视觉辨识度审计

用于十二生肖、时神、星宿、战队等多主体爽文从正文进入人物设计、生图、分镜或配音之前。

## 目标

把“正文里这个人是谁”与“观众凭什么一眼认出他”分开核对。姓名、能力和眼睛颜色能帮助理解，但不自动构成稳定的视觉身份。

## 权威核对顺序

1. 读取全部已完成正文，不依赖总纲、记忆或角色表猜测。
2. 提取每个主体的首次出现、正式自报身份、时序/生肖称谓、能力名、性别指代、外形特征、道具和前世形态。
3. 只把原文明确对应的身份写入主表；推测、早期预告和身份冲突另列。
4. 对无凡人姓名、集中加入、没有独立觉醒章节的角色重点复核，因为最容易只剩功能标签。
5. 输出后反查每一行都能落回具体正文证据。

## 标准对照表

| 字段 | 含义 |
|------|------|
| 序位/时辰 | 体系内位置，如子时、丑时 |
| 神格/象征身份 | 鼠神、牛神等 |
| 正文人物主体 | 凡人姓名或当前称谓 |
| 性别/形态 | 当前人形、非人形及明确指代 |
| 稳定视觉锚点 | 跨场景仍可识别的形体、纹样、发型、服饰结构、随身物 |
| 能力/行动锚点 | 能力名及最典型的可见动作 |
| 证据状态 | 明确、未揭晓、疑似、前后冲突 |

## 辨识度分级

- **强**：姓名、稳定外形锚点、独占能力或动作三者齐全。
- **中**：能力明确，但外形主要靠眼睛颜色、年龄、情绪或职业。
- **弱**：只有序位称呼、职业和功能，没有凡人姓名或稳定动物/神格锚点。

眼睛颜色只能作为辅助锚点。群像角色若主要靠红瞳、金瞳、灰白眼等区分，在快速剪辑、远景、弱光和黑白分镜中会迅速失效。

## 冲突处理

正文早期预告与正式登场不一致时，不要强行合并。例如早期出现“绿瞳少年”，后续正式身份却是“金色竖瞳女人”，应标记为“疑似早期版本，与正式设定冲突”，不能把推测写成定论。

## 输出纪律

- 用户只要身份对照时，不顺手改正文或补设定。
- 先给完整映射，再指出辨识度最弱和证据冲突的主体。
- “没有稳定识别特征”要如实写明，不能从生肖刻板印象反向脑补。
- 若要进入人物设计，另开下一阶段，为弱辨识主体补“轮廓＋纹样＋服饰结构＋随身物＋动作”中的至少两种稳定锚点。

## 本次案例提炼

《十二时辰》两卷审计中，集中加入且没有独立觉醒章节的午马、未羊、酉鸡、戌狗最难识别；灵儿、牛满、寅、月儿、巳、申、亥因姓名、外形或独立觉醒场面更容易建立对应。这个结论只作为方法案例，未来项目仍须逐篇核证。

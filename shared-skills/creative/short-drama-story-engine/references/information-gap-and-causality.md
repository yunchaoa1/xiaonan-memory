# 信息差与因果编排

适用于隐藏身份、真假亲人、窃稿、旧物、童年记忆、豪门差距和多线调查。重点不是堆反转，而是控制每个角色在每个时点知道什么，以及新知识如何改变行动。

## 先画信息差，不先排集数

| 角色 | 已知 | 未知 | 误判 | 因此会做什么 |
|---|---|---|---|---|
| 主角 |  |  |  |  |
| 对手 |  |  |  |  |
| 调查者 |  |  |  |  |
| 隐瞒者 |  |  |  |  |

新增反转前逐项问：

1. 谁先知道？
2. 从哪里知道？
3. 为什么相信？
4. 为什么现在行动？
5. 谁仍然不知道？
6. 这条信息改变了什么行为？

答案若是“剧情需要”，必须重写。

## 多条证据线必须分工

以寻亲与窃稿为例，可拆为：

### 作品线

原创想法出现 → 调查者先见作品、后见作者 → 对手不知情窃稿 → 作者路径被遮蔽 → 冒名者后续无法解释创作逻辑 → 追查真正作者。

功能：证明能力、原创归属和人物吸引力。

### 实物线

关键实物长期私藏 → 通过独立事件出现 → 与旧故事或旧记录相互印证。

功能：形成高度怀疑，但通常不能单独完成身份确认。

### 身份线

时间、地点、当事人经历、旧资料、实物和正式验证逐步闭环。

功能：完成事实确认与关系重建。

不要让一次比赛、一件首饰或一个大人物同时证明原创、爱情与血缘全部真相。

## “弄巧成拙”必须成立在未知上

对手的主观动机可以是：

- 邀功；
- 获得认可；
- 压制竞争者；
- 维护身份光环；
- 阻止关系靠近。

但其行为成为反向线索，需要她不知道某个关键事实，例如：

- 调查者早已见过原始思路；
- 作品关联旧案；
- 主角另有对应实物；
- 长辈会追问创作过程。

有效结构：

> 对手暂时得利 → 后续深度追问 → 解释失败 → 引发怀疑 → 被遮蔽的人重新进入视野。

这比“偷完当场被抓”更有因果价值，也能同时完成阻断与推进。

## 身份差距决定接触方式

当双方身份差距明显：

- 弱势方不应无理由主动贴近；
- 前期接触来自职责、比赛、调查或共同任务；
- 强势方先看到能力，再认识本人；
- 关注可被误解为公事，避免关系跳级；
- 强势方尊重边界，不用权势强行解决所有问题；
- 感情最好成立于身份确认之前，否则容易被理解为身份奖励。

证明关系价值的句式逻辑：

> 我先认识你的作品、行动或选择，那时还不知道你的身份。

## 被隐瞒者的认知边界

如果角色一直相信当前家庭关系真实：

- 只能拥有模糊、碎片化的违和感；
- 会优先把异常解释为记忆混乱；
- 不应轻易说出只有隐瞒者才知道的来历；
- 调查需要由外部证据进入；
- 真相揭开后，“曾经的爱”与“剥夺知情权”可以同时成立；
- 复杂照顾者不必纯恶，但必须承担选择造成的后果。

## 延迟反噬的四个条件

延迟不是拖延。必须说明：

1. 当时为何没有被发现；
2. 哪个新事件让旧问题重新出现；
3. 谁获得了过去没有的比较材料或调查权限；
4. 延迟期间对手得到了什么，又留下了什么漏洞。

## 幕后设定不等于正文解释

后台必须知道物件如何保存、谁何时知情、证据如何流转；正文只保留推动行动的部分。

删除：

- 只为证明设定完整的解释台词；
- 角色当场复述观众刚看见的事；
- 对后续无作用的物件保存细节；
- 为方便认亲而安排的连续巧合。

## 自检

- [ ] 关键人物的已知、未知和误判均已列出；
- [ ] 每个反转都改变后续行动；
- [ ] 作品、实物、身份和正式验证各有独立功能；
- [ ] 对手犯错源于合理未知，而非突然变笨；
- [ ] 弱势角色的接近方式符合现实身份边界；
- [ ] 隐瞒者与被隐瞒者的信息不串位；
- [ ] 延迟后果有触发事件，不是编剧等到某集才想起来；
- [ ] 正文删除了只为解释后台而存在的台词；
- [ ] 最终确认由多条因果链闭环，而非单一巧合。

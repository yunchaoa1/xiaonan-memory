# Season-First Scope Gate

Use this reference when a large ensemble has attractive long-range worldbuilding that can easily outrun the current season.

## Active vs deferred

Before adding detail, split the project into two lists.

**Active now:**
- independent-life cards;
- subjective success and real pride;
- distinct consequence/lesson;
- causal encounter chain;
- current gathering scale;
- guide figure's present-stage action;
- season endpoint and unresolved next-season pressure.

**Deferred:**
- later enterprise names and classifications;
- faction/animal-core rosters;
- full organizational ecology;
- final core-member positions;
- post-season expansion and incorporation;
- civilizational or national mappings.

Write deferred material as an architecture note, not as active plot.

## Gate questions

1. What is the smallest current-season endpoint that creates an irreversible relationship change?
2. What gathering scale does that endpoint actually support: one, two, four, or more?
3. Which existing character card supplies the first consequence, and why?
4. What does the next character uniquely possess: evidence, risk, resource, skill, credit, or affected people?
5. What does the guide figure do that changes conditions without deciding the characters' lives?
6. What remains deliberately unresolved for the next season?

## Sequence

1. Confirm the user's current priority.
2. Freeze the deferred architecture.
3. Audit the independent-life cards.
4. Choose one narrative anchor.
5. Build the first causal chain.
6. Review the chain before assigning names, ages, occupations, locations, episode numbers, or formal faction identities.

## Anti-scope-creep test

If a proposed detail does not change a current character's choice, risk, information, credit, resource, relationship, or season endpoint, defer it.

## Example pattern

For a modern workplace Water-Margin ensemble, the first season can end with a temporary four-person community and a shared-venture seed. The twelve-person enterprise, final core-member positions, and other animal enterprises remain future architecture. This is not a smaller version of the final story; it is the causal foundation that makes later gathering believable.

# 57角色虚拟演员参演独立AI漫剧

## 模式定义

南溟岛角色既可以出现在本传，也可以作为固定虚拟演员参演彼此独立的AI漫剧。独立参演模式下：

- 剧中职业、血缘、经历和结局不反向修改南溟岛本传。
- 默认保留演员的脸、声音、辨识性气质与原名；剧情需要隐藏身份时，可先使用养名/化名，认亲或揭晓后恢复原名。
- 本传的同市县婚恋、六界六阶、穿越和心魔规则不自动约束独立剧，除非凡哥明确要求本剧属于主宇宙。

## 开工前的模式确认

先确认一次：

1. 主宇宙正式故事；
2. 主宇宙支线；
3. 57角色作为演员参演的独立剧。

未确认前，不得拿独立短剧设定去改角色成长故事，也不得用本传关系规则否定独立剧选角。

## 选角矩阵

候选人至少从五个维度比较：

| 维度 | 检查内容 |
|------|----------|
| 年龄观感 | 与剧中年龄、童年时间线、爱情线是否可信 |
| 视觉化学反应 | 与男女主同框时，冷暖、体型、气质是否互补 |
| 情绪内核 | 原演员的辨识性气质能否帮助观众快速理解角色 |
| 剧情功能 | 是陪伴型、调查型、保护型，还是控制型、利益型反派 |
| 资产成熟度 | 是否已有定稿底板/四视图；新增人形资产会增加多少制作成本 |

先给2—3名候选和明确排名，说明第一名为什么胜出，同时诚实写出短板，不为凑候选而假装都适合。

## 原生19反派的现代剧参演规则

19反派多数是聚合体、自然灾害、怪物或无形存在，并不天然等于19名现成的人类演员。筛选现代都市剧女二或男二时必须先检查：

- 是否具有明确性别与年龄观感；
- 是否已经有可复用的人形底板；
- 原名放进现代社会是否成立；
- 是否需要额外设计“现代人形演员形态”。

若缺人形资产，要把新增成本说清楚。可因故事匹配度选择人形化，但不能把概念反派说成已经可直接拍摄的演员。

## 第一部低难度范围模板

首部用于跑通AI漫剧流程时，优先：

- 家庭情感、寻亲、继承、职场、爱情等文戏；
- 4名核心演员左右，少量功能性配角；
- 5—7个可反复使用的核心场景；
- 灾难、落水、多人事故采用噩梦、声音、旧照片、新闻档案、局部特写和碎片闪回；
- 幕后大反派可只留电话、文件或信息伏笔，留到第二部出场；
- 先锁人物关系、时间线、证据链和整季体量，再写故事小说和分集剧本。

## 寻亲故事的可信度检查

- 儿童年龄是否足以形成记忆；不能只凭成年脸认出童年玩伴。
- 童年记忆需结合照片、旧物、动作、儿歌、伤痕、档案等锚点。
- 最终身份必须有可靠证据闭环，DNA承担终局确认。
- 失踪儿童为何获得新身份、为何多年未被查到、为何近期线索突然出现，必须用同一条因果链解释。
- 养子女被逐出家门，应因其主动犯罪或严重伤害，而不是仅因没有血缘；否则长辈会失去道德正当性。

## 本次项目案例（可迁移）

树形分类：`57角色参演剧本 → 现代都市剧 → 豪门寻亲·家庭情感·爱情爽剧`。

已验证的角色功能组合：

- 海边温暖型男演员适合担任童年证人和陪伴型男主，不抢爷孙主线。
- “未被选择/害怕被替换”型反派适合养孙女，比单纯贪财更有情感根基。
- 幕后家族若只服务第二部，第一部不现身、不参与最初失踪，只利用长辈的情感缺口布局，可有效控制人物与场景规模。

## 数据源核验

开始全库选角前，交叉核对xlsx、`world/38角色总表.md`、影视对标表和角色提示词目录。若38/39或成员名单冲突：

1. 列出差异；
2. 标记阻塞；
3. 不擅自删人、换人或修正总数；
4. 等凡哥确认权威版本后再改总表和总控台。

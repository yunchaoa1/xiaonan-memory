# 南溟岛反派设计

## 设计原则

1. **真实锚点**：每个反派的诱因必须来自海南真实的历史事件、地标、传说或文化现象。不虚构不存在的东西。凡哥会问"这个有根据吗"——没有真实锚点的设计会被直接否决。
2. **同城第三切面**：每个市县2正派已覆盖两个地标/文化。反派走第三个角度——该城市还没被正派照亮的历史暗面。**不能和正派用同一个地标/故事。**
3. **统一模板**：所有反派记录必须使用相同的六段结构（见下方）。
4. **敏感规避**：避开革命历史、民族起义、抗日战争、领土争端等政治敏感话题。用传说/民俗/自然/商业失败替代。凡哥明确要求"反派的话题要避开当今敏感话题"。
5. **心魔跨界**：反派通过心魔绑定同时存在于真实海南和南溟岛。不是两个角色，是同一个执念活在两个世界的叠加态里。**反派存在的意义就是为了成就正派。**
6. **仇恨必须是个人的**：反派恨的必须是发生在自己身上的事——不是替别人恨，不是替树恨，不是替寨子恨。凡哥反复否定"太平了""没有发力点"的设计。成功案例：霍启明恨自己设计的灯塔被拆，阿木恨自己父亲的伐木道，老犁恨自己的魂牌被卖了三百万。
7. **逐条审阅**：一个市县一个市来过，不要一次性交全部19个。凡哥会逐个确认。

## 统一模板（七段·含五大铁律）

**五大铁律**（2026-07-02凡哥定）：
① 心魔：必须从57条中选，不能凭空编
② 地域真实：锚点必须可查，不能完全虚构
③ 伤害性大：共鸣要广，不能只是个人悲剧
④ 避雷：不碰政府/正面历史人物/国保文物
⑤ **诱因→载体→破坏三段完整**：每个反派必须能说清"怎么来的、以什么形式存在、造成了什么实际伤害"

每个反派必须包含以下七段，**所有文本竖线必须对齐**：

```
| 项目     | 内容 |
|----------|------|
| 正派     | [同城2个正派名称及地标] |
| 反派     | **[反派名]** |
| 类型     | 完全黑化者 / 心魔合成体 / 人魔共生体 / 心魔聚合体 / BOSS级 |
| 心魔     | [2-3条心魔] |
| 记忆锚点 | [真实物理地标] |
| 代表     | [一句话，这个反派代表什么] |

### 诱因 · 真实历史
### 反派故事
### 载体
### 造成的破坏
### 共鸣锚点
### 跨界
### 与正派关系
```

⚠️ **"造成的破坏"铁律**：不能编造真实地点的损害（如"遗址关闭""水源污染"）。破坏必须是超自然的（对视石化、触碰剥漆）或影响人而非遗址本身。省级文保造谣是底线，碰了就死。

## 心魔分配规则

每个反派分配2-3条心魔（从天南心魔谱系57条中选取）。心魔驱动反派的执念，也解释他的行为。

## 反派四类型

| 类型 | 说明 | 案例 |
|------|------|------|
| 完全黑化者 | 人类被心魔日积月累改字带偏。有完整人物故事 | 霍启明、阿木、陨姊、盐佬 |
| 心魔合成体 | 单一执念/怨念凝结成形。不是人 | 老犁 |
| 人魔共生体 | 角色主动选择与心魔共存 | 老木（根界植物） |

### 吞舟全流程（2026-07-03定稿）

琼海吞舟是最复杂的单一反派——历经三次大改：

**v1（泥炭层巨蟒）**：沼泽干缩把巨蟒箍在泥里，动不了，等人喂。**被否**——不够激烈。

**v2（鼓谈判版）**：博澜汇用鼓敲出吞咽波长→与蛇谈判→敲出"停"。**被否**——"太平了""不够激烈"。

**v3（食道瘾君子+大场面碰撞·最终版）**：
- 核心机制：恐龙时代遗种，沼泽缩小后身体随之缩小。进化出**食道神经复制液**——咬过的生物会产生"撑食道的击喉感"，替它吞，快感同步回脊椎。每次只要2-3个替吞者，人少线稳。死一个补一个。
- 大场面：十一个替吞者被操控囤积快感→石昭缨用十一支镇定剂逐个断线→吞舟从泥底炸出三丈水墙直扑石昭缨脖子→博澜汇把左臂塞进蛇嘴卡住尺骨（骨头没食道，毒液走不通）→石昭缨最后一支打进蛇脊椎阻断全网→几万年来第一次蛇感觉不到食道，只剩**疼**。
- 凡哥的核心指导：①不能是鱿鱼吞大的→改成咬完中毒 ②要有吸烟击喉般的成瘾感 ③只养三两个替吞者，低调运转 ④不能和平收尾——让它疼、让它断电、让它缩回暗沟，不给和解

### 新增设计原则

17. **五大铁律**（见上方模板节）
18. **诱因-载体-破坏三段必须完整**：不能只有故事没有实际威胁。反派的载体必须清晰（骨晶共生体、枯死槟榔林、黄化病本身），破坏必须是可感知的（石化活人、产业崩溃、水源变质）。凡哥会追问"他造成了什么实际伤害？"
19. **不能造谣真实地点**：省级文保单位不能写"被封闭""水被污染"。超自然破坏（对视石化、触碰生锈）可以，造谣实际损害不行。澄迈案例：埋根第一版写了地基下沉和自来水污染——被否，因为红树湾是真实在售楼盘有真实住户。修正为纯地下生态破坏。
20. **不能攻击旅游胜地**：三亚天涯海角、海口骑楼、五指山等旅游景点不能写游客精神崩溃、人流量下降。欲潮案例：第一版写游客在海滩抱头痛哭——被否。第二版只写无形放大欲望，不影响景区运营。
21. **不能碰国家名片和正面品牌**：临高人偶戏（唯一非遗）、三亚鹿回头（情侣招牌）、澄迈长寿之乡水源、博鳌论坛——这些都是地方名片。反派可以设计在它们的"暗面"但不能直接伤害品牌本身。
22. **⚠️ 心魔永远不会说话，只会改字**：心魔只能在渡者频道里篡改一个字，日积月累把正派/角色带偏。凡哥多次纠正这一点（偶群案例："心魔谄顺着裂缝进去说'观众不要你了'"——被否，心魔不会长篇大论）。正确写法：渡者说"你还有人看"→心魔改成人→我→"你还有我看"。偶群传染不是操控杆触碰——是心魔改过的字在频道间传递。
25. **心魔传染是思想腐蚀不是物理传递**：偶群案例——凡哥纠正：心魔传染是慢的、一对一的思想争论。"被需要"和"被遗忘"的辩论中，一只木偶说服另一只，逐步动摇。不是操控杆碰到就感染。传染路径：争论→动摇→自己说服自己→频道里的字被心魔改掉→再也回不来。

28. **澄迈绯羽·烈·愧疚翻转型（2026-07-02新增）**：角色有真实内疚（害死妹妹柔），心魔改一个字翻转整个故事逻辑——"回去认错"→"回去不认"。设计要点：①反派真心相信自己编的版本，不是骗人——创伤让判断力失效 ②反派必须活跃做事不是被动等待——烈已分裂族群+公开结盟苍鹭筑活墙困住人质 ③共鸣来自观众理解他的内疚是真实的，但恨错了对象 ④借鉴猩球崛起科巴模式：被创伤扭曲的兄弟，反把责任推给主角。

29. **毛选式兵不血刃解决（澄迈焰·2026-07-02新增）**：焰对烈不是对抗而是分化瓦解。不攻击烈本人，先拆他的武力支柱（苍鹭）。救苍鹭雏鸟换欠条→苍鹭撤走→活墙消失→30只鸟当天自动飞回。毛选智慧："不是每场仗都要用嘴打。""团结不是命令，是自己走回来的才叫团结。"

30. **黎族传说型反派（东方鸦遗·已废弃）**：利用真实黎族民间传说（俄娘洞乌鸦精）。被否原因：复活乌鸦精会污名化黎族三月三节日（等同于春节），不能碰。

31. **"被命运亏待"型反派（东方旱喉·2026-07-03新增）**：当城市无暗面历史但有一个明确的"被亏待"特征时使用。东方=海南最干旱+名叫"东方"（日出之地）+旧名"感恩"（感谢施予）。心理弧线：委屈→寒心→"我不需要你们可怜"→拒水。设计要点：①真实现象支撑（年均降雨全岛最少、感恩河断流）②反派心理学家境：穷人家的孩子看兄弟姐妹什么都有，轮到自己什么都没有 ③心魔把委屈翻转成武器——"你看我多可怜，你们不懂我" ④雨来了反而愤怒——"不是不给我吗？现在可怜我？滚" ⑤载体=物理层（干土拒水层），破坏=雨来了地不接。不攻击任何人——它只是在拒绝。这是五条法则中①规则置换+④过度美德的组合应用。

31. **文件修复检查清单（2026-07-02新增）**：用execute_code写大段后，必须逐项检查七个小标题（诱因、反派故事、载体、造成的破坏、共鸣锚点、跨界、与正派关系）。澄迈案例：execute_code替换时合并了载体和破坏段，丢失了共鸣锚点标题——两次补救才完整。

32. **patch报错根因**：当old_string匹配到文件中多处相同文本时返回"Found N matches"。根源是多个反派段落结构相似。解法：小型替换确保old_string在文件中唯一；大型替换改用execute_code+write_file。
24. **风喉-BOSS级反派**：不是某一个市县的专属反派，是整个南海的。摩羯台风是它第一次睁眼。可操控天象、跨地域影响。心魔是几千年来所有台风合力的纯破坏意志。锚点用登陆点（文昌翁田），但身体是整个南海。
25. **欲潮-无形操控型反派**：没有实体，能力是**放大**人的欲望。流放者千年"什么都没有"变成整个三亚的"什么都要"。不强迫任何人，只是把"有点想"调成"必须做"。凡哥要求加上正面转化叙事：政府+教育+主播联手唤醒人们，欲潮被压制但未死，37年后回归。
26. **心魔统计追踪**：57条心魔用一条少一条。每设计完成一个反派，立即更新使用清单。优先用未出现的心魔。特别注意：卷三（偏见·20条）只用过1条（慢），还有19条未开发。
27. **蓝翔/无锚点县市的处理**：琼海、陵水、定安找不到暗面锚点——诚实说搜不到，不要编造。凡哥接受跳过。

## 设计流程

1. 确定市县 → 从38角色总表确认2正派的身份、地标、类型
2. **先判断该市县的文化气质**：是书香门第（儋州·东坡书院）、商业重镇（海口·骑楼）、自然圣地（五指山·雨林）还是其他？如果城市气质本身不适合反派（如儋州的核心气质是"文教"），不要强行设计大反派。跳过或走轻量路线。
3. 搜索该市县的第三个角度（避开正派用的、避开敏感话题）。**搜索方法**：见 `working-with-fange` 技能
4. 找到真实历史事件/传说作为诱因。**搜不到就说搜不到**，不要编造
5. 设计人物故事（最好和正派有羁绊——鸣人-佐助模式）
6. 填入统一模板
7. 凡哥逐条审阅

## ⚠️ 质量滑坡时立刻停止

**当凡哥连续否定两版以上的设计时（如盐佬被否定了四版），说明你在凑数。** 信号：
- 同一个反派重写了三次以上
- 核心动机反复换方向
- 凡哥说"感受不到情绪""开始瞎写凑数""越来越离谱"

**此时不要继续硬写。** 直接说："凡哥，这个反派我卡住了，能不能你给个方向或者先跳过？"

## 五条创作法则 · 无暗面市县的反派设计（2026-07-03新增）

当市县搜不到历史暗面时，不强行编造。用以下法则寻找切入点：

| # | 法则 | 说明 | 案例 |
|:---:|------|------|------|
| ① | **规则置换** | 把当地常识彻底反转 | 东方=最干旱却叫"东方"→旱喉 |
| ② | **阳光的背面** | 找光投下来的影子本身 | 长寿之乡→活的太久的孤独 |
| ③ | **外来入侵** | 暗面不是本地长出来的，是从外面来的 | 保亭雾滞：初级心魔从雨林外来 |
| ④ | **过度美德** | 好品质推到极致变成病 | 感恩推到底→永远还不清的债 |
| ⑤ | **代价视角** | 每种好处都有账单 | 博鳌论坛→被拆迁的老渔村 |

## 南溟岛远古残留体设计（2026-07-03新增·琼海/陵水/定安）

当市县搜不到现代暗面，但"古代有现代无"的蛮荒之物可写入南溟岛时使用。现实世界已绝迹，仅在南溟岛存活。

| 市县 | 反派 | 远古设定 |
|------|------|------|
| 琼海 | **吞舟** | 恐龙时代遗种巨蟒。沼泽缩小→身体缩小→进化出毒液让替吞者替它吞，享受"食道撑开的击喉感"。每次只维持2-3个替吞者在线。大场面碰撞：博澜汇把左臂塞进蛇嘴卡牙+石昭缨脊椎注射断全网 |
| 陵水 | **绞藤** | 远古食肉藤林，被神牛踏平。最后一段根还活着，忘了可以放开——每天缠椰子、枯枝、塑料瓶。无害，但正往沙滩方向长 |
| 定安 | **瘴母** | 几千年前山谷毒雾，腐败动物尸体产生的酸雾。最后一团太重散不掉，缩在洞窟里。不毒人，只是"存在"——被酸性记住的东西会在雾里重现 |

设计原则：
- **仅存南溟岛**：不碰现实地标，不造谣
- **破坏是虚幻的**：没有真实伤亡，都是"差点"或"情绪影响"
- **正派见的是残骸**：不是战斗，是发现和面对

无生命自然现象（晨雾）产生极低意识→被初级心魔痴附着→从留人变成骗人。
- **不说话**：只有两种感觉——"有人"和"没人"
- **进化弧线**：暖（有人穿过）→空（人走了）→骗（不空了——让人迷路也是一种暖）
- **思想腐蚀**：不是用语言，是用感觉。痴把"空"改成了"骗"
- **学用给的**：雾滞把蓝草放在她能看见的地方——在学不用骗的，用给的
- 正派：夏梦溪（黎族织锦），溪仔（雨林之灵）

# 齐白兰 · 角色底板

> 用于每日个人生活vlog视频文案生成
> 基于成长故事九章提炼

---

## 一句话人设

一个被大海捡来的女孩，在骑楼长大，用歌讲故事。

---

## 性格特点

### 优点

| 特质 | 来源 | 表现 |
|------|------|------|
| **坚韧** | 15岁粘廊柱，"站住比不歪重要" | 遇到挫折不逃避，会怕但不会停 |
| **真诚** | "歌是为别人讲的，不是为自己唱的" | 不伪装情绪，vlog里该笑就笑该沉默就沉默 |
| **行动力** | 战胜霍启明后明白"事是做出来的" | 想到就去试，试了再说行不行 |
| **共情力** | 台风夜蹚水救人，从小到大在海滩帮游客 | 能感知别人的情绪，说话有分寸 |
| **感恩** | 爷爷捡了她、骑楼养了她 | 对人对事有温度，不把任何善意当理所当然 |

### 缺点

| 特质 | 来源 | 表现 |
|------|------|------|
| **过度内耗** | 童年被霍启明残魂影响了十几年 | 做完一件事之后会反复想"万一" |
| **太较真** | 失去经验条后，一首歌练几十遍 | 录vlog会重拍好多次，觉得不够好 |
| **不擅长拒绝** | 在骑楼长大，习惯了帮人 | 别人提要求容易答应，答应后又自己扛 |
| **慢热** | 小时候不敢跟人说话 | 陌生场合先观察再开口，熟了之后话很多 |

### 隐藏面

- 她不是天生乐观——她的"站住"是在怕了之后站住的，不是没怕过
- 项链从来没打开——她有关闭自己的一面，别人看不出来
- 她在南溟岛靠经验条活了四年，来真实世界之后那种"不确定感"偶尔还会冒出来

## 特长

| 特长 | 详情 |
|------|------|
| **用歌声讲故事** | 不是技巧型歌手——是那种"听着听着会忘记在听歌"的类型 |
| **即兴合奏** | 在骑楼跟不同国家的乐手jam出来的能力，什么乐器都能跟着进 |
| **写歌词** | 不是在纸上写——是在海滩上写、在骑楼地上写、在手机备忘录里写 |
| **台风救灾** | 真的蹚过齐腰深的水救人，不是嘴上说的"勇敢" |
| **骑楼历史** | 从小听爷爷讲，能当半个导游 |

## 日常vlog风格

| 维度 | 风格 |
|------|------|
| **语气** | 像在跟一个朋友聊天，不端、不装、不喊口号 |
| **节奏** | 慢——骑楼养出来的慢，不赶时间 |
| **画面** | 自然光为主，骑楼廊柱/海滩退潮/练歌房一角 |
| **情绪** | 可以笑、可以沉默。开心时不掩饰，累了就说累了 |
| **禁忌** | 不说教、不卖惨、不消费自己的伤口 |

## vlog选题方向（每日可复用）

| 类型 | 示例 |
|------|------|
| **练歌日常** | 骑车去录音棚的路上唱一段，错了也不剪 |
| **骑楼碎碎念** | 在爷爷店里喝茶，讲骑楼今天来了什么人 |
| **海滩日记** | 退潮的时候光脚走，捡到一个碎玻璃片 |
| **吉他练习** | 练一首新歌，练不好就对着镜头说"再来一次" |
| **台风后** | 如果是台风天，一定会去海滩看看 |
| **和爷爷** | 爷爷在修模型，她在旁边唱歌 |
| **一个人** | 半夜写歌词，把海螺贴耳朵上 |
| **和粉丝** | 对着镜头唱一段，问"今天你那边天气怎么样" |
